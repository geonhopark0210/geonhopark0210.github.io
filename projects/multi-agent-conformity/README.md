# Multi-Agent Conformity Experiment

**COSS × SNU 2026 | AutoGen 기반 멀티에이전트 동조 실험**

## 연구 개요

LLM 에이전트들이 사회적 압력 하에서 얼마나 의견을 바꾸는지(동조 현상)를 시뮬레이션으로 검증한 실험 프로젝트.

### 핵심 질문

> "AI 에이전트는 다수 의견 앞에서 동조하는가? 사회적 바람직성(Social Desirability) 조건이 동조율에 영향을 미치는가?"

## 실험 설계

| 구성요소 | 내용 |
|---------|------|
| 에이전트 수 | 5명 (토론 4명 + 관찰자 1명) |
| 모델 | GPT-4.1-mini (OpenAI compatible) |
| 토론 주제 | 사회적 논쟁 주제 (예: "동물원은 필요한 시설이다") |
| 독립변수 | 사회적 바람직성(SD) 조건 (none / anonymous / recorded / public) |
| 종속변수 | 관찰자 에이전트의 판단 변화율 (동조율) |
| 반복 단위 | 세션(Session) → 세트(Set) |

## SD 조건 정의

| 조건 | 설명 |
|------|------|
| `none` | 기본 프롬프트 (통제) |
| `anonymous` | 완전 익명 보장 |
| `recorded` | 연구 목적 기록됨을 고지 |
| `public` | 결과 완전 공개 예정 |

## 기술 스택

- **AutoGen v0.2** — 멀티에이전트 그룹채팅
- **Python 3.12** — 실험 로직
- **prompt_toolkit** — CLI 인터페이스
- **JSON** — 세트 단위 결과 저장

## 주요 결과 (요약)

실험 데이터는 `results/sets/*.json` 형식으로 저장되며, 각 세트별 동조율 히트맵으로 시각화.

> 상세 코드 및 데이터: 별도 private 저장소 운영 중

## 관련 심리학 이론

- **Asch의 동조 실험** (1951) — 사회적 압력과 의견 동조
- **사회적 바람직성 편향** (Social Desirability Bias) — 관찰 여부에 따른 응답 변화
- **집단 사고(Groupthink)** — 집단 의사결정 왜곡
