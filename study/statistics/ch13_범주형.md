### 3.1 범주형 자료 (Categorical Data)

#### 직관부터 시작

> **질문**: "CBT를 받은 집단에서 PHQ-9 점수가 낮아졌다 — 이것을 어떻게 측정했는가?"

지금까지는 PHQ-9 *점수*라는 연속형 숫자를 비교했다. 그런데 임상 연구에서는 종종 이렇게 결과를 측정한다:

- **회복했는가? / 못 했는가?** (예/아니오)
- **진단이 유지되는가? / 관해(remission)되었는가?**
- **치료 반응군(responder) / 비반응군(non-responder)**

이런 **범주(category)** 로 분류된 자료를 범주형 자료라 한다.
숫자가 아니라 *집단 소속*이 결과다.

#### 범주형 자료의 종류

| 종류 | 설명 | 임상 예시 |
|------|------|-----------|
| **명목 척도 (Nominal)** | 순서 없는 범주 | 치료 조건(CBT/약물/통제), 성별 |
| **순서 척도 (Ordinal)** | 순서는 있지만 간격 불균등 | 증상 심각도(없음/경증/중등/중증) |
| **이분형 (Dichotomous)** | 명목 척도 중 2개 범주 | 회복 여부(예/아니오), 진단(있음/없음) |

> **핵심 납득 포인트**: 범주형 자료는 **빈도(count)와 비율(proportion)** 로 요약한다.
> "평균"이 아니다. "100명 중 72명이 회복" 처럼 센다.
> 분석 도구가 t-검정이나 ANOVA가 아닌 **χ²(카이제곱) 검정**으로 바뀌는 이유다.

#### 분할표 (Contingency Table)

두 범주형 변수를 동시에 정리하는 표다.

**예시: CBT 집단 vs. 대기자 통제 집단, 회복 여부**

```
              회복(○)   미회복(✕)   행 합계
CBT 집단        43         17          60
대기자 집단      28         32          60
─────────────────────────────────────────
열 합계          71         49         120
```

- **셀(cell)**: 각 조합의 빈도 (예: CBT이면서 회복한 사람 = 43명)
- **행 합계(row marginal)**: 각 치료 집단의 전체 수
- **열 합계(column marginal)**: 회복/미회복 전체 수
- **전체합(grand total)**: N = 120

### 3.2 χ² 적합도 검정 (Chi-Square Goodness-of-Fit Test)

#### 직관부터 시작

> **질문**: "우리 병원에서 PHQ-9 기반으로 분류한 환자 100명의 우울 범주 분포가, 전국 역학 자료와 일치하는가?"

전국 역학 자료는 "우울 없음 50% / 경증 30% / 중등도 이상 20%"라고 한다.
우리 병원 100명은 "우울 없음 40명 / 경증 40명 / 중등도 이상 20명"이 나왔다.

이 차이가 **우연히 발생한 것인가, 아니면 진짜로 다른 것인가?**

이것이 적합도 검정이다: **관측된 분포가 기대(이론) 분포와 일치하는지** 검증한다.

#### 가설 구조

```
H₀: 세 범주의 관측 비율이 기대 비율과 같다
     (전국 기준 = 50% / 30% / 20%)
H₁: 적어도 한 범주의 비율이 기대 비율과 다르다
```

#### 기대빈도 계산

기대빈도(Expected frequency) = 전체 n × 기대 비율

| 범주 | 관측빈도 Oᵢ | 기대비율 | 기대빈도 Eᵢ |
|------|------------|----------|------------|
| 우울 없음 | 40 | .50 | 100 × .50 = **50** |
| 경증 | 40 | .30 | 100 × .30 = **30** |
| 중등도 이상 | 20 | .20 | 100 × .20 = **20** |
| 합계 | 100 | 1.00 | 100 |

#### χ² 통계량 계산

```
χ² = Σ [(Oᵢ − Eᵢ)² / Eᵢ]

  = (40−50)²/50 + (40−30)²/30 + (20−20)²/20
  = 100/50  +  100/30  +  0/20
  = 2.00   +  3.33   +  0.00
  = 5.33

df = k − 1 = 3 − 1 = 2
```

χ²(2) = 5.33의 임계값(α = .05) = 5.991
→ 5.33 < 5.991 이므로 **p > .05, H₀ 채택**

> **핵심 납득 포인트**: χ² 통계량은 "관측빈도와 기대빈도의 차이가 전체적으로 얼마나 큰가?"를 하나의 숫자로 요약한다.
> 차이가 클수록 χ²이 커지고, H₀를 기각할 확률(= 유의할 확률)이 높아진다.

### 3.3 χ² 독립성 검정 (Chi-Square Test of Independence)

#### 직관부터 시작

> **질문**: "치료 조건(CBT vs. 대기자)과 회복 여부(예/아니오) — 이 두 변수가 서로 관련이 있는가?"

만약 **독립**이라면: 치료 조건에 관계없이 회복률이 같아야 한다.
만약 **관련이 있다면**: CBT 집단의 회복률이 대기자 집단과 달라야 한다.

독립성 검정은 **두 범주형 변수 사이의 연관성**이 있는지 검증한다.

#### 가설 구조

```
H₀: 치료 조건과 회복 여부는 독립이다 (관련이 없다)
H₁: 치료 조건과 회복 여부는 독립이 아니다 (관련이 있다)
```

#### 기대빈도 계산

두 변수가 독립이라면, 기대빈도는 **확률의 독립 법칙**으로 계산한다:

$$E_{ij} = \frac{(\text{행 합계}_i) \times (\text{열 합계}_j)}{N}$$

```
기대빈도 공식:
Eᵢⱼ = (행 합계 × 열 합계) / 전체합

예시: E(CBT, 회복) = (60 × 71) / 120 = 4260 / 120 = 35.5
```

**분할표 + 기대빈도:**

```
              회복(○)          미회복(✕)       행 합계
CBT 집단    43  (E=35.5)     17  (E=24.5)      60
대기자 집단  28  (E=35.5)     32  (E=24.5)      60
─────────────────────────────────────────────────
열 합계          71               49              120
```

#### χ² 통계량 계산 (3.4 손계산 예시로 이어짐)

```
df = (r − 1)(c − 1) = (2 − 1)(2 − 1) = 1
```

> **핵심 납득 포인트**: 왜 Eᵢⱼ = (행합 × 열합) / N인가?
>
> 두 변수가 독립이라면, P(CBT이고 회복) = P(CBT) × P(회복)이어야 한다.
> P(CBT) = 60/120 = .50, P(회복) = 71/120 = .5917
> P(CBT이고 회복) = .50 × .5917 = .2958
> 기대빈도 = N × P = 120 × .2958 = 35.5 ← 공식과 일치!

### 3.4 효과크기: φ와 Cramér's V

#### 왜 효과크기가 필요한가?

χ²은 표본 크기 n에 비례한다. 똑같이 "CBT 회복률 72%, 대기자 47%" 결과여도:
- n = 20이면 χ² ≈ 1.60, p = .21 → 유의하지 않음
- n = 200이면 χ² ≈ 16.0, p < .001 → 매우 유의함

**χ² 자체는 효과의 강도를 알려주지 않는다.**
효과크기 지표가 필요한 이유다.

#### φ (파이계수): 2×2 분할표 전용

```
φ = √(χ² / n)
```

| Cohen 기준 | φ 값 |
|-----------|------|
| 작은 효과 | .10 |
| 중간 효과 | .30 |
| 큰 효과 | .50 |

#### Cramér's V: 2×2보다 큰 분할표

```
V = √( χ² / (n × min(r−1, c−1)) )

  min(r−1, c−1): 행수−1과 열수−1 중 작은 값

  예: 2×3 분할표 → min(2−1, 3−1) = min(1, 2) = 1
  예: 3×3 분할표 → min(3−1, 3−1) = min(2, 2) = 2
```

- 2×2 분할표에서는 Cramér's V = φ
- Cohen 기준: **작은 .10 / 중간 .30 / 큰 .50** (φ와 동일)

> **핵심 납득 포인트**: 논문에서 "V = .27, indicating a moderate effect"가 나오면,
> 두 변수의 관련성이 *있긴 한데 강하지는 않다*는 뜻이다.
> p값이 아무리 작아도, V가 .10 미만이면 관련이 거의 없는 것에 가깝다.

### 3.5 독립성 검정 vs. 동질성 검정

이 두 검정은 **공식과 절차가 동일하다.** 차이는 연구 설계(표본 추출 방식)에 있다.

| | 독립성 검정 (Test of Independence) | 동질성 검정 (Test of Homogeneity) |
|--|-----------------------------------|----------------------------------|
| **표본 추출** | 단일 표본에서 두 변수 측정 | 두 집단을 독립적으로 표집 |
| **질문** | "두 변수가 관련이 있는가?" | "두 집단에서 분포가 같은가?" |
| **예시** | 100명에서 성별과 우울 진단 관련성 | CBT 50명과 대기자 50명에서 회복 비율이 같은가? |
| **공식** | χ² = Σ[(O−E)²/E] | 동일 |

> **핵심 납득 포인트**: 심리학 RCT(무작위 대조 실험)에서 CBT vs. 대기자를 비교하면
> 사실상 **동질성 검정**이 더 정확한 표현이다. 두 집단을 *따로* 모집·배정했기 때문이다.
> 그러나 소프트웨어 출력과 해석은 독립성 검정과 동일하므로, 논문에서는 "test of independence"로
> 표기되는 경우도 많다. 어느 쪽으로 불러도 계산 결과는 같다.

---

### 3.6 검정의 가정 및 주의사항

χ² 검정이 유효하려면 다음 조건이 필요하다:

**1. 기대빈도 규칙**
- 모든 셀의 기대빈도 ≥ 5가 권장된다
- 기대빈도 < 5인 셀이 있으면 → **Fisher's exact test** 사용

**2. 관측치 독립성**
- 한 참가자가 하나의 셀에만 포함되어야 한다
- 반복 측정 자료(동일 참가자가 여러 번 측정된 경우)에는 적용 불가

**3. χ² 검정의 한계**
- χ² 검정은 **관련이 있다/없다**만 알려줌
- **방향(어느 집단의 비율이 높은가)** 은 분할표 비율을 직접 확인해야 함
- 기여 정도 확인: 표준화 잔차 = (O−E)/√E → |표준화 잔차| > 2이면 그 셀이 유의한 기여

> **핵심 납득 포인트**: Fisher's exact test는 가능한 모든 분할표 배열의 확률을 직접 계산한다.
> 기대빈도가 작아 χ² 근사가 부정확할 때의 대안이다. n이 작은 pilot 연구나
> 희귀 진단 연구에서 자주 등장한다.

## 4. 수식 정리

### 기호 목록

```
Oᵢ   = 관측빈도 (observed frequency)     — 실제 센 숫자
Eᵢ   = 기대빈도 (expected frequency)     — 귀무가설 하에서 기대되는 숫자
k    = 범주 수 (적합도 검정)
r    = 행 수 (row)
c    = 열 수 (column)
n    = 전체 표본 크기
χ²   = 카이제곱 통계량
df   = 자유도
φ    = 파이계수 (2×2 분할표 효과크기)
V    = Cramér's V (r×c 분할표 효과크기)
```

### 핵심 수식 4개

```
(1) χ² 적합도 검정:
    χ² = Σ [(Oᵢ − Eᵢ)² / Eᵢ]
    df = k − 1

(2) χ² 독립성/동질성 검정:
    χ² = Σ [(Oᵢⱼ − Eᵢⱼ)² / Eᵢⱼ]
    df = (r − 1)(c − 1)

(3) 기대빈도 (독립성 검정):
    Eᵢⱼ = (행 합계 × 열 합계) / N

(4) 효과크기:
    φ = √(χ² / n)               ← 2×2 분할표
    V = √(χ² / (n × min(r−1, c−1))) ← r×c 분할표
```

---

### 손계산 예시: 2×2 분할표 전 과정

**연구 상황**: CBT 집단(n=50)과 대기자 통제 집단(n=50)에서 PHQ-9 기준 우울 회복 여부를 조사했다. (N = 100)

**Step 1: 분할표 작성**

```
              회복(○)   미회복(✕)   행 합계
CBT 집단        35         15          50
대기자 집단      20         30          50
─────────────────────────────────────────
열 합계          55         45         100
```

**Step 2: 기대빈도 계산** (Eᵢⱼ = 행합 × 열합 / N)

```
E(CBT, 회복)     = 50 × 55 / 100 = 2750 / 100 = 27.5
E(CBT, 미회복)   = 50 × 45 / 100 = 2250 / 100 = 22.5
E(대기자, 회복)  = 50 × 55 / 100 = 2750 / 100 = 27.5
E(대기자, 미회복)= 50 × 45 / 100 = 2250 / 100 = 22.5

확인: 모든 기대빈도 ≥ 5 ✓ → χ² 검정 적용 가능
```

**Step 3: χ² 계산**

```
χ² = (35−27.5)²/27.5 + (15−22.5)²/22.5 + (20−27.5)²/27.5 + (30−22.5)²/22.5

   = (7.5)²/27.5   + (−7.5)²/22.5 + (−7.5)²/27.5  + (7.5)²/22.5
   = 56.25/27.5    + 56.25/22.5   + 56.25/27.5    + 56.25/22.5
   = 2.045         + 2.500        + 2.045          + 2.500
   = 9.09
```

**Step 4: 자유도 및 유의성 판단**

```
df = (r−1)(c−1) = (2−1)(2−1) = 1

임계값 (α = .05, df = 1) = 3.841
임계값 (α = .01, df = 1) = 6.635

9.09 > 6.635 → p < .01  →  H₀ 기각
```

**Step 5: 효과크기 계산**

```
φ = √(χ² / n) = √(9.09 / 100) = √0.0909 = .302 ≈ .30

Cohen 기준: .30 = 중간 효과(moderate effect)
```

**Step 6: APA 형식 보고**

```
χ²(1, N = 100) = 9.09, p = .003, φ = .30
```

> **해석**: CBT 집단의 회복률(70%)이 대기자 집단(40%)보다 유의하게 높았으며, 중간 크기의 효과를 보였다.

## 5. 심리학 연구 맥락 연결

### 시나리오 A: 적합도 검정 — PTSD 심각도 분포 비교

**상황**: 재난 피해자 지원 센터에서 PCL-5를 사용해 PTSD 심각도를 분류했다. 전국 역학 조사에서는 "증상 없음 50% / 경증 30% / 중등 이상 20%"로 분포한다고 한다. 우리 센터의 내담자 200명을 분류해보니: 증상 없음 60명 / 경증 80명 / 중등 이상 60명이었다.

**분석:**
- H₀: 우리 센터 내담자 분포가 전국 역학 기준과 일치한다
- 기대빈도: 없음 = 200×.50 = 100, 경증 = 200×.30 = 60, 중등 이상 = 200×.20 = 40

```
χ² = (60−100)²/100 + (80−60)²/60 + (60−40)²/40
   = 1600/100 + 400/60 + 400/40
   = 16.00 + 6.67 + 10.00
   = 32.67

df = 3−1 = 2
임계값 (α = .001, df = 2) = 13.82
32.67 >> 13.82 → p < .001
```

**결론**: 우리 센터 내담자의 PTSD 분포는 전국 역학 자료와 유의하게 다르다, χ²(2, N = 200) = 32.67, p < .001. 경증 및 중등도 이상 비율이 전국 기준보다 높다.

---

### 시나리오 B: 독립성 검정 — CBT vs. 대기자의 우울 회복 비율

**상황**: 우울장애 RCT 연구에서 CBT 집단(n = 60)과 대기자 통제 집단(n = 60)을 12주 치료 후 PHQ-9 점수로 회복 여부(PHQ-9 < 10 = 회복)를 분류했다.

```
              회복    미회복   합계
CBT 집단       43       17      60    → 회복률 71.7%
대기자 집단     28       32      60    → 회복률 46.7%
───────────────────────────────────
합계           71       49     120
```

**기대빈도**: E(CBT, 회복) = 60×71/120 = 35.5, E(CBT, 미회복) = 60×49/120 = 24.5 등

**결과**: χ²(1, N = 120) = 9.63, p = .002, φ = .28

> **해석**: 치료 조건(CBT vs. 대기자)과 회복 여부는 유의한 관련이 있었다. CBT 집단의 회복률(71.7%)이 대기자 집단(46.7%)보다 통계적으로 유의하게 높았으며, 효과크기는 중간 수준이었다(φ = .28).

> **주의**: 이 연구는 RCT이므로 인과 추론이 가능하다. 그러나 χ² 검정 자체가 인과를 "증명"하는 것이 아니라, 무작위 배정이라는 실험 설계가 인과 추론의 근거다.

## 6. 논문 스니펫 읽기 실습

아래 가상의 논문 Results 절 일부를 읽고 질문에 답하라.

---

*"A chi-square test of independence was conducted to examine the association between treatment condition (CBT vs. waitlist control) and treatment response (responder vs. non-responder). The analysis revealed a significant association, χ²(1, N = 120) = 9.63, p = .002, φ = .28. A significantly higher proportion of participants in the CBT group were classified as responders (72%) compared to the waitlist group (47%). To further examine individual cell contributions, standardized residuals were computed; the CBT/responder cell showed the largest deviation (SR = 2.81), indicating that this cell was the primary driver of the significant association."*

---

**연습 질문:**

1. `χ²(1, N = 120) = 9.63`에서 각 숫자(1, 120, 9.63)가 의미하는 것은 무엇인가?
2. `φ = .28`의 의미는 무엇이며, Cohen 기준으로 효과크기는 어느 수준인가?
3. "significant association"은 "CBT가 회복에 인과적 영향을 미친다"는 주장을 지지하는가?
4. 만약 한 셀의 기대빈도가 4.2라면, 이 분석에서 어떤 문제가 생기고 어떻게 해야 하는가?
5. 이 연구처럼 CBT와 대기자 집단을 따로 배정해 비교하면, 독립성 검정과 동질성 검정 중 어느 것이 설계상 더 정확한 표현인가?

---

**모범 답안:**

1. **각 숫자 해석**:
   - `1` = 자유도(df). df = (2−1)(2−1) = 1이므로 2×2 분할표임을 알 수 있음
   - `N = 120` = 전체 표본 크기
   - `9.63` = χ² 검정통계량. 관측빈도와 기대빈도의 전체 차이를 요약한 값

2. **φ = .28 해석**:
   - φ = .28은 치료 조건과 치료 반응 사이 관련성의 크기를 나타냄
   - Cohen 기준(.10 = 작은, .30 = 중간, .50 = 큰): .28은 **중간 효과에 약간 미치지 못하는 수준**
   - 통계적으로는 유의하지만(p = .002), 효과가 매우 강하지는 않음을 뜻함

3. **인과 추론 주의**:
   - χ² 검정은 **연관성(association)** 만 확인할 뿐, 인과관계를 증명하지 않음
   - 인과 추론이 가능한지는 **연구 설계**가 결정함 — 이 연구가 RCT(무작위 배정)라면 인과 추론 가능, 관찰 연구라면 불가
   - "a significant association"이라는 표현 자체도 인과를 주장하지 않음에 주목

4. **기대빈도 < 5 문제**:
   - χ² 통계량은 정규분포 근사에 기반하므로, 기대빈도가 너무 작으면 p값이 부정확해짐
   - 해결책: **Fisher's exact test** 사용 — 분할표의 모든 가능한 배열을 정확히 계산하므로 소표본에서도 정확

5. **독립성 vs. 동질성 검정**:
   - 이 연구는 CBT 집단과 대기자 집단을 **따로 모집·배정**했으므로 → **동질성 검정**이 설계상 더 정확한 표현
   - 그러나 공식, 절차, 소프트웨어 출력이 완전히 동일하므로, 논문에서 "test of independence"로 보고해도 틀리지 않음

## 7. 오개념 경고

> **⚠️ 오개념 1**: "χ² = 9.63이 크다 → 두 변수의 관계가 강하다"
>
> → 틀렸다. χ²은 **표본 크기 n에 비례**한다. 같은 비율 차이라도 n이 크면 χ²이 크게 나온다.
> 예: CBT 72% vs. 대기자 47% — n = 20이면 χ² ≈ 1.6(유의하지 않음), n = 200이면 χ² ≈ 16(유의함).
> 효과의 **강도**는 반드시 φ나 Cramér's V로 판단해야 한다.

> **⚠️ 오개념 2**: "p < .05이면 두 변수의 관계가 강하다"
>
> → 틀렸다. p값은 효과의 크기가 아니라 **표본 크기와 효과 크기의 복합 산물**이다.
> n이 충분히 크면, φ = .05 수준의 매우 약한 관련도 p < .001로 유의해진다.
> p값이 아무리 작아도, φ나 V가 .10 미만이면 실질적 의의가 거의 없다.

> **⚠️ 오개념 3**: "χ² 검정으로 인과관계를 알 수 있다"
>
> → 틀렸다. χ² 검정은 두 변수 사이에 **연관성(association)이 있는지**만 말한다.
> 인과관계는 **연구 설계**의 문제다 — 무작위 배정(RCT)이 있어야 인과 추론이 가능하다.
> "treatment condition과 recovery가 유의하게 관련되었다"는 문장이 곧 "CBT가 회복을 유발했다"를 뜻하지 않는다.

> **⚠️ 오개념 4**: "분할표의 비율이 다르면 항상 χ²이 유의하다"
>
> → 틀렸다. 비율 차이가 같아도 n에 따라 결과가 달라진다.
> 반대로: 비율 차이가 매우 커도 n이 너무 작으면 유의하지 않을 수 있다 (검정력 부족).
> 비율과 χ² 유의성은 별개의 문제다.

> **⚠️ 오개념 5**: "Fisher's exact test는 χ² 대신 항상 쓰는 것이 좋다"
>
> → 틀렸다. Fisher's exact test는 **기대빈도 < 5인 소표본 상황** 전용이다.
> 기대빈도 ≥ 5이고 n이 큰 상황에서는 χ²이 Fisher보다 **더 효율적이고 일반화가 잘 된다**.
> Fisher's exact test는 계산 복잡도가 높아 큰 분할표에는 적합하지 않다.

## 부록: 비모수 검정 개관 (Non-parametric Tests)

> **CLAUDE.md §5 보완 주제**: "비모수 검정 개관 — 정규성 가정 위반 시 대안, 임상 연구에서 빈번"

---

### 왜 비모수 검정이 필요한가?

Ch.9~11에서 배운 t-검정과 ANOVA는 중요한 가정을 전제로 한다:

- **정규성 가정**: 모집단이 정규분포를 따른다
- **등분산 가정**: 비교하는 집단들의 분산이 같다

이 가정이 위반되는 상황:

| 상황 | 예시 |
|------|------|
| 소표본 (n < 30) | 파일럿 연구, 희귀 진단 집단 |
| 분포가 심하게 비대칭 | 반응시간, 수입, 입원 기간 |
| 이상값(outlier)이 다수 | 임상 데이터 특유의 극단값 |
| 순서 척도 데이터 | 5점 리커트 척도, 심각도 등급 |

---

### 주요 비모수 검정 대응표

| 모수 검정 (parametric) | 비모수 대안 (non-parametric) | 비교 대상 |
|----------------------|------------------------------|-----------|
| 단일표본 t-검정 | Wilcoxon 부호순위 검정 (Wilcoxon signed-rank test) | 중앙값 vs. 기준값 |
| 독립표본 t-검정 | Mann-Whitney U 검정 | 두 독립 집단 비교 |
| 대응표본 t-검정 | Wilcoxon 부호순위 검정 | 짝지어진 두 조건 비교 |
| 일원분산분석 (ANOVA) | Kruskal-Wallis 검정 | 세 집단 이상 비교 |
| 반복측정 ANOVA | Friedman 검정 | 반복측정 세 조건 이상 |
| Pearson 상관 | Spearman 순위상관 (ρ), Kendall τ | 두 변수의 관련성 |

---

### 작동 원리: 순위(Rank) 기반 분석

비모수 검정은 원점수 대신 **순위(rank)** 를 사용한다.

```
원점수:  [3,  7, 15, 22, 45]
순위:    [1,  2,  3,  4,  5]

비모수 검정의 장점:
  - 이상값에 강함: 45가 4500이 되어도 순위는 5 그대로
  - 분포 가정 불필요: 순위는 어떤 분포도 가능
```

---

### 비모수 검정의 장단점

**장점:**
- 정규성, 등분산 가정이 필요 없음
- 소표본에서도 사용 가능
- 이상값에 강함 (robust)
- 순서 척도 데이터에 적합

**단점:**
- **검정력(statistical power)이 낮다**: 같은 n으로는 모수 검정보다 유의미한 결과 찾기 어려움
- 효과크기 해석이 덜 직관적
- 일부 검정은 다수 집단이나 복잡한 설계에 적용 어려움

> **핵심 납득 포인트**: 비모수 검정은 "만능 대안"이 아니라 **가정이 위반될 때의 안전망**이다.
> 정규성 가정이 합리적으로 충족된다면 (특히 n ≥ 30인 경우, 중심극한정리에 의해),
> 모수 검정이 더 검정력이 높아 선호된다.
> 논문 Methods에서 "Owing to non-normality, Mann-Whitney U tests were used"와 같은
> 표현을 보면, 분포 가정 위반에 대한 적절한 대응임을 알 수 있다.

---

- *"Mann-Whitney U tests were used to compare the two groups on non-normally distributed variables"*
- *"Spearman's rank-order correlation was computed between symptom severity and treatment duration"*
