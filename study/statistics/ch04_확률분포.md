### 3.1 확률변수 (Random Variable)

#### 직관부터 시작

> **질문**: "CBT 치료를 받는 내담자 한 명을 무작위로 선택했을 때, 그 사람의 PHQ-9 점수는 얼마일까?"

답을 모른다. 0에서 27 사이 어딘가겠지만 정확히 예측할 수 없다. 이처럼 **결과를 미리 알 수 없지만, 가능한 범위는 알고 있는** 변수 — 이것을 **확률변수 (random variable)**라 한다.

#### 핵심 용어 정의

| 개념 | 정의 | 기호 | 예시 |
|------|------|------|------|
| **확률변수 (random variable)** | 실험 결과를 실수값으로 대응시키는 함수 | X, Y | X = "선택된 내담자의 PHQ-9 점수" |
| **이산확률변수 (discrete r.v.)** | 가능한 값이 셀 수 있는(countable) 경우 | X | X = "치료 중 탈락 세션 수" (0, 1, 2, ...) |
| **연속확률변수 (continuous r.v.)** | 가능한 값이 구간 위의 실수값 전체인 경우 | X | X = "BDI-II 점수" (이론상 연속) |

#### 이산 vs. 연속 구분

```
[이산확률변수 예시]
X = PHQ-9 심각도 카테고리 코드
  가능한 값: 0 (없음), 1 (경미), 2 (중등), 3 (심각)
  ───────○───────○───────○───────○───────
         0       1       2       3

[연속확률변수 예시]
Y = BDI-II 점수 (0~63점, 연속으로 취급)
  ─────────────────────────────────────
  0                                   63
  (이론적으로 어느 값도 가능)
```

> **임상 주의점**: 심리 척도 점수는 사실 이산(정수)이지만, 통계 분석에서는 보통 **연속확률변수로 취급**한다. 값의 범위가 충분히 넓으면(예: 0~63점) 연속 근사가 실용적이다. 논문에서 "BDI-II scores were treated as continuous"라는 표현이 이 관행을 반영한다.

> **핵심 납득 포인트**: 확률변수는 "아직 관찰하기 전의 X"다. 표본에서 관찰한 값(x₁, x₂, ..., xₙ)은 확률변수의 실현값(realization)이다. 모집단에서의 이론적 패턴이 확률변수이고, 표본 데이터는 그 패턴에서 뽑힌 관측치다.

### 3.2 확률분포 (Probability Distribution)

#### 3.2.1 확률질량함수 (Probability Mass Function, PMF) — 이산형

**직관**: "이 확률변수 X가 각 값을 가질 확률은 얼마인가?"를 표로 또는 함수로 나타낸 것.

**형식**: P(X = x) = 각 가능한 값 x에 대한 확률

**PMF의 조건** (필수):
1. 0 ≤ P(X = x) ≤ 1 (각 확률은 0 이상 1 이하)
2. Σ P(X = x) = 1 (모든 확률의 합 = 1)

**예시**: X = "CBT 치료 중 세션 탈락 횟수"

| x | P(X = x) |
|---|----------|
| 0 | .60 |
| 1 | .25 |
| 2 | .10 |
| 3 | .05 |
| **합계** | **1.00** |

```
[PMF 막대 그래프]
P(X=x)
 .60 │ ██
     │ ██
 .25 │ ██ ██
     │ ██ ██
 .10 │ ██ ██ ██
 .05 │ ██ ██ ██ ██
     └──────────────
       0  1  2  3    x (탈락 횟수)
```

해석: "CBT 내담자의 60%는 탈락 없이 치료를 완주하고, 25%는 1번 빠지며, ..."

> **핵심 납득 포인트**: PMF는 히스토그램(표본)의 이론적 버전이다. 표본 히스토그램은 "실제로 뽑힌 n명의 데이터"를 보여주지만, PMF는 "모집단 전체의 이론적 패턴"을 나타낸다. 표본이 커질수록 히스토그램이 PMF에 가까워진다.

---

#### 3.2.2 확률밀도함수 (Probability Density Function, PDF) — 연속형

**직관**: 연속확률변수에서는 특정 점(예: X = 15.000)의 확률은 언제나 0이다. 대신 **구간의 확률**만 의미가 있다.

```
P(a ≤ X ≤ b) = f(x) 곡선 아래 a~b 사이의 넓이(면적)

  f(x)
   │      ╭──╮
   │    ╭─╯  ╰─╮
   │  ╭─╯      ╰──╮
   │╭─╯            ╰──
   └────────────────── x
        a    b
        └────┘
          이 면적 = P(a ≤ X ≤ b)
```

**PDF의 조건**:
1. f(x) ≥ 0 (음수 불가)
2. 전체 면적 = 1: ∫f(x)dx = 1

**임상 예시**: BDI-II 점수 분포가 정규분포를 따른다면,
- P(BDI-II ≥ 14) = 중등도 이상 우울 비율 = 곡선 아래 14점 이상의 면적

> **핵심 납득 포인트**: 연속확률변수에서 "P(X = 14) = ?" 라고 묻는 것은 무의미하다 — 답은 항상 0이다. 대신 "P(BDI-II ≥ 14)"처럼 구간을 물어야 한다. 이것이 Ch.6(정규분포)에서 "z표를 이용해 구간 확률을 구하는" 이유다.

### 3.3 기댓값 (Expected Value)

#### 직관부터 시작

> **질문**: "이 치료 프로그램을 무한히 많은 내담자에게 적용한다면, 평균적으로 탈락 횟수는 몇 번이 될까?"

이 "이론적 평균"이 **기댓값 E(X)**이며, 모평균 **μ**와 같다.

```
E(X) = μ = Σ xᵢ × P(X = xᵢ)
           각 값 × 그 값의 확률  (모두 더함)
```

기호 해설:
- E(X) = 기댓값 (expected value). E는 "Expectation(기대)"의 약자
- xᵢ = X가 취할 수 있는 i번째 값
- P(X = xᵢ) = 그 값의 확률 (가중치)

**직관**: "각 값이 얼마나 자주 나오는지(확률)를 가중치로 삼아 가중평균을 낸다."

---

#### 3.3.1 모평균 — 손계산 예시

**데이터**: X = CBT 세션 탈락 횟수, 위 PMF 사용

```
E(X) = 0×P(X=0) + 1×P(X=1) + 2×P(X=2) + 3×P(X=3)
     = 0×.60    + 1×.25    + 2×.10    + 3×.05
     = 0        + .25      + .20      + .15
     = .60

해석: 이론적으로 내담자 1인당 평균 탈락 횟수 = 0.60회
     즉 μ = 0.60 (모평균)
```

**중요한 구분**:

| | 기호 | 정의 | 특징 |
|--|------|------|------|
| **모평균** | μ | E(X) = 이론적 기댓값 | 알 수 없음 (이론값) |
| **표본평균** | x̄ | Σxᵢ / n = 관측된 평균 | 계산 가능 (표본에서) |

> **핵심 납득 포인트**: μ = E(X)는 "무한히 반복했을 때의 장기 평균"이다. 우리가 실제로 계산하는 x̄는 그 μ의 추정치다. 좋은 추정이 되려면 표본이 크고 편향이 없어야 한다 — 이것이 Ch.9에서 "모평균에 대한 추론"을 가능하게 하는 논리다.

---

#### 3.3.2 모분산과 모표준편차 — 손계산 예시

**직관**: "값들이 모평균(기댓값) 주위에 얼마나 퍼져 있는가?"

```
모분산:       σ² = E[(X − μ)²] = Σ (xᵢ − μ)² × P(X = xᵢ)

계산 공식:    σ² = E(X²) − [E(X)]²  ← 이 공식이 계산이 더 편리함

모표준편차:   σ = √σ²
```

**손계산** (탈락 횟수 X, μ = .60):

```
1단계: E(X²) 계산
E(X²) = 0²×.60 + 1²×.25 + 2²×.10 + 3²×.05
      = 0×.60  + 1×.25  + 4×.10  + 9×.05
      = 0      + .25    + .40    + .45
      = 1.10

2단계: σ² 계산
σ² = E(X²) − [E(X)]²
   = 1.10 − (.60)²
   = 1.10 − .36
   = .74

3단계: σ 계산
σ = √.74 ≈ .86

해석: 모평균 μ = .60 주위로 ±0.86 정도 퍼져 있음 (이론적 표준편차)
```

**직접 계산법으로 검증** (정의대로):

```
σ² = Σ(xᵢ − μ)² × P(X = xᵢ)
   = (0−.60)²×.60 + (1−.60)²×.25 + (2−.60)²×.10 + (3−.60)²×.05
   = .36×.60      + .16×.25       + 1.96×.10      + 5.76×.05
   = .216         + .040          + .196          + .288
   = .74  ✓ (두 공식의 결과 일치)
```

### 3.4 합분포와 주변분포 (Joint and Marginal Distributions)

#### 직관부터 시작

> **질문**: "PHQ-9 심각도(X)와 STAI 불안 수준(Y), 이 두 변수를 동시에 고려하면 어떻게 될까?"

두 확률변수를 동시에 다루는 분포가 **합분포(joint distribution)**이다.

#### 합분포 (Joint Distribution)

X = PHQ-9 심각도 (0=정상, 1=경미 이상)
Y = STAI 불안 수준 (0=낮음, 1=높음)

**합확률질량함수** P(X = x, Y = y):

|        | Y = 0 (불안 낮음) | Y = 1 (불안 높음) | **주변 P(X)** |
|--------|-----------------|-----------------|--------------|
| **X = 0 (PHQ-9 정상)** | .30 | .20 | **.50** |
| **X = 1 (PHQ-9 경미+)** | .10 | .40 | **.50** |
| **주변 P(Y)** | **.40** | **.60** | **1.00** |

- 예: P(X=0, Y=1) = .20 = "PHQ-9 정상이면서 불안 높음" 비율

#### 주변분포 (Marginal Distribution)

합분포에서 한 변수의 분포만 뽑아낸 것 — 표의 행 합계 또는 열 합계가 주변분포다.

```
X의 주변분포:
  P(X = 0) = P(X=0, Y=0) + P(X=0, Y=1) = .30 + .20 = .50
  P(X = 1) = P(X=1, Y=0) + P(X=1, Y=1) = .10 + .40 = .50

Y의 주변분포:
  P(Y = 0) = P(X=0, Y=0) + P(X=1, Y=0) = .30 + .10 = .40
  P(Y = 1) = P(X=0, Y=1) + P(X=1, Y=1) = .20 + .40 = .60
```

> **Ch.2·Ch.3 연결**: 분할표(Ch.2 §3.2.2)에서 행·열 합계를 전체 n으로 나누면 주변분포가 된다. 이미 알고 있는 개념이다. 이제 그것을 확률의 언어로 표현한 것이다.

#### 조건부분포와의 관계

Ch.3에서 배운 조건부확률이 여기서도 적용된다:

```
P(Y = 1 | X = 1) = P(X=1, Y=1) / P(X=1)
                 = .40 / .50
                 = .80

해석: PHQ-9가 경미 이상인 사람 중 80%가 불안도 높다
     반면 P(Y=1) = .60 → PHQ-9 심각도를 알면 불안 예측이 크게 달라짐 (종속!)
```

> **핵심 납득 포인트**: 합분포 → 주변분포 → 조건부분포의 흐름이 통계 분석의 기초 구조다. 회귀분석(Ch.12)은 본질적으로 "X가 주어졌을 때 Y의 조건부분포의 평균(조건부 기댓값)"을 모형화하는 것이다.

### 3.5 공분산과 상관계수

#### 직관부터 시작

> **질문**: "PHQ-9 점수가 높을수록 STAI 불안도 높은 경향이 있는가?"

Ch.2에서 피어슨 상관계수 r(표본)을 배웠다. 이제 모집단 버전 **ρ (rho)**를 배운다.

#### 모공분산 (Population Covariance)

```
Cov(X, Y) = σₓᵧ = E[(X − μₓ)(Y − μᵧ)]
                 = E(XY) − μₓ × μᵧ  ← 계산이 편리한 공식
```

**위 합분포 데이터로 손계산**:

```
μₓ = E(X) = 0×.50 + 1×.50 = .50
μᵧ = E(Y) = 0×.40 + 1×.60 = .60

E(XY) = Σ Σ xy × P(X=x, Y=y)
       = 0×0×.30 + 0×1×.20 + 1×0×.10 + 1×1×.40
       = 0 + 0 + 0 + .40
       = .40

Cov(X,Y) = E(XY) − μₓ×μᵧ
          = .40 − .50×.60
          = .40 − .30
          = .10

해석: Cov(X,Y) = .10 > 0 → 양의 공분산
     PHQ-9 심각도가 높은 쪽이 불안도 높은 경향
```

#### 모상관계수 (Population Correlation Coefficient)

```
ρ(X, Y) = Cov(X, Y) / (σₓ × σᵧ)

범위: −1 ≤ ρ ≤ +1
```

공분산의 크기는 단위에 의존하므로, 표준편차로 나눠 단위를 없앤 것이 ρ.

**모분산 계산**:

```
σₓ² = E(X²) − μₓ²
    = (0²×.50 + 1²×.50) − .50²
    = .50 − .25 = .25
σₓ = √.25 = .50

σᵧ² = E(Y²) − μᵧ²
    = (0²×.40 + 1²×.60) − .60²
    = .60 − .36 = .24
σᵧ = √.24 ≈ .490

ρ = Cov(X,Y) / (σₓ × σᵧ)
  = .10 / (.50 × .490)
  = .10 / .245
  ≈ .408

해석: PHQ-9 심각도와 불안 수준 사이의 모상관계수 ρ ≈ .41 (중간 강도의 양의 관계)
```

**표본 r과 모집단 ρ의 관계**:

| | 기호 | 정의 |
|--|------|------|
| 표본 상관계수 | r | 표본에서 계산. Ch.2에서 배운 피어슨 r |
| 모집단 상관계수 | ρ (rho) | 이론적 값. E(XY) 기반. r이 ρ를 추정 |

> **핵심 납득 포인트**: r은 표본에서 계산한 통계량, ρ는 모집단의 이론적 모수다. 논문에서 "r(88) = .58, p < .001"이라고 보고하는 것은 표본 상관계수 r = .58로 모집단 ρ가 0이 아닌지 검정한 결과다.

## 4. 수식 정리

```
=== 기호 약속 ===
X, Y      = 확률변수 (대문자)
x, y      = 확률변수의 실현값 (소문자)
μ = μₓ   = 모평균 = E(X) (모수: 그리스 문자)
σ         = 모표준편차           (모수: 그리스 문자)
σ²        = 모분산               (모수: 그리스 문자)
ρ         = 모상관계수           (모수: 그리스 문자)
x̄         = 표본평균              (통계량: 로마 문자)
s, s²     = 표본표준편차, 표본분산 (통계량: 로마 문자)
r         = 표본 피어슨 상관계수   (통계량: 로마 문자)

=== 수식 목록 ===

① 확률질량함수 (PMF) 조건
   P(X = xᵢ) ≥ 0          ← 각 확률 비음수
   Σ P(X = xᵢ) = 1        ← 모든 확률의 합 = 1

② 기댓값 (모평균)
   μ = E(X) = Σ xᵢ × P(X = xᵢ)
   직관: 확률로 가중한 평균 — "장기 평균값"

③ 모분산 (정의 공식)
   σ² = E[(X − μ)²] = Σ (xᵢ − μ)² × P(X = xᵢ)
   직관: 각 값의 제곱편차를 확률로 가중평균

④ 모분산 (계산 공식, 더 편리)
   σ² = E(X²) − [E(X)]²
      = Σ xᵢ² × P(X = xᵢ) − μ²

⑤ 모표준편차
   σ = √σ²

⑥ 합확률질량함수 조건
   P(X = x, Y = y) ≥ 0
   Σₓ Σᵧ P(X = x, Y = y) = 1

⑦ 주변분포
   P(X = x) = Σᵧ P(X = x, Y = y)   ← Y에 대해 합산
   P(Y = y) = Σₓ P(X = x, Y = y)   ← X에 대해 합산

⑧ 모공분산
   Cov(X, Y) = σₓᵧ = E[(X − μₓ)(Y − μᵧ)]
                    = E(XY) − μₓ × μᵧ

⑨ 모상관계수
   ρ = Cov(X, Y) / (σₓ × σᵧ)     범위: −1 ≤ ρ ≤ +1

=== 손계산 예시 요약 (X = 탈락 횟수 PMF) ===
데이터: P(X=0)=.60, P(X=1)=.25, P(X=2)=.10, P(X=3)=.05

μ     = 0×.60 + 1×.25 + 2×.10 + 3×.05 = .60
E(X²) = 0×.60 + 1×.25 + 4×.10 + 9×.05 = 1.10
σ²    = E(X²) − μ² = 1.10 − .36 = .74
σ     = √.74 ≈ .86
```

### 시나리오 A: PHQ-9 심각도 분포의 이론적 모형

임상 연구에서 "이 지역의 성인 인구에서 PHQ-9 심각도 분포는 어떠한가?"를 모형화한다.

X = PHQ-9 심각도 수준 (0=없음, 1=경미, 2=중등, 3=중등도심각, 4=심각)

**지역사회 표본 기반 추정 모형** (가상 데이터):

| x | PHQ-9 심각도 | P(X = x) |
|---|------------|----------|
| 0 | 없음 (0~4점) | .50 |
| 1 | 경미 (5~9점) | .25 |
| 2 | 중등 (10~14점) | .13 |
| 3 | 중등도 심각 (15~19점) | .08 |
| 4 | 심각 (20~27점) | .04 |
| **합** | | **1.00** |

```
E(X) = 0×.50 + 1×.25 + 2×.13 + 3×.08 + 4×.04
     = 0 + .25 + .26 + .24 + .16
     = .91

해석: 이 모집단에서 평균적인 PHQ-9 심각도 코드 = 0.91
     → 전형적인 지역사회 성인은 "없음~경미" 경계에 가까움

P(중등도 이상) = P(X ≥ 2) = .13 + .08 + .04 = .25
해석: 인구의 약 25%가 PHQ-9 중등도 이상 우울증 의심
```

> **중요한 시사점**: 이 확률분포가 모집단을 기술하는 **이론적 모형**이다. 실제 지역사회 역학 조사를 하면 이 분포를 추정할 수 있다. 새로운 선별 연구는 이 사전 모형(사전확률)을 출발점으로 삼는다.

## 6. 논문 스니펫 읽기 실습

다음은 가상의 논문 결과 보고 방식이다. 읽고 질문에 답하라.

---

*"The probability distribution of the number of missed CBT sessions (X) was modeled based on electronic health records from 160 outpatients. The distribution was as follows: P(X = 0) = .56, P(X = 1) = .25, P(X = 2) = .13, P(X = 3) = .06. The expected number of missed sessions was E(X) = 0.69 (SD = 0.90). A higher number of missed sessions was associated with greater depressive symptom severity at termination, Cov(X, BDI-II) = 4.20."*

---

**연습 질문:**

1. 이 PMF가 유효한 확률분포인지 확인하라. (합이 1인가? 모든 확률이 0 이상인가?)
2. 제시된 공식에 따라 E(X)를 직접 손계산하고 보고된 0.69와 비교하라.
3. P(X ≥ 2) = ? (두 번 이상 결석할 확률)
4. "SD = 0.90"이 무엇을 의미하는가? 이것은 표본 SD인가, 모 SD인가?
5. Cov(X, BDI-II) = 4.20 > 0의 임상적 의미는 무엇인가?

---

**모범 답안:**

**1. PMF 유효성 확인**
```
합계: .56 + .25 + .13 + .06 = 1.00  ✓
각 확률: 모두 0 이상  ✓
→ 유효한 PMF
```

**2. E(X) 손계산**
```
E(X) = 0×.56 + 1×.25 + 2×.13 + 3×.06
     = 0     + .25   + .26   + .18
     = .69

보고된 값 0.69와 일치.  ✓

해석: 이론적으로 내담자 1인당 평균 결석 횟수 ≈ 0.69회
```

**3. P(X ≥ 2) = ?**
```
P(X ≥ 2) = P(X = 2) + P(X = 3)
          = .13 + .06
          = .19

또는 여사건 이용: P(X ≥ 2) = 1 − P(X ≤ 1) = 1 − (.56+.25) = 1 − .81 = .19

해석: 내담자 19%가 2회 이상 결석한다
```

**4. SD = 0.90의 의미**
```
SD = σ ≈ 0.90 → σ² = 0.81

이 맥락에서는 PMF 기반 모분산에 해당하는 σ(모집단 표준편차)로 볼 수 있다.
전체 모형에서의 이론적 퍼짐.

손계산으로 확인:
E(X²) = 0²×.56 + 1²×.25 + 2²×.13 + 3²×.06
       = 0 + .25 + .52 + .54 = 1.31
σ² = E(X²) − [E(X)]² = 1.31 − (.69)² = 1.31 − .476 = .834
σ = √.834 ≈ 0.913 ≈ 0.90  ✓ (반올림 차이)
```

**5. Cov(X, BDI-II) = 4.20 > 0의 의미**
```
양의 공분산 → 결석 횟수가 많을수록 치료 종결 시 BDI-II 점수가 높은(증상이 심한) 경향.

단위가 있는 값이므로 크기 해석이 어렵다.
→ 표준화된 상관계수 ρ를 계산해야 크기를 해석할 수 있다.
   논문에서 종종 "r = .38, p = .002"처럼 표본 상관계수로 보고한다.
```

## 7. 오개념 경고

> **⚠️ 오개념 1**: "E(X)는 X가 가장 많이 나오는 값이다"
> → **아니다.** E(X)는 확률로 가중된 평균이지, 최빈값(mode)이 아니다.
>
> 위 탈락 횟수 예시: P(X=0) = .60으로 0이 가장 자주 나오지만, E(X) = .60 ≠ 0.
> E(X)는 "장기적으로 무한히 반복했을 때의 평균값"이다. 한 번의 시행에서 나오지 않는 값(예: 0.60회 탈락)일 수도 있다.

> **⚠️ 오개념 2**: "연속확률변수에서 P(X = 15) = .20이다"
> → **연속확률변수에서 특정 점의 확률은 항상 0이다.**
>
> BDI-II = 15점인 사람이 많다고 해도, P(X = 15.000000...) = 0. 이것이 수학적 사실이다.
> 연속확률변수에서는 "구간의 확률"만 의미가 있다: P(14 ≤ X ≤ 16).
> 히스토그램의 막대 높이가 "그 구간에 속하는 비율"을 나타내는 것처럼, PDF에서는 면적이 확률이다.

> **⚠️ 오개념 3**: "모평균 μ와 표본평균 x̄는 같은 것이다"
> → **완전히 다른 것이다.** 이 혼동이 통계의 가장 근본적인 오류다.
>
> - **μ**: 이론적 값. 모집단 전체의 특성. 알 수 없다. 기댓값 E(X).
> - **x̄**: 관측값. 우리가 실제로 구한 n개 표본의 평균. 계산 가능. μ의 추정치.
>
> 논문에서 "M = 23.4"는 x̄이지, μ가 아니다. μ는 영원히 알 수 없고, 우리는 x̄로 추론할 뿐이다.

> **⚠️ 오개념 4**: "ρ = 0이면 두 변수는 독립이다"
> → **독립이면 ρ = 0이지만, 역은 성립하지 않는다.**
>
> 반례: X가 −2, −1, 0, 1, 2 각각 확률 .2씩인 확률변수이고, Y = X²이라 하자.
> Cov(X, Y) = E(XY) − E(X)E(Y) = E(X³) − E(X)E(X²).
> E(X) = 0이므로 Cov(X,Y) = 0 → ρ = 0.
> 하지만 Y = X²이므로 X와 Y는 완전히 종속이다!
>
> ρ = 0은 "선형 관계가 없다"는 것이지, "독립이다"는 것이 아니다.

> **⚠️ 오개념 5**: "PMF의 확률이 1을 넘어도 된다"
> → **안 된다.** 공리 1 위반이다.
>
> 간혹 확률밀도함수(PDF)의 f(x) 값이 1을 초과하는 것을 보고 혼동한다. PDF에서는 f(x) 값 자체가 아니라 **면적**이 확률이므로, f(x) > 1이어도 된다. 단, 전체 면적은 반드시 1. 하지만 PMF에서 P(X=x) > 1은 절대 불가능하다.

## 부록: 보완 주제 — 선형 변환 규칙 (Linear Transformation Rules)

> **이 주제가 중요한 이유**: 교재에 명시적이지 않지만, Ch.6(정규분포)에서 **표준화(standardization)**와 **z-점수**를 이해하는 데 필수적인 수학적 기반이다.

---

### 선형 변환이란?

확률변수 X를 Y = aX + b 형태로 변환하는 것.

**임상 예시**: BDI-II 점수 X → 백분위 환산 점수 Y = 2X + 10

---

### 기댓값의 선형 변환 규칙

```
E(aX + b) = aE(X) + b

기호 해설:
  a = 스케일(scale) 변환 계수
  b = 위치(location) 이동 상수
  → 각각 독립적으로 기댓값에 영향
```

**손계산 예시**: X에 대해 E(X) = .60, Y = 3X + 2

```
E(Y) = 3×E(X) + 2 = 3×.60 + 2 = 1.80 + 2 = 3.80
```

---

### 분산의 선형 변환 규칙

```
Var(aX + b) = a²Var(X)

주목: 상수 b(이동)는 분산에 영향 없음!
     분산은 "퍼짐"의 측도 — 전체를 이동시켜도 퍼짐은 안 바뀜
     a²가 붙는 이유: a로 스케일을 늘리면 분산은 a² 배가 됨
```

**손계산 예시**: σ²(X) = .74, Y = 3X + 2

```
Var(Y) = 3²×Var(X) = 9×.74 = 6.66
σ(Y) = √6.66 ≈ 2.58
```

---

### Ch.6에서의 핵심 적용: 표준화 (Standardization)

**Z = (X − μ) / σ** 는 a = 1/σ, b = −μ/σ인 선형 변환이다.

```
E(Z) = E[(X−μ)/σ]
     = (1/σ) × E(X) − μ/σ
     = (1/σ) × μ − μ/σ
     = μ/σ − μ/σ = 0

Var(Z) = (1/σ)² × Var(X)
       = (1/σ²) × σ²
       = 1

결론: Z = (X−μ)/σ로 변환하면 항상 E(Z) = 0, Var(Z) = 1
      → "표준화"의 수학적 근거
```

> **핵심 납득 포인트**: Ch.6에서 "BDI-II 점수를 z-점수로 변환한다"는 것이 바로 이 선형 변환이다. 어떤 척도든 (μ, σ²)만 알면 → z-점수로 변환 → 표준정규분포표로 확률 계산. 선형 변환 규칙이 그 기초다.

---

### 실용적 요약

| 변환 | 기댓값 | 분산 |
|------|--------|------|
| Y = X + b | E(X) + b | Var(X) |
| Y = aX | aE(X) | a²Var(X) |
| Y = aX + b | aE(X) + b | a²Var(X) |
| Z = (X−μ)/σ | 0 | 1 |
