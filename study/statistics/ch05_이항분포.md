### 3.1 베르누이 분포 (Bernoulli Distribution)

#### 직관부터 시작

> **질문**: "내담자 한 명에게 CBT를 했을 때 '치료 반응(성공)' vs. '무반응(실패)'만 가능하다면?"

이것이 가장 단순한 확률 모형 — **베르누이 시행(Bernoulli trial)**이다.

- 결과가 딱 두 가지: **성공(1)** 또는 **실패(0)**
- 성공 확률: **p**
- 실패 확률: **1−p = q**

#### PMF

```
P(X = 1) = p         ← 성공
P(X = 0) = 1 − p    ← 실패

또는 하나의 식으로: P(X = x) = p^x × (1−p)^(1−x)  (x = 0 또는 1)
```

#### 기댓값과 분산

```
E(X)   = p           ← "성공 확률 자체"가 기댓값
Var(X) = p(1−p)      ← p = .5일 때 최대 (.25), p → 0 또는 1일 때 최소
σ      = √[p(1−p)]
```

**손계산 예시**: p = .70 (치료 반응률 70%)

```
E(X)   = .70
Var(X) = .70 × .30 = .21
σ      = √.21 ≈ .458
```

> **핵심 납득 포인트**: 베르누이 분포는 "한 번의 성공/실패 시행"이다. p = .5일 때 분산이 최대(.25)인 것은 직관적이다 — 결과가 가장 불확실할 때(50:50) 퍼짐이 가장 크다. p가 0이나 1에 가까울수록 결과가 거의 확실해지므로 분산이 줄어든다.

### 3.2 이항분포 (Binomial Distribution)

#### 직관부터 시작

> **질문**: "내담자 5명에게 CBT를 했을 때, 정확히 3명이 치료에 반응할 확률은?"

**베르누이 시행을 n번 독립적으로 반복**하면 이항분포가 된다.

#### 이항분포의 4가지 조건 (모두 만족해야 적용 가능)

```
조건 1: 시행 횟수 n이 고정되어 있다
조건 2: 각 시행의 결과는 성공 또는 실패, 두 가지뿐이다
조건 3: 각 시행에서 성공 확률 p가 일정하다
조건 4: 각 시행은 서로 독립이다
```

| 조건 | 임상 예시 충족 여부 |
|------|------------------|
| n 고정 | "5명에게 실시" → n = 5 ✓ |
| 성공/실패 | "반응 vs. 무반응" ✓ |
| p 일정 | "각 환자의 반응률 = .70" — 동질 집단이면 ✓ |
| 독립 | "각 환자 반응은 다른 환자에게 영향 없음" — 같은 치료사이면 주의! |

#### PMF — 이항계수의 역할

```
P(X = k) = C(n, k) × p^k × (1−p)^(n−k)

C(n, k) = n! / [k! × (n−k)!]  ← "n개 중 k개를 고르는 경우의 수"

기호 해설:
  n       = 시행 횟수 (총 환자 수)
  k       = 성공 횟수 (치료 반응자 수)
  p       = 각 시행의 성공 확률
  1−p     = 실패 확률
  C(n,k)  = k명이 성공하고 n−k명이 실패하는 순서의 경우의 수
  p^k     = k번 성공할 확률
  (1−p)^(n−k) = n−k번 실패할 확률
```

**직관**: "3명이 성공하고 2명이 실패하는 특정 순서(예: 성공-성공-성공-실패-실패) 하나의 확률은 p³(1−p)²이다. 그런데 이런 순서가 C(5,3) = 10가지 가능하다. 따라서 곱한다."

#### 기댓값과 분산

```
X ~ B(n, p) 이면:

E(X)   = np              ← "n번 시행에서 기대되는 성공 횟수"
Var(X) = np(1−p)
σ      = √[np(1−p)]
```

#### 손계산 예시 — n = 5, p = .60

**P(X=k) 전체 계산:**

```
C(5,0) = 1   C(5,1) = 5   C(5,2) = 10
C(5,3) = 10  C(5,4) = 5   C(5,5) = 1

P(X=0) = 1  × .60⁰ × .40⁵ = 1  × 1      × .010 = .010
P(X=1) = 5  × .60¹ × .40⁴ = 5  × .60    × .026 = .077
P(X=2) = 10 × .60² × .40³ = 10 × .36    × .064 = .230
P(X=3) = 10 × .60³ × .40² = 10 × .216   × .160 = .346
P(X=4) = 5  × .60⁴ × .40¹ = 5  × .130   × .400 = .259
P(X=5) = 1  × .60⁵ × .40⁰ = 1  × .078   × 1    = .078
                                              합계 = 1.000 ✓

E(X) = np = 5 × .60 = 3.0
Var(X) = np(1−p) = 5 × .60 × .40 = 1.20
σ = √1.20 ≈ 1.095
```

```
[이항분포 B(5, .60) 막대 그래프]
P(X=k)
 .346│         ██
 .259│         ██  ██
 .230│      ██ ██  ██
 .077│   ██ ██ ██  ██  ██
 .010│██ ██ ██ ██  ██  ██
     └───────────────────
       0  1  2  3   4   5   k
                ↑
              E(X) = 3.0  (분포가 여기에 집중)
```

> **핵심 납득 포인트**: 이항분포에서 "가장 가능성 높은 결과"는 k = np(기댓값)이다. 5명 중 기대 성공자 수 = 5×.60 = 3명이고, 실제로 P(X=3)이 가장 높다. 기댓값은 단순 산술이 아니라 실제로 "가장 흔히 나오는" 결과에 해당한다.

### 3.3 초기하분포 (Hypergeometric Distribution)

#### 직관부터 시작

> **질문**: "20명의 환자 중 8명이 MDD이다. 이 집단에서 5명을 비복원 추출하면, MDD 환자가 정확히 2명일 확률은?"

이항분포와 달리 **비복원 추출(without replacement)**이므로 각 시행이 독립이 아니다. 이 경우 **초기하분포**를 사용한다.

#### 이항분포 vs. 초기하분포 비교

| | 이항분포 | 초기하분포 |
|--|---------|-----------|
| **추출 방식** | 복원 추출 (with replacement) | 비복원 추출 (without replacement) |
| **독립성** | 각 시행 독립 | 이전 선택이 다음에 영향 |
| **모집단 크기** | 무한 또는 매우 큼 | 유한 (N이 명시됨) |
| **임상 예시** | 치료 반응률 p로 n명 치료 | N명 집단에서 n명 무작위 선발 |

#### PMF

```
P(X = k) = C(K, k) × C(N−K, n−k) / C(N, n)

기호 해설:
  N = 모집단 크기 (전체 환자 수)
  K = 모집단에서 관심 범주(MDD) 수
  n = 표본 크기 (뽑는 수)
  k = 표본에서 관심 범주(MDD) 수
```

**손계산 예시**: N=20, K=8 (MDD), n=5, k=2

```
P(X=2) = C(8,2) × C(12,3) / C(20,5)

C(8,2)  = 28
C(12,3) = 220
C(20,5) = 15504

P(X=2) = 28 × 220 / 15504
        = 6160 / 15504
        ≈ .397

해석: 20명 중 5명을 비복원 추출할 때 MDD 2명일 확률 ≈ 40%
```

**기댓값과 분산**:

```
E(X)   = n × K/N = 5 × 8/20 = 2.0
Var(X) = n × (K/N) × (1−K/N) × (N−n)/(N−1)
       = 5 × .40 × .60 × 15/19
       ≈ 5 × .24 × .789 ≈ .947

비교: 이항분포 B(5, .40)의 분산 = 5×.40×.60 = 1.20
→ 초기하분포의 분산이 더 작다.
   유한 집단에서 비복원 추출이면 이항보다 변동이 적음
   (N−n)/(N−1) = 유한 모집단 수정 인수 (finite population correction factor)
```

> **핵심 납득 포인트**: N이 충분히 클 때(예: N ≥ 20n), 초기하분포는 이항분포로 근사된다. 임상 연구에서 대형 데이터베이스에서 소수를 뽑는 경우, 굳이 초기하분포를 쓰지 않고 이항분포를 쓰는 이유다. "표집 비율이 5% 미만이면 이항으로 근사 충분"이라는 실용적 기준이 있다.

### 3.4 포아송 분포 (Poisson Distribution)

#### 직관부터 시작

> **질문**: "주당 위기 전화가 평균 3건 온다면, 특정 주에 5건이 올 확률은?"

**포아송 분포**는 단위 시간(또는 공간)에서 **희귀 사건이 발생하는 횟수**를 모형화한다.

#### 포아송 분포의 적용 조건

```
조건 1: 사건은 독립적으로 발생한다
조건 2: 사건 발생률(λ)이 일정하다 (시간에 따라 안 바뀜)
조건 3: 두 사건이 정확히 같은 순간에 발생하는 확률 = 0
```

**임상 예시**:
- 위기 상담 센터의 시간당 전화 건수
- 내담자의 주당 패닉 발작 횟수
- 임상 연구에서 일 년간 재입원 횟수

#### PMF

```
P(X = k) = e^(−λ) × λ^k / k!

기호 해설:
  λ (람다) = 단위 시간당 평균 발생 횟수 (모수)
  k        = 관측된 발생 횟수 (0, 1, 2, ...)
  e        ≈ 2.71828 (자연로그의 밑)
  k!       = k의 계승 (factorial): k! = k×(k−1)×...×2×1
```

#### 기댓값과 분산

```
E(X) = λ     ← 기댓값 = 모수 λ
Var(X) = λ   ← 분산도 λ (포아송의 특징: 평균 = 분산!)
σ = √λ
```

#### 손계산 예시 — λ = 2 (주당 평균 위기 전화 2건)

```
e^(−2) ≈ 0.1353

P(X=0) = e^(−2) × 2⁰ / 0! = 0.1353 × 1 / 1   = .135
P(X=1) = e^(−2) × 2¹ / 1! = 0.1353 × 2 / 1   = .271
P(X=2) = e^(−2) × 2² / 2! = 0.1353 × 4 / 2   = .271
P(X=3) = e^(−2) × 2³ / 3! = 0.1353 × 8 / 6   = .180
P(X=4) = e^(−2) × 2⁴ / 4! = 0.1353 × 16 / 24 = .090
P(X=5) = e^(−2) × 2⁵ / 5! = 0.1353 × 32 / 120 = .036

E(X) = Var(X) = λ = 2.0
σ = √2 ≈ 1.41
```

> **핵심 납득 포인트**: 포아송 분포의 놀라운 특성 — **평균과 분산이 같다(λ).** 임상 데이터에서 "사건 횟수(count data)"의 평균과 분산을 비교했을 때 비슷하면, 포아송 분포가 적합한 모형일 수 있다. 반대로 분산이 평균보다 훨씬 크면(**과분산**, overdispersion) 음이항분포(negative binomial) 등을 고려한다.

## 4. 수식 정리

```
=== 기호 약속 ===
n       = 이항분포에서 시행 횟수 (고정)
k       = 성공 횟수 (0, 1, 2, ..., n)
p       = 성공 확률 (모수)
1−p = q = 실패 확률
λ       = 포아송 분포 모수 (단위 시간당 평균 발생률)
C(n,k)  = 이항계수 = n! / [k!(n−k)!]
e       ≈ 2.71828 (자연로그의 밑)

=== 수식 목록 ===

[베르누이 분포 Bernoulli(p)]
① PMF:    P(X = 1) = p,  P(X = 0) = 1−p
② E(X)  = p
③ Var(X) = p(1−p)

[이항분포 B(n, p)]
④ PMF:    P(X = k) = C(n, k) × p^k × (1−p)^(n−k)
            C(n,k) = n! / [k!(n−k)!]
⑤ E(X)  = np
⑥ Var(X) = np(1−p)
⑦ σ      = √[np(1−p)]

[초기하분포 Hyper(N, K, n)]
⑧ PMF:    P(X = k) = C(K,k) × C(N−K, n−k) / C(N, n)
⑨ E(X)  = n × K/N
⑩ Var(X) = n × (K/N) × (1−K/N) × (N−n)/(N−1)

[포아송 분포 Poisson(λ)]
⑪ PMF:    P(X = k) = e^(−λ) × λ^k / k!
⑫ E(X)  = λ
⑬ Var(X) = λ   ← 평균 = 분산 (포아송의 특징)

=== 손계산 예시 요약 (이항분포 B(5, .60)) ===
P(X=3) = C(5,3) × .60³ × .40²
        = 10 × .216 × .16
        = .346

E(X)    = 5 × .60 = 3.0
Var(X)  = 5 × .60 × .40 = 1.20
σ       = √1.20 ≈ 1.10

이항계수 빠른 계산:
C(5,0)=1, C(5,1)=5, C(5,2)=10, C(5,3)=10, C(5,4)=5, C(5,5)=1
```

## 5. 심리학 연구 맥락 연결

### 시나리오 A: 치료 반응율 — 이항분포 적용

임상 RCT에서 CBT 치료 반응율(response rate)을 모형화한다.

**연구 가정**: CBT의 MDD 치료 반응율 p = .60 (기존 메타분석 기반)

**질문들**:

```
[그룹 A: n = 10명 집단]
E(X) = np = 10 × .60 = 6.0명
σ    = √[np(1−p)] = √[10 × .60 × .40] = √2.40 ≈ 1.55

P(X ≥ 8) = P(X=8) + P(X=9) + P(X=10)
         = C(10,8)×.60⁸×.40² + C(10,9)×.60⁹×.40 + C(10,10)×.60¹⁰
         = 45×.0168×.16 + 10×.0101×.40 + 1×.0060×1
         = .121 + .040 + .006
         = .167

해석: 10명 중 8명 이상이 반응할 확률 ≈ 17%
```

이 계산은 "치료 시험(clinical trial)에서 얼마나 많은 성공 사례가 필요한가?"를 판단할 때 사용된다. **검정력(statistical power)** 계산의 기초다.

---

### 시나리오 B: 위기 발생 횟수 — 포아송 분포 적용

임상 슈퍼비전 연구에서 치료사 1인당 월간 위기 상황(suicidal ideation 보고 케이스) 발생 건수를 모형화한다.

```
가정: 치료사 1인당 월 평균 위기 발생 = λ = 1.5건

P(한 달에 위기 0건) = e^(-1.5) × 1.5⁰ / 0!
                   = 0.2231 × 1 / 1 = .223

P(한 달에 위기 3건 이상) = 1 − P(X≤2)
  P(X=0) = .223
  P(X=1) = e^(-1.5) × 1.5 / 1 = 0.2231 × 1.5 = .335
  P(X=2) = e^(-1.5) × 2.25 / 2 = 0.2231 × 1.125 = .251
  P(X≤2) = .223 + .335 + .251 = .809
  P(X≥3) = 1 − .809 = .191

해석: 치료사가 한 달에 3건 이상의 위기 상황을 만날 확률 ≈ 19%
     → 월간 슈퍼비전 빈도, 비상 연락 프로토콜 설계의 근거가 됨
```

## 6. 논문 스니펫 읽기 실습

다음은 가상의 논문 결과 보고다. 읽고 질문에 답하라.

---

*"A CBT therapist tracked treatment completion (success, X = 1) versus dropout (failure, X = 0) for n = 8 consecutive patients. Based on prior meta-analytic evidence, the probability of successful treatment completion was assumed to be p = .70. Assuming that each patient's outcome was independent, the number of completers X was modeled as a Binomial(n = 8, p = .70) distribution. The expected number of completions was E(X) = 5.6 (SD = 1.30). In this therapist's actual caseload, only 3 patients completed treatment."*

---

**연습 질문:**

1. E(X)와 SD를 직접 계산해 보고된 값을 확인하라.
2. P(X = 3) = ? (실제 관찰된 3명 완주의 이론적 확률)
3. P(X ≥ 7) = ? (7명 이상이 완주할 확률)
4. "assuming that each patient's outcome was independent" — 이 가정이 실제로 위반될 수 있는 상황은?
5. 실제 x = 3이 관찰되었다. 이것은 p = .70 가정에 의심을 제기하는가?

---

**모범 답안:**

**1. E(X)와 SD 계산**
```
E(X) = np = 8 × .70 = 5.60  ✓ (보고된 값과 일치)

Var(X) = np(1−p) = 8 × .70 × .30 = 1.68
σ = √1.68 ≈ 1.296 ≈ 1.30  ✓ (반올림 차이)
```

**2. P(X = 3)**
```
P(X=3) = C(8,3) × .70³ × .30⁵

C(8,3) = 8! / (3! × 5!) = (8×7×6) / (3×2×1) = 56

.70³ = .343
.30⁵ = .00243

P(X=3) = 56 × .343 × .00243
        = 56 × .000833
        ≈ .047

해석: p = .70 가정 하에서 8명 중 3명만 완주할 확률 ≈ 4.7%
     상당히 낮은 확률 → 이 치료사의 실적이 기대보다 낮은 것은 우연이라고 보기 어렵다
```

**3. P(X ≥ 7)**
```
P(X=7) = C(8,7) × .70⁷ × .30¹
        = 8 × .082 × .30
        = 8 × .0247
        ≈ .197

P(X=8) = C(8,8) × .70⁸ × .30⁰
        = 1 × .0576 × 1
        ≈ .058

P(X ≥ 7) = .197 + .058 = .255

해석: 기대보다 매우 좋은 결과(7명 이상 완주)가 나올 확률 ≈ 25.5%
```

**4. 독립 가정 위반 상황**
```
다음 경우에 독립 가정이 깨진다:

(1) 치료사 효과(therapist effect): 같은 치료사가 담당하므로, 치료사의
    그날 컨디션, 기술, 치료적 동맹 방식이 모든 환자에게 공통으로 영향.
    → Ch.11 다층모형(multilevel modeling)이 필요한 상황

(2) 시간적 효과: 치료사가 첫 4명을 경험한 후 실력이 늘어 후반 4명에게는
    성공률이 다를 수 있음 → p가 일정하다는 조건 위반

(3) 환자 간 상호작용: 집단치료 또는 같은 병동 환자들이면 서로 영향 가능
```

**5. x = 3 관찰의 의미**
```
P(X ≤ 3) = P(X=0) + P(X=1) + P(X=2) + P(X=3)

P(X=0) = .30⁸ = .00007
P(X=1) = C(8,1)×.70×.30⁷ = 8×.70×.00022 = .001
P(X=2) = C(8,2)×.70²×.30⁶ = 28×.49×.00073 = .010
P(X=3) ≈ .047 (위에서 계산)

P(X ≤ 3) ≈ .00007 + .001 + .010 + .047 ≈ .058

p = .70 가정 하에서 3명 이하가 완주할 확률 ≈ 5.8%
→ 매우 드문 결과. 이 치료사의 p가 .70보다 낮을 가능성이 있음.
→ Ch.8에서 배울 "가설검정"이 바로 이런 판단을 공식화한다:
   "관찰된 결과가 충분히 드물면, 가정한 p를 의심한다 (p-값 < .05)"
```

## 7. 오개념 경고

> **⚠️ 오개념 1**: "이항분포는 p = .5일 때만 쓸 수 있다"
> → **아니다.** p는 0과 1 사이 어떤 값도 가능하다. p = .70의 치료 반응률, p = .05의 부작용 발생률, p = .95의 약 복약 순응률 — 모두 이항분포 적용 가능.
>
> 혼동의 이유: "이항(binary)"이라는 단어가 "반반"처럼 들리기 때문. 하지만 이항은 "두 종류의 결과"를 뜻하지 "확률이 같다"는 뜻이 아니다.

> **⚠️ 오개념 2**: "이항분포의 조건을 대충 확인해도 된다"
> → **독립성 조건과 p 일정 조건은 심각하게 검토해야 한다.**
>
> 같은 치료사가 담당하는 n명 환자, 또는 치료 순서가 영향을 주는 경우, 각 환자의 반응은 독립이 아니다. 이항분포를 잘못 적용하면 분산이 과소추정되어 가설검정 결과가 왜곡된다. 논문 Methods에서 "independence was assumed"라는 문장이 나오면, 그 가정이 타당한지 비판적으로 검토하는 것이 연구자의 역할이다.

> **⚠️ 오개념 3**: "포아송 분포에서 평균이 크면 분산도 반드시 같다"
> → **이론적으로는 그렇지만, 실제 데이터가 포아송을 따른다는 보장이 없다.**
>
> 관측된 데이터에서 분산이 평균보다 훨씬 크면(과분산, overdispersion), 포아송 가정이 위반된 것이다. 임상 count data(입원 횟수, 자해 횟수 등)에서는 과분산이 매우 흔하다. 이때는 음이항분포(negative binomial) 또는 영과잉모형(zero-inflated model)을 고려해야 한다.

> **⚠️ 오개념 4**: "초기하분포와 이항분포는 N의 크기만 다르다"
> → **근본적 차이는 복원 여부(with vs. without replacement)다.**
>
> N이 아무리 커도, 비복원 추출이면 초기하분포가 엄밀히 옳다. 다만 N이 충분히 크면(표집 비율 n/N < 5%) 이항으로 근사해도 오차가 작아 실용적으로 이항을 쓴다. N이 작을수록 유한 모집단 수정 인수 (N−n)/(N−1)의 효과가 커진다.

> **⚠️ 오개념 5**: "E(X) = 3.5이면 3번이나 4번 중 하나가 나온다"
> → **기댓값은 장기 평균이지 실제 관찰값이 아니다.** (Ch.4에서도 나온 오개념)
>
> B(5, .70)에서 E(X) = 3.5인데, 이항분포의 실현값은 항상 정수(0,1,2,3,4,5). 3.5번 성공은 불가능하다. 단, 무한히 많은 시행을 반복하면 평균이 3.5에 수렴한다.

## 부록: 보완 주제 — 이항분포의 정규 근사 (Normal Approximation to Binomial)

> **이 주제가 중요한 이유**: 이항분포의 n이 클 때 직접 계산이 어렵다. 정규분포(Ch.6)로 근사하면 간편하다. 또한 이것이 **중심극한정리(Ch.7)**의 가장 직관적인 예시다.

---

### 왜 근사하는가?

이항분포 B(n, p)에서 n이 커질수록 분포의 형태가 종 모양에 가까워진다.

```
[B(5, .60)]           [B(20, .60)]          [B(100, .60)]
   ██                       ██                     ██
   ████                  ████████               ████████
   ████████          ████████████████       ████████████████
─────────────    ──────────────────────    ──────────────────
  n 작음: 비대칭    n 중간: 점차 대칭화       n 큼: 정규분포처럼
```

---

### 근사 조건

```
정규 근사를 사용하려면:
  np ≥ 5     (기대 성공 횟수가 5 이상)
  n(1−p) ≥ 5 (기대 실패 횟수가 5 이상)

예: n=50, p=.60 → np=30 ≥ 5 ✓, n(1−p)=20 ≥ 5 ✓ → 정규 근사 가능
    n=10, p=.05 → np=0.5 < 5 ✗ → 포아송 근사 고려 (이항 직접 계산)
```

---

### 근사 공식

```
X ~ B(n, p)  이면:
X ≈ N(μ, σ²)  단,  μ = np,  σ² = np(1−p)

연속성 수정 (continuity correction):
  P(X = k)   → P(k−.5 ≤ Y ≤ k+.5)    (Y는 정규확률변수)
  P(X ≥ k)   → P(Y ≥ k−.5)
  P(X ≤ k)   → P(Y ≤ k+.5)
```

---

### 임상 예시

n = 50명, p = .60인 CBT 연구. P(X ≥ 35) = ?

```
μ = np = 30
σ = √[np(1−p)] = √12 ≈ 3.46

연속성 수정: P(X ≥ 35) ≈ P(Y ≥ 34.5)

z = (34.5 − 30) / 3.46 = 4.5 / 3.46 ≈ 1.30

Ch.6 정규분포 표에서: P(Z ≥ 1.30) ≈ .097

해석: 50명 중 35명 이상이 반응할 확률 ≈ 10%
```

> **핵심 납득 포인트**: 이항분포 직접 계산은 n이 크면 불가능에 가깝다(C(50,35) 같은 수). 정규 근사로 간편하게 해결한다. 이것이 Ch.6(정규분포)와 Ch.7(중심극한정리)를 배워야 하는 구체적 이유다.
