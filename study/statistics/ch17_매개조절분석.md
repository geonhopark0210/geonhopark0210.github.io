### 3.1 연구 질문의 차이: 회귀 vs. 매개 vs. 조절

#### 직관부터 시작

> **질문**: "스트레스가 높을수록 우울이 높다는 것은 알겠다. 그런데 도대체 스트레스가 우울을 어떻게 만드는가? 그리고 같은 스트레스를 받아도 어떤 사람은 우울이 심해지고 어떤 사람은 아닌 이유는 무엇인가?"

이 두 가지 질문에 각각 답하는 것이 매개 분석과 조절 분석이다.

```
[세 가지 분석의 구조]

1. 회귀분석 (Regression):
   "X가 Y를 예측하는가?"

   X ──────────────→ Y
   스트레스             우울

2. 매개분석 (Mediation):
   "X가 M을 통해 Y에 영향을 주는가?"

   X ──── a ────→ M ──── b ────→ Y
   스트레스          수면 장애          우울
         \________________________/
                   c' (직접 효과)

3. 조절분석 (Moderation):
   "X의 효과가 Z에 따라 달라지는가?"

   X ──────────────────────────→ Y
   스트레스   ↗                     우울
   Z (사회적 지지)
   (Z가 높으면 X→Y 효과가 약해짐)
```

| 분석 | 핵심 질문 | 추가 변수의 역할 | 예시 |
|------|-----------|------------------|------|
| 회귀분석 | X가 Y를 예측하는가? | 없음 (단순) 또는 공변량 | 스트레스 → 우울 |
| 매개분석 | X가 M을 **경유하여** Y에 영향을 주는가? | M이 X와 Y 사이에 위치 (매개변수) | 스트레스 → 수면 장애 → 우울 |
| 조절분석 | X의 효과가 Z에 **따라** 달라지는가? | Z가 X-Y 관계의 크기를 조절 (조절변수) | 사회적 지지에 따라 스트레스의 우울 효과 변화 |

> **핵심 납득 포인트**: 매개와 조절은 완전히 다른 질문이다. 매개는 "어떤 경로로?"(메커니즘), 조절은 "어떤 조건에서?"(경계 조건)를 묻는다. 심리학 논문에서 "mediator"와 "moderator"를 혼동하는 것은 가장 치명적인 해석 오류 중 하나다.

### 3.2 매개 분석 (Mediation Analysis)

#### 직관부터 시작

> **질문**: "외상을 경험한 사람이 PTSD 증상을 보이는 이유는 무엇인가? 단순히 외상 경험 자체가 직접 증상을 만드는 것인가, 아니면 외상이 인지적 회피를 만들고, 그 인지적 회피가 PTSD 증상을 악화시키는 것인가?"

매개 분석은 X와 Y 사이의 "블랙박스"를 열어 **메커니즘**을 규명하는 분석이다.

```
[매개 분석의 기본 구조]

       경로 a          경로 b
  X ──────────→ M ──────────→ Y
  외상           인지적 회피      PTSD 증상
  경험
   \________________________________/
            직접 효과 c'

   총 효과 c = c' + (a × b)
              직접 효과 + 간접 효과
```

#### a. Baron & Kenny (1986) 4단계 방법

Baron & Kenny의 고전적 방법은 4개의 회귀 방정식을 순서대로 검정한다:

| 단계 | 회귀 방정식 | 확인 사항 | 경로 |
|------|-------------|-----------|------|
| 1단계 | Y = β₀ + **c**X + ε | X → Y 유의 (총 효과) | c |
| 2단계 | M = β₀ + **a**X + ε | X → M 유의 | a |
| 3단계 | Y = β₀ + bM + c'X + ε | M → Y 유의 (X 통제 하) | b |
| 4단계 | 위와 동일 | c' 변화 확인 (직접 효과) | c' |

**4단계 결과 해석**:
- **완전 매개 (Full Mediation)**: 4단계에서 c' ≈ 0 (X의 직접 효과 사라짐)
  → M이 X와 Y를 완전히 설명함
- **부분 매개 (Partial Mediation)**: 4단계에서 c'가 여전히 유의하지만, c보다 감소
  → M이 X-Y 관계의 일부만 설명함

```
[완전 매개 vs. 부분 매개]

완전 매개:
  X ──→ M ──→ Y
  X ─────→ Y (M 없을 때 c 유의)
  X  ...(M 있을 때 c' ≈ 0, 비유의)

부분 매개:
  X ──→ M ──→ Y
  X ─────→ Y (c 유의)
  X ──────→ Y (M 있어도 c' 여전히 유의, 단 c'< c)
```

#### b. 간접효과 (Indirect Effect)

매개 분석의 핵심 수치는 **간접효과 (a × b)**이다:

```
간접효과 = a × b
         = (X→M의 회귀계수) × (M→Y의 회귀계수, X 통제)

총 효과 c = 직접효과 c' + 간접효과 (a×b)
```

**수치 예시**:
- a = 0.54 (스트레스 → 수면 장애)
- b = 0.38 (수면 장애 → 우울, 스트레스 통제)
- 간접효과 = 0.54 × 0.38 = **0.205 ≈ 0.21**

이 값이 "통계적으로 0과 다른가?"를 검정하는 것이 매개 분석의 핵심이다.

#### c. 왜 Baron & Kenny만으로는 부족한가

Baron & Kenny 방법의 두 가지 한계:

**한계 1: 1단계(X→Y)가 유의하지 않아도 매개는 가능하다**

이를 **직접효과 없는 매개 (suppressed mediation 또는 indirect-only mediation)** 라 한다.
- 예: X가 M을 통해 Y를 높이는 경로(a×b > 0)와, X가 Y를 직접 낮추는 경로(c' < 0)가 동시에 존재하면, 두 효과가 상쇄되어 c ≈ 0으로 보일 수 있다.
- 이 경우 Baron & Kenny 1단계에서 탈락하지만 실제로는 매개가 존재한다.

**한계 2: a×b의 표집분포는 정규분포가 아니다**

Sobel 검정(z = a×b / SE)은 간접효과가 정규분포를 따른다고 가정하지만, a와 b의 곱은 실제로 **비대칭 분포**를 따른다. 특히 표본이 작을 때 Sobel 검정은 제1종 오류율이 왜곡된다.

```
[간접효과 a×b의 표집분포 모양]

실제 분포 (비대칭):        정규분포 가정 (Sobel):
    ████                         ██
   ██████                       ████
  ████████                    ████████
─────────────                ─────────────
   0    0.3                     0    0.3
← 꼬리가 길다                  대칭적이라고 가정
```

**→ 해결책: 부트스트래핑**

#### d. 부트스트래핑 (Bootstrapping)

부트스트래핑은 수식이 아닌 **컴퓨터 재표집**으로 신뢰구간을 구하는 방법이다.

```
[부트스트래핑 절차]

원본 표본 (n = 100명)
  ↓
1회: 100명을 복원 추출하여 새 표본 생성 → a₁×b₁ 계산
2회: 100명을 복원 추출하여 새 표본 생성 → a₂×b₂ 계산
...
5000회: → a₅₀₀₀×b₅₀₀₀ 계산
  ↓
5000개의 간접효과 값의 분포를 그린다
  ↓
하위 2.5%~상위 2.5% → 95% 신뢰구간
```

**해석 기준**:
- **신뢰구간이 0을 포함하지 않는다** → 간접효과 유의 (매개 있음)
- **신뢰구간이 0을 포함한다** → 간접효과 비유의 (매개 없음)

| Bootstrap 95% CI 결과 | 해석 |
|-----------------------|------|
| [0.09, 0.35] | 0을 포함하지 않음 → **유의한 간접효과** |
| [-0.03, 0.25] | 0을 포함함 → 비유의한 간접효과 |
| [0.05, 0.38] | 0을 포함하지 않음 → **유의한 간접효과** |

**Hayes PROCESS macro (Model 4)**:
- SPSS/SAS/R에서 사용 가능한 매개 분석 전용 프로그램
- Model 4: 단순 매개 (Simple Mediation): X → M → Y
- "PROCESS macro was used with 5,000 bootstrap samples" → 논문에서 가장 흔히 보이는 표현

> **핵심 납득 포인트**: 부트스트래핑 신뢰구간의 해석은 단 한 가지다. "구간이 0을 포함하지 않으면 간접효과가 유의미하다." p값 대신 신뢰구간을 사용하기 때문에 "p < .05"라는 문구가 없어도 된다. 이것이 현대 매개 분석의 표준이다.

### 3.3 조절 분석 (Moderation Analysis)

#### 직관부터 시작

> **질문**: "스트레스가 우울을 예측한다는 것은 알겠다. 그런데 사회적 지지가 높은 사람과 낮은 사람에서 스트레스의 우울 효과가 같을까? 사회적 지지가 '완충제' 역할을 하지 않을까?"

조절 분석은 "X → Y 관계의 크기 또는 방향이 **Z에 따라 다른가?**"를 묻는다.

```
[조절 분석의 구조]

사회적 지지(Z) 낮음  →  스트레스(X)의 우울(Y) 효과 크다
사회적 지지(Z) 높음  →  스트레스(X)의 우울(Y) 효과 작다

그래프로 보면:
우울 ↑
    │  Z 낮음 / (가파른 기울기)
    │        /
    │       /  Z 높음 (완만한 기울기)
    │      / /
    │     / /
    └────────────
         스트레스 →
```

#### a. 조절 분석의 회귀 모형

조절 분석은 X×Z **상호작용 항 (interaction term)** 을 회귀에 추가한다:

$$Y = \beta_0 + \beta_1 X + \beta_2 Z + \beta_3 (X \times Z) + \varepsilon$$

| 기호 | 명칭 | 의미 |
|------|------|------|
| β₁ | X의 주효과 | Z = 0일 때 X의 Y에 대한 효과 |
| β₂ | Z의 주효과 | X = 0일 때 Z의 Y에 대한 효과 |
| β₃ | 상호작용 계수 | X가 1단위 증가할 때, X의 효과가 Z에 따라 얼마나 변하는가 |
| X×Z | 상호작용 항 | X와 Z를 곱한 새 변수 |

**가설**:
- H₀: β₃ = 0 (조절 없음 — X의 효과가 Z에 따라 달라지지 않는다)
- H₁: β₃ ≠ 0 (조절 있음 — X의 효과가 Z에 따라 달라진다)

β₃가 유의하면 **조절 효과 있음**으로 결론 내린다.

#### b. 왜 반드시 중심화(centering)를 해야 하는가

**문제**: X×Z 항을 그냥 만들면, X×Z는 X와 Z 각각과 매우 높은 상관을 가진다.

예시:
- X = 스트레스 (범위 0~40, 평균 20)
- Z = 사회적 지지 (범위 12~60, 평균 36)
- X×Z = X에 Z를 곱한 값

만약 스트레스가 높을수록 X×Z도 크고, 사회적 지지가 높을수록 X×Z도 크다면, 회귀에서 β₁, β₂, β₃를 따로 추정하기가 불가능해진다 (**다중공선성 (multicollinearity)**).

**해결책: 중심화 (centering)**

$$X' = X - \bar{X}, \quad Z' = Z - \bar{Z}$$

중심화 후 상호작용 항:

$$X' \times Z' = (X - \bar{X})(Z - \bar{Z})$$

| 중심화 전 | 중심화 후 |
|-----------|-----------|
| X×Z는 X, Z와 높은 다중공선성 | X'×Z'는 X', Z'와 낮은 상관 |
| β₁, β₂, β₃ 추정치 불안정 | 추정치 안정적, 해석 가능 |
| 절편의 의미 없음 | 절편 = X, Z 모두 평균일 때 Y |

```
[중심화 예시]

원래 데이터:
  참가자 1: X=25(스트레스), Z=30(사회적 지지)  → X×Z=750
  참가자 2: X=30(스트레스), Z=40(사회적 지지)  → X×Z=1200

중심화 후 (x̄=20, z̄=36):
  참가자 1: X'=25-20=5,  Z'=30-36=-6  → X'×Z' = -30
  참가자 2: X'=30-20=10, Z'=40-36=4   → X'×Z' = 40
```

> **핵심 납득 포인트**: 중심화는 계산 결과를 바꾸지 않는다. 중심화 전·후의 β₃는 동일하다. 다만 중심화 후에는 β₁("Z가 평균일 때 X의 효과")과 β₂("X가 평균일 때 Z의 효과")가 의미있는 해석을 가지게 된다. 중심화를 하지 않으면 β₁은 "Z = 0(사회적 지지가 0점)일 때 스트레스의 효과"가 되어버리는데, Z = 0인 사람은 현실에 존재하지 않는다.

#### c. 단순 기울기 분석 (Simple Slopes Analysis)

β₃가 유의하면 "조절이 있다"는 것은 알겠지만, **어느 방향으로, 어느 정도로** 조절이 일어나는지는 모른다. 이를 알기 위해 **단순 기울기 분석**을 한다.

**절차**: Z를 3개 수준으로 나누어 각 수준에서 X의 Y에 대한 기울기를 계산한다.

| Z 수준 | 정의 | X→Y 기울기 (단순 기울기) |
|--------|------|--------------------------|
| Z 낮음 | z̄ − 1SD | β₁ + β₃ × (z̄ − 1SD) |
| Z 평균 | z̄ | β₁ + β₃ × z̄ = β₁ (중심화 후) |
| Z 높음 | z̄ + 1SD | β₁ + β₃ × (z̄ + 1SD) |

각 단순 기울기에 대해 t 검정으로 유의성을 확인한다.

**수치 예시** (β₁ = 0.43, β₃ = -0.23, SD_Z = 8):
```
Z 낮음 (z̄−1SD = 0−8 = -8): 기울기 = 0.43 + (-0.23)×(-8) = 0.43 + 1.84 = 0.62
Z 평균 (z̄ = 0):             기울기 = 0.43 + (-0.23)×0   = 0.43
Z 높음 (z̄+1SD = 0+8 = 8):  기울기 = 0.43 + (-0.23)×8  = 0.43 - 1.84 = -0.18 (비유의)
```

해석: 사회적 지지가 낮을 때(b=0.62) 스트레스의 우울 효과가 가장 크고, 사회적 지지가 높을 때(b=-0.18) 효과가 사라진다 (또는 역전).

**시각화**:
```
[단순 기울기 그래프 (Simple Slopes Plot)]

우울 ↑
 30 │          ·━━━━━━━━━━━━━━━  Z 낮음 (가파름)
    │      ·━━━
    │  ·━━━
 20 │━━━━━━━━━━━━━━━━━━━━━━━  Z 평균
    │━━━━━━━━━━━━━━━━━
 10 │━━━━━━━━━━━━                  Z 높음 (완만/평탄)
    │
    └─────────────────────────
      낮음     평균     높음     스트레스 →
```

또는 **Johnson-Neyman plot**: Z의 어느 값부터 X의 효과가 유의해지는지/안 해지는지를 연속적으로 보여주는 그래프. PROCESS macro가 자동 생성한다.

#### d. Hayes PROCESS macro Model 1

- 조절 분석의 표준 도구
- SPSS, SAS, R 모두 사용 가능
- 자동으로 단순 기울기 분석 + Johnson-Neyman plot 제공
- 논문 보고: "Moderation analysis was conducted using Hayes' (2022) PROCESS macro (Model 1)."

> **핵심 납득 포인트**: 상호작용 항 β₃의 유의성만 확인해서는 안 된다. "어느 수준에서 효과가 유의하고 어느 수준에서는 없는가?"를 보여주는 단순 기울기 분석이 세트로 따라와야 한다. 임상적으로 "사회적 지지가 높으면 스트레스의 영향이 없다"는 결론은 개입 전략 개발에 직결된다.

### 3.4 매개와 조절의 결합: 조절된 매개 (Moderated Mediation)

#### 직관부터 시작

> **질문**: "스트레스(X) → 반추(M) → 우울(Y) 경로가 있다고 하자. 이 간접효과(a×b)가 마음챙김 수준(Z)에 따라 다를까? 마음챙김이 높은 사람은 스트레스를 받아도 반추가 덜 일어나서 우울이 덜 생기는 것인가?"

**조절된 매개**: 간접효과 자체가 조절변수 Z에 따라 달라지는 것

```
[조절된 매개의 구조]

경우 1: Z가 a 경로를 조절할 때 (Hayes Model 7)
   Z
   ↓ (조절)
X ──────→ M ──→ Y

   Z가 높으면 a가 작아짐 → 간접효과 a×b도 작아짐

경우 2: Z가 b 경로를 조절할 때 (Hayes Model 14)
X ──→ M ──────→ Y
         ↑ (조절)
         Z

   Z가 높으면 b가 작아짐 → 간접효과 a×b도 작아짐
```

**검정 방법**: 부트스트래핑으로 **조절된 매개 지수 (Index of Moderated Mediation)** 를 계산한다.
- 지수의 95% 부트스트랩 신뢰구간이 0을 포함하지 않으면 → 조절된 매개 유의

| Hayes PROCESS Model | 분석 유형 |
|---------------------|-----------|
| Model 1 | 조절 분석 (단순) |
| Model 4 | 매개 분석 (단순) |
| Model 7 | 조절된 매개 (a 경로 조절) |
| Model 14 | 조절된 매개 (b 경로 조절) |
| Model 6 | 이중 매개 (X→M₁→M₂→Y) |

> **핵심 납득 포인트**: 조절된 매개는 "개입의 누구에게"를 답한다. "마음챙김을 높이는 개입이 스트레스-우울 경로를 차단한다"면, 마음챙김이 낮은 고위험 집단에게 마음챙김 훈련을 우선 적용해야 한다는 임상적 결론이 나온다.

## 4. 수식 정리

### 기호 약속

```
X        : 독립변수 (예측변수, predictor)
M        : 매개변수 (mediator)
Z        : 조절변수 (moderator)
Y        : 종속변수 (outcome)

경로 a   : X → M의 회귀계수 (X가 M을 예측하는 정도)
경로 b   : M → Y의 회귀계수, X 통제 (M이 Y를 예측하는 정도)
경로 c   : X → Y의 총 효과 (M 없을 때)
경로 c'  : X → Y의 직접 효과 (M 통제 후)

a×b      : 간접효과 (indirect effect)
β₃       : 상호작용 계수 (조절 분석)
X'       : 중심화된 X = X − x̄
Z'       : 중심화된 Z = Z − z̄
```

### 핵심 수식

```
■ 매개 분석 경로 방정식

  1단계 (총 효과):    Y = β₀ + cX + ε₁
  2단계 (a 경로):     M = β₀ + aX + ε₂
  3단계 (b, c' 경로): Y = β₀ + bM + c'X + ε₃

■ 효과 분해
  총 효과   c  = 직접 효과 c' + 간접 효과 a×b
  간접 효과    = a × b

  예시: c = 0.33, c' = 0.12, a×b = 0.21
       0.33 = 0.12 + 0.21  (확인)

■ 부트스트래핑 간접효과 검정
  H₀: a×b = 0
  95% Bootstrap CI: [LL, UL]
  유의 기준: LL > 0 또는 UL < 0 (CI가 0을 포함하지 않음)

  예: [0.09, 0.35] → 유의
  예: [-0.03, 0.25] → 비유의

■ 조절 분석 모형 (중심화 후)
  Y = β₀ + β₁X' + β₂Z' + β₃(X'×Z') + ε

  β₃ 해석: X가 1단위 증가할 때 X의 효과가 Z 1단위 증가에 따라 β₃만큼 변한다

■ 단순 기울기 공식
  Z = z_수준 일 때, X의 Y에 대한 기울기:
  단순 기울기 = β₁ + β₃ × z_수준

  z_낮 = z̄' − 1SD_Z (중심화 후 −1SD)
  z_평균 = 0 (중심화 후 평균)
  z_높 = z̄' + 1SD_Z (중심화 후 +1SD)
```

### 완전 손계산 예시 1: 매개 분석 (n = 100 가상 데이터 요약)

**연구 설계**: 스트레스(X) → 수면 장애(M) → 우울(Y), n = 100명

```
[단계별 회귀 결과]

1단계: Y ~ X  (총 효과)
  우울 = 3.20 + 0.33 × 스트레스
  c = 0.33, t(98) = 4.21, p < .001  → 1단계 통과

2단계: M ~ X  (a 경로)
  수면 장애 = 2.10 + 0.54 × 스트레스
  a = 0.54, SE = 0.09, t(98) = 5.96, p < .001  → 2단계 통과

3단계+4단계: Y ~ M + X  (b, c' 경로)
  우울 = 1.82 + 0.38 × 수면 장애 + 0.12 × 스트레스
  b  = 0.38, SE = 0.07, t(97) = 5.35, p < .001  → 3단계 통과
  c' = 0.12, SE = 0.10, t(97) = 1.21, p = .230  → 4단계: c'가 비유의

[효과 분해]
  간접 효과 = a × b = 0.54 × 0.38 = 0.2052 ≈ 0.21
  직접 효과 c' = 0.12
  총 효과  c  = 0.12 + 0.21 = 0.33  (확인: c와 일치)

[부트스트래핑 결과]
  간접 효과 = 0.21, SE = 0.07
  Bootstrap 95% CI [0.09, 0.35]  → 0을 포함하지 않음 → 유의

[결론]
  수면 장애가 스트레스와 우울의 관계를 완전 매개한다.
  (c' = 0.12, p = .230 → 직접 효과 비유의 → 완전 매개)
```

### 완전 손계산 예시 2: 조절 분석 (중심화 포함)

**연구 설계**: X = 스트레스, Z = 사회적 지지, Y = 우울, n = 100명
x̄ = 20, z̄ = 36, SD_Z = 8

```
[중심화]
  X' = X − 20,   Z' = Z − 36

[조절 분석 회귀 결과]
  우울 = 14.20 + 0.43×X' + (−0.31)×Z' + (−0.23)×(X'×Z')

  β₁ = 0.43  (p < .001): Z 평균일 때 스트레스의 효과
  β₂ = -0.31 (p = .002): X 평균일 때 사회적 지지의 효과
  β₃ = -0.23 (p = .012): 상호작용 계수 → 조절 있음!
  ΔR² = .04: 상호작용 항 추가로 설명력 4% 증가

[단순 기울기 계산]
  SD_Z' = 8 (중심화 후 SD는 동일)

  Z 낮음 (Z' = -8):  기울기 = 0.43 + (-0.23)×(-8) = 0.43 + 1.84 = 0.62
                     t = ?, p < .001 → 유의
  Z 평균 (Z' = 0):   기울기 = 0.43 + (-0.23)×0   = 0.43
                     t = ?, p < .001 → 유의
  Z 높음 (Z' = +8):  기울기 = 0.43 + (-0.23)×(8) = 0.43 - 1.84 = -0.18 (≈ 0.18)
                     p = .124 → 비유의

[해석]
  사회적 지지가 낮을 때: 스트레스가 1점 오를수록 우울이 평균 0.62점 오름 (유의)
  사회적 지지가 평균일 때: 스트레스가 1점 오를수록 우울이 평균 0.43점 오름 (유의)
  사회적 지지가 높을 때: 스트레스와 우울의 관계가 유의하지 않음 (p = .124)
  → 사회적 지지가 스트레스의 우울 효과를 완충한다 (buffering effect)
```

## 5. 심리학 연구 맥락 연결

### 시나리오 A: 매개 분석 — PTSD와 인지적 회피

> 임상심리 연구자가 외상 경험이 PTSD 증상에 영향을 미치는 메커니즘을 탐색한다. 가설: "외상 경험(X)이 인지적 회피(M)를 증가시키고, 인지적 회피가 PTSD 증상(Y)을 악화시킨다." n = 150명의 재난 생존자.

**사용 척도**:
- X: 외상 경험 유무 (0/1) 또는 외상 심각도 척도 (Trauma Severity Index)
- M: 인지적 회피 척도 (Cognitive Avoidance Questionnaire, CAQ)
- Y: PCL-5 (PTSD Checklist for DSM-5, 0~80점)

**가상 분석 결과**:
- a = 0.61 (외상 → 인지적 회피): t(148) = 7.32, p < .001
- b = 0.44 (인지적 회피 → PCL-5, 외상 통제): t(147) = 5.89, p < .001
- c' = 0.18 (외상 → PCL-5 직접 효과): t(147) = 2.01, p = .046
- 간접 효과 = 0.61 × 0.44 = 0.27, Bootstrap 95% CI [0.14, 0.42]

**결론**: 인지적 회피가 외상과 PTSD의 관계를 **부분 매개**한다.
- 직접 효과(c' = 0.18)가 여전히 유의 → 완전 매개가 아닌 부분 매개
- 간접 효과 유의 → 인지적 회피가 경로의 일부

**임상적 함의**:
- 인지적 회피를 감소시키는 치료(예: 장기 노출 치료 PE, 인지처리치료 CPT)가 PTSD 치료에 효과적일 수 있다
- 외상과 PTSD의 직접 경로도 존재하므로, 인지적 회피 외에 다른 메커니즘도 탐색이 필요하다

### 시나리오 B: 조절 분석 — 마음챙김의 완충 효과

> 상담심리 연구자가 범불안 증상(X)이 삶의 질(Y)에 미치는 부정적 영향을 마음챙김(Z)이 조절하는지 탐색한다. 가설: "마음챙김 수준이 높을수록 불안의 삶의 질 저하 효과가 약화된다." n = 200명의 대학생.

**사용 척도**:
- X: GAD-7 (Generalized Anxiety Disorder Scale, 0~21점), 중심화 처리
- Z: MAAS (Mindful Attention Awareness Scale, 15~90점), 중심화 처리
- Y: WHOQOL-BREF (세계보건기구 삶의 질 척도, 0~100점)

**가상 분석 결과**:
- β₁ = −0.48 (GAD-7 주효과, Z 평균일 때): "불안이 1점 높을수록 삶의 질이 0.48점 낮다", p < .001
- β₂ = +0.32 (MAAS 주효과, X 평균일 때): "마음챙김이 1점 높을수록 삶의 질이 0.32점 높다", p < .001
- β₃ = +0.19 (GAD-7 × MAAS): "마음챙김이 높을수록 불안의 삶의 질 저하 효과가 완화된다", p = .008

**단순 기울기 분석**:

| 마음챙김 수준 | 불안 → 삶의 질 기울기 | 유의성 |
|---------------|----------------------|--------|
| 낮음 (M-1SD) | -0.73 | p < .001 |
| 평균 (M) | -0.48 | p < .001 |
| 높음 (M+1SD) | -0.23 | p = .089 |

**임상적 함의**:
- 마음챙김이 높은 대학생은 불안이 높아도 삶의 질이 크게 저하되지 않는다
- 마음챙김 기반 스트레스 감소(MBSR) 프로그램이 고불안 학생에게 우선적으로 필요하다
- 마음챙김 수준이 낮은 집단이 불안에 가장 취약하므로, 이 집단을 표적으로 한 예방 개입이 필요하다

### 연습 질문 1: Excerpt 1에서 완전 매개로 결론 내린 근거는?

**모범 답안**:

완전 매개의 기준은 "M(반추)을 통제한 후 X(스트레스)의 Y(우울)에 대한 직접 효과(c')가 유의하지 않아야 한다"는 것이다.

발췌문에서:
- M을 통제하기 전 총 효과 c는 언급되지 않았지만, 간접효과(0.21) + 직접효과(0.12) = 0.33으로 추산 가능
- M(반추)을 통제한 후 직접 효과 c' = 0.12, p = .230 → **p > .05이므로 비유의**
- 이는 "스트레스가 반추를 거치지 않고 우울에 직접 영향을 미치는 경로가 통계적으로 0에 가깝다"는 의미다

따라서 **완전 매개**: 스트레스의 우울 효과 전체가 반추를 통해 전달된다고 볼 수 있다.

**주의**: "완전 매개"는 c' = 0이 확실하다는 뜻이 아니라, 표본에서 c'가 유의하지 않았다는 통계적 결론이다. 표본 크기가 작으면 c' = 0.12도 "비유의"로 나올 수 있으므로, 결론 시 신중한 표현이 필요하다.

---

### 연습 질문 2: a×b = 0.21의 신뢰구간이 0을 포함하지 않는 것의 의미는?

**모범 답안**:

95% Bootstrap CI [0.09, 0.35]는 두 가지를 의미한다:

**통계적 의미**: 간접효과의 진짜 모집단값이 "95% 신뢰구간" [0.09, 0.35] 안에 있을 가능성이 높다. 구간의 하한(0.09)이 0보다 크므로 간접효과는 **양(+)의 방향으로 유의미하게 0과 다르다**. 즉, H₀: a×b = 0을 기각한다.

**실질적 의미**: 스트레스가 반추를 통해 우울에 미치는 간접효과는 최소 0.09에서 최대 0.35 사이에 있을 것으로 추정된다. 간접효과가 0이 아님이 통계적으로 지지된다.

**왜 신뢰구간을 사용하는가?** 간접효과 a×b의 표집분포는 정규분포를 따르지 않으므로(비대칭), 전통적인 z 검정(Sobel test)은 부정확하다. 부트스트래핑은 수천 번의 재표집으로 실제 분포를 추정하여 더 정확한 신뢰구간을 제공한다.

---

### 연습 질문 3: Excerpt 2에서 β₃ = -0.23의 해석은?

**모범 답안**:

β₃ = -0.23 (상호작용 계수, Stress × Social Support)의 해석:

"사회적 지지가 1단위 높아질 때, 스트레스의 우울에 대한 효과(기울기)가 0.23만큼 감소한다."

더 구체적으로:
- β₃가 음수(-0.23)이므로: 사회적 지지가 **높을수록** 스트레스의 우울 증가 효과가 **약해진다**
- p = .012 < .05이므로 이 조절 효과는 통계적으로 유의미하다

이것은 **버퍼링 효과(buffering effect)**: 사회적 지지가 스트레스와 우울 사이의 관계를 완충한다는 가설을 지지한다.

단순 기울기 분석에서 이를 구체적으로 확인할 수 있다:
- 사회적 지지 낮을 때: 기울기 = 0.62 (스트레스의 우울 효과 강함)
- 사회적 지지 높을 때: 기울기 = 0.18, p = .124 (비유의 → 효과 사라짐)

---

### 연습 질문 4: "ΔR² = .04"는 무엇을 의미하는가?

**모범 답안**:

ΔR² (Delta R-squared, R² 변화량)는 **상호작용 항(Stress × Social Support)을 모형에 추가했을 때 설명력이 얼마나 증가했는가**를 나타낸다.

분석 순서:
```
모형 1: Y ~ X + Z (주효과만)             → R²_1 (기본 설명력)
모형 2: Y ~ X + Z + X×Z (상호작용 항 추가) → R²_2
ΔR² = R²_2 − R²_1 = .04
```

해석: 상호작용 항(X×Z)을 추가함으로써 우울 분산의 **추가 4%**를 설명하게 되었다.

**효과크기 판단** (Cohen, 1988):
- ΔR² = .02: 작은 효과
- ΔR² = .13: 중간 효과
- ΔR² = .04: 작은 효과에 해당

따라서 ΔR² = .04는 통계적으로 유의하지만(p = .012) 효과크기는 작다. 조절 효과의 크기 자체는 크지 않으나, 사회적 지지가 스트레스-우울 관계를 조절한다는 증거는 확보되었다.

---

### 연습 질문 5: "High social support에서 관계가 유의하지 않다"는 것이 어떤 임상적 함의를 갖는가?

**모범 답안**:

"사회적 지지가 높은 수준일 때 스트레스와 우울의 관계가 유의하지 않다(b = 0.18, p = .124)"는 다음과 같은 임상적 함의를 갖는다:

**1. 보호요인으로서의 사회적 지지**:
높은 사회적 지지는 스트레스가 우울로 이어지는 경로를 차단한다. 사회적 지지가 충분한 사람은 스트레스를 경험해도 우울로 발전하지 않을 수 있다.

**2. 개입 대상 선정**:
사회적 지지가 낮은 집단(b = 0.62, 스트레스-우울 효과 가장 큼)이 스트레스에 가장 취약하다. 이 집단을 우선 개입 대상으로 선정해야 한다.

**3. 치료 전략**:
단순히 스트레스 감소(예: 이완 훈련)만 목표로 하는 것보다, 사회적 지지 네트워크 강화를 병행하는 것이 더 효과적일 수 있다. 특히 사회적 지지가 낮은 내담자에게 사회기술 훈련, 지지 집단 개입 등을 추가로 제공해야 한다.

**4. 예방 프로그램 설계**:
학교 상담이나 지역사회 정신건강 프로그램에서, 사회적 지지가 취약한 집단(고립된 학생, 이주민, 독거 노인 등)을 대상으로 예방적 개입을 설계할 수 있다.

## 7. 오개념 경고

> **⚠️ 오개념 1**: "Baron & Kenny 4단계를 모두 충족해야 매개가 증명된다"

이 생각은 1986년 기준이다. 현재 심리학 분야의 표준은 **부트스트래핑 간접효과** 검정이다. Baron & Kenny 1단계(X→Y 유의성)는 더 이상 필요 없다. 1단계에서 X→Y가 유의하지 않아도, 간접효과(a×b)의 부트스트랩 95% CI가 0을 포함하지 않으면 매개가 지지된다. 현재 APA 논문에서 "Baron & Kenny criteria"만으로 매개를 주장하면 심사자들로부터 이의가 제기될 수 있다. Hayes(2022), MacKinnon et al.(2004) 등을 참조하라.

---

> **⚠️ 오개념 2**: "매개와 조절을 같은 분석으로 동시에 검정하면 된다"

매개와 조절은 **완전히 다른 연구 질문**을 다루며, 다른 분석 방법이 필요하다. "매개 분석을 하면 조절도 알 수 있다"는 생각은 틀렸다. 조절된 매개(moderated mediation)는 두 분석을 결합한 별도의 분석(Hayes PROCESS Model 7 또는 14)이 필요하며, 이를 위한 별도의 가설과 해석 기준이 있다. 연구 질문을 먼저 명확히 하고, 그에 맞는 분석 방법을 선택해야 한다.

---

> **⚠️ 오개념 3**: "직접 효과가 사라지면 M이 Y의 원인임이 증명된다"

**매개도 상관 ≠ 인과**이다. 부트스트래핑으로 간접효과를 통계적으로 확인해도, M이 Y의 인과적 원인임을 주장할 수는 없다. 횡단 설계에서는 X → M → Y의 방향이 아니라 M → X → Y, 또는 제3의 혼재변수가 X, M, Y를 모두 유발할 수 있다. 인과적 매개(causal mediation)를 주장하려면 무선 배정 실험 또는 종단 설계가 필요하다.

---

> **⚠️ 오개념 4**: "부트스트래핑을 1,000번만 해도 충분하다"

현재 권장 기준은 **최소 5,000번 (일반적으로 5,000~10,000번)** 이다. 표본이 작을수록(n < 100), 간접효과가 작을수록 더 많은 재표집이 필요하다. 1,000번으로는 신뢰구간이 불안정하여 반복 실행 시 결과가 달라질 수 있다. Hayes PROCESS의 기본값은 5,000번이며, 논문에는 "5,000 bootstrap samples"라고 반드시 명시해야 한다.

---

> **⚠️ 오개념 5**: "조절 분석에서 중심화는 선택사항이다"

중심화는 **필수**다. 중심화 없이 X×Z 항을 만들면, X×Z는 X 및 Z와 극도로 높은 상관을 가지게 되어 다중공선성이 심각해진다. 이 경우 β₁, β₂의 추정치가 불안정하고 해석 불가능해진다. VIF(분산팽창지수)가 10 이상으로 치솟을 수 있다. 중심화는 X×Z 항 자체의 해석에는 영향을 주지 않으면서(β₃는 동일), 주효과 해석을 의미있게 만들고 다중공선성을 해소한다.

---

> **⚠️ 오개념 6**: "PROCESS macro가 없으면 매개·조절 분석을 할 수 없다"

PROCESS macro는 편의 도구이지, 유일한 방법이 아니다. 동일한 분석을 다양한 방법으로 수행할 수 있다:
- **R**: `mediation` 패키지, `lavaan` 패키지 (구조방정식 기반), `processR` 패키지
- **Python**: `pingouin`, `semopy`
- **SPSS**: 내장 매크로 기능, 또는 lavaan의 R 연동
- **Mplus**: 구조방정식 기반으로 더 유연한 매개·조절 모형 가능

다만 Hayes PROCESS가 APA 논문에서 가장 많이 인용되고, 임상/상담심리 분야에서 표준처럼 사용되므로, 논문을 읽을 때 "PROCESS macro (Model 4)"라는 표현에 익숙해지는 것이 중요하다.

---

> **⚠️ 오개념 7**: "조절 효과 ΔR² = .04는 작으니 의미없다"

조절 효과는 일반적으로 작은 효과크기(ΔR² = .01~.05)를 보이는 경향이 있으며, 이는 심리학에서 정상적이다. Frazier et al.(2004)에 따르면, 상호작용 효과는 주효과보다 일반적으로 작게 나타난다. ΔR² = .04가 통계적으로 유의하고(p = .012), 임상적으로 의미있는 조절 패턴(사회적 지지 높음 → 스트레스 효과 없음)을 보인다면, 효과크기가 작아도 중요한 발견이다. 효과크기만으로 임상적 유의성을 판단하지 말 것.

---

## 8. 자기점검

### 페인만 기법 — 개념을 완전히 이해했는지 확인

**질문 1**: "매개 분석에서 c = c' + a×b라는 공식의 의미를 직관적으로 설명하라."

힌트: c는 M을 모르는 상태에서 X → Y의 전체 효과이고, c'는 M을 아는 상태에서의 효과다. a×b는 무엇인가?

모범 설명:
```
c  = 총 효과: X만 보고 Y를 예측할 때의 효과 (M의 존재를 모름)
c' = 직접 효과: M을 알고 나서도 여전히 X가 Y에 주는 효과 (M을 통제)
a×b = 간접 효과: X가 M을 경유하여 Y에 주는 효과
c = c' + a×b
→ X가 Y에 미치는 총 영향 = 직접 경로 + M을 통한 간접 경로
예: c=0.33 = c'=0.12 + a×b=0.21
```

**질문 2**: "조절 분석에서 상호작용 항 β₃를 해석할 때 '단순 기울기 분석'이 왜 필요한가?"

힌트: β₃가 유의하다는 것은 "조절이 있다"는 것만 알 뿐이다. 구체적으로 무엇을 더 알아야 하는가?

모범 설명:
```
β₃ = -0.23, p = .012라는 것만으로는:
  - X의 효과가 Z에 따라 다르다는 것은 알지만
  - Z가 낮을 때 X의 효과가 얼마인지 (0.62?)
  - Z가 높을 때 X의 효과가 유의한지 (p=.124?)
  → 이것을 모른다!

단순 기울기 분석으로:
  - 각 Z 수준에서 X의 기울기와 유의성을 계산
  - "Z 낮음 → 효과 강함, Z 높음 → 효과 없음"이라는 구체적 패턴 파악
  - 이것이 임상적으로 중요한 정보
```

**질문 3**: "완전 매개와 부분 매개 중 어느 것이 더 좋은 결과인가?"

힌트: 매개 분석의 목적이 무엇인지 생각하라.

모범 설명:
```
"좋고 나쁨"의 문제가 아니라 이론적 예측과의 일치 문제다.

연구자의 이론이 "M이 X-Y 관계를 완전히 설명한다"면 완전 매개가 이론 지지.
이론이 "M도 중요하지만 직접 경로도 있다"면 부분 매개가 이론 지지.

임상적으로:
완전 매개 → M을 제거하면 X-Y 관계도 없어짐 → M만 타겟팅 가능
부분 매개 → M도 중요하지만, M 외의 다른 경로도 타겟팅 필요

→ 둘 다 가치있는 발견. 연구 목적과 이론에 따라 다르다.
```

### 논문 용어 즉시 해석 연습

다음 문장에서 핵심 통계 표현을 한국어로 해석하라:

1. "The indirect effect (a×b = 0.21, 95% CI [0.09, 0.35]) was statistically significant."
   → 간접효과 0.21의 95% 부트스트랩 신뢰구간이 [0.09, 0.35]이며, 0을 포함하지 않으므로 통계적으로 유의하다.

2. "The interaction term was significant (B = −0.23, p = .012, ΔR² = .04), indicating moderation."
   → 상호작용 항이 유의하여(β₃ = -0.23, p = .012), 조절 효과가 있음을 나타낸다. 상호작용 항 추가로 설명력이 4% 증가했다.

3. "Simple slopes analysis revealed significant associations at low and average, but not high levels of social support."
   → 단순 기울기 분석 결과, 사회적 지지가 낮은 수준과 평균 수준에서는 유의한 관계가 나타났지만, 높은 수준에서는 유의하지 않았다.

| 상호작용 항 | Interaction Term | "interaction term (X×Z)", "product term" |
| R² 변화량 | Change in R-squared / Delta R-squared | "ΔR² = .04", "R² change" |
| 다중공선성 | Multicollinearity | "VIF", "variance inflation factor" |
| 조절된 매개 지수 | Index of Moderated Mediation | "index of moderated mediation", "IMM" |
| 단순 매개 | Simple Mediation | "simple mediation model", "Model 4" |
| Hayes PROCESS | Hayes PROCESS macro | "PROCESS macro (Model 1/4/7)", "Hayes (2022)" |
| 억제 매개 | Suppressed Mediation | "inconsistent mediation", "suppressor effect" |

## 부록 A: 구조방정식 모형 (SEM) 개요

*이 부록은 Ch.17 매개 분석에서 자연스럽게 이어지는 심화 주제다.*

---

### SEM이란 무엇인가?

**구조방정식 모형 (Structural Equation Modeling, SEM)** 은 여러 개의 회귀 방정식을 동시에 추정하는 분석 방법이다. 매개 분석은 SEM의 특수한 경우다.

```
[매개 분석 vs. SEM 비교]

일반 매개 분석 (Hayes PROCESS):
  1단계: Y ~ X
  2단계: M ~ X
  3단계: Y ~ M + X
  (3개의 별도 회귀를 순서대로 실행)

SEM 매개 분석 (lavaan):
  X → M → Y의 경로를 동시에 추정
  측정 오차를 모형에 포함 가능
  (더 정확하고 유연)
```

### SEM의 두 부분

| 구성 요소 | 명칭 | 내용 |
|-----------|------|------|
| 측정 모형 | Measurement Model | 잠재변수(구성개념)가 관측변수(문항)들로 어떻게 측정되는가 |
| 구조 모형 | Structural Model | 잠재변수들 간의 관계 (경로, 회귀 방향) |

**왜 SEM이 더 강력한가?**
- **잠재변수 (Latent Variable)**: 우울, 불안 같은 심리학 구성개념은 직접 측정할 수 없다. SEM에서는 여러 문항들의 공통 분산을 **잠재변수**로 추출하여, 측정 오차를 통제한 후 분석한다.
- 일반 회귀에서는 척도 점수(관측변수)를 직접 사용하므로 측정 오차가 분석에 포함되어 계수를 약화(attenuation)시킨다.

```
[잠재변수 구조]

                      ┌─ 문항 1 (+ 오차 e₁)
          잠재변수    ├─ 문항 2 (+ 오차 e₂)
         "우울"(F) ──┼─ 문항 3 (+ 오차 e₃)
                      └─ 문항 4 (+ 오차 e₄)

F: 공통 요인 (우울의 진짜 점수)
eᵢ: 각 문항의 고유 오차 (측정 오차 + 문항 특이성)
```

### SEM과 경로분석 (Path Analysis)

- **경로분석 (Path Analysis)**: 관측변수들 간의 인과 경로를 다이어그램으로 표현하고 동시에 추정. SEM에서 측정 오차를 무시한 특수 경우
- 매개 분석은 경로분석의 기본 형태
- SEM은 경로분석 + 측정 모형을 통합한 것

### SEM 적합도 지수 읽기

SEM 결과에는 모형 적합도를 나타내는 여러 지수가 보고된다:

| 지수 | 권장 기준 | 의미 |
|------|-----------|------|
| CFI (Comparative Fit Index) | ≥ .95 | 기저 모형 대비 적합도 |
| TLI (Tucker-Lewis Index) | ≥ .95 | CFI의 보정판 |
| RMSEA | ≤ .06 | 근사 오차 (낮을수록 좋음) |
| SRMR | ≤ .08 | 표준화 잔차 평균 제곱근 |
| χ² / df | < 3 | 모형이 데이터를 얼마나 잘 재현하는가 |

**논문에서 자주 보이는 표현**: "The model demonstrated acceptable fit: χ²(14) = 23.4, p = .054, CFI = .97, TLI = .96, RMSEA = .05, SRMR = .04."

## 부록 B: Hayes PROCESS Macro 사용 안내

### PROCESS란?

Andrew Hayes(오하이오 주립대)가 개발한 매개·조절·조절된 매개 분석 전용 SPSS/SAS 매크로.
현재 R 버전(`processR` 패키지)도 제공.

참고문헌: Hayes, A. F. (2022). *Introduction to mediation, moderation, and conditional process analysis* (3rd ed.). Guilford Press.

### 모델 번호 체계

PROCESS는 92가지 사전 정의된 분석 모형을 번호로 관리한다:

```
Model 1:  조절 분석 (단순)
          Y = f(X, Z, X×Z)

Model 4:  단순 매개 분석
          X → M → Y

Model 6:  이중 매개 분석
          X → M₁ → M₂ → Y

Model 7:  조절된 매개 (a 경로 조절)
          Z가 X→M 경로를 조절

Model 14: 조절된 매개 (b 경로 조절)
          Z가 M→Y 경로를 조절

Model 58: 조절된 이중 매개 등
```

### SPSS에서 PROCESS 실행 방법

```
[SPSS 명령문 예시 — Model 4 (단순 매개)]

PROCESS
  /y = depression
  /x = stress
  /m = rumination
  /model = 4
  /boot = 5000
  /conf = 95.

[결과 읽기]
  a:    X→M 계수 (스트레스→반추)
  b:    M→Y 계수 (반추→우울, X 통제)
  c':   직접 효과 (X→Y, M 통제)
  c:    총 효과 (X→Y)

  INDIRECT EFFECTS:
    Effect  SE  LLCI  ULCI
    0.21    0.07  0.09  0.35  ← 이 행이 핵심
    (0을 포함하지 않음 → 유의)
```

### R에서 lavaan으로 매개 분석

```r
# 패키지 설치
install.packages("lavaan")
library(lavaan)

# 매개 모형 명세
model <- '
  # a 경로: X → M
  rumination ~ a * stress

  # b, c 경로: M → Y, X → Y
  depression ~ b * rumination + c_prime * stress

  # 간접 효과 정의
  indirect := a * b
  total    := c_prime + a * b
'

# 모형 추정 (부트스트래핑)
fit <- sem(model, data = mydata, se = "bootstrap", bootstrap = 5000)

# 결과 확인
summary(fit, fit.measures = TRUE)
parameterEstimates(fit, ci = TRUE, boot.ci.type = "bca.simple")
```
