### 3.1 기본 개념

#### 직관부터 시작

> **질문**: "이 치료가 효과 있을 확률은?" — '확률'이라는 단어를 우리는 매일 쓴다. 이제 수학적으로 정의하자.

확률은 **불확실한 상황에서 어떤 결과가 얼마나 가능한지**를 0과 1 사이의 숫자로 표현하는 것이다.

#### 핵심 용어 정의

| 개념                                 | 정의                         | 예시                                                               |
| ------------------------------------ | ---------------------------- | ------------------------------------------------------------------ |
| **실험 (experiment)**          | 결과가 불확실한 시행         | CBT 1회기 후 내담자 반응 관찰                                      |
| **표본공간 (sample space, S)** | 가능한 모든 결과의 집합      | S = {호전, 무반응, 악화}                                           |
| **사건 (event, A)**            | 표본공간의 부분집합          | A = {호전}                                                         |
| **합사건 (A∪B)**              | A 또는 B가 발생              | A = {호전}, B = {무반응} → A∪B = {호전, 무반응}                  |
| **교사건 (A∩B)**              | A와 B가 동시 발생            | A = {CBT 참여}, B = {증상 개선} → A∩B = {CBT 참여이고 증상 개선} |
| **여사건 (Aᶜ)**               | A가 발생하지 않음            | A = {호전}이면 Aᶜ = {무반응, 악화}                                |
| **상호배타 사건**              | A∩B = ∅ (동시에 발생 불가) | A = {호전}, B = {악화}                                             |

#### ASCII 벤다이어그램

```
[합사건 A∪B]              [교사건 A∩B]              [여사건 Aᶜ]

 ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
 │  S              │       │  S              │       │  S              │
 │  ┌───┐ ┌───┐    │       │  ┌───┬───┐      │       │  ┌───────────┐  │
 │  │ A │∪│ B │    │       │  │ A │A∩B│ B    │       │  │     Aᶜ    │  │
 │  │▓▓▓│ │▓▓▓│    │       │  │   │▓▓▓│      │       │  │  ┌─────┐  │  │
 │  └───┘ └───┘    │       │  └───┴───┘      │       │  │  │  A  │  │  │
 │  (A 또는 B)      │       │  (A 그리고 B)     │       │  │  └─────┘  │  │
 └─────────────────┘       └─────────────────┘       └─────────────────┘
```

> **핵심 납득 포인트**: 표본공간(S), 사건(A, B), 교사건(A∩B)은 분할표의 구조와 정확히 대응된다. 분할표의 각 칸이 교사건이고, 행·열 합계가 합사건이다. 즉 Ch.2에서 이미 확률의 언어를 사용한 셈이다.

### 3.2 확률의 이해

#### 3.2.1 고전적 확률 (Classical Probability)

**직관**: "모든 결과가 동등하게 가능하다면, 원하는 결과의 비율이 곧 확률이다."

```
P(A) = A에 속하는 경우의 수 / S의 총 경우의 수
```

- **조건**: 모든 결과가 동등하게 가능(equally likely)해야 한다
- **임상 예시**: 외래 환자 4명 중 무작위로 1명 선택. 진단명이 MDD, GAD, PTSD, OCD 각 1명.
  ```
  P(MDD) = 1/4 = .25
  P(MDD 또는 GAD) = 2/4 = .50
  ```

> **핵심 납득 포인트**: 고전적 확률은 "직접 세는 것"이다. 모든 결과가 동등하게 가능하다는 가정이 현실에서는 성립하지 않는 경우가 많다 — 심리 현상에서 '완벽한 무작위'는 드물다. 그래서 두 번째 접근이 필요하다.

---

#### 3.2.2 상대도수의 극한 개념 (Long-run Relative Frequency)

**직관**: 동전을 1000번 던지면 앞면이 약 0.5에 수렴한다. **많이 반복할수록** 관찰 비율이 어떤 값에 가까워진다. 그 극한값이 확률이다.

```
P(A) = lim(n→∞) [A 발생 횟수 / n]
```

- **임상 연결**: "CBT의 치료 성공률"은 이론적으로 무한히 많은 환자에게 CBT를 적용했을 때의 장기 성공 비율이다. 우리가 논문에서 보는 "성공률 72%"는 표본에서의 추정치다.

```
[수렴 직관]
10번 시행:  앞면 6번 → 0.6  (아직 불안정)
100번:      앞면 52번 → 0.52
1000번:     앞면 501번 → 0.501
10000번:    앞면 4993번 → 0.4993  ← 0.5에 수렴
```

> **핵심 납득 포인트**: 임상 연구의 "효과 크기"나 "치료 반응률"은 이 장기적 상대도수의 추정치다. 작은 표본(n = 20)에서 나온 "90% 성공률"은 불안정한 추정이다. 표본이 클수록 추정이 안정된다.

---

#### 3.2.3 확률의 공리 (Axioms of Probability, Kolmogorov)

수학자 콜모고로프는 1933년 확률의 정의를 3가지 공리로 정립했다. 어떤 확률도 이 3가지를 만족해야 한다.

| 공리             | 수식                                        | 의미                            |
| ---------------- | ------------------------------------------- | ------------------------------- |
| **공리 1** | 0 ≤ P(A) ≤ 1                              | 확률은 0 이상 1 이하            |
| **공리 2** | P(S) = 1                                    | 전체 표본공간의 확률은 반드시 1 |
| **공리 3** | A와 B가 상호배타이면, P(A∪B) = P(A) + P(B) | 겹치지 않으면 그냥 더한다       |

> **핵심 납득 포인트**: 3개 공리만으로 확률론 전체가 유도된다. "치료 성공 확률이 1.2이다"는 공리 1 위반. "모든 진단의 확률을 더했는데 0.8이다"는 공리 2 위반. 공리가 위반되면 그것은 확률이 아니다.

### 3.3 확률의 기본정리

#### 여사건 법칙 (Complement Rule)

**직관**: "이 치료에서 성공하지 않을 확률"은 "1에서 성공 확률을 뺀 것"이다.

```
P(Aᶜ) = 1 − P(A)
```

- 예: CBT 성공 확률이 P(성공) = .72이면, P(비성공) = 1 − .72 = .28
- 논문에서: "the probability of dropout was 1 − .78 = .22"

---

#### 덧셈법칙 (Addition Rule)

**직관**: "A 또는 B가 일어날 확률"을 구하고 싶다. P(A)와 P(B)를 더하면 되는가? — **안 된다.** A∩B (둘 다 해당하는 경우)를 두 번 세게 된다.

```
일반 덧셈법칙:  P(A∪B) = P(A) + P(B) − P(A∩B)

특수 경우 (상호배타):  P(A∩B) = 0이므로
                       P(A∪B) = P(A) + P(B)
```

**손계산 예시** (분할표 데이터, n = 100):

|                   | MDD 있음     | MDD 없음     | 행 합계       |
| ----------------- | ------------ | ------------ | ------------- |
| **여성**    | 30           | 20           | **50**  |
| **남성**    | 20           | 30           | **50**  |
| **열 합계** | **50** | **50** | **100** |

```
A = "여성",  B = "MDD 있음"

P(A)     = 50/100 = .50
P(B)     = 50/100 = .50
P(A∩B)  = 30/100 = .30  ← 여성이면서 MDD인 경우

P(A∪B)  = .50 + .50 − .30 = .70

해석: "여성이거나 MDD가 있을 확률" = .70
     → 100명 중 70명이 여성이거나 MDD가 있다 (또는 둘 다)
```

> **핵심 납득 포인트**: P(A) + P(B)만 계산하면 .50 + .50 = 1.00이 나온다. 이것은 "모든 사람이 여성이거나 MDD"라는 뜻이 되어 틀렸다. A∩B를 뺌으로써 이중 계산을 수정한다.

### 3.4 조건부확률 (Conditional Probability)

#### 직관부터 시작

> **질문**: "CBT에 참여했다는 것을 알 때, 이 사람의 증상이 개선될 확률은?"

"이미 어떤 정보를 알고 있을 때, 확률이 어떻게 바뀌는가?" — 이것이 **조건부확률**의 핵심이다.

```
P(B | A) = P(A∩B) / P(A)

읽는 법: "A가 주어졌을 때 B의 확률"
         "A라는 조건 하에서 B가 일어날 확률"
```

- **P(B | A)**: A가 발생했다고 알고 있는 상황에서, B가 발생할 확률
- 분모가 P(A)인 이유: A가 발생했다는 사실이 알려졌으므로, 표본공간이 S에서 A로 축소된다

**임상 예시**: 위 분할표에서

```
P(MDD | 여성) = P(여성 ∩ MDD) / P(여성)
              = (.30) / (.50)
              = .60

해석: "여성이라는 것을 알 때, MDD일 확률 = .60"
     → 여성 50명 중 30명이 MDD이므로 30/50 = .60 (직접 계산과 일치)

P(MDD | 남성) = P(남성 ∩ MDD) / P(남성)
              = (.20) / (.50)
              = .40
```

> **핵심 납득 포인트**: 조건부확률은 "분모를 바꾸는 것"이다. 전체 100명이 아니라, 조건에 해당하는 50명만 보는 것이다. 정보를 알게 되면 표본공간이 줄어든다 — 이것이 조건부확률의 직관이다.

---

#### 2×2 분할표로 조건부확률 읽기

2×2 분할표는 두 범주형 변수를 동시에 정리한 표다. 조건부확률은 "한 행(또는 열)만 보기"로 바로 계산된다.

**가상 데이터**: 8주간 CBT 프로그램 참여 여부 × 우울 증상 개선 여부 (BDI-II 기준), n = 200

|                     | 증상 개선    | 증상 지속     | 행 합계       |
| ------------------- | ------------ | ------------- | ------------- |
| **CBT 참여**  | 60           | 20            | **80**  |
| **대기 통제** | 10           | 110           | **120** |
| **열 합계**   | **70** | **130** | **200** |

```
P(증상 개선 | CBT 참여)   = 60/80  = .750
  → "CBT에 참여한 사람 중 증상이 개선된 비율"

P(증상 개선 | 대기 통제) = 10/120 ≈ .083
  → "대기 통제 집단 중 증상이 개선된 비율"

P(CBT 참여 | 증상 개선)  = 60/70  ≈ .857
  → "증상이 개선된 사람 중 CBT에 참여했던 비율"

P(대기 통제 | 증상 지속) = 110/130 ≈ .846
  → "증상이 지속된 사람 중 대기 통제에 속했던 비율"
```

분모에 주목한다. P(증상 개선 | CBT 참여)의 분모는 전체 200명이 아니라 **CBT 참여 80명**이다. 조건을 주면 표본공간이 그 조건에 해당하는 행(또는 열)으로 좁아진다.

---

#### 곱셈법칙 (Multiplication Rule)

조건부확률 정의를 변환하면:

```
P(A∩B) = P(A) × P(B | A)

해석: "A와 B 둘 다 일어날 확률"
    = "A가 일어날 확률" × "A가 일어난 후 B가 일어날 확률"
```

---

### 3.5 독립사건 (Independent Events)

#### 직관부터 시작

> **질문**: "환자 A의 치료 반응이 환자 B의 치료 반응에 영향을 주는가?"

**독립**이란: A가 발생했는지 여부가 B의 확률에 **아무 영향을 미치지 않는** 것이다.

```
독립의 정의:  P(B | A) = P(B)
              "A가 주어졌을 때 B의 확률"이
              "조건 없는 B의 확률"과 같다

동치 조건:    P(A∩B) = P(A) × P(B)
```

**종속**이란: A가 발생했는지 여부가 B의 확률을 **바꾸는** 것이다. 즉, P(B | A) ≠ P(B). 종속이 강할수록 A를 아는 것이 B에 대한 더 많은 정보를 준다.

**위 분할표로 독립성 확인**:

```
P(CBT 참여) = 80/200 = .40
P(증상 개선) = 70/200 = .35
P(CBT 참여 ∩ 증상 개선) = 60/200 = .30

독립이라면: P(CBT 참여) × P(증상 개선) = .40 × .35 = .14
실제:        P(CBT 참여 ∩ 증상 개선)    = .30

.30 ≠ .14 → CBT 참여와 증상 개선은 종속(dependent)
           → 당연히 종속이어야 한다 — 그래야 CBT가 의미 있는 개입이다!
```

**임상적 의미**:

- "두 환자의 치료 반응이 독립적이다" — 같은 치료사에게 치료받은 경우 **독립 가정에 문제가 생길 수 있다.** 치료사의 기술, 태도, 치료적 동맹이 같은 치료사에게 치료받는 모든 환자에게 공통적으로 영향을 미치기 때문이다.

> **핵심 납득 포인트**: 독립성은 통계 분석의 가장 중요한 가정 중 하나다. t검정, ANOVA, 회귀분석 — 거의 모든 통계는 관측치가 서로 독립이라는 가정 위에 세워진다. 이 가정이 깨지면 분석 결과가 왜곡된다.

## 4. 수식 정리

```
=== 기호 약속 ===
S           = 표본공간 (sample space)
A, B        = 사건 (event)
Aᶜ          = A의 여사건
A∪B         = 합사건 (A 또는 B)
A∩B         = 교사건 (A 그리고 B)
P(A)        = 사건 A의 확률
P(B | A)    = 조건부확률 (A 주어졌을 때 B의 확률)
∅           = 공사건 (아무것도 발생하지 않는 사건)

=== 수식 목록 ===

① 고전적 확률
   P(A) = (A에 속하는 경우의 수) / (S의 총 경우의 수)
   조건: 모든 결과가 동등하게 가능(equally likely)

② 여사건 법칙
   P(Aᶜ) = 1 − P(A)
   직관: 전체는 1. 일어나지 않을 확률 = 1 − 일어날 확률

③ 일반 덧셈법칙
   P(A∪B) = P(A) + P(B) − P(A∩B)
   상호배타일 때: P(A∪B) = P(A) + P(B)  [P(A∩B)=0이므로]

④ 조건부확률 정의
   P(B | A) = P(A∩B) / P(A)
   기호 해설: 분자 P(A∩B) = A와 B 둘 다 일어날 확률
             분모 P(A)    = 조건이 되는 사건의 확률

⑤ 곱셈법칙 (조건부확률 변환)
   P(A∩B) = P(A) × P(B | A)
           = P(B) × P(A | B)  [순서 상관없음]

⑥ 독립 조건
   정의:    P(B | A) = P(B)
   동치:    P(A∩B) = P(A) × P(B)
   직관: "A를 알아도 B의 확률이 바뀌지 않는다"

=== 손계산 예시 (n=100 분할표) ===

데이터:  성별(여/남) × MDD 진단(있음/없음)
         여성∩MDD=30, 여성∩MDD없음=20
         남성∩MDD=20, 남성∩MDD없음=30  합계=100

A = "여성",  B = "MDD 있음"

P(A)     = 50/100 = .50
P(B)     = 50/100 = .50
P(A∩B)  = 30/100 = .30

[덧셈법칙]
P(A∪B) = .50 + .50 − .30 = .70
  → "여성이거나 MDD가 있을 확률 = 70%"

[조건부확률]
P(B | A) = P(A∩B) / P(A) = .30 / .50 = .60
  → "여성이라는 조건 하에서 MDD일 확률 = 60%"

[독립성 검토]
P(A) × P(B) = .50 × .50 = .25
P(A∩B) = .30
.30 ≠ .25 → 성별과 MDD 진단은 종속 사건
  → 여성이라는 정보가 MDD 확률을 .50에서 .60으로 높임
```

## 5. 심리학 연구 맥락 연결

### 시나리오 A: 우울과 불안의 공병 — 조건부확률의 방향

임상 장면에서 우울장애(MDD)와 불안장애(GAD)는 종종 함께 나타난다. 공병(comorbidity)을 조건부확률로 정리하면 어떻게 되는가?

**가상 데이터** (임상 내담자 n = 200):

|                    | GAD 있음     | GAD 없음      | 합계          |
| ------------------ | ------------ | ------------- | ------------- |
| **MDD 있음** | 50           | 70            | **120** |
| **MDD 없음** | 10           | 70            | **80**  |
| **합계**     | **60** | **140** | **200** |

```
P(GAD | MDD)      = 50 / 120 ≈ .417
  → "MDD 환자 중 42%가 GAD도 있다"

P(MDD | GAD)      = 50 / 60  ≈ .833
  → "GAD 환자 중 83%가 MDD도 있다"

P(MDD | GAD 없음) = 70 / 140 = .500
  → "GAD가 없는 내담자 중 MDD 비율 = 50%"
  → GAD 유무에 따라 MDD 확률이 달라진다 → 두 장애는 종속
```

**핵심 교훈**: P(GAD | MDD) ≈ .42 ≠ P(MDD | GAD) ≈ .83. 방향이 바뀌면 값이 완전히 달라진다. "MDD 환자의 42%는 GAD도 있다"와 "GAD 환자의 83%는 MDD도 있다"는 같은 데이터에서 나왔지만 전혀 다른 숫자다 — 분모가 다르기 때문이다.

> **중요한 시사점**: 공병률을 보고할 때 방향을 명확히 해야 한다. "MDD 환자에서 GAD 동반율"과 "GAD 환자에서 MDD 동반율"은 같은 연구에서 나오더라도 전혀 다른 숫자다. 논문을 읽을 때 분모가 무엇인지 반드시 확인하라.

### 시나리오 B: 치료 순응과 완주의 조건부확률

CBT 연구에서 치료 탈락 예측을 분석한다.

**연구 질문**: 초기 3주를 지속한 내담자가 전체 치료를 완주할 확률은, 무조건적인 완주 확률보다 높은가?

```
[가상 데이터] n = 150명

P(치료 완주) = 90/150 = .60  ← 전체 완주율

P(초기 3주 지속) = 100/150 = .67
P(완주 ∩ 3주 지속) = 85/150 = .57

P(완주 | 3주 지속) = .57 / .67 ≈ .85

해석: "초기 3주를 지속한 내담자의 완주율 = 85%"
     "전체 완주율 60%"보다 25%p 높다
     → 3주 지속이 완주에 강하게 연관됨 (종속 사건)
```

이 분석은 **치료 연구에서 탈락 예측 모형**의 기초가 된다. 논문에서 "early treatment adherence predicted treatment completion (OR = 4.2, p < .001)"과 같은 문장이 이러한 조건부 확률 차이를 정식 검정한 결과다.

## 6. 논문 스니펫 읽기 실습

다음은 가상의 논문 Methods/Results 절 일부다. 읽고 질문에 답하라.

---

*"A randomized controlled trial enrolled 200 adults with moderate-to-severe depression (BDI-II ≥ 20). Participants were assigned to either an 8-week group CBT program (n = 80) or a waitlist control condition (n = 120). Clinical improvement was defined as a ≥ 50% reduction in BDI-II score at week 8. Of the CBT group, 60 (75%) met the improvement criterion. Of the waitlist group, 10 (8.3%) met the criterion."*

---

**분할표 구성** (먼저 직접 그려보고 아래와 비교하라):

|                     | 증상 개선    | 증상 지속     | 행 합계       |
| ------------------- | ------------ | ------------- | ------------- |
| **CBT 참여**  | 60           | 20            | **80**  |
| **대기 통제** | 10           | 110           | **120** |
| **열 합계**   | **70** | **130** | **200** |

---

**연습 질문:**

1. P(증상 개선) = ?
2. P(증상 개선 | CBT 참여) = ?
3. P(CBT 참여 | 증상 개선) = ?
4. P(증상 개선 | 대기 통제) = ?
5. CBT 참여 여부와 증상 개선 여부는 독립 사건인가?

---

**모범 답안:**

**1. P(증상 개선) = ?**

```
P(증상 개선) = 70 / 200 = .350

해석: 전체 참여자 200명 중 70명(35%)이 증상 개선 기준을 충족했다.
```

**2. P(증상 개선 | CBT 참여) = ?**

```
P(증상 개선 | CBT 참여) = 60 / 80 = .750

해석: CBT에 참여한 80명 중 60명(75%)이 증상 개선 기준을 충족했다.
     분모가 전체 200명이 아니라 CBT 참여자 80명임에 주목하라.
```

**3. P(CBT 참여 | 증상 개선) = ?**

```
P(CBT 참여 | 증상 개선) = 60 / 70 ≈ .857

해석: 증상이 개선된 70명 중 60명(약 86%)이 CBT 참여자였다.
     ※ P(증상 개선 | CBT 참여) = .750 ≠ P(CBT 참여 | 증상 개선) ≈ .857
     조건부확률의 방향이 바뀌면 분모가 달라지므로 값도 달라진다.
```

**4. P(증상 개선 | 대기 통제) = ?**

```
P(증상 개선 | 대기 통제) = 10 / 120 ≈ .083

해석: 대기 통제 집단 120명 중 10명(약 8%)만 증상 개선 기준을 충족했다.
     CBT 집단의 75%와 비교하면 약 9배 차이다.
```

**5. CBT 참여 여부와 증상 개선 여부는 독립 사건인가?**

```
독립이라면: P(CBT) × P(개선) = P(CBT ∩ 개선)이어야 한다.

P(CBT 참여) = 80 / 200 = .400
P(증상 개선) = 70 / 200 = .350
P(CBT) × P(개선) = .400 × .350 = .140

실제 P(CBT ∩ 개선) = 60 / 200 = .300

.300 ≠ .140 → 두 사건은 종속(dependent) 사건이다.

해석: CBT 참여 여부를 알면 증상 개선 확률이 달라진다.
     [조건 없을 때]     P(개선) = .35
     [CBT 참여 조건]    P(개선 | CBT) = .75
     [대기 통제 조건]   P(개선 | 대기) ≈ .08
     → CBT 참여 정보가 증상 개선 확률을 크게 바꾼다 → 종속 사건.
     → 두 사건이 종속이라는 것은 CBT가 증상 개선과 연관되어 있음을 뜻한다.
```

## 7. 오개념 경고

> **⚠️ 오개념 1**: "P(A|B) = P(B|A)이다"
> → **완전히 다르다.** 조건부확률의 방향(무엇이 주어지는가)이 핵심이다.
>
> - P(증상 개선 | CBT 참여) = **.75** (CBT에 참여했다면 개선될 확률)
> - P(CBT 참여 | 증상 개선) ≈ **.857** (개선된 사람이 CBT 참여자였을 확률)
>
> 이 둘을 혼동하면 연구 결과의 해석이 완전히 뒤집힌다. "CBT 참여 후 개선율이 75%이므로, 개선된 사람 중 75%가 CBT 참여자다"는 잘못된 해석이다.

> **⚠️ 오개념 2**: "독립 = 상호배타"
> → **정반대다.** 헷갈리지 말 것.
>
> - **상호배타**: A와 B가 동시에 발생 불가. A가 일어나면 B의 확률은 0이 된다. → **가장 강한 종속!**
> - **독립**: A가 발생해도 B의 확률이 변하지 않는다.
>
> 예시: "CBT 참여이면서 CBT 미참여"는 상호배타 (동시 불가능, 가장 강한 종속).
> "첫 번째 환자의 치료 반응과 두 번째 환자의 치료 반응"은 독립 (서로 영향 없음).

> **⚠️ 오개념 3**: "P(A∪B) = P(A) + P(B)가 항상 성립한다"
> → **상호배타일 때만** 성립한다. 일반적으로는 P(A∩B)를 빼야 한다.
>
> P(여성) = .50, P(MDD) = .50인데 P(여성이거나 MDD) = 1.00? → 틀렸다.
> 실제 P(A∪B) = .50 + .50 − .30 = .70. 두 사건이 겹치는 부분을 뺀다.

> **⚠️ 오개념 4**: "확률 0.95이면 거의 확실하다 → 확률 0.05이면 무시해도 된다"
> → **맥락이 중요하다.** "비행기가 추락할 확률이 5%"라면 무시할 수 있는가?
>
> 특히 **p-값 해석 주의**: Ch.8에서 배울 내용이지만, p = .05는 "귀무가설이 참일 때 이런 결과가 나올 확률이 5%"이다. "가설이 틀릴 확률 95%"가 아니다. p-값에 대한 가장 흔한 오해이므로 지금부터 인식해두자.

> **⚠️ 오개념 5**: "큰 수의 법칙 = 오래 하면 반드시 이긴다"
> → **도박사의 오류(gambler's fallacy)다.** 상대도수의 극한 개념을 잘못 적용한 것이다.
>
> 동전을 9번 던져 모두 앞면이 나왔다면, 10번째에서 뒷면이 나올 "보상"이 있는가? → **없다.** 각 시행은 독립이며, 과거 결과는 다음 결과에 영향을 주지 않는다. 장기적으로 앞면이 0.5에 수렴하는 것은 앞으로의 **무한히 많은 시행의 평균**이 0.5에 가까워진다는 것이지, 지금 당장 뒷면이 더 나온다는 뜻이 아니다.

1. **조건부확률의 직관**: "P(B|A)를 조건 없는 P(B)와 비교하면서, 조건이 주어졌을 때 확률이 왜 달라지는지 예시를 들어 설명하라. '표본공간이 좁아진다'는 것이 무슨 뜻인가?"
2. **독립과 상호배타의 차이**: "독립과 상호배타는 어떻게 다른가? 둘을 혼동하면 어떤 실수가 생기는가? 각각 임상 예시를 하나씩 들어 설명하라."
3. **조건의 방향**: "P(증상 개선 | CBT 참여) = .75인데, P(CBT 참여 | 증상 개선) ≈ .857인 이유는? 두 확률이 다른 이유를 분모 관점에서 설명하라."

### 논문 용어 확인

다음 문장에서 확률 관련 개념을 찾아 해석하라:

- *"The probability of dropout was significantly higher in the waitlist control group (.38) compared to the CBT group (.12)."*
  → P(탈락 | 통제집단) = .38, P(탈락 | CBT) = .12. 두 조건부확률을 비교하는 문장.
- *"The probability of symptom improvement was .75 in the CBT group compared to .08 in the waitlist control group, indicating that group assignment and symptom improvement were not independent."*
  → P(개선 | CBT) = .75, P(개선 | 대기 통제) = .08. 두 조건부확률을 비교하며 종속성을 확인한 문장. "given that..."은 조건부확률의 영어 표현이다.

## 10. 이 챕터에서 다음 챕터로

**챕터 3이 남긴 질문:**

> "확률을 배웠다. 사건 하나에 확률을 부여하는 법은 알겠다. 그런데 '변수 하나가 취할 수 있는 모든 값'에 확률을 체계적으로 부여하면 어떻게 될까?"

이 질문이 **확률분포(probability distribution)**로 이어진다:

- **이산형**: 우울 심각도 수준(없음/경미/중등/심각) 각각에 확률 부여 → **확률질량함수**
- **연속형**: BDI-II 점수 0~63점 각 구간에 확률 부여 → **확률밀도함수**

→ **챕터 4: 확률분포** — 확률변수, 기댓값(모평균 μ), 모분산(σ²)


## 부록: 보완 주제 — 베이즈 정리 (Bayes' Theorem)

> 이 부록은 본문에서 다루지 않은 진단 검사 용어(양성/음성 판정, 민감도, 특이도, PPV)를 처음 도입한다. 심화 학습을 원하는 경우에 읽는다.

> **이 주제가 중요한 이유**: 교재에 없지만, 임상 진단 정확도 해석과 의학통계 논문에서 필수적인 개념이다. 아래에서 "유병률이 낮으면 PPV가 낮다"는 현상을 수학적으로 정확히 설명해준다.

---

### 공식

```
P(A | B) = [P(B | A) × P(A)] / P(B)

구성 요소:
  P(A)        = 사전확률 (prior probability) — B를 관찰하기 전 A의 확률
  P(B | A)    = 우도 (likelihood) — A가 참일 때 B를 관찰할 확률
  P(B)        = 주변 확률 (marginal probability) — B가 발생할 전체 확률
  P(A | B)    = 사후확률 (posterior probability) — B를 관찰한 후 A의 확률
```

**읽는 법**: "B라는 증거를 본 후, A에 대한 믿음을 어떻게 업데이트하는가?"

---

### P(B) 계산 — 전확률 공식 (Law of Total Probability)

B가 일어나는 모든 경우의 수를 더해서 P(B)를 계산한다:

```
P(B) = P(B | A) × P(A) + P(B | Aᶜ) × P(Aᶜ)
```

---

### 진단 검사 용어 정의

베이즈 정리를 임상에 적용하려면 먼저 네 가지 용어를 알아야 한다.

```
민감도 (sensitivity)
  = 실제 환자 중 검사가 "양성"으로 판정한 비율
  = P(양성 판정 | 실제 환자)
  → 환자를 놓치지 않는 능력. 높을수록 좋음.

특이도 (specificity)
  = 실제 정상인 중 검사가 "음성"으로 판정한 비율
  = P(음성 판정 | 실제 정상)
  → 정상인을 환자로 잘못 분류하지 않는 능력. 높을수록 좋음.

PPV — 양성 예측도 (Positive Predictive Value)
  = 검사에서 "양성"이 나왔을 때, 실제로 환자일 확률
  = P(실제 환자 | 양성 판정)
  → "양성 판정을 믿어도 되는가?"를 알려주는 수치.
     민감도·특이도와 달리, 유병률에 따라 크게 달라진다.
```

> **핵심 납득 포인트**: 민감도·특이도는 검사 자체의 성능이고, PPV는 "이 집단에서 이 검사를 쓸 때" 나오는 결과다. 같은 검사도 집단(유병률)이 다르면 PPV가 완전히 달라진다.

---

### 임상 적용: 유병률이 낮을 때 PPV가 낮아지는 이유

**설정**: PHQ-9, 민감도 = .85, 특이도 = .85

**사례 1: 고위험 임상 집단 (유병률 = .40)**

```
P(MDD) = .40  (사전확률)
P(MDD 없음) = .60

P(PHQ-9 양성) = P(양성 | MDD) × P(MDD) + P(양성 | MDD없음) × P(MDD없음)
              = .85 × .40 + .15 × .60
              = .34 + .09
              = .43

P(MDD | 양성) = [P(양성 | MDD) × P(MDD)] / P(양성)
              = (.85 × .40) / .43
              = .34 / .43
              ≈ .791

→ PPV ≈ .79: 양성 10명 중 약 8명이 실제 MDD
```

**사례 2: 지역사회 일반 집단 (유병률 = .05)**

```
P(MDD) = .05  (사전확률)
P(MDD 없음) = .95

P(PHQ-9 양성) = .85 × .05 + .15 × .95
              = .0425 + .1425
              = .185

P(MDD | 양성) = (.85 × .05) / .185
              = .0425 / .185
              ≈ .230

→ PPV ≈ .23: 양성 10명 중 약 2~3명만 실제 MDD!
```

**비교 요약**:

| 집단                      | 유병률 | PPV            |
| ------------------------- | ------ | -------------- |
| 고위험 임상 집단          | .40    | .79            |
| 지역사회 일반 집단        | .05    | .23            |
| 검사 성능 (민감도/특이도) | —     | .85/.85 (동일) |

> **핵심 납득 포인트**: 똑같은 검사(민감도 85%, 특이도 85%)를 사용해도, 어떤 집단에 적용하느냐에 따라 PPV가 .79에서 .23으로 크게 달라진다. 이것은 검사의 문제가 아니라 **베이즈 정리의 수학적 결과**다.
>
> 사전확률(유병률)이 낮을수록, 같은 양성 결과라도 그것이 진짜 환자일 가능성은 낮아진다. 이것이 **선별 검사를 임상에서 사용할 때 반드시 유병률을 고려해야 하는 이유**이며, "양성 판정 = 확진"이 아닌 이유다.

---

### 논문에서 베이즈 정리

- **"pre-test probability"** (검사 전 확률) = 사전확률 P(A)
- **"post-test probability"** (검사 후 확률) = 사후확률 P(A|B)
- **"likelihood ratio"** (우도비) = P(양성|MDD) / P(양성|MDD없음) — 양성 우도비라고 함
- 이 개념들은 진단 검사 타당도 논문(sensitivity, specificity, predictive values)에서 반드시 등장한다
