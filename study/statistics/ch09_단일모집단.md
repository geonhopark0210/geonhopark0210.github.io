### 3.1 t분포 (t Distribution)

#### 직관부터 시작

> **문제**: Ch.8에서 z = (x̄ − μ₀)/(σ/√n) ~ N(0,1)을 이용했다. 그런데 실제로는 σ를 모른다. s로 대체하면?

```
t = (x̄ − μ₀) / (s/√n) ~ t(df = n−1)

→ z분포가 아니라 t분포를 따른다!
  이유: s는 표본에서 추정한 값 — 추정 오차 때문에 분포가 더 퍼진다
```

#### t분포의 특성

```
[t분포 vs 표준정규분포 비교]

         ╭──── N(0,1)
         │   ╭─── t(df=5)
         │   │  ╭── t(df=1)
         │   │  │
 ────────╯   │  │ ╰─────────
             │  ╰───────────
             ╰─────────────────
      -3    -2   -1   0   1   2   3

특성:
1. 평균 = 0 (정규분포와 같음)
2. 분산 > 1 (정규분포보다 퍼짐 — "두꺼운 꼬리")
3. 단봉 대칭 (모양은 종 모양)
4. df(자유도)에 따라 모양이 다름:
   df 작을수록 → 꼬리가 두꺼움 (불확실성 큼)
   df → ∞ → N(0,1)에 수렴
```

#### 자유도 (Degrees of Freedom, df)

```
단일표본 t검정: df = n − 1

왜 n−1인가?
  t = (x̄ − μ₀) / (s/√n)에서 s를 계산할 때 x̄를 사용함.
  x̄를 먼저 추정했으므로 n개의 편차 중 자유롭게 변할 수 있는 것은 n−1개.
  (마지막 값은 나머지로 결정됨)

직관: "8명의 STAI-T 점수의 평균 = 48이라는 것을 알면,
      7명의 점수를 알면 8번째 점수는 자동으로 결정된다 → 자유도 = 7 = n−1"
```

#### t-표의 임계값

t분포는 df에 따라 달라지므로, z-표 대신 t-표를 사용한다.

```
[t-표 일부 발췌 — 양측 95% 신뢰구간(α=.05) 임계값 t*]

df  │  t*(α/2=.025)
────┼──────────────
 5  │  2.571
10  │  2.228
15  │  2.131
20  │  2.086
24  │  2.064
30  │  2.042
40  │  2.021
60  │  2.000
120 │  1.980
∞   │  1.960  ← z값과 같아짐

읽는 법: n=25이면 df=24 → t* = 2.064
         (n이 클수록 t* → 1.960에 가까워짐)
```

> **핵심 납득 포인트**: 왜 t값이 z값보다 큰가? s로 σ를 추정하는 추가적인 불확실성 때문이다. 신뢰구간이 z를 쓸 때보다 약간 더 넓어진다. n이 클수록 s가 σ에 가까워지므로 불확실성이 줄어 t* → z*에 수렴한다. n ≥ 120이면 실용적으로 z를 써도 거의 차이 없다.

### 3.2 모평균에 대한 추론

#### 3.2.1 신뢰구간 (Confidence Interval for μ)

```
x̄ ± t* × (s/√n)

단, t* = t(α/2, df=n−1): df=n−1의 t분포에서 양측 α/2 임계값
```

**손계산 예시**: BDI-II 측정, n=16, x̄=24.3, s=8

```
SE = s/√n = 8/√16 = 8/4 = 2.0
df = 16 − 1 = 15
t*(df=15, 양측 95%) = 2.131

95% CI = 24.3 ± 2.131 × 2.0
        = 24.3 ± 4.262
        = [20.04,  28.56]

해석: "이 방법으로 반복 구성하면 95%의 CI가 μ를 포함한다.
      이 CI는 [20.04, 28.56]."

99% CI: t*(df=15, 양측 99%) = 2.947
        = 24.3 ± 2.947 × 2.0 = 24.3 ± 5.894 = [18.41,  30.19]
        → 99% CI가 더 넓다 (더 확실하게 μ를 포함하려면 범위 필요)
```

---

#### 3.2.2 가설검정 (One-Sample t-Test)

```
귀무가설:     H₀: μ = μ₀
검정통계량:   t = (x̄ − μ₀) / (s/√n)   df = n−1
결정 기준:    |t| > t*(α/2, df) 이면 H₀ 기각
```

**APA 보고 형식**:

```
t(df) = t값, p = .xxx  [또는 p < .001]
예: t(15) = 2.15, p = .048, 95% CI [20.04, 28.56]
```

**손계산 예시**: H₀: μ = 20, n=16, x̄=24.3, s=8

```
SE = 2.0
t = (24.3 − 20) / 2.0 = 4.3 / 2.0 = 2.15
df = 15

t-표에서: t*(df=15, 양측 α=.05) = 2.131
|t| = 2.15 > 2.131 → H₀ 기각 (p < .05)

더 정확한 p-값:
  t(15) = 2.15, 양측 → p ≈ .048  (경계선에 가까움!)

결론: "이 임상 집단의 모평균 BDI-II는 20과 통계적으로 유의하게 다르다
       [t(15) = 2.15, p = .048, 95% CI (20.04, 28.56)]."

[CI와 가설검정의 일치 확인]
CI [20.04, 28.56]에 H₀ 값(20)이 포함되어 있는가?
→ 20.04 ≤ 20? → No, 아슬아슬하게 포함 안 됨 → H₀ 기각과 일치 ✓
```

> **핵심 납득 포인트**: t = 2.15는 "관측된 x̄가 H₀ 기준값에서 SE 단위로 2.15배 떨어졌다"는 뜻이다. df=15에서 이 정도의 거리는 p ≈ .048 — 흔치 않은 결과다. 하지만 p = .048은 p = .001과 매우 다른 수준의 증거다. p-값의 크기 자체에도 의미가 있다.

### 3.3 모분산에 대한 추론

#### 직관부터 시작

> **질문**: "두 치료 집단의 평균은 비슷하지만, 치료 반응의 **변동성**(분산)이 다른가?" 또는 "측정 도구의 분산이 기준값 σ₀²과 다른가?"

모분산 추론에는 **카이제곱 분포(χ² distribution)**를 사용한다.

#### χ²분포와 중심축량

```
χ² = (n−1)s² / σ₀²  ~ χ²(df = n−1)

기호 해설:
  (n−1)s² = 표본분산을 자유도로 "스케일링"한 값
  σ₀² = H₀에서 가정하는 모분산
  df = n−1
```

**χ²분포의 특성**:

```
[χ²분포 모양]

f(x)  df=5          df=10           df=20
  │   ╭─╮            ╭──╮              ╭───╮
  │ ╭─╯ ╰────    ──╭─╯  ╰──────   ──╭──╯   ╰────
  └──────────── ────────────────  ──────────────
    0  5  10       0   10  20       0    20   40

특성:
  - 비대칭 (오른쪽 꼬리)
  - 0 이상의 값만 가짐 (분산은 음수 불가)
  - df에 따라 모양 변화
```

#### 신뢰구간 (95% CI for σ²)

```
[(n−1)s² / χ²_(α/2),  (n−1)s² / χ²_(1−α/2)]

단, χ²_(α/2) = 상위 α/2에 해당하는 χ² 임계값
    χ²_(1−α/2) = 하위 α/2에 해당하는 χ² 임계값
```

**손계산 예시**: n=16, s²=64 (s=8), 95% CI for σ²

```
df = 15
χ²_(0.025, df=15) = 27.488   (상위 2.5% 임계값)
χ²_(0.975, df=15) = 6.262    (하위 2.5% 임계값)

95% CI for σ² = [(15×64)/27.488,  (15×64)/6.262]
              = [960/27.488,  960/6.262]
              = [34.93,  153.32]

95% CI for σ = [√34.93, √153.32] = [5.91, 12.38]

해석: "모표준편차 σ가 약 5.9에서 12.4 사이에 있을 95% CI"
```

> **핵심 납득 포인트**: 분산의 CI가 비대칭인 이유는 χ²분포가 비대칭이기 때문이다. 평균의 CI (t분포 사용)는 t값을 대칭으로 ±하지만, 분산의 CI는 두 다른 임계값을 사용한다.

### 3.4 모비율에 대한 추론

#### 직관부터 시작

> **질문**: "이 치료 프로그램에서 표본 100명 중 62명이 반응했다(p̂ = .62). 모집단의 실제 반응률(p)은 얼마인가? 그리고 p = .50이라는 주장을 기각할 수 있는가?"

#### 3.4.1 모비율 신뢰구간

```
p̂ ± z* × √[p̂(1−p̂)/n]

조건: np̂ ≥ 5, n(1−p̂) ≥ 5  (정규 근사 조건)
```

**손계산 예시**: n=100, X=62, p̂=.62

```
SE = √[p̂(1−p̂)/n] = √[.62×.38/100] = √[.2356/100] = √.002356 ≈ .04854

95% CI = .62 ± 1.96 × .04854
       = .62 ± .095
       = [.525,  .715]

해석: "모집단의 실제 치료 반응률은 52.5%~71.5% 범위 내에 있을 것 (95% CI)"
```

#### 3.4.2 표본 크기 결정

```
오차 한계(margin of error) E를 정하면:
  n = (z* / E)² × p*(1−p*)

p*를 모를 때 보수적 추정: p* = .5 (이때 분산 최대)
p*를 알 때: 선행 연구나 파일럿 연구의 p̂ 사용
```

**손계산 예시**: E = .05 (오차 ±5%), 95% 신뢰수준, p* = .5

```
n = (1.96 / .05)² × .5 × .5
  = (39.2)² × .25
  = 1536.64 × .25
  = 384.16
  → n ≥ 385명 필요

선행 연구에서 p* ≈ .62로 알려진 경우:
  n = (1.96/.05)² × .62 × .38
    = 1536.64 × .2356
    ≈ 362
  → n ≥ 362명 (p* = .5보다 약간 적음)
```

#### 3.4.3 모비율 가설검정

```
귀무가설:     H₀: p = p₀
검정통계량:   z = (p̂ − p₀) / √[p₀(1−p₀)/n]
               주의: H₀의 p₀를 SE 계산에 사용! (p̂가 아님)
```

**손계산 예시**: H₀: p = .50, n=100, p̂ = .62

```
SE_H₀ = √[p₀(1−p₀)/n] = √[.50×.50/100] = √.0025 = .05

z = (.62 − .50) / .05 = .12/.05 = 2.40

양측 p-값 = 2 × P(Z > 2.40) = 2 × .0082 = .0164

결정 (α=.05): p = .016 < .05 → H₀ 기각
결론: "이 치료의 모집단 반응률은 50%가 아니다 (z = 2.40, p = .016)."

[CI와의 일치 확인]
95% CI [.525, .715]에 p₀=.50 포함? → No (.50 < .525) → H₀ 기각과 일치 ✓
```

> **핵심 납득 포인트**: 비율 검정에서 SE 계산 시 **CI는 p̂**, **가설검정은 p₀**를 사용한다. CI는 "모비율이 어디 있는가?"를 추정하므로 표본 정보 p̂을 쓰고, 가설검정은 "H₀(p=p₀)가 참이라면?"을 기준으로 하므로 p₀를 쓴다.

## 4. 수식 정리

```
=== 기호 약속 ===
t*        = t분포 임계값 (df = n−1)
df        = 자유도 (degrees of freedom) = n−1
χ²*       = χ²분포 임계값 (df = n−1)
E         = 오차 한계 (margin of error)
p₀        = H₀에서 가정하는 모비율

=== 수식 목록 ===

[모평균 추론 — t분포 사용]
① t-검정통계량
   t = (x̄ − μ₀) / (s/√n)   df = n−1

② 모평균 신뢰구간
   x̄ ± t* × (s/√n)
   t* = t(α/2, df=n−1)

[모분산 추론 — χ²분포 사용]
③ χ²-검정통계량
   χ² = (n−1)s² / σ₀²   df = n−1

④ 모분산 신뢰구간 (비대칭!)
   [(n−1)s² / χ²_(α/2),   (n−1)s² / χ²_(1−α/2)]

[모비율 추론 — z분포 사용]
⑤ 모비율 신뢰구간
   p̂ ± z* × √[p̂(1−p̂)/n]
   조건: np̂ ≥ 5, n(1−p̂) ≥ 5

⑥ 모비율 검정통계량 (H₀의 p₀ 사용!)
   z = (p̂ − p₀) / √[p₀(1−p₀)/n]

⑦ 표본 크기 결정
   n = (z*/E)² × p*(1−p*)
   p* 미지 시: p* = .5 (보수적 추정, n 최대화)

=== 손계산 예시 요약 ===
[모평균 t검정] n=16, x̄=24.3, s=8, H₀: μ=20
  SE = 8/4 = 2.0
  t = (24.3−20)/2.0 = 2.15, df=15
  t*(15, .05) = 2.131 < 2.15 → p < .05 → H₀ 기각
  95% CI = 24.3 ± 2.131×2.0 = [20.04, 28.56]

[모비율 z검정] n=100, p̂=.62, H₀: p=.50
  SE_H₀ = √(.50×.50/100) = .05
  z = (.62−.50)/.05 = 2.40 → p = .016 → H₀ 기각
  95% CI = .62 ± 1.96×.0485 = [.525, .715]
```

## 5. 심리학 연구 맥락 연결

### 시나리오 A: 임상 집단의 PHQ-9 규준 비교

**연구 질문**: "일차의료기관 내원 환자의 PHQ-9 평균이 지역사회 규준(μ₀=5)보다 높은가?"

```
데이터: n=25, x̄=9.8, s=5.4
H₀: μ = 5.0
Hₐ: μ > 5.0  (단측 — 임상 집단이 높을 것으로 예상)

SE = 5.4/√25 = 5.4/5 = 1.08
df = 24
t = (9.8 − 5.0) / 1.08 = 4.8 / 1.08 ≈ 4.44

단측 t*(df=24, α=.05) = 1.711
|t| = 4.44 >> 1.711 → p << .001 → H₀ 강하게 기각

95% CI (양측): 9.8 ± 2.064 × 1.08 = 9.8 ± 2.229 = [7.57, 12.03]

APA 보고: t(24) = 4.44, p < .001, 95% CI [7.57, 12.03]

임상적 의미:
  Cohen's d = (9.8 − 5.0)/5.4 = 4.8/5.4 ≈ 0.89  (대 효과크기)
  → 통계적으로도 유의하고, 임상적으로도 의미 있는 차이
```

### 시나리오 B: 치료 반응률과 모비율 추론

**연구 질문**: "이 CBT 프로그램의 반응률이 무작위보다(p=.50보다) 높은가? 그리고 실제 반응률의 95% CI는?"

```
데이터: n=80, 반응자 X=56, p̂ = 56/80 = .70

H₀: p = .50
H₁: p > .50 (단측)

SE_H₀ = √(.50×.50/80) = √.003125 ≈ .0559
z = (.70 − .50) / .0559 = .20/.0559 ≈ 3.58
단측 p-값 = P(Z > 3.58) ≈ .0002

95% CI: SE_p̂ = √(.70×.30/80) = √.002625 ≈ .0512
        .70 ± 1.96×.0512 = .70 ± .100 = [.60, .80]

결론: "이 CBT의 모집단 반응률은 50%보다 통계적으로 유의하게 높으며
      [z = 3.58, p < .001], 95% CI는 [.60, .80]이다."
```

## 6. 논문 스니펫 읽기 실습

다음은 가상의 논문 Results 절이다. 읽고 질문에 답하라.

---

*"Post-treatment BDI-II scores in the CBT group (n = 25) were compared against the clinical cutoff of 14 (moderate severity) using a one-sample t-test. The mean post-treatment score was M = 18.4 (SD = 6.2, SE = 1.24). The test yielded t(24) = 3.55, p = .002 (two-tailed), 95% CI [15.84, 20.96]. Cohen's d = 0.71, indicating a large effect. Additionally, the proportion of participants who achieved remission (BDI-II < 14) was p̂ = .52. A one-sample z-test indicated that this proportion was not significantly different from chance (H₀: p = .50), z = 0.40, p = .69, 95% CI [.32, .72]."*

---

**연습 질문:**

1. t = 3.55는 어떻게 계산되는가? 손계산으로 확인하라.
2. "95% CI [15.84, 20.96]"을 보고 H₀: μ=14에 대해 α=.05 검정 결론을 내려라.
3. Cohen's d = 0.71의 의미는? 통계적 유의성(p=.002)과 어떻게 다른가?
4. 관해율 p̂ = .52, z = 0.40, p = .69의 의미는?
5. "t(24)"에서 24는 무엇인가?

---

**모범 답안:**

**1. t = 3.55 계산 확인**
```
SE = s/√n = 6.2/√25 = 6.2/5 = 1.24

t = (x̄ − μ₀) / SE = (18.4 − 14) / 1.24 = 4.4 / 1.24 ≈ 3.548 ≈ 3.55  ✓

df = n−1 = 24
```

**2. CI로 H₀ 결론**
```
95% CI = [15.84, 20.96]
H₀ 값 μ₀ = 14

14 < 15.84 → 14가 CI 밖에 있다 → α=.05에서 H₀ 기각

해석: "CBT 후 BDI-II 평균은 임상 절단점(14)과 통계적으로 유의하게 다르다."
     단, 14점보다 여전히 높음 → 평균적으로 여전히 중등도 수준에 해당
```

**3. Cohen's d = 0.71의 의미**
```
d = (x̄ − μ₀) / s = (18.4 − 14) / 6.2 = 4.4/6.2 ≈ 0.71

Cohen(1988) 기준: d = 0.71은 "중간~대" 효과크기

통계적 유의성과 효과크기의 차이:
  p = .002: "H₀를 기각할 충분한 증거" — n=25, 이 정도 차이면 유의
  d = 0.71: "차이의 실질적 크기" — 표본 크기에 무관한 표준화 지표

중요: p < .001이어도 d = 0.05이면 실질적으로 무의미한 차이일 수 있음.
      d = 0.71 + p = .002 → 통계적·실질적 모두 의미 있는 결과.
```

**4. 관해율 결과 해석**
```
p̂ = .52, H₀: p = .50 → z = (.52−.50)/√(.50×.50/25) = .02/.10 = 0.20
(또는 100명 아니라 25명이면: SE = √(.50×.50/25) = .10, z = .02/.10 = 0.20)

논문의 n=25이면 z = (.52−.50)/√(.50×.50/25) = .02/.10 = 0.20
하지만 논문에서 z = 0.40이 보고되었으므로, 계산에 쓴 n이 다를 수 있음.
(예: p̂ = .52, n = 100이면 SE = .05, z = .02/.05 = 0.40 ✓ → 논문에 n=100인 집단)

p = .69 >> .05 → H₀ 기각 실패
해석: "관해율이 우연(50%)보다 높다는 통계적 증거가 없다."
95% CI [.32, .72] 안에 .50이 포함 → H₀ 기각 실패와 일치

하지만: "효과가 없다"가 아님. 표본이 작으면 검정력 부족 가능성
```

**5. t(24)의 24**
```
24 = df = n−1 = 25−1

df는 t분포의 모양을 결정함.
APA 보고에서 t(df)는 어떤 t분포를 사용했는지 명시.
df = 24의 t분포에서 |t| ≥ 3.55의 p-값이 .002임.
```

## 7. 오개념 경고

> **⚠️ 오개념 1**: "t검정은 n이 작을 때 쓰고, n이 크면 z검정을 써야 한다"
> → **거의 모든 실제 연구에서 σ를 모르므로 t검정을 쓴다.** n이 커지면 t* → z*에 수렴하므로 차이가 작아지지만, t검정이 옳은 방법이다.
>
> n이 클 때 z검정을 써도 결과가 거의 같은 것이지, z를 써야 하는 것이 아니다. 일부 논문에서 n이 크면 z값으로 보고하기도 하지만, t값이 더 정확하다.

> **⚠️ 오개념 2**: "t값이 크면 효과가 크다"
> → **t값은 효과 크기가 아니다.** t = (x̄ − μ₀) / SE에서 n이 크면 SE가 작아지므로, 같은 효과 크기(같은 x̄ − μ₀)여도 n이 클수록 t가 커진다.
>
> 효과 크기: Cohen's d = (x̄ − μ₀) / s — 표본 크기와 무관
> 검정통계량: t = d × √n — 표본 크기에 비례

> **⚠️ 오개념 3**: "95% CI는 데이터의 95%가 이 구간에 있다는 뜻이다"
> → **신뢰구간(CI)과 예측구간(prediction interval)을 혼동한 것이다.**
>
> - 95% CI [20.04, 28.56]: "모평균 μ가 이 범위에 있을 것" — 모수에 대한 추론
> - 95% 예측구간: "새로운 개인의 점수가 이 범위에 있을 것" — 훨씬 넓음
>
> n=16에서 SD=8이면, 개인 점수의 95% 범위는 대략 x̄ ± 2s ≈ 24.3 ± 16 = [8.3, 40.3]으로 CI보다 훨씬 넓다. CI는 개인 데이터의 범위가 아니라 모평균 추정의 불확실성이다.

> **⚠️ 오개념 4**: "가설검정에서 H₀의 p₀가 아닌 p̂을 SE에 써도 된다"
> → **검정통계량 계산 시 반드시 H₀의 p₀를 써야 한다.** p̂을 쓰면 "H₀가 참이라는 가정 하에서"라는 전제가 깨진다.
>
> - CI 계산: p̂ ± z* × √[p̂(1−p̂)/n]  (p̂ 사용)
> - 검정 SE: √[p₀(1−p₀)/n]  (p₀ 사용)
>
> 둘을 혼동하면 잘못된 검정 결과가 나온다.

> **⚠️ 오개념 5**: "χ²분포를 이용한 분산 검정은 정규성에 민감하지 않다"
> → **t검정보다 훨씬 민감하다.** 모분산 추론의 χ² 검정은 정규성 가정에 매우 민감하다. 데이터가 정규분포에서 조금만 벗어나도 결과가 크게 달라진다. 이 때문에 실제 연구에서 단독으로 분산을 검정하기보다는 Levene's test(Ch.10에서 등분산 검정으로 등장)가 더 강건한 대안으로 자주 사용된다.

## 부록: 보완 주제 — 신뢰구간 해석의 주요 오개념 완전 정리

> **이 주제가 중요한 이유**: CLAUDE.md §5에서 Ch.9 연결 보완 주제로 명시됨. 신뢰구간 해석 오개념은 심리학자들 사이에서도 매우 흔하며, 논문 해석 능력에 직결된다.

---

### 오개념 1: "이 CI가 μ를 포함할 확률이 95%다"

```
[틀린 이유]
μ는 고정된 참값이다. 특정 CI [20.04, 28.56]이 μ를 포함하느냐는
이미 결정되어 있다 — μ가 20~28.56 사이에 있거나 없거나.

[올바른 해석]
"이 방법(x̄ ± t* × SE)으로 반복해서 CI를 만들면, 그 중 95%가 μ를 포함한다."

[비유]
낚시를 하는데 그물 크기가 95% 확률로 물고기를 잡는다고 하자.
이번에 그물을 던졌다 — 물고기가 잡혔거나 안 잡혔거나 둘 중 하나.
"이 그물이 잡을 확률 95%"는 방법의 장기적 성공률이지,
이 특정 시도에 대한 확률이 아니다.
```

---

### 오개념 2: "CI가 좁을수록 더 좋은 연구다"

```
CI가 좁아지는 두 가지 경우:
  (a) n이 크다 → SE = s/√n 감소 → 좋은 연구!
  (b) s(데이터 변동성)가 작다 → 동질적 집단 → 일반화 제한 가능

단순히 "CI가 좁다"고 무조건 좋은 것이 아니다.
CI 폭은 연구 질을 판단하는 하나의 기준이지 유일한 기준이 아니다.
```

---

### 오개념 3: "두 CI가 겹치지 않으면 반드시 통계적으로 유의하다"

```
[틀린 이유]
두 독립집단의 CI가 겹치지 않으면 유의하지만,
CI가 겹쳐도 유의할 수 있다.

[규칙]
집단 A의 95% CI와 집단 B의 95% CI가 겹쳐도,
차이(A−B)에 대한 95% CI에 0이 포함되지 않으면 유의함.

→ 두 집단 CI 비교로 유의성을 판단하지 말고, 차이에 대한 CI를 사용하라.
   (Ch.10에서 정식으로 다룸)
```

---

### 올바른 CI 해석 요약

```
95% CI [15.84, 20.96]이란:

✓ "이 방법으로 반복 구성하면 95%의 CI가 μ를 포함한다"
✓ "α=.05 수준에서 H₀: μ=14를 기각한다" (14 ∉ CI)
✓ "μ의 그럴듯한 범위는 [15.84, 20.96]이다" (신뢰 가능한 값의 집합)

✗ "이 CI가 μ를 포함할 확률이 95%다"
✗ "데이터의 95%가 이 범위에 있다"
✗ "μ는 정확히 CI 중간값(18.4)이다"
```
