### 3.1 통계적 추론의 분류

#### 직관부터 시작

> **질문**: "표본에서 x̄ = 45.2를 계산했다. 이것으로 모평균 μ에 대해 어떤 주장을 할 수 있는가?"

두 가지 방법이 있다:

```
방법 1: 추정 (Estimation)
  "μ는 아마 45.2 정도일 것이다" (점추정)
  "μ는 42.3과 48.1 사이에 있을 것이다" (구간추정)

방법 2: 가설검정 (Hypothesis Testing)
  "μ = 40이라는 주장이 이 데이터와 양립 가능한가?"
  → Yes/No로 답함
```

```
[통계적 추론의 두 기둥]

통계적 추론
    ├── 추정 (Estimation)
    │     ├── 점추정 (Point Estimation): x̄ = 45.2
    │     └── 구간추정 (Interval Estimation): [42.3, 48.1]
    │
    └── 가설검정 (Hypothesis Testing)
          "H₀: μ = 40 → 기각 또는 채택"
```

> **핵심 납득 포인트**: 신뢰구간은 "μ가 어디쯤 있는가?"를 추정하고, 가설검정은 "μ = μ₀라는 주장이 데이터와 맞는가?"를 판단한다. 둘은 같은 수학을 다른 방식으로 사용한다. 논문에서는 종종 둘 다 보고된다: `t(48) = 3.21, p = .002, 95% CI [2.4, 9.8]`.

---

### 3.2 점추정과 중심축량

#### 점추정 (Point Estimation)

모수를 **하나의 숫자**로 추정하는 것.

| 모수 | 추정량 | 예시 |
|------|--------|------|
| 모평균 μ | 표본평균 x̄ | μ ≈ x̄ = 45.2 |
| 모분산 σ² | 표본분산 s² | σ² ≈ s² = 144 |
| 모비율 p | 표본비율 p̂ | p ≈ p̂ = .68 |

**좋은 점추정의 조건 — 불편성 (Unbiasedness)**:

```
E(x̄) = μ  ← x̄은 μ의 불편추정량
           (표본을 반복 추출하면 x̄의 평균이 μ에 일치)

E(s²) = σ²  ← s²이 (n−1)로 나누는 이유 (Ch.2 §3.4.2 연결)
```

#### 중심축량 (Pivotal Quantity)

**모수를 포함하지만, 그 분포가 모수에 의존하지 않는** 통계량.

```
Z = (x̄ − μ) / (σ/√n) ~ N(0, 1)

왜 "중심축량"인가?
  Z의 분포가 N(0, 1)이므로 μ와 σ가 무엇이든 Z-표 하나로 모든 계산 가능
  → 이것으로 신뢰구간도 만들고, 가설검정도 한다
```

> **핵심 납득 포인트**: 중심축량이 추론통계의 "공통 도구"다. μ가 뭔지 몰라도, σ를 알면 Z를 계산해 N(0,1) 분포를 쓸 수 있다. 이 원리가 신뢰구간과 가설검정 모두에 적용된다.

---

### 3.3 구간추정과 신뢰구간

#### 직관부터 시작

> **문제**: x̄ = 45.2 하나만 보고하면 그 추정이 얼마나 믿을 만한지 알 수 없다. n=4에서 나왔는가, n=400에서 나왔는가에 따라 신뢰도가 완전히 다르다.

**해결책**: 불확실성을 구간으로 표현한다.

```
95% 신뢰구간 공식 (σ 알 때):
CI = x̄ ± z* × SE
   = x̄ ± z* × (σ/√n)

95%이면: z* = 1.960
99%이면: z* = 2.576
```

#### 손계산 예시

**설정**: n=64, x̄=45.2, σ=12 (STAI-T, 모표준편차 가정)

```
SE = σ/√n = 12/√64 = 12/8 = 1.5

95% CI = x̄ ± 1.96 × SE
        = 45.2 ± 1.96 × 1.5
        = 45.2 ± 2.94
        = [42.26,  48.14]

99% CI = x̄ ± 2.576 × SE
        = 45.2 ± 2.576 × 1.5
        = 45.2 ± 3.86
        = [41.34,  49.06]

신뢰수준이 높아지면 (95% → 99%): 구간이 넓어진다
더 확실하게 주장하려면 더 넓은 범위를 허용해야 함
```

#### 신뢰구간의 올바른 해석 — 가장 중요한 개념

> **95% 신뢰구간 [42.26, 48.14]의 정확한 의미**:
>
> "**이 방법으로 신뢰구간을 반복해서 만들면, 그 중 95%가 실제 μ를 포함한다.**"

이것을 그림으로 이해한다:

```
[반복 표집으로 만든 여러 개의 95% CI]

표본 1:  ─────[────────]────────  ← μ 포함 ✓
표본 2:       ──────[──────]───   ← μ 포함 ✓
표본 3:  ────────────[──────]──   ← μ 포함 ✓
표본 4:               ────[────]  ← μ 불포함 ✗  (5%에 해당)
표본 5:  ──[──────]─────────────  ← μ 포함 ✓
...
1000개 중 약 950개가 μ를 포함   ← "95% 신뢰"의 의미

                  ↑
                  μ (고정, 알 수 없는 참값)
```

**실제 연구에서**: 우리는 표본을 한 번만 뽑는다. 그래서 특정 CI [42.26, 48.14]가 μ를 포함하는지 절대 알 수 없다. "이 방법으로 만든 구간들의 95%가 μ를 포함한다"는 절차적 신뢰다.

> **핵심 납득 포인트**: 신뢰구간은 μ에 대한 직접적 확률이 아니다. 특정 CI [42.26, 48.14]가 μ를 포함할 확률은 0 또는 1 — μ는 고정값이므로 이미 포함하거나 포함하지 않는다. "95%"는 이 구간을 만드는 **방법의 장기적 성공률**이다. (흔한 오개념은 §7에서 다시 정리)

### 3.4 가설검정의 개념과 원리

---

#### 3.4.1 가설 (Hypotheses)

**직관**: "이 새로운 CBT 프로그램이 기존보다 효과가 있는가?" — 이 질문을 수학적으로 표현하면?

```
귀무가설 H₀ (Null Hypothesis):
  "효과가 없다", "차이가 없다", "기준값과 같다"
  → 기각하려고 세우는 가설. 항상 등호(=)를 포함.

대립가설 Hₐ (Alternative Hypothesis, H₁):
  "효과가 있다", "차이가 있다"
  → 연구자가 입증하고 싶은 주장.
```

**방향에 따른 분류**:

```
양측검정 (two-tailed):   H₀: μ = 40  vs  Hₐ: μ ≠ 40
단측검정 (one-tailed):   H₀: μ = 40  vs  Hₐ: μ > 40  (또는 μ < 40)
```

**임상 예시**:

| 연구 질문 | H₀ | Hₐ |
|----------|----|----|
| "MDD 집단의 STAI-T가 규준과 다른가?" | μ = 40 | μ ≠ 40 (양측) |
| "CBT가 통제군보다 BDI-II를 낮추는가?" | μ_CBT = μ_통제 | μ_CBT < μ_통제 (단측) |
| "이 선별검사의 반응률이 .50과 다른가?" | p = .50 | p ≠ .50 (양측) |

> **핵심 납득 포인트**: 귀무가설은 "반증하고 싶은 현상 유지 주장"이다. 법정에서 "피고는 무죄"(H₀)를 기본 가정으로 두고, 유죄를 입증(H₀ 기각)하는 것과 구조가 같다. H₀를 기각하지 못해도, 그것이 H₀가 "사실임을 증명"한 것은 아니다 — 단지 증거가 부족한 것이다.

---

#### 3.4.2 유의수준과 오류

**두 가지 판단 오류**:

```
현실       │  H₀ 기각          │  H₀ 채택(기각 않음)
───────────┼────────────────────┼─────────────────────
H₀ 참      │ 1종 오류(α)        │  올바른 결정
           │ (False Positive)   │
───────────┼────────────────────┼─────────────────────
H₀ 거짓   │  올바른 결정        │ 2종 오류(β)
           │ (검정력 = 1−β)     │ (False Negative)
```

```
1종 오류 (Type I Error, α):
  "실제로 효과가 없는데(H₀ 참), 효과가 있다고 판단"
  → 위양성(false positive)
  → 확률 = α (유의수준, significance level)
  → 연구자가 사전에 설정. 관행: α = .05

2종 오류 (Type II Error, β):
  "실제로 효과가 있는데(H₀ 거짓), 효과가 없다고 판단"
  → 위음성(false negative)
  → 확률 = β
  → 검정력(power) = 1 − β: "실제 효과를 검출할 확률"
```

**임상 맥락으로 이해**:

```
연구 상황: "이 새 치료법이 기존보다 효과적인가?"

1종 오류: "사실은 효과 없는데 '효과 있다'고 결론"
  → 임상 현장에 효과 없는 치료 도입
  → 환자에게 불필요한 치료, 비용 낭비

2종 오류: "사실은 효과 있는데 '효과 없다'고 결론"
  → 효과 있는 치료를 폐기
  → 환자들이 더 나은 치료를 못 받음

어느 쪽이 더 나쁜가? → 맥락에 따라 다름
  (신약 안전성: 1종 오류 엄격히 통제, α = .01 또는 .001)
  (탐색적 연구: 2종 오류 통제가 더 중요, α = .10)
```

**트레이드오프**:

```
α를 낮추면 (엄격해지면):
  → 1종 오류 줄어듦
  → 하지만 2종 오류(β) 증가 → 검정력 감소

→ 이 트레이드오프를 해결하는 방법: 표본 크기 늘리기 (부록 참고)
```

---

#### 3.4.3 검정통계량 (Test Statistic)

**직관**: "관측된 x̄와 H₀에서 가정한 μ₀의 차이가, SE로 나누었을 때 얼마나 크가?"

```
z-검정통계량 (σ 알 때):

z = (x̄ − μ₀) / (σ/√n) = (x̄ − μ₀) / SE

해석: "H₀가 참이라면 나올 것으로 기대되는 값(μ₀)에서
      관측된 x̄까지의 거리를 SE 단위로 표현한 것"

|z|가 클수록 → H₀와 관측 결과가 멀다 → H₀를 의심해야 함
```

**손계산 예시**: H₀: μ = 40, x̄ = 45.2, σ = 12, n = 64

```
SE = 12/√64 = 12/8 = 1.5

z = (45.2 − 40) / 1.5 = 5.2 / 1.5 ≈ 3.47

해석: 관측된 x̄ = 45.2는 H₀ 기준값 40에서 3.47 표준오차 떨어짐
     → N(0,1) 분포에서 |Z| > 3.47은 매우 드문 일
```

---

#### 3.4.4 유의확률(p-값)

**p-값의 정확한 정의** — 가장 자주 오해되는 개념:

> **p-값 = "귀무가설(H₀)이 참이라는 가정 하에서, 관측된 검정통계량만큼 극단적이거나 더 극단적인 값이 나올 확률"**

```
p-값 계산 예시:

z = 3.47, 양측검정 (Hₐ: μ ≠ 40)

p-값 = P(|Z| ≥ 3.47 | H₀ 참)
     = 2 × P(Z ≥ 3.47)
     = 2 × .0003
     = .0006

해석: "μ = 40이 참이라면, 이 정도로 극단적인 x̄가 나올 확률은 0.06%"
```

**판단 기준**:

```
p-값 < α(유의수준):  H₀ 기각 → "통계적으로 유의하다"
p-값 ≥ α:           H₀ 기각 실패 → "통계적으로 유의하지 않다"

예시 (α = .05):
  p = .0006 < .05 → H₀: μ=40 기각 → "μ는 40이 아니다"
  p = .085 > .05  → H₀ 기각 실패 → "μ=40을 반박할 충분한 증거 없음"
```

> **핵심 납득 포인트**: p-값은 H₀가 참일 때 데이터가 나올 확률이다. "H₀가 참일 확률"이 아니다. μ는 고정값이므로 H₀가 참이거나 거짓이지, 확률이 없다. p-값이 측정하는 것은 **데이터의 희소성(데이터가 얼마나 특이한가)**이지, **가설의 참·거짓 확률**이 아니다.

## 4. 수식 정리

```
=== 기호 약속 ===
μ₀        = 귀무가설에서 가정하는 모평균 (고정값)
α         = 유의수준 (significance level); 관행: .05
z*        = 신뢰구간 임계값 (95%: z*=1.96, 99%: z*=2.576)
z_obs     = 관측된 검정통계량
p-값      = 관측 통계량만큼 극단적인 값이 나올 확률 (H₀ 하)

=== 수식 목록 ===

① 표준오차
   SE = σ/√n   (σ 알 때)
   SE = s/√n   (σ 모를 때, s로 대체 → t분포, Ch.9)

② 점추정
   μ를 x̄로 추정: E(x̄) = μ (불편추정량)

③ 신뢰구간 (σ 알 때)
   x̄ ± z* × SE
   95% CI: z* = 1.96
   99% CI: z* = 2.576

④ z-검정통계량
   z = (x̄ − μ₀) / SE = (x̄ − μ₀) / (σ/√n)

⑤ p-값 (양측검정)
   p = 2 × P(Z ≥ |z_obs|)

⑥ 결정 규칙
   p < α  → H₀ 기각 (통계적으로 유의)
   p ≥ α  → H₀ 기각 실패

=== 손계산 예시 (n=64, x̄=45.2, σ=12, H₀: μ=40) ===

SE = 12/8 = 1.5

95% CI = 45.2 ± 1.96 × 1.5 = 45.2 ± 2.94 = [42.26, 48.14]
         → CI에 40이 없음 → "μ = 40은 이 구간 밖" → H₀ 기각과 일치

z = (45.2 − 40) / 1.5 = 3.47

p-값 = 2 × P(Z ≥ 3.47) ≈ 2 × .0003 = .0006

결정 (α = .05): p = .0006 < .05 → H₀ 기각
→ "이 집단의 모평균 STAI-T는 40이 아니다 (통계적으로 유의)"

[신뢰구간과 가설검정의 대응 관계]
  95% CI에 μ₀가 포함되면 → α=.05에서 H₀ 기각 안 됨 (일치)
  95% CI에 μ₀가 없으면  → α=.05에서 H₀ 기각 (일치)
  두 방법은 같은 수학을 다른 방식으로 표현한 것!
```

## 5. 심리학 연구 맥락 연결

### 시나리오 A: PTSD 선별 집단의 불안 수준

**연구 질문**: "재난 피해자 선별 집단의 STAI-T 평균이 규준(μ₀=40)보다 높은가?"

```
데이터: n=64, x̄=45.2, σ=12
H₀: μ = 40
Hₐ: μ > 40  (단측검정 — 연구자가 높을 것이라 예상)

SE = 12/√64 = 1.5

z = (45.2 − 40) / 1.5 = 3.47

단측 p-값 = P(Z ≥ 3.47) ≈ .0003

결정 (α = .05): p = .0003 < .05 → H₀ 기각
결론: "재난 피해자 집단의 STAI-T 모평균은 규준 40보다 통계적으로 유의하게 높다 (z = 3.47, p < .001)."

95% 단측 CI (하한): x̄ − 1.645 × SE = 45.2 − 2.47 = 42.73
→ μ ≥ 42.73 (단측 95% CI)
```

### 시나리오 B: 가설검정의 오류 유형 임상 사례

| | 치료 효과 실제로 있음 | 치료 효과 실제로 없음 |
|--|----------------------|----------------------|
| **"효과 있다" 결론 (H₀ 기각)** | 올바른 결정 ✓ | **1종 오류** (α = .05) |
| **"효과 없다" 결론 (H₀ 유지)** | **2종 오류** (β) | 올바른 결정 ✓ |

**시나리오**:
- 새 CBT 프로그램 개발. 실제로는 효과 없음.
- n=15의 소규모 파일럿 연구: 운 좋게 p = .038 → "효과 있다!" 결론 → **1종 오류**
- 이후 n=200의 대규모 RCT: p = .43 → 진실이 드러남

1종 오류 예방을 위해: α를 낮추거나 (예: .01), 사전등록(preregistration), 복제 연구.

> **중요한 시사점**: α = .05는 "20번 중 1번은 실제로 효과 없어도 유의하게 나온다"는 허용이다. 따라서 단일 연구의 p < .05는 효과가 실재한다는 확정적 증거가 아니다. 복제 연구와 메타분석이 중요한 이유다.

## 6. 논문 스니펫 읽기 실습

다음은 가상의 논문 Results 절이다. 읽고 질문에 답하라.

---

*"Among the 64 participants with a primary diagnosis of Posttraumatic Stress Disorder (PTSD), the mean score on the State-Trait Anxiety Inventory, Trait subscale (STAI-T; Spielberger et al., 1983) was M = 45.2 (SD = 11.8, SE = 1.48). A one-sample z-test was conducted to compare this sample mean against the normative population mean (μ₀ = 40.0, σ = 12.0). The test yielded z = 3.47, p < .001 (two-tailed). The 95% confidence interval for the population mean was [42.26, 48.14]."*

---

**연습 질문:**

1. 귀무가설과 대립가설을 기호로 쓰고 해석하라.
2. z = 3.47은 어떻게 계산되었는가? 손계산으로 확인하라.
3. "p < .001 (two-tailed)"의 정확한 의미는?
4. 95% CI [42.26, 48.14]를 보고 α = .05 수준에서 H₀: μ=40을 기각할 수 있는가? 이유는?
5. 이 결과에서 1종 오류가 발생했을 가능성이 있는가? 어떻게 판단하는가?

---

**모범 답안:**

**1. 가설 설정**
```
H₀: μ = 40  (PTSD 집단의 STAI-T 모평균은 규준과 같다)
Hₐ: μ ≠ 40  (PTSD 집단의 STAI-T 모평균은 규준과 다르다)
양측검정: 차이의 방향을 사전에 특정하지 않음
```

**2. z 계산 확인**
```
SE = σ/√n = 12.0/√64 = 12.0/8.0 = 1.500
z = (x̄ − μ₀) / SE = (45.2 − 40.0) / 1.500 = 5.2 / 1.500 ≈ 3.47  ✓

※ 논문의 SE = 1.48은 σ=12 대신 s=11.8을 사용했기 때문:
   SE_s = s/√n = 11.8/8 = 1.475 ≈ 1.48
   (실제 연구에서는 σ 모르므로 s 사용 → t검정, Ch.9)
```

**3. p < .001의 의미**
```
"H₀(μ=40)이 참이라는 가정 하에서, |z| ≥ 3.47이 나올 확률이 .001 미만이다."

p = 2 × P(Z ≥ 3.47) ≈ 2 × .0003 = .0006 → 따라서 p < .001 ✓

오해하기 쉬운 해석 (모두 틀림):
  ✗ "μ=40일 확률이 0.1% 미만이다"
  ✗ "이 결과가 사실일 확률이 99.9% 이상이다"
  ✗ "효과 크기가 크다"
```

**4. CI로 H₀ 판단**
```
95% CI = [42.26, 48.14]
이 구간에 μ₀ = 40이 포함되어 있는가? → 포함되지 않음 (40 < 42.26)

→ α = .05에서 H₀: μ=40 기각 가능

이유: 95% CI 밖에 μ₀가 있다는 것은 α=.05에서 p < .05와 동치임.
     신뢰구간과 가설검정은 같은 수학의 두 가지 표현이므로 항상 일치한다.
```

**5. 1종 오류 가능성**
```
1종 오류는 "H₀가 실제로 참인데 기각하는 것."

이 연구만으로는 1종 오류 발생 여부를 알 수 없다. μ의 참값을 알 수 없기 때문이다.
α = .05라면 장기적으로 5%의 확률로 1종 오류가 발생한다.

가능성 판단 근거:
  - p < .001: 매우 작은 p값 → 1종 오류일 가능성은 낮지만 0이 아님
  - n=64: 중간 크기, 특이한 표본일 가능성 존재
  - 복제 연구 결과가 일치하면 1종 오류 가능성 낮아짐

결론: 단일 연구에서 1종 오류 확인 불가. 복제 연구와 메타분석이 필요하다.
```

## 7. 오개념 경고

> **⚠️ 오개념 1**: "95% CI는 이 구간에 μ가 있을 확률이 95%다"
> → **정확하지 않다.** μ는 고정된 참값이므로 특정 CI [42.26, 48.14]가 μ를 포함하는지는 이미 정해져 있다(포함하거나 포함하지 않거나). 확률이 없다.
>
> 정확한 해석: "이 방법으로 신뢰구간을 반복 계산하면, 그 중 95%가 μ를 포함한다."
> 즉 95%는 **이 특정 구간**의 속성이 아니라 **이 방법의 장기적 성공률**이다.

> **⚠️ 오개념 2**: "p = .0006은 H₀가 참일 확률이 0.06%다"
> → **p-값은 H₀의 확률이 아니다.** 가장 흔하고 위험한 오해다.
>
> p-값은 "H₀가 참이라는 전제 하에서 이런 데이터가 나올 확률"이다. H₀가 참일 확률이 아니다. 뒤집으면 안 된다.
>
> 비유: "범인이 현장에 없다면 이 증거가 나올 확률"과 "이 증거가 있을 때 범인이 현장에 없을 확률"은 전혀 다르다. (Ch.3 조건부확률의 방향!)

> **⚠️ 오개념 3**: "p > .05이면 효과가 없다"
> → **"증거 없음 ≠ 없음의 증거"다.** p > .05는 "귀무가설을 기각할 충분한 증거가 없다"는 것이지, "효과가 없다"는 것이 아니다.
>
> n=5인 소규모 연구: 실제로 큰 효과가 있어도 검정력이 낮아 p > .05가 나올 수 있다(2종 오류). "유의하지 않다 = 효과 없다"라는 해석은 틀렸다.

> **⚠️ 오개념 4**: "p < .05이면 효과가 크다(임상적으로 의미 있다)"
> → **통계적 유의성과 임상적 의의는 완전히 다르다.** n이 매우 크면 아주 작은 차이도 p < .05가 된다.
>
> 예: n = 10,000에서 BDI-II 차이 0.3점, p = .001 → 통계적으로 유의하지만 임상적으로 무의미. 효과크기(Cohen's d, η² 등)를 함께 보고해야 한다. (부록 참고)

> **⚠️ 오개념 5**: "α = .05는 과학적으로 정당화된 기준이다"
> → **관례(convention)이지 자연법칙이 아니다.** Ronald Fisher가 제안한 실용적 기준이 굳어진 것이다.
>
> 상황에 따라: 신약 임상시험(α = .01 또는 .001), 탐색적 연구(α = .10), 유전체 연구(α = 5×10⁻⁸). 최근 "p < .005로 기준을 낮춰야 한다"는 논의도 있다. α 선택은 1종·2종 오류의 상대적 비용에 관한 판단이다.

## 부록: 보완 주제 — 통계적 검정력과 G*Power

> **이 주제가 중요한 이유**: 논문의 Methods 절에서 "a priori power analysis was conducted using G*Power" 같은 문장을 자주 보게 된다. 연구 전 표본 크기를 어떻게 결정하는지, 검정력이 무엇인지를 이해하지 못하면 연구 설계를 비판적으로 읽을 수 없다.

---

### 검정력 (Statistical Power) = 1 − β

```
"실제로 효과가 있을 때, 그것을 통계적으로 검출할 확률"

검정력에 영향을 주는 4가지 요소:
  1. 표본 크기 n     ↑ → 검정력 ↑ (가장 직접적)
  2. 효과 크기       ↑ → 검정력 ↑ (실제 차이가 클수록 쉽게 검출)
  3. 유의수준 α      ↑ → 검정력 ↑ (하지만 1종 오류도 증가)
  4. 표준편차 σ      ↓ → 검정력 ↑ (변동성이 작을수록 차이 보기 쉬움)
```

---

### 효과크기 (Effect Size)

통계적 유의성과 독립적으로 **실질적 크기**를 표현:

```
Cohen's d (두 평균 차이):
  d = (μ₁ − μ₂) / σ_pooled

Cohen(1988) 기준:
  d = 0.20: 소 (small)
  d = 0.50: 중 (medium)
  d = 0.80: 대 (large)

논문에서: t(48) = 2.31, p = .025, d = 0.65
          → 통계적으로 유의하고, 효과 크기는 중간~대 수준
```

---

### G*Power를 이용한 표본 크기 결정

**사전 검정력 분석 (a priori power analysis)** 의 논리:

```
연구자가 결정해야 할 것:
  α = .05 (유의수준)
  1−β = .80 (목표 검정력)
  d = 0.50 (예상 효과 크기, 선행 연구 기반)

위 조건에서 필요한 n은?
→ G*Power 계산: 양측 단일표본 t검정 기준 n ≈ 33

APA 논문에서:
  "An a priori power analysis (G*Power 3.1; Faul et al., 2009) indicated
   that n = 33 was needed to detect a medium effect size (d = 0.50) with
   80% power at α = .05 (two-tailed)."
```

**검정력 부족 연구(underpowered study)의 문제**:

```
n = 10으로 d = 0.50을 검출하려 하면:
  검정력 ≈ .18 → 18%의 확률로만 검출 가능
  즉 82%의 확률로 2종 오류 발생

검정력이 낮은 연구의 두 가지 문제:
  1. 효과가 있어도 발견 못 함 (2종 오류)
  2. 발견했을 때의 효과 크기가 과대추정됨 (출판 편향과 결합)
     → "유의한 결과만 출판" → 작은 표본의 유의한 결과는 운이 좋았을 가능성
```

> **핵심 납득 포인트**: 논문을 읽을 때 Methods에 검정력 분석이 없고 n이 매우 작다면 (예: n=15 per group), 유의하지 않은 결과를 "효과 없음"으로 해석하지 말아야 한다. 검정력이 낮아서 발견하지 못했을 수 있기 때문이다.
