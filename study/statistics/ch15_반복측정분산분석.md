> **"같은 환자에게 치료 전(T1), 치료 중(T2), 치료 후(T3)에 BDI-II를 측정해서 시점 간에 우울 점수가 변화했는지 알고 싶다."**

여기서 핵심은 **같은 사람을 여러 번 측정**한다는 점이다. 이 경우 일원배치 ANOVA를 그냥 쓰면 큰 문제가 생긴다 — 독립성 가정을 위반하기 때문이다.

Ch.15는 이 상황을 위해 설계된 **반복측정 분산분석 (repeated measures ANOVA)** 을 다룬다. 이 방법의 핵심 장점은 "같은 사람이기 때문에 생기는 개인차(개인마다 원래 점수가 높거나 낮은 것)"를 오차에서 제거해서 **검정력(statistical power)** 을 높인다는 점이다.

### 3.1 반복측정 설계란: 왜 독립성 가정을 의도적으로 위반하는가?

#### 직관부터 시작

> **질문**: "BDI-II를 같은 환자에게 치료 전(T1), 치료 중(T2), 치료 후(T3)에 세 번 측정했다. 이 데이터로 일원배치 ANOVA를 그냥 쓰면 어떤 문제가 생기는가?"

일원배치 ANOVA의 핵심 가정 중 하나는 **독립성(independence)**: 모든 관측값이 서로 독립이어야 한다. 그런데 같은 환자의 T1, T2, T3 점수는 독립이 아니다.

왜냐하면:

```
환자 A: 원래 우울 점수가 높은 사람 → T1, T2, T3 점수 모두 상대적으로 높을 것
환자 B: 원래 우울 점수가 낮은 사람 → T1, T2, T3 점수 모두 상대적으로 낮을 것

→ 같은 환자의 세 측정값은 서로 상관이 있다 (독립이 아님)
```

이를 **독립성 가정 위반**이라고 한다. 일원배치 ANOVA는 이 위반을 알아채지 못하고, 결과적으로 부정확한 F-통계량을 산출한다.

#### 그렇다면 반복측정 ANOVA는 무엇이 다른가?

반복측정 설계는 독립성 가정 위반을 **"오히려 장점으로 전환"** 한다.

핵심 아이디어:

```
[일원배치 ANOVA의 오차 구조]
SS_within = 집단 내 변동
           = 참가자 간 개인차 + 순수 잔차 오차
           (이 둘을 구분하지 못함)

[반복측정 ANOVA의 오차 구조]
SS_within 을 두 부분으로 분리:
  SS_subjects = 참가자 간 개인차 (A씨는 원래 점수가 높다는 사실)
  SS_error    = 순수 잔차 오차 (우리가 설명하지 못하는 진짜 잔차)

→ F 계산 시 SS_error만 분모로 사용 → 분모가 작아짐 → F가 커짐 → 검정력 향상!
```

**비유로 이해하기:**

10명의 학생이 치료 전/후 시험을 보는 상황을 생각해보자. 어떤 학생은 원래 공부를 잘해서 전/후 모두 점수가 높다. 이 "원래 점수 수준"(개인차)은 치료 효과와는 관계없는 노이즈다. 반복측정 ANOVA는 이 노이즈를 분리해서 제거하므로, 순수한 치료 효과(시점 간 변화)를 더 정확하게 포착할 수 있다.

> **핵심 납득 포인트**
>
> 반복측정 설계는 독립성 가정을 "의도적으로 위반"하는 것이 아니다. 정확히 말하면, 같은 참가자를 반복 측정한다는 설계 자체가 개인차를 통제하는 **장점**이 된다. 일원배치 ANOVA는 이 개인차를 오차에 뭉뚱그려 넣지만, 반복측정 ANOVA는 이를 **별도로 분리**하여 더 순수한 검정을 가능하게 한다. 결과적으로 **같은 연구에서 더 적은 표본으로 더 강한 검정력**을 얻을 수 있다.

### 3.2 SS 분해의 차이: 일원배치 vs. 반복측정

#### 일원배치 ANOVA의 변동 분해

```
SS_total = SS_between + SS_within

SS_between: 집단(시점) 간 차이
SS_within:  집단 내 변동 (개인차 + 잔차 오차가 뭉쳐 있음)

F = MS_between / MS_within
```

#### 반복측정 ANOVA의 변동 분해

```
SS_total = SS_time + SS_subjects + SS_error

SS_time:     시점 간 차이  ← 우리가 검정하려는 것
SS_subjects: 참가자 간 개인차  ← 오차에서 제거!
SS_error:    순수한 잔차 오차  (= SS_within − SS_subjects)

F = MS_time / MS_error   ← MS_subjects는 F 계산에 사용 안 함!
```

**핵심 차이를 표로 정리:**

| 구분 | 일원배치 ANOVA | 반복측정 ANOVA |
|------|----------------|----------------|
| 변동 분해 | SS_total = SS_between + SS_within | SS_total = SS_time + SS_subjects + SS_error |
| F의 분자 | MS_between | MS_time |
| F의 분모 | MS_within (개인차 포함) | MS_error (개인차 제거) |
| 개인차 처리 | 오차에 포함 | 별도 분리 → 검정력 향상 |
| 독립성 가정 | 필요 | 불필요 (대신 구형성 가정 필요) |

#### 자유도 계산

```
k = 시점 수 (number of time points)
n = 참가자 수 (number of participants)
N = k × n (총 관측값 수)

df_time     = k − 1              (시점 수 − 1)
df_subjects = n − 1              (참가자 수 − 1)
df_error    = (k − 1)(n − 1)     (자유도 곱)
df_total    = N − 1 = kn − 1

확인: df_time + df_subjects + df_error
    = (k−1) + (n−1) + (k−1)(n−1)
    = (k−1) + (n−1) + kn − k − n + 1
    = kn − 1 = df_total  ✓
```

**자유도 예시 (k = 3, n = 20):**

```
df_time     = 3 − 1 = 2
df_subjects = 20 − 1 = 19
df_error    = (3−1)(20−1) = 2 × 19 = 38
df_total    = 3 × 20 − 1 = 59

일원배치 ANOVA였다면:
  df_between = 2
  df_within  = 60 − 3 = 57  ← 반복측정에서는 19가 SS_subjects로 분리됨

→ 반복측정 ANOVA에서 F 분모의 df_error = 38로,
  일원배치의 df_within = 57보다 작다 (더 순수한 오차 추정)
```

> **핵심 납득 포인트**
>
> "F 분모의 자유도가 작아지면 F가 더 작아지지 않나?"라는 의문이 들 수 있다. 하지만 그것보다 **MS_error가 훨씬 크게 줄어드는 효과**가 더 크다. SS_subjects(개인차)를 분리했기 때문에 MS_error의 분자(SS_error)가 대폭 감소하고, 결국 F는 일원배치 ANOVA보다 커지는 경향이 있다. 이것이 반복측정 설계의 핵심 장점이다.

### 3.3 구형성 가정 (Sphericity Assumption)

#### 직관부터 시작

> **질문**: "반복측정 ANOVA는 독립성 가정 대신 어떤 가정이 필요한가?"

반복측정 ANOVA는 독립성 가정 대신 **구형성 (sphericity)** 가정을 요구한다.

#### 구형성이란?

**구형성 (sphericity)**: 모든 시점 쌍의 차이 점수들이 **동일한 분산**을 가져야 한다는 가정이다.

예를 들어 T1, T2, T3이 세 시점이면:

```
차이 점수들의 분산이 모두 같아야 한다:
  Var(T1 − T2) = Var(T1 − T3) = Var(T2 − T3)
```

**구형성 가정을 직관적으로 이해하기:**

```
[구형성 충족 예시]
  T1 → T2 변화: 어떤 사람은 5점 낮아지고, 어떤 사람은 3점 높아짐 → Var = 4
  T1 → T3 변화: 어떤 사람은 6점 낮아지고, 어떤 사람은 2점 높아짐 → Var ≈ 4
  T2 → T3 변화: 어떤 사람은 5점 낮아지고, 어떤 사람은 3점 높아짐 → Var ≈ 4
  → 세 쌍의 분산이 비슷하다 → 구형성 충족

[구형성 위반 예시]
  T1 → T2 변화: Var = 4  (초기 변화가 일관적)
  T2 → T3 변화: Var = 20 (후기 변화가 매우 다양: 어떤 사람은 크게 낮아지고, 어떤 사람은 별 변화 없음)
  → 차이 분산이 크게 다르다 → 구형성 위반
```

#### 구형성 위반의 결과

구형성이 위반되면:

```
F값이 과대 추정된다 → 1종 오류(α) 팽창
→ 실제로는 유의하지 않은데 유의하다고 잘못 결론 낼 위험 증가
```

즉, 구형성 위반을 무시하고 반복측정 ANOVA를 실시하면 **결과가 너무 "관대"하게** 나온다.

#### Mauchly의 구형성 검정 (Mauchly's Test of Sphericity)

구형성 가정의 충족 여부를 공식적으로 검정하는 방법이 **Mauchly 검정**이다.

```
H₀: 구형성 가정이 충족된다 (모든 차이 점수의 분산이 동일하다)
Hₐ: 구형성 가정이 위반된다

p < .05 → H₀ 기각 → 구형성 위반 → 수정이 필요하다!
p ≥ .05 → H₀ 기각 실패 → 구형성 위반을 입증하지 못함 → 수정 없이 진행 가능
```

**APA 보고 형식 예시:**

> "Mauchly's test indicated that the assumption of sphericity was violated, χ²(2) = 7.84, p = .020"

여기서 χ²(2)의 자유도 2는: k(k−1)/2 − 1 = 3×2/2 − 1 = 2 (k = 3일 때)

#### 구형성 위반 시 해결책 세 가지

| 방법 | 내용 | 특성 |
|------|------|------|
| Greenhouse-Geisser (GG) 수정 | ε(엡실론)을 이용해 자유도 축소 수정 | 보수적 (conservative) |
| Huynh-Feldt (HF) 수정 | ε을 더 관대하게 추정해 자유도 수정 | 덜 보수적 (less conservative) |
| MANOVA로 전환 | 다변량 방법으로 전환, 구형성 불필요 | 표본이 클 때 유리 |

**실무 지침:**

```
ε ≥ .75 → Huynh-Feldt 수정 (논문에서 자주 사용)
ε < .75 → Greenhouse-Geisser 수정 (더 보수적, 더 안전)
표본이 매우 클 때 → MANOVA 고려
```

> **핵심 납득 포인트**
>
> 구형성 검정을 왜 하는가? — "공정한 F값"을 보고하기 위해서다. 구형성이 위반되면 F가 실제보다 부풀려지므로, ε 수정을 통해 자유도를 줄여 F를 더 엄격하게 판정한다. 논문에서 소수점 자유도("F(1.48, 27.37)")가 등장하는 이유가 바로 이 ε 수정 때문이다. 자유도가 소수점이라는 것은 "구형성 위반을 교정했다"는 신호다.

---

### 3.4 ε(엡실론) 수정 방법

#### ε(엡실론)이란?

**ε (epsilon)**: 구형성 가정의 위반 정도를 0과 1 사이의 값으로 나타내는 지수다.

```
ε의 범위: 1/(k−1) ≤ ε ≤ 1

  ε = 1:       완전한 구형성 (수정 불필요)
  ε = 1/(k−1): 최대 위반 (최대 수정 필요)

예: k = 3이면
  최솟값: ε = 1/(3−1) = 0.5
  최댓값: ε = 1 (완전 구형성)
```

#### ε을 이용한 자유도 수정

구형성이 위반된 경우, 원래 자유도에 ε을 곱해서 축소한다:

```
원래 자유도:
  df_time  = k − 1
  df_error = (k−1)(n−1)

수정된 자유도 (Greenhouse-Geisser 또는 Huynh-Feldt):
  df'_time  = ε × (k − 1)
  df'_error = ε × (k−1)(n−1)
```

**수정의 효과:**

```
ε = 0.74, k = 3, n = 20이면:

  원래 df_time  = 3 − 1 = 2
  원래 df_error = (3−1)(20−1) = 38

  수정된 df'_time  = 0.74 × 2 = 1.48
  수정된 df'_error = 0.74 × 38 = 28.12

→ 자유도가 줄어들면서 임계 F값이 커지고
  → 더 엄격한 기준으로 유의성을 판정한다
```

#### 논문 보고 형식

```
APA 7판 구형성 위반 보고 표준 형식:

"Mauchly's test indicated that the assumption of sphericity was violated,
 χ²(2) = 8.43, p = .015; therefore, degrees of freedom were corrected
 using Greenhouse-Geisser estimates (ε = .72)."

이어서 F 결과:
"Results revealed a significant effect of time,
 F(1.44, 27.36) = 9.87, p < .001, partial η² = .34."

여기서:
  1.44 = 0.72 × (3−1) = 0.72 × 2     (수정된 df_time)
 27.36 = 0.72 × (3−1)(20−1) = 0.72 × 38  (수정된 df_error)
```

**ε 값의 해석:**

```
ε = 1.00: 완전 구형성 → 수정 불필요
ε = 0.90: 가벼운 위반 → 수정 권장
ε = 0.70: 중간 위반   → GG 수정 필요
ε = 0.50: 심각한 위반 → GG 수정 또는 MANOVA 고려
ε = 1/(k−1): 최대 위반
```

> **핵심 납득 포인트**
>
> ε 수정은 "벌점 시스템"과 같다. 구형성을 위반할수록(ε이 낮을수록) 자유도가 더 많이 줄어든다. 자유도가 줄면 F 분포의 임계값이 올라가고, 결국 동일한 F 값으로 유의미한 결론을 내리기가 더 어려워진다. 이것은 "규칙을 어긴 만큼 더 엄격한 기준을 적용한다"는 논리다.

### 3.5 손계산 예시 (소규모 데이터)

#### 설정

- k = 3 시점 (T1: 치료 전, T2: 치료 중, T3: 치료 후)
- n = 4 참가자
- 결과 변수: BDI-II 점수

**데이터:**

| 참가자 | T1 (치료 전) | T2 (치료 중) | T3 (치료 후) | 참가자 합계 | 참가자 평균 (x̄ᵢ.) |
|--------|------------|------------|------------|------------|----------------|
| P1     | 30         | 24         | 18         | 72         | 24.0           |
| P2     | 22         | 18         | 12         | 52         | 17.3           |
| P3     | 28         | 20         | 14         | 62         | 20.7           |
| P4     | 24         | 18         | 16         | 58         | 19.3           |
| **시점 합계** | **104** | **80** | **60** | **244** | |
| **시점 평균 (x̄.ⱼ)** | **26.0** | **20.0** | **15.0** | | **전체 평균: 20.33** |

**전체 평균 계산:**

```
x̄ = 244 / (3 × 4) = 244 / 12 ≈ 20.33
```

---

**Step 1: SS_time 계산 (시점 간 변동)**

```
SS_time = n × Σⱼ (x̄.ⱼ − x̄)²

x̄.₁ = 26.0, x̄.₂ = 20.0, x̄.₃ = 15.0, x̄ = 20.33

SS_time = 4 × [(26.0 − 20.33)² + (20.0 − 20.33)² + (15.0 − 20.33)²]
        = 4 × [(5.67)²          + (−0.33)²          + (−5.33)²]
        = 4 × [32.15            + 0.11               + 28.41]
        = 4 × 60.67
        = 242.67
```

---

**Step 2: SS_subjects 계산 (참가자 간 변동)**

```
SS_subjects = k × Σᵢ (x̄ᵢ. − x̄)²

x̄₁. = 24.0, x̄₂. = 17.3, x̄₃. = 20.7, x̄₄. = 19.3, x̄ = 20.33

SS_subjects = 3 × [(24.0 − 20.33)² + (17.3 − 20.33)² + (20.7 − 20.33)² + (19.3 − 20.33)²]
            = 3 × [(3.67)²          + (−3.03)²          + (0.37)²          + (−1.03)²]
            = 3 × [13.47            + 9.18               + 0.14              + 1.06]
            = 3 × 23.85
            = 71.56
```

---

**Step 3: SS_total 계산**

```
SS_total = ΣΣ (xᵢⱼ − x̄)²

각 관측값에서 전체 평균(20.33)을 뺀 값을 제곱해서 모두 합산:

P1: (30−20.33)² + (24−20.33)² + (18−20.33)²
  = 93.51        + 13.47        + 5.43
  = 112.41

P2: (22−20.33)² + (18−20.33)² + (12−20.33)²
  = 2.79         + 5.43         + 69.39
  = 77.61

P3: (28−20.33)² + (20−20.33)² + (14−20.33)²
  = 58.83        + 0.11         + 40.07
  = 99.01

P4: (24−20.33)² + (18−20.33)² + (16−20.33)²
  = 13.47        + 5.43         + 18.75
  = 37.65

SS_total = 112.41 + 77.61 + 99.01 + 37.65 = 326.68
```

---

**Step 4: SS_error 계산**

```
SS_error = SS_total − SS_time − SS_subjects
         = 326.68 − 242.67 − 71.56
         = 12.45
```

---

**Step 5: 자유도**

```
df_time     = k − 1       = 3 − 1 = 2
df_subjects = n − 1       = 4 − 1 = 3
df_error    = (k−1)(n−1) = 2 × 3  = 6
df_total    = kn − 1      = 12 − 1 = 11

검산: 2 + 3 + 6 = 11 = df_total  ✓
```

---

**Step 6: 평균제곱 (MS) 계산**

```
MS_time     = SS_time     / df_time     = 242.67 / 2 = 121.34
MS_subjects = SS_subjects / df_subjects = 71.56  / 3 = 23.85  ← F 계산에 사용 안 함
MS_error    = SS_error    / df_error    = 12.45  / 6 = 2.08
```

---

**Step 7: F-통계량**

```
F = MS_time / MS_error = 121.34 / 2.08 ≈ 58.34

F(2, 6) = 58.34
F_임계값(.05, 2, 6) ≈ 5.14  →  58.34 >> 5.14  →  p < .001  (매우 유의!)
```

---

**Step 8: 분산분석표 완성**

```
반복측정 ANOVA 분산분석표
┌─────────────────────┬────────┬────┬────────┬────────┐
│ 변동원              │   SS   │ df │   MS   │   F    │
├─────────────────────┼────────┼────┼────────┼────────┤
│ 시점 간 (Time)      │ 242.67 │  2 │ 121.34 │ 58.34* │
│ 참가자 간 (Subjects)│  71.56 │  3 │  23.85 │  —     │
│ 오차 (Error)        │  12.45 │  6 │   2.08 │        │
│ 합계 (Total)        │ 326.68 │ 11 │        │        │
└─────────────────────┴────────┴────┴────────┴────────┘
* p < .001
```

---

**Step 9: 일원배치 ANOVA와의 비교 — SS_subjects 제거의 효과**

```
만약 일원배치 ANOVA를 그대로 적용했다면:
  SS_within  = SS_subjects + SS_error = 71.56 + 12.45 = 83.01 (두 변동이 합쳐짐)
  df_within  = N − k = 12 − 3 = 9
  MS_within  = 83.01 / 9 ≈ 9.22

  F_일원배치 = MS_between / MS_within = 121.34 / 9.22 ≈ 13.16

반복측정 ANOVA에서는:
  MS_error = 2.08  (개인차 제거됨)
  F_반복측정 = 121.34 / 2.08 ≈ 58.34

→ F 값 비교: 13.16 (일원배치) vs. 58.34 (반복측정)
→ SS_subjects(개인차)를 제거하자 F가 4.4배 커졌다!
→ 반복측정 ANOVA의 검정력이 훨씬 높음을 확인
```

---

**Step 10: 효과크기 계산**

```
partial η²_time = SS_time / (SS_time + SS_error)
                = 242.67 / (242.67 + 12.45)
                = 242.67 / 255.12
                ≈ .951

→ 매우 큰 효과 (소규모 예시이므로 이 정도로 크게 나옴)
```

**APA 보고 형식:**

```
"A one-way repeated measures ANOVA revealed a significant effect of
 time, F(2, 6) = 58.34, p < .001, partial η² = .95."
```

> **핵심 납득 포인트**
>
> 이 손계산에서 핵심을 하나만 기억하자: 일원배치 ANOVA에서는 MS_within = 9.22이었는데, 반복측정 ANOVA에서는 MS_error = 2.08로 크게 줄었다. 줄어든 만큼(SS_subjects = 71.56)이 바로 "참가자마다 원래 BDI 점수가 다른 것"에 해당한다. 이 개인차를 분리하자 검정력이 대폭 향상된다.

### 3.6 사후검정

#### 반복측정 ANOVA 후 사후검정이 필요한 이유

반복측정 ANOVA의 F-검정(전체 검정, omnibus test)은 "적어도 한 쌍의 시점이 다르다"만을 알려준다. 어떤 시점들이 서로 다른지는 **사후검정(post-hoc tests)** 이 필요하다.

#### Bonferroni 교정 쌍별 비교 (가장 일반적)

반복측정 설계에서 가장 자주 쓰이는 사후검정 방법은 **대응표본 t-검정 + Bonferroni 교정**이다.

```
시점 쌍 수(m): k = 3이면 m = C(3,2) = 3

수정 유의수준: α' = .05 / 3 ≈ .017

각 시점 쌍에 대해 대응표본 t-검정 실시:
  T1 vs. T2:  paired t-test, p-값을 α' = .017과 비교
  T1 vs. T3:  paired t-test, p-값을 α' = .017과 비교
  T2 vs. T3:  paired t-test, p-값을 α' = .017과 비교
```

**손계산 예시 데이터로 T1 vs. T3 대응표본 t-검정:**

```
T1: 30, 22, 28, 24  → x̄₁ = 26.0
T3: 18, 12, 14, 16  → x̄₃ = 15.0

차이 점수 d = T1 − T3: 12, 10, 14, 8
x̄_d = (12 + 10 + 14 + 8) / 4 = 44 / 4 = 11.0

s_d = √[Σ(d − x̄_d)² / (n−1)]
    = √[(1² + 1² + 3² + 3²) / 3]
    = √[(1 + 1 + 9 + 9) / 3]
    = √[20/3]
    = √6.67 ≈ 2.58

t = x̄_d / (s_d / √n) = 11.0 / (2.58 / √4) = 11.0 / 1.29 ≈ 8.53

t(3) = 8.53, p < .001 → .017 기준으로도 유의함
```

#### 효과크기: partial η²

반복측정 ANOVA에서 효과크기는 **partial η²** 을 사용한다 (일반 η²과 다름).

```
partial η²_time = SS_time / (SS_time + SS_error)

         (분모에 SS_subjects를 포함시키지 않음!)

일반 η²와의 차이:
  일반 η²_time = SS_time / SS_total
              = SS_time / (SS_time + SS_subjects + SS_error)
              → SS_subjects까지 분모에 포함되어 더 작게 나옴

  partial η² > 일반 η²  (항상)

논문에서는 partial η²을 보고하는 것이 일반적
```

**Cohen의 partial η² 해석 기준 (ANOVA 맥락):**

```
.01 : 작은 효과 (small)
.06 : 중간 효과 (medium)
.14 : 큰 효과 (large)
```

> **핵심 납득 포인트**
>
> 반복측정 ANOVA 후 사후검정으로 "그냥 대응표본 t-검정 여러 번"을 쓰면 1종 오류 팽창 문제가 생긴다. 그래서 반드시 Bonferroni 교정(또는 다른 다중비교 교정)을 적용해야 한다. 논문에서 "paired t-tests with Bonferroni correction"이라는 표현을 보면 "대응표본 t-검정을 하되 Bonferroni로 α를 조정했다"는 의미다.

### 3.7 혼합설계 (Mixed Design) 간략 소개

#### 혼합설계란?

**혼합설계 (mixed design)**: **피험자간 요인 (between-subjects factor)** 과 **피험자내 요인 (within-subjects factor)** 이 동시에 포함된 설계.

```
피험자간 요인: 참가자가 속한 집단 (예: CBT 집단 vs. 약물치료 집단)
               → 한 참가자는 한 집단에만 속함

피험자내 요인: 반복 측정된 변수 (예: T1, T2, T3 시점)
               → 한 참가자가 모든 시점에서 측정됨
```

#### 임상 연구의 가장 흔한 형태

```
예: 치료 집단(CBT / 약물치료) × 시점(T1 / T2 / T3) 혼합설계

    CBT 집단 (n = 15):  T1(30) → T2(22) → T3(14)
    약물 집단 (n = 15): T1(28) → T2(25) → T3(20)

논문에서:
  "A 2(group: CBT vs. pharmacotherapy) × 3(time: T1, T2, T3)
   mixed ANOVA was conducted."
```

#### 혼합설계의 세 가지 검정

```
1. 주효과 — 집단 (main effect of group):
   CBT 집단과 약물치료 집단의 평균 점수가 전반적으로 다른가?
   → 피험자간 효과 (between-subjects effect)

2. 주효과 — 시점 (main effect of time):
   세 시점의 평균 점수가 유의하게 다른가?
   → 피험자내 효과 (within-subjects effect)

3. 상호작용 효과 — Group × Time:
   시점에 따른 변화 패턴이 집단별로 다른가?
   → "치료 효과가 시점에 따라 집단별로 다르게 나타나는가?"
```

#### 왜 상호작용이 가장 중요한가?

```
[상호작용이 없는 경우: 두 집단의 시점별 변화 양상이 평행]
BDI
35 |  CBT: ●──●──●
30 |
25 |  약물: ○──○──○
20 |
   |  T1   T2   T3
   → 두 집단 모두 같은 속도로 좋아짐
   → "어떤 치료를 하든 변화 패턴은 같다"

[상호작용이 있는 경우: 두 집단의 시점별 변화 양상이 교차 또는 분기]
BDI
35 |  약물: ○──────○────────○  (별 변화 없음)
30 |
25 |  CBT: ●──●
20 |           ──●  (급격히 개선)
   |  T1   T2   T3
   → CBT는 시간이 갈수록 빠르게 좋아지지만, 약물치료는 그렇지 않음
   → "치료 방법에 따라 변화 패턴이 다르다!" ← 이것이 핵심 임상 질문
```

**APA 보고 형식:**

```
"Results revealed a significant Group × Time interaction,
 F(2, 56) = 8.43, p < .001, partial η² = .23."
```

> **핵심 납득 포인트**
>
> 혼합설계에서 주효과(집단 효과, 시점 효과)가 유의해도, 상호작용이 유의하지 않으면 "두 치료의 효과가 다르게 나타난다"는 결론을 내릴 수 없다. 반대로, 상호작용이 유의하면 주효과의 해석이 제한된다 — "어떤 집단에서 시점 효과가 있는지"를 따로 살펴봐야 하기 때문이다. 임상 연구에서 "우리 치료가 더 효과적이다"는 주장은 대부분 유의한 Group × Time 상호작용으로 뒷받침된다.

## §4 수식 정리

```
■ 기호 약속
k        : 시점 수 (number of time points)
n        : 참가자 수 (number of participants)
N        : 총 관측값 수 = k × n
xᵢⱼ     : i번째 참가자의 j번째 시점 관측값
x̄        : 전체(grand) 평균 = ΣΣxᵢⱼ / N
x̄ᵢ.     : i번째 참가자의 시점 평균 (행 평균)
x̄.ⱼ     : j번째 시점의 참가자 평균 (열 평균)
SS_time     : 시점 간 제곱합
SS_subjects : 참가자 간 제곱합
SS_error    : 잔차 오차 제곱합
SS_total    : 전체 제곱합
MS_time     : 시점 간 평균제곱
MS_error    : 잔차 오차 평균제곱
ε        : 엡실론 (구형성 교정 지수)
ε_GG     : Greenhouse-Geisser 엡실론
ε_HF     : Huynh-Feldt 엡실론
partial η² : 편에타제곱 (효과크기)
```

---

### [수식 1] SS 분해

```
SS_total = ΣΣ (xᵢⱼ − x̄)²
         (모든 관측값이 전체 평균에서 벗어난 정도)

SS_time = n × Σⱼ (x̄.ⱼ − x̄)²
         (시점 평균이 전체 평균에서 벗어난 정도, n으로 가중)

SS_subjects = k × Σᵢ (x̄ᵢ. − x̄)²
             (참가자 평균이 전체 평균에서 벗어난 정도, k로 가중)

SS_error = SS_total − SS_time − SS_subjects
          (나머지 순수 잔차)

항등식: SS_total = SS_time + SS_subjects + SS_error  (변동의 분해)
```

**직관 설명:**
- SS_time: "T1에서 T3으로 갈수록 평균이 낮아지는가?" — 시점 효과
- SS_subjects: "P1은 원래 점수가 높고, P2는 원래 점수가 낮다" — 개인차
- SS_error: "그 두 가지로도 설명 안 되는 나머지" — 순수 오차

---

### [수식 2] 자유도와 평균제곱

```
df_time     = k − 1
df_subjects = n − 1
df_error    = (k−1)(n−1)
df_total    = kn − 1

MS_time     = SS_time     / df_time
MS_subjects = SS_subjects / df_subjects  (← F 계산에는 사용 안 함!)
MS_error    = SS_error    / df_error

F = MS_time / MS_error
```

---

### [수식 3] ε 수정 자유도

```
ε_GG (Greenhouse-Geisser epsilon):
  공식이 복잡하므로 소프트웨어(SPSS, R)가 자동 계산
  범위: 1/(k−1) ≤ ε_GG ≤ 1

수정된 자유도:
  df'_time  = ε × (k − 1)
  df'_error = ε × (k−1)(n−1)

수정 후 F-검정:
  F[df'_time, df'_error] = MS_time / MS_error
  (MS 자체는 변하지 않고, 자유도만 줄어듦)
```

---

### [수식 4] 효과크기

```
partial η²_time = SS_time / (SS_time + SS_error)

주의: 분모가 SS_total이 아님!
  일반 η²  = SS_time / SS_total         (SS_subjects도 분모에 포함)
  partial η² = SS_time / (SS_time + SS_error)  (SS_subjects 분모에서 제외)

→ partial η² ≥ 일반 η² (항상)

Cohen(1988) partial η² 기준:
  .01 : 작은 효과
  .06 : 중간 효과
  .14 : 큰 효과
```

```

**분석 절차:**
```
1. Mauchly's test 실시
   → p < .05이면: GG 또는 HF 수정 적용
   → p ≥ .05이면: 수정 없이 진행

2. 반복측정 ANOVA 실시
   → F(df_time, df_error), p, partial η² 산출

3. 유의하면 → Bonferroni 교정 쌍별 비교
   → T1 vs. T2, T1 vs. T3, T2 vs. T3 각각 검정

4. 결과 보고

```

  GG ε = .74 적용

  사후검정(Bonferroni):
    T1 vs. T3: p < .001 (유의)

## §6 논문 스니펫 읽기 실습

### 가상 논문 발췌 (APA 7판 형식)

> **Study excerpt:**
>
> Participants with major depressive disorder (N = 20) completed the Beck Depression Inventory-II (BDI-II) at three time points: pre-treatment (T1), mid-treatment at Week 6 (T2), and post-treatment at Week 12 (T3). A one-way repeated measures ANOVA was conducted to examine changes in BDI-II scores across three time points (pre-treatment, mid-treatment, post-treatment). Mauchly's test indicated that the assumption of sphericity was violated, χ²(2) = 7.84, p = .020; therefore, degrees of freedom were corrected using Greenhouse-Geisser estimates (ε = .74). Results revealed a significant effect of time, F(1.48, 27.37) = 12.34, p < .001, partial η² = .40. Post hoc comparisons using Bonferroni correction indicated significant reductions from pre- to post-treatment (p < .001) and from mid- to post-treatment (p = .032), but not from pre- to mid-treatment (p = .124).

---

### 연습 질문 및 모범 답안

**Q1.** Mauchly's test 결과 χ²(2) = 7.84, p = .020이 나왔다. 왜 Greenhouse-Geisser 수정이 필요했는가?

**모범 답안:**

Mauchly's test의 귀무가설은 "구형성 가정이 충족된다"이다. p = .020 < .05이므로 귀무가설을 기각 — 즉, **구형성 가정이 위반되었다**고 판단한다.

구형성이 위반되면 반복측정 ANOVA의 F-통계량이 실제보다 **과대 추정**되어 1종 오류(α) 팽창이 발생한다. 이를 교정하기 위해 Greenhouse-Geisser ε을 이용해 자유도를 줄이는 수정이 필요하다.

GG 수정을 하지 않으면 "유의하지 않은 결과를 유의하다"고 잘못 결론 내릴 위험이 높아진다.

---

**Q2.** F(1.48, 27.37)에서 자유도 1.48과 27.37은 어떻게 계산되었는가? 원래 자유도는 얼마인가?

**모범 답안:**

원래 자유도(수정 전):
```
k = 3 시점, n = 20 참가자

df_time     = k − 1       = 3 − 1 = 2
df_error    = (k−1)(n−1) = 2 × 19 = 38
```

Greenhouse-Geisser 수정 후 (ε = .74):
```
df'_time  = ε × (k−1)       = .74 × 2  = 1.48
df'_error = ε × (k−1)(n−1) = .74 × 38 = 28.12 ≈ 27.37
```

(논문의 27.37은 반올림 차이이며, 정확히는 .74 × 38 = 28.12이지만 SPSS 등의 소프트웨어가 더 정밀한 소수점을 사용해 27.37이 나온 것이다.)

소수점 자유도가 등장하는 이유는 ε = .74 < 1, 즉 완전 구형성이 아니기 때문이다. 소수점 자유도는 "구형성 위반을 교정했다"는 신호다.

---

**Q3.** partial η² = .40은 어떻게 해석하는가?

**모범 답안:**

partial η² = .40의 의미:

**수식으로 해석:**
```
partial η²_time = SS_time / (SS_time + SS_error) = .40

즉, BDI-II 점수의 "순수 오차를 제외한 변동" 중 40%가 시점 간 차이로 설명된다.
```

**Cohen(1988) 기준으로:**
```
.01: 작은 효과
.06: 중간 효과
.14: 큰 효과  ← .40은 이보다 훨씬 큼

→ partial η² = .40은 매우 큰 효과크기
```

**임상적 해석:**
시점(치료 전/중/후)이 BDI-II 점수 변동을 크게 설명한다. 즉, 이 CBT 치료는 우울 증상 감소에 실질적으로 의미 있는 효과를 보였다고 해석할 수 있다.

---

**Q4.** 사후검정 결과를 요약하면 어떻게 되는가? "T1 vs. T2: p = .124"인데도 전체 F가 유의한 이유는?

**모범 답안:**

Bonferroni 교정(α' = .05/3 ≈ .017) 기준:

```
T1(pre) vs. T3(post): p < .001 < .017  → 유의 (가장 큰 차이)
T2(mid) vs. T3(post): p = .032 > .017  → 유의 (p = .032이지만 α' 기준으로는 유의)
T1(pre) vs. T2(mid):  p = .124 > .017  → 유의하지 않음

※ 주의: "p = .032"는 α = .05보다는 작지만, Bonferroni 교정 기준 α' = .017보다는 크다.
   논문에서는 유의하다고 보고하였으므로, 이 연구에서는 수정 기준을 다르게 적용했거나
   (예: α' = .05), 또는 원문 표현을 그대로 읽어야 한다.
```

**전체 F가 유의한 이유:**
전체 검정(omnibus test)인 반복측정 ANOVA는 "적어도 한 쌍의 시점이 다르다"만을 검정한다. T1 vs. T3의 차이(p < .001)가 충분히 커서 전체 F가 유의해졌다. T1 vs. T2가 유의하지 않다는 것은 "치료 초기(0~6주) 사이에는 유의한 변화가 없었지만, 후기(6~12주, 또는 전체 0~12주)에 유의한 변화가 있었다"고 해석한다.

---

**Q5.** 이 연구에서 N은 몇 명인가? df로부터 N을 추정하는 방법을 설명하라.

**모범 답안:**

발췌문에서 직접 명시: **N = 20명**

df로부터 확인하는 방법:
```
원래 df_error = (k−1)(n−1) = 38

k = 3 (시점 수: T1, T2, T3)
(k−1) = 2
(n−1) = 38 / 2 = 19
n = 20

N = k × n = 3 × 20 = 60 (총 관측값 수)
참가자 수 = n = 20명
```

## §7 오개념 경고

> **⚠️ 오개념 1: "반복측정이면 대응표본 t-검정을 여러 번 하면 된다."**
>
> **바로잡기:** 대응표본 t-검정을 여러 번 반복하면 두 가지 문제가 생긴다.
>
> 첫째, **1종 오류 팽창**: k = 3 시점이면 쌍별 비교 3번, α = .05로 각각 검정하면 familywise error rate ≈ .143. "유의하지 않은 차이"도 유의하다고 잘못 결론 낼 위험이 3배 가까이 커진다.
>
> 둘째, **반복측정 ANOVA의 장점을 버리는 것**: 반복측정 ANOVA는 SS_subjects(개인차)를 분리해 검정력을 높이는 것이 핵심이다. 단순 t-검정을 여러 번 하면 이 장점을 활용하지 못한다.
>
> 올바른 접근: 반복측정 ANOVA로 전체 검정을 먼저 실시하고, 유의하면 **Bonferroni 교정을 적용한 대응표본 t-검정**으로 사후검정을 한다.

---

> **⚠️ 오개념 2: "구형성 가정은 정규성 가정과 같다."**
>
> **바로잡기:** 완전히 다른 가정이다.
>
> - **정규성 가정**: 각 시점의 점수 분포가 정규분포를 따라야 한다 (각 열의 분포 형태에 관한 것).
> - **구형성 가정**: 모든 시점 쌍의 **차이 점수들의 분산이 동일**해야 한다 (변동의 동질성에 관한 것).
>
> ```
> 예시:
>   정규성: T1 점수들이 종 모양 분포인가? → Shapiro-Wilk 검정
>   구형성: Var(T1−T2) = Var(T1−T3) = Var(T2−T3)인가? → Mauchly 검정
> ```
>
> 논문에서 Mauchly's test를 보고하는 이유는 정규성이 아니라 **구형성**을 확인하는 것이다.

---

> **⚠️ 오개념 3: "ε(엡실론) 값이 낮을수록 더 좋다."**
>
> **바로잡기:** ε 값이 낮다는 것은 구형성 위반이 심각하다는 의미이므로, 좋지 않다.
>
> ```
> ε = 1.0: 완전한 구형성 → 수정 불필요 → 이상적
> ε = 0.7: 중간 위반 → 자유도 30% 감소 수정
> ε = 0.5: 심각한 위반 → 자유도 50% 감소 수정
>           → 검정력 크게 감소, MANOVA 고려 필요
> ```
>
> 연구자 입장에서 ε이 낮으면 낮을수록 자유도 수정이 커지고, 결과적으로 같은 데이터라도 더 엄격한 기준이 적용되어 유의한 결론을 내리기 어려워진다. 구형성 가정을 충족하는 연구 설계가 이상적이다.

---

> **⚠️ 오개념 4: "반복측정 ANOVA의 F는 일원배치 ANOVA보다 항상 더 크다."**
>
> **바로잡기:** 일반적으로 맞지만, "항상"은 아니다.
>
> SS_subjects(개인차)를 오차에서 제거하기 때문에 MS_error가 줄고 F가 커지는 것이 일반적이다. 하지만:
>
> ```
> 반례가 가능한 경우:
>   만약 참가자들 간에 개인차가 거의 없다면 (SS_subjects ≈ 0)
>   → 오차 분모의 자유도만 작아지고 (df_error < df_within)
>   → MS_error가 MS_within보다 오히려 클 수 있음
>   → F_반복측정 < F_일원배치 가능
>
> 결론: 반복측정 ANOVA의 장점은 개인차(SS_subjects)가 클 때 극대화된다.
>       개인차가 거의 없는 동질적 표본에서는 반복측정 설계의 이점이 작다.
> ```

---

> **⚠️ 오개념 5: "혼합설계에서 집단 효과와 시점 효과가 모두 유의하면 상호작용도 유의하다."**
>
> **바로잡기:** 세 가지 효과(집단 주효과, 시점 주효과, 상호작용)는 **독립적**으로 판단해야 한다. 두 주효과가 유의해도 상호작용이 유의하지 않을 수 있고, 반대로 두 주효과가 유의하지 않아도 상호작용이 유의할 수 있다.
>
> ```
> 예시 — 주효과 유의 + 상호작용 비유의:
>   CBT:  T1=30 → T2=20 → T3=10  (20점 감소)
>   약물: T1=20 → T2=15 → T3=10  (10점 감소, 출발점만 다름)
>   → 집단 주효과: 유의 (CBT가 전반적으로 높음)
>   → 시점 주효과: 유의 (시간이 지날수록 감소)
>   → 상호작용: 비유의 (두 집단의 감소 패턴이 평행함)
>
> 임상적으로 중요한 질문인 "어떤 치료가 더 효과적인가?"는
> 상호작용(Group × Time)으로 검정해야 한다.
> ```

---

> **⚠️ 오개념 6: "partial η²는 일반 η²와 같다."**
>
> **바로잡기:** 반복측정 ANOVA에서 두 효과크기는 분모가 달라 값이 다르다.
>
> ```
> 일반 η²_time = SS_time / SS_total
>              = SS_time / (SS_time + SS_subjects + SS_error)
>              → SS_subjects가 분모에 포함 → 더 작게 나옴
>
> partial η²_time = SS_time / (SS_time + SS_error)
>                → SS_subjects 분모에서 제외 → 더 크게 나옴
>
> 예: SS_time = 242, SS_subjects = 72, SS_error = 12인 경우
>   일반 η²   = 242 / (242 + 72 + 12) = 242 / 326 ≈ .74
>   partial η² = 242 / (242 + 12)      = 242 / 254 ≈ .95
>
> → 차이가 크다! SPSS 등 소프트웨어의 기본 출력은 partial η²이므로
>   논문 해석 시 어떤 η²인지 반드시 확인해야 한다.
> ```

## §8 자기점검

   *(힌트: p < .05이면 귀무가설이 기각된다. 귀무가설이 무엇인지 먼저 확인하자.)*

3. 논문에서 "F(1.72, 32.61) = 15.43"을 보았다. k와 n은 얼마인가? ε은 얼마인가?

## §10 다음 챕터 연결

이 챕터는 **연속형 종속변수**와 **반복 측정**이라는 설계를 다뤘다. 이제 자연스럽게 다음 질문이 생긴다:

> **"종속변수가 이진형(0/1, 예/아니오)이라면 어떻게 분석하는가?"**
> "CBT 치료 후 '관해(remission)'에 도달했는가, 도달하지 못했는가를 예측하려면?"

반복측정 ANOVA는 BDI-II 점수(연속형)의 변화를 분석했다. 그런데 임상 연구에서는 "치료 반응 여부", "재발 여부", "진단 여부"처럼 **이진(binary) 결과 변수**가 매우 흔하다.

이런 이진 결과를 예측하는 방법이 **로지스틱 회귀 (logistic regression)** 다.

```
[Ch.15 반복측정 분산분석]
    "종속변수: 연속형 (BDI-II 점수)"
    "설계: 같은 참가자를 여러 번 측정"
    "질문: 시점에 따라 평균 점수가 변화했는가?"
            ↓
[Ch.16 로지스틱 회귀]
    "종속변수: 이진형 (관해 여부: 0/1)"
    "설계: 독립변수로 연속형·범주형 모두 가능"
    "질문: X가 1 증가할 때 사건 발생 오즈(odds)는 얼마나 변하는가?"
```

Ch.16에서 만날 핵심 개념들:
- 로짓 변환 (logit transformation): 확률(0~1)을 로그 오즈(−∞~+∞)로 변환
- 오즈비 (odds ratio, OR): "X가 1 증가하면 사건 발생 확률이 몇 배로 변하는가?"
- 로지스틱 회귀계수 (β): 오즈 변화의 log 스케일 추정
- 혼합 모형 (mixed models): 반복측정 + 이진 결과를 동시에 다루는 고급 방법

## 부록

### A. 반복측정 ANOVA vs. 대응표본 t-검정 — 언제 무엇을 쓰는가?

| 구분 | 대응표본 t-검정 | 반복측정 ANOVA |
|------|----------------|----------------|
| 비교 시점 수 | **2개** (전/후) | **3개 이상** |
| 1종 오류 문제 | 없음 (1번 검정) | 있음 → 사후검정 필요 |
| 개인차 제거 | 차이 점수로 자동 제거 | SS_subjects로 명시적 제거 |
| 구형성 가정 | 불필요 | 필요 (시점이 3개 이상이므로) |
| 논문 사용 빈도 | 전후 비교에 자주 사용 | 3시점 이상 종단 연구에 필수 |
| APA 보고 형식 | t(df) = ..., p = ..., d = ... | F(df₁, df₂) = ..., p = ..., partial η² = ... |

**핵심 규칙:**
```
시점이 2개 → 대응표본 t-검정
시점이 3개 이상 → 반복측정 ANOVA (+ Mauchly's test)

※ 단, 시점이 2개라도 집단이 추가되면 (예: CBT vs. 약물 × 전/후)
  혼합설계 ANOVA를 사용한다.
```

### B. 결측값 처리 (Missing Data)

반복측정 연구에서 참가자가 모든 시점에 참여하지 못하면 결측값이 생긴다. 이 처리 방법은 논문의 타당성에 큰 영향을 미친다.

**결측 메커니즘 세 가지:**

```
MCAR (Missing Completely At Random, 완전 무작위 결측):
  결측이 어떤 변수와도 관련 없음
  예: 참가자가 측정 당일 갑자기 병원에 가서 빠짐
  → 완전 분석(listwise deletion)도 무방

MAR (Missing At Random, 무작위 결측):
  결측이 관측된 다른 변수와는 관련 있으나, 결측된 값 자체와는 무관
  예: 초기 BDI 점수가 높은 사람들이 중도 탈락하는 경향
  → Multiple Imputation, FIML(Full Information Maximum Likelihood) 권장

MNAR (Missing Not At Random, 비무작위 결측):
  결측이 결측된 값 자체와 관련
  예: 증상이 악화된 사람들이 더 많이 중도 탈락
  → 가장 다루기 어려움, 민감도 분석(sensitivity analysis) 필요
```

**논문에서 결측값 처리 보고 예시:**

> "Missing data were handled using full information maximum likelihood (FIML) estimation. Little's MCAR test indicated that data were not missing completely at random, χ²(12) = 18.43, p = .102; therefore, the MAR assumption was adopted."

### C. 반복측정 ANOVA와 MANOVA의 관계

**MANOVA (Multivariate ANOVA)**: 반복측정 데이터를 다변량(multivariate) 방법으로 분석하는 대안.

| 구분 | 반복측정 ANOVA | MANOVA |
|------|----------------|--------|
| 구형성 가정 | 필요 | 불필요 |
| 검정 방식 | 단변량 F 통계량 | Wilks' Λ, Pillai's trace 등 다변량 통계량 |
| 표본 크기 요건 | 작아도 가능 | n > k가 필요 (참가자 수 > 시점 수) |
| 구형성 위반 시 | ε 수정 필요 | 수정 불필요 |
| 검정력 | 구형성 충족 시 더 높음 | 구형성 위반 시 더 높을 수 있음 |

**실무 지침:**
```
구형성 충족 (Mauchly p ≥ .05) → 반복측정 ANOVA
구형성 위반 + n이 충분히 큼   → MANOVA 고려
구형성 위반 + n이 작음        → GG 또는 HF 수정 반복측정 ANOVA
```

### D. 고급 확장: 선형 혼합 모형 (Linear Mixed Models)

반복측정 ANOVA의 한계를 극복한 현대적 방법이 **선형 혼합 모형 (Linear Mixed Models, LMM)** 또는 **다층 모형 (Multilevel Models)** 이다.

**반복측정 ANOVA의 한계:**
```
① 결측값이 있으면 해당 참가자 전체를 분석에서 제외 (listwise deletion)
② 측정 간격이 불규칙한 경우 처리 불가
③ 시점이 많아질수록 구형성 위반 가능성 증가
④ 공변량(covariate) 모형화가 제한적
```

**선형 혼합 모형의 장점:**
```
① 결측값이 있는 참가자도 가용한 데이터를 모두 활용
② 불규칙한 측정 간격 처리 가능
③ 구형성 가정 불필요 (공분산 구조를 직접 모형화)
④ 임의 효과(random effects)로 개인차를 유연하게 모형화
```

**논문에서 보이는 형태:**
> "Data were analyzed using linear mixed models (LMM) with restricted maximum likelihood (REML) estimation. Time was entered as a fixed effect, and a random intercept was specified to account for within-person correlation."

*(선형 혼합 모형은 대학원 수준의 내용이므로, 학부 단계에서는 이런 방법이 존재한다는 것만 인식하면 된다.)*
