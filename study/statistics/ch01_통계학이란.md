## 3. 핵심 개념 학습

---

### 3.1 모집단과 표본

#### 직관부터 시작

> **질문**: "한국 대학생의 평균 우울 수준을 알고 싶다면, 어떻게 해야 할까?"

가장 정확한 방법: 한국 대학생 전원(약 200만 명)에게 BDI(Beck Depression Inventory)를 실시한다.
→ **불가능하다.** 비용, 시간, 현실적 접근 불가.

**그래서 우리는 일부를 뽑아 측정하고, 그 결과로 전체를 추론한다.**
이 논리가 통계학 전체의 토대다.

#### 핵심 용어 정의

| 개념                          | 정의                                     | 예시                                    |
| ----------------------------- | ---------------------------------------- | --------------------------------------- |
| **모집단 (Population)** | 연구자가 관심을 갖는*모든* 대상의 집합 | 한국 대학생 전체                        |
| **표본 (Sample)**       | 모집단에서 실제로 뽑힌 일부              | BDI를 실시한 300명                      |
| **모수 (Parameter)**    | 모집단의 특성을 나타내는 수치            | 한국 대학생*전체*의 평균 우울 점수 μ |
| **통계량 (Statistic)**  | 표본의 특성을 나타내는 수치              | 300명 표본의 평균 우울 점수 x̄         |

#### 기호 약속 (논문에서 반드시 나온다)

```
모집단 → 그리스 문자 사용:  μ (모평균),  σ (모표준편차),  σ² (모분산)
표본   → 로마 문자 사용:    x̄ (표본평균), s (표본표준편차), s² (표본분산)
```

> **핵심 납득 포인트**: 우리가 실제로 *계산*할 수 있는 것은 통계량(x̄, s)뿐이다.
> μ, σ는 원리상 계산 불가능하다 (모집단 전체를 조사하지 않는 한).
> **통계학이란, 통계량을 이용해 모수를 *추측*하는 학문이다.**

---

#### 기술통계 vs. 통계적 추론

이 구분은 **챕터 2~13 전체를 두 덩어리로 나누는 핵심**이다.

|                    | **기술통계 (Descriptive Statistics)** | **통계적 추론 (Statistical Inference)**    |
| ------------------ | ------------------------------------------- | ------------------------------------------------ |
| **하는 일**  | 수집된 데이터 자체를 요약·묘사             | 표본으로 모집단에 대해 주장                      |
| **질문**     | "이 300명의 평균 우울은 얼마인가?"          | "한국 대학생 전체의 우울은 높다고 할 수 있는가?" |
| **결과물**   | 평균, 표준편차, 그래프                      | 신뢰구간, p-값, 가설검정 결과                    |
| **챕터**     | Ch.2                                        | Ch.8~13                                          |
| **논문에서** | Table 1 (기술통계표)                        | Results 본문 (t(48) = 2.31, p = .025)            |

> **오개념 경고 ①**: 기술통계는 "쉬운 것", 추론통계는 "어려운 것"이 아니다.
> 목적이 다른 것이다. 기술통계는 *묘사*, 추론통계는 *주장*이다.

### 3.2 자료수집방법

#### 왜 수집 방법이 중요한가?

**결론의 일반화 가능성(generalizability)** 이 표집 방법에 달려 있기 때문이다.

편의표본(convenience sample)으로 얻은 결과 — 예를 들어 "심리학과 수업을 듣는 학생들" — 를 "한국 대학생 전체"에 일반화할 수 있는가? **원칙적으로 불가능하다.**

확률적 표집(probability sampling)이 그래서 중요하다:
**모집단의 모든 구성원이 표본에 뽑힐 확률이 0이 아니어야** 통계적 추론이 정당화된다.

---

#### 2.1 단순확률추출 (Simple Random Sampling)

**직관**: 제비뽑기. 모든 사람이 동일한 확률로 뽑힌다.

```
모집단: [1, 2, 3, ..., 200만 명]
↓ 난수 생성
표본: [78만번, 3만번, 155만번, ...] n명
```

- **장점**: 편향 없음, 이론적으로 가장 단순
- **단점**: 모집단 명단(표집틀, sampling frame)이 필요, 소수집단이 과소 표집될 수 있음
- **논문에서**: "Participants were randomly selected from..."

---

#### 2.2 계통추출 (Systematic Sampling)

**직관**: 줄 세워 놓고 k번째마다 한 명씩 뽑기.

```
예시: 1000명 명단에서 100명 뽑기 → k = 10
     → 1~10 중 무작위로 시작점 선택 (예: 7)
     → 7, 17, 27, 37, ... 번 선택
```

- **장점**: 명단만 있으면 쉽게 적용 가능
- **단점**: 명단에 주기적 패턴이 있으면 편향 발생 (예: 기숙사 방 배치가 남/여/남/여 반복인데 k=2로 추출)
- **논문에서**: 행정 데이터나 병원 기록 사용 연구에서 등장

---

#### 2.3 층화확률추출 (Stratified Random Sampling)

**직관**: 모집단을 먼저 *층(stratum)* 으로 나누고, 각 층에서 따로 무작위 추출.

```
예시: 성별·학년 층화
     모집단 → [남/1학년] [남/2학년] ... [여/4학년] (8개 층)
     각 층에서 비율에 맞게 무작위 추출
```

- **장점**: 소수 집단도 충분히 표집 가능, 추정 정확도 향상
- **단점**: 층을 나누는 기준 변수가 필요, 설계가 복잡
- **논문에서**: 역학 연구, 국가 대표 표본 연구에서 필수적

---

#### 2.4 편의표본 (Convenience Sampling)

**직관**: 구하기 쉬운 사람을 뽑는다.

심리학 연구의 현실: 모집단 명단을 구해 무작위 추출하는 것은 대부분의 경우 불가능하다. 그래서 실제 연구의 상당수는 **접근하기 쉬운 대상**에서 표본을 수집한다.

```
예시:
  - 자기 수업을 듣는 학부생 모집
  - 병원에 내원한 환자 중 조건을 충족한 사람 등록
  - 온라인 광고를 보고 자원한 참가자
```

- **장점**: 현실적으로 실행 가능, 비용·시간 절약
- **단점**: 뽑힐 확률이 사람마다 다름 → 통계적 추론의 정당성이 약해짐 → 결과를 모집단 전체에 일반화하기 어려움
- **논문에서**: `"Participants were recruited from..."`, `"Undergraduate volunteers were..."`, `"Patients presenting at..."` 등 **모집(recruit)** 동사가 등장하면 편의표본일 가능성이 높다

> **핵심 납득 포인트**: 편의표본은 *나쁜* 방법이 아니다. 현실적으로 불가피한 경우가 많다.
> 문제는 **편의표본임을 인식하지 못하고** 결과를 모집단 전체에 성급히 일반화할 때 생긴다.
> 논문의 Limitations 절에서 "convenience sample"이 언급되는 이유가 바로 이것이다.

---

#### 확률 표집 vs. 비확률 표집 — 핵심 대비

|                       | **확률 표집**                  | **비확률 표집 (편의표본)** |
| --------------------- | ------------------------------------ | -------------------------------- |
| **방법**        | 단순확률추출, 계통추출, 층화확률추출 | 편의표본, 자원자 표집 등         |
| **뽑힐 확률**   | 계산 가능                            | 알 수 없음                       |
| **통계적 추론** | 정당화됨                             | 제한적                           |
| **논문에서**    | 역학 연구, 국가 대표 표본            | 임상·실험 연구 대부분           |

#### 네 방법 비교 요약

```
단순확률추출:  [전체에서 랜덤]               ← 확률 표집
계통추출:      [순서대로 k번째]              ← 확률 표집
층화확률추출:  [층 나누기 → 각 층에서 랜덤] ← 확률 표집
편의표본:      [접근 가능한 대상에서 모집]   ← 비확률 표집
```

> **핵심 납득 포인트**: 위 세 가지 확률 표집은 누가 뽑힐지 모르지만,
> 뽑힐 확률은 계산 가능하다. 이것이 통계적 추론을 정당화하는 근거다.
> 편의표본은 이 근거가 없기 때문에, 결과 해석 시 반드시 일반화 한계를 명시해야 한다.

### 3.3 가중치 (Weights)

이 섹션은 이 교과서에서 비교적 고급 주제다. 임상·상담 연구에서 직접 사용할 일은 적으나, **국가 대표 데이터(NHANES, KoreanGSS 등)를 사용하는 논문을 읽을 때 반드시 나온다.**

#### 왜 가중치가 필요한가?

표집 설계가 복잡해지면, **일부 집단이 의도적으로 더 많이/적게 뽑힌다.**
이 불균형을 보정하지 않으면 추정이 왜곡된다.

**비유**: 어떤 도시의 평균 소득을 추정하고 싶다. 그런데 표본에 부자가 과다 포함되었다. 단순 평균을 내면? 실제보다 높게 나온다. 이를 보정하는 것이 가중치다.

---

#### 3.1 추출확률에 따른 가중치

층화추출에서 각 층의 추출 확률이 다를 수 있다.
(예: 소수 집단을 더 많이 뽑아서 분석력 확보)

```
가중치 w_i = 1 / (추출확률 π_i)
```

- 추출확률이 낮을수록(= 드물게 뽑혔을수록) 가중치가 커진다
- **수식의 논리**: 이 사람 한 명이 모집단의 더 많은 사람을 "대표"하기 때문

#### 3.2 무응답에 따른 가중치

표본으로 뽑혔어도 설문에 응답하지 않는 경우가 발생한다.
무응답이 랜덤하지 않으면 편향이 생긴다 (예: 심한 우울증 환자가 더 많이 무응답).

이 편향을 줄이기 위해 응답자에게 추가 가중치를 부여한다.

#### 3.3 사후층화를 위한 가중치

표본의 인구통계학적 구성이 모집단과 다를 때(예: 표본에 여성이 더 많음),
인구센서스 비율에 맞게 사후 조정하는 가중치.

> **논문 읽기 포인트**: 국가 대표 표본을 사용한 논문에서는 Methods에
> "Analyses were conducted using sampling weights to account for the complex survey design"
> 과 같은 문장이 등장한다. 이때 당황하지 않으면 된다.

## 4. 수식 정리 (이 챕터의 핵심 수식)

이 챕터는 수식이 거의 없다. 기호 약속이 전부다.

```
모집단 크기:   N
표본 크기:     n
모평균:        μ  (뮤, mu)
표본평균:      x̄  (x-bar)
모표준편차:    σ  (시그마, sigma)
표본표준편차:  s
모분산:        σ²
표본분산:      s²
모비율:        π  또는  p  (교재마다 다름)
표본비율:      p̂  (p-hat)
```

> 이 기호들은 앞으로 모든 챕터에서 반복 등장한다.
> 지금 외우는 것이 아니라, *왜 두 종류인지*만 납득하고 넘어가라.

## 5. 심리학 연구 맥락 연결

### 시나리오 A: 단일 기관 연구

A 병원 정신건강의학과에서 기분장애 환자 50명을 모집해 새 치료 프로그램의 효과를 연구했다.

- **모집단**: 기분장애 환자 *전체* (한국? 전 세계? → 논문에서 명확히 해야 함)
- **표본**: A 병원 환자 50명
- **통계량**: 이 50명의 치료 전후 평균 HAM-D 점수 변화 (x̄ = -8.3)
- **모수**: 기분장애 환자 *전체*에서 이 치료의 평균 효과 (μ, 알 수 없음)
- **표집 방법**: 편의표본(convenience sample) → 일반화에 제한

### 시나리오 B: 국가 역학 연구

국민건강영양조사에서 층화복합표본설계를 사용해 전국 성인 10,000명의 정신건강을 조사했다.

- **모집단**: 한국 성인 전체
- **표본**: 층화추출된 10,000명
- **표집 방법**: 층화확률추출 → 결과를 전국 성인에게 일반화 가능
- **가중치**: 추출확률·무응답·사후층화 가중치 모두 적용

> **중요한 시사점**: 같은 "10명 중 8명이 우울 증상을 경험" 이라는 결과도,
> 편의표본이냐 층화확률표본이냐에 따라 결론의 의미가 완전히 다르다.

## 6. 논문 스니펫 읽기 실습

다음은 가상의 논문 Methods 절 일부다. 읽고 질문에 답하라.

---

*"Participants were recruited from three outpatient clinics in Seoul (N = 127). Inclusion criteria included a primary diagnosis of Major Depressive Disorder (MDD) and current score above 17 on the Hamilton Depression Rating Scale (HAM-D). Participants completed the Beck Depression Inventory-II (BDI-II) at baseline, post-treatment (8 weeks), and 3-month follow-up. The final analysis included 112 participants who completed all assessments."*

---

**연습 질문:**

1. 이 연구의 **모집단**은 무엇인가?
2. **표본 크기** n은 얼마인가? (처음 모집된 수 vs 최종 분석 수)
3. 이 표본은 어떤 **표집 방법**에 가까운가? 왜?
4. 이 연구 결과를 "MDD 환자 전체"에 일반화할 수 있는가? 제한점은?
5. `BDI-II 점수의 평균 변화 = -12.3`이 논문에 보고되었다면, 이것은 **모수**인가 **통계량**인가?

**모범 답안:**

1. 논문에 명시되지 않았으나, 문맥상 "MDD 진단을 받은 성인 외래 환자"
2. 처음 127명 → 최종 112명 (탈락률 약 12%)
3. 편의표본 (convenience sample) — 서울 3개 외래 클리닉에서만 모집, 확률추출 아님
4. 일반화에 제한 있음: 서울 외래 환자에 한정, 중증도 기준(HAM-D > 17) 제한
5. **통계량** (x̄) — 112명 표본의 평균. μ는 알 수 없다.

## 7. 오개념 경고

> **⚠️ 오개념 1**: "표본이 크면 모집단이다"
> → 틀렸다. 표본이 아무리 커도 표본은 표본이다. 10만 명도 표본이다.
> 모집단은 *관심 대상 전체*이지, 숫자로 정의되지 않는다.

> **⚠️ 오개념 2**: "기술통계를 하면 추론통계는 필요 없다"
> → 틀렸다. 기술통계는 표본을 *묘사*할 뿐, 모집단에 대해 아무 주장도 하지 않는다.
> 논문에서 기술통계표(Table 1)만 보고 결론을 내릴 수 없다.

> **⚠️ 오개념 3**: "편의표본도 크면 괜찮다"
> → 위험하다. 1936년 Literary Digest 선거 예측 사례: 10만 명 전화 조사로
> Roosevelt 낙선 예측 → 완전히 틀림. 전화기 소유자(부유층)만 뽑혔기 때문.
> 편향된 방법으로 많이 뽑아봤자 편향은 줄지 않는다.

> **⚠️ 오개념 4**: "무작위 = 아무렇게나"
> → 통계에서 '무작위(random)'는 *예측 불가능하지만 확률이 계산 가능한 것*을 의미한다.
> 아무렇게나 고르는 것과 다르다. 연구자가 "저 사람이 착해 보여서" 뽑는 건 무작위가 아니다.

> **⚠️ 오개념 5**: "randomly가 나오면 무작위 표집이다"
> → 틀렸다. 논문에서 random이 쓰이는 맥락은 두 가지로 완전히 다르다.
>
> | | **무작위 표집 (Random Sampling)** | **무작위 배정 (Random Assignment)** |
> |---|---|---|
> | **무엇을** 무작위로 하는가 | 모집단에서 *누구를 뽑는가* | 뽑힌 참가자를 *어느 조건에 넣는가* |
> | **목적** | 표본이 모집단을 대표하게 함 | 집단 간 사전 차이를 제거 (실험 통제) |
> | **관련 개념** | 표집(sampling), 일반화 가능성 | 실험설계, 인과관계 추론 |
> | **논문 표현** | "randomly selected from...", "stratified sampling" | "randomly assigned to conditions" |
>
> 예: *"Participants were randomly assigned to conditions from a pool of undergraduate volunteers"*
> → "randomly"는 실험 **조건 배정**에 해당. 표본은 자원자(volunteers) → **편의표본**.
> 이 문장에 무작위 *표집*은 없다.

## 9. 한영 용어 대조표

| 한국어        | 영어                                 | 논문에서 자주 보이는 형태                         |
| ------------- | ------------------------------------ | ------------------------------------------------- |
| 모집단        | Population                           | "The population of interest was..."               |
| 표본          | Sample                               | "A sample of N = 127 was recruited..."            |
| 모수          | Parameter                            | "population parameter"                            |
| 통계량        | Statistic                            | "sample statistic"                                |
| 모평균        | Population mean                      | μ                                                |
| 표본평균      | Sample mean                          | M = 23.4 또는 x̄ = 23.4                          |
| 기술통계      | Descriptive statistics               | "Descriptive statistics are presented in Table 1" |
| 추론통계      | Inferential statistics               | "Inferential analyses indicated..."               |
| 단순확률추출  | Simple random sampling               | "randomly selected from..."                       |
| 층화확률추출  | Stratified random sampling           | "stratified sampling was employed..."             |
| 가중치        | Weight / Sampling weight             | "weighted analyses", "using survey weights"       |
| 표집틀        | Sampling frame                       | "The sampling frame consisted of..."              |
| 일반화 가능성 | Generalizability / External validity | "limits the generalizability of findings"         |
| 편의표본      | Convenience sample                   | "convenience sample of undergraduate students"    |
