### 3.1 확률표본과 통계량

#### 직관부터 시작

> **질문**: "한국 성인의 평균 우울 수준(μ)을 알고 싶다. 표본 100명에서 x̄ = 12.4를 얻었다. 이것을 믿어도 되는가?"

x̄는 그냥 숫자가 아니다 — 표본을 **다시 뽑으면 다른 값이 나온다.** x̄ 자체가 확률변수다!

#### 핵심 용어 재확인 및 확장

| 개념 | 기호 | 특성 |
|------|------|------|
| **확률표본 (random sample)** | x₁, x₂, ..., xₙ | 모집단에서 독립적으로 뽑힌 n개의 값 |
| **통계량 (statistic)** | x̄, s², p̂ | 표본에서 계산한 값. **표집 시마다 달라진다** |
| **표본평균** | x̄ = Σxᵢ/n | 통계량의 가장 중요한 예 |
| **표본분산** | s² = Σ(xᵢ−x̄)²/(n−1) | 모분산 σ²의 추정치 |
| **표본비율** | p̂ = X/n | 이항분포에서 성공 횟수 X를 n으로 나눈 것 |

**핵심 인식 전환**:

```
Ch.1~6의 관점: x̄는 표본에서 계산한 고정된 숫자
Ch.7의 관점:   x̄는 확률변수 — 표본을 반복 추출하면 값이 달라진다

[같은 모집단에서 반복 표집]
  1번째 표본 (n=36): x̄₁ = 24.1
  2번째 표본 (n=36): x̄₂ = 25.8
  3번째 표본 (n=36): x̄₃ = 23.6
  ...
  1000번째 표본:     x̄₁₀₀₀ = 24.9

  이 x̄값들이 어떤 분포를 따르는가? → 표집분포
```

> **핵심 납득 포인트**: 통계량(x̄, s², p̂)은 고정값이 아니라 **확률변수**다. 그래서 "이 x̄이 얼마나 믿을 만한가?"라는 질문에 확률로 답할 수 있다. 이것이 Ch.8~13 추론통계의 모든 기반이다.

### 3.2 표집분포 (Sampling Distribution)

#### 직관부터 시작

> **직관 실험**: 모집단이 BDI-II N(μ=24, σ=8)이다. 여기서 n=36명씩 무한히 반복해서 표본을 뽑으면, 각 표본의 x̄는 어떤 값들이 나올까?

```
[표집분포 개념 시각화]

모집단 분포              표집분포 (x̄의 분포)
N(24, 8²)               n=4일 때         n=36일 때
     ╭──╮                   ╭──╮               ╭─╮
   ╭─╯  ╰─╮             ╭─╯  ╰─╮            ╭─╯ ╰─╮
╭──╯        ╰──╮      ╭──╯      ╰──╮       ╭──╯     ╰──╮
─────────────── x   ──────────────── x̄   ─────────────── x̄
μ=24, σ=8          μ=24, SE=4            μ=24, SE=4/3

→ n이 커질수록 x̄의 분포가 좁아짐 (SE 감소)
```

#### 표집분포의 정의와 표준오차

```
표집분포 (sampling distribution):
  통계량(x̄ 등)이 반복 표집에서 가지는 확률분포

표준오차 (standard error, SE):
  SE = σ / √n

  기호 해설:
    σ = 모집단의 표준편차
    n = 표본 크기
    SE = x̄의 표집분포에서의 표준편차
```

**표준오차의 의미**:

```
SE = σ/√n 는 "표본평균들이 모평균 주위에 얼마나 퍼져 있는가"를 나타낸다

예시: σ = 8, μ = 24
  n = 4:  SE = 8/√4  = 8/2  = 4.0  (x̄가 많이 흔들림)
  n = 16: SE = 8/√16 = 8/4  = 2.0
  n = 36: SE = 8/√36 = 8/6  ≈ 1.33
  n = 64: SE = 8/√64 = 8/8  = 1.0  (x̄가 μ 주위에 안정적으로 모임)
```

> **핵심 납득 포인트**: 표본이 클수록 SE가 작아진다 — "더 많은 정보로 추정할수록 추정이 정밀해진다"는 직관과 일치한다. SE = σ/√n에서 n이 4배가 되어야 SE가 절반이 된다. 표본 크기 늘리기가 생각보다 비효율적인 이유다.

### 3.3 표본평균의 분포와 중심극한정리

#### 경우 1: 모집단이 정규분포일 때

```
모집단: X ~ N(μ, σ²)  이면

표본평균: x̄ ~ N(μ, σ²/n)    ← n에 상관없이 정확히 성립!

표준화:   Z = (x̄ − μ) / (σ/√n) = (x̄ − μ) / SE  ~ N(0, 1)
```

**손계산 예시**: BDI-II 모집단 N(μ=24, σ=8), n=36

```
SE = 8/√36 = 8/6 ≈ 1.33

표집분포: x̄ ~ N(24, 1.33²)

P(x̄ > 26) = P(Z > (26−24)/1.33)
           = P(Z > 2/1.33)
           = P(Z > 1.50)
           = 1 − .9332
           = .0668

해석: n=36 표본에서 x̄ > 26을 얻을 확률은 약 7%
     → "x̄ = 26.5이라는 결과가 나왔다. 이것은 μ = 24라는 가정 하에서 얼마나 특이한가?"
        = P(x̄ ≥ 26.5) = P(Z ≥ (26.5−24)/1.33) = P(Z ≥ 1.88) ≈ .030
        → 약 3%로 드문 결과 → μ가 24가 아닐 수 있다는 증거 (Ch.8 가설검정 예고!)
```

---

#### 경우 2: 모집단이 어떤 분포든 — 중심극한정리 (Central Limit Theorem, CLT)

> **중심극한정리 (CLT)**: 모집단 분포가 **어떤 형태이든** (정규분포가 아니어도!), n이 충분히 크면 표본평균 x̄의 분포는 **정규분포에 가까워진다.**

```
모집단: 어떤 분포든 (평균 μ, 분산 σ²)
n이 충분히 크면:  x̄ ≈ N(μ, σ²/n)

실용적 기준: n ≥ 30이면 대부분의 경우 정규 근사 충분
             (모집단이 극단적으로 왜도가 심하면 더 큰 n 필요)
```

**CLT의 위력 — 시각화**:

```
[왜도 있는 모집단 (반응시간)]   [n=5]      [n=30]      [n=100]
  ██                            ╭╮          ╭─╮           ╭─╮
  ████                       ╭╮ ╰╮        ╭╯ ╰╮         ╭╯ ╰╮
  ████████                ╭──╯╰──╯──     ╭╯   ╰╮        ╭╯   ╰╮
  ████████████████       ─────────────  ───────────    ────────────
    0   100  200 ms   (여전히 비대칭)  (점차 대칭)   (거의 정규)
```

**CLT가 통계학에서 왜 이렇게 중요한가?**

```
현실에서 모집단 분포는 대부분 모른다.
BDI-II 점수: 양의 왜도 있음
반응시간: 매우 강한 양의 왜도
소득 데이터: 극단적 왜도

그런데 n ≥ 30이면? → x̄는 N(μ, σ²/n)으로 취급 가능
→ t검정, 신뢰구간, ANOVA 모두 이 근사를 사용!
→ "왜 n=30이면 모수적 검정(t검정 등)을 써도 되는가?"의 답이 CLT
```

> **핵심 납득 포인트**: CLT는 "마법"처럼 보이지만 수학적으로 엄밀히 증명된다. 직관은 이렇다: x̄는 n개의 독립적인 관측값의 평균이다. 극단값 하나가 나와도 나머지 n−1개가 균형을 잡아준다. n이 클수록 이 균형 효과가 강해지고, 결국 정규분포로 수렴한다. 이것이 **독립적인 많은 요인들의 합이 정규분포에 가까워지는** 이유이기도 하다 (Ch.6에서 심리 척도가 종 모양인 이유).

### 3.4 이항분포의 정규근사 (Sampling Distribution of p̂)

#### 표본비율의 표집분포

n번의 이항 시행에서 성공 횟수 X ~ B(n, p)이면, 표본비율 p̂ = X/n의 분포:

```
E(p̂)    = p              ← p̂은 p의 불편추정량
Var(p̂)  = p(1−p)/n
SE(p̂)   = √[p(1−p)/n]

n이 클 때 (np ≥ 5, n(1−p) ≥ 5):
  p̂ ≈ N(p, p(1−p)/n)
```

**손계산 예시**: n=100명에게 CBT, p=.60 (치료 반응률)

```
E(p̂)  = .60
SE(p̂) = √[.60×.40/100] = √[.24/100] = √.0024 ≈ .049

P(p̂ ≥ .70) = P(Z ≥ (.70−.60)/.049)
            = P(Z ≥ .10/.049)
            = P(Z ≥ 2.04)
            = 1 − .979
            ≈ .021

해석: n=100, p=.60 가정 하에서 표본비율이 .70 이상 나올 확률 ≈ 2.1%
     → 실제로 p̂ = .70이 관찰되었다면? 드문 결과 → p = .60 의심 (Ch.8 연결)
```

> **핵심 납득 포인트**: x̄의 표집분포와 p̂의 표집분포는 구조가 동일하다. 둘 다 CLT에 의해 정규분포로 근사된다. 표준오차만 공식이 다를 뿐이다:
> - x̄의 SE = σ/√n
> - p̂의 SE = √[p(1−p)/n]
>
> 이 두 공식이 Ch.9(단일모집단 추론)에서 신뢰구간과 가설검정의 핵심이 된다.

## 4. 수식 정리

```
=== 기호 약속 ===
x̄         = 표본평균 (통계량, 확률변수)
μ         = 모평균 (모수, 고정)
σ         = 모표준편차 (모수)
s         = 표본표준편차 (통계량)
n         = 표본 크기
SE        = 표준오차 (standard error)
p̂         = 표본비율 (통계량, 확률변수)
p         = 모비율 (모수)

=== 수식 목록 ===

① 표본평균의 표집분포 (모집단이 정규분포일 때)
   x̄ ~ N(μ, σ²/n)   (n에 상관없이 정확)

② 표준오차
   SE(x̄) = σ/√n
   해석: "표본평균들이 모평균 주위에 얼마나 퍼져 있는가"

③ 표준화 (z-변환, 표집분포 적용)
   Z = (x̄ − μ) / (σ/√n) = (x̄ − μ) / SE ~ N(0, 1)
   주의: 분모가 σ가 아니라 σ/√n (= SE)!

④ 중심극한정리 (CLT)
   n ≥ 30이면 (대략): x̄ ≈ N(μ, σ²/n)
   (모집단 분포에 상관없이)

⑤ 표본비율의 표집분포
   E(p̂)   = p
   Var(p̂) = p(1−p)/n
   SE(p̂)  = √[p(1−p)/n]
   n이 클 때: p̂ ≈ N(p, p(1−p)/n)

=== 손계산 예시 (n=36, μ=24, σ=8) ===
SE = 8/√36 = 8/6 ≈ 1.333

P(x̄ > 26):
  z = (26 − 24) / 1.333 = 2/1.333 ≈ 1.50
  P(Z > 1.50) = 1 − .9332 = .0668 ≈ 7%

P(x̄ < 22):
  z = (22 − 24) / 1.333 = −2/1.333 ≈ −1.50
  P(Z < −1.50) = .0668 ≈ 7%

P(22 ≤ x̄ ≤ 26):
  = P(−1.50 ≤ Z ≤ 1.50) = .9332 − .0668 = .8664 ≈ 87%
```

### 시나리오 A: 임상 연구의 표준오차와 신뢰도

CBT 효과 연구에서 STAI-T 점수(μ=50, σ=12, 모집단)를 측정한다.

```
[연구 규모별 표준오차 비교]

연구 A: n=9   → SE = 12/√9  = 12/3  = 4.0
연구 B: n=36  → SE = 12/√36 = 12/6  = 2.0
연구 C: n=144 → SE = 12/√144= 12/12 = 1.0

해석:
  연구 A의 x̄는 ±4점 오차 범위 (상당히 불안정)
  연구 C의 x̄는 ±1점 오차 범위 (매우 안정적)

  "n을 4배 늘려야 SE가 절반" → 정밀도 향상에 비용이 많이 든다!
```

**P(x̄ > 53)의 연구 크기별 비교**:

```
연구 A (SE=4.0): P(Z > (53−50)/4.0) = P(Z > 0.75) = .227
연구 B (SE=2.0): P(Z > (53−50)/2.0) = P(Z > 1.50) = .067
연구 C (SE=1.0): P(Z > (53−50)/1.0) = P(Z > 3.00) = .001

해석: 같은 x̄ = 53이 나와도, n이 클수록 더 "놀라운(드문)" 결과로 평가됨
     → n이 클수록 작은 차이도 통계적으로 유의해지는 이유 (Ch.8 연결)
```

### 시나리오 B: 치료 반응률 추정의 정밀도

**연구 질문**: "이 치료 프로그램의 실제 반응률(p)은 얼마인가? 표본에서 p̂를 관찰했을 때 얼마나 믿을 수 있는가?"

```
[표본 크기별 SE(p̂) 비교] (p = .60 가정)

n=25:   SE = √[.60×.40/25]   = √.0096 ≈ .098  (±10%p 오차)
n=100:  SE = √[.60×.40/100]  = √.0024 ≈ .049  (±5%p 오차)
n=400:  SE = √[.60×.40/400]  = √.0006 ≈ .024  (±2.5%p 오차)

→ 반응률 추정을 "±5%p 이내"로 정밀하게 하고 싶다면 n ≈ 100 필요
  이것이 "표본 크기 결정(sample size calculation)"의 논리적 기반
```

> **중요한 시사점**: 논문에서 보고하는 "M = 24.3, SE = 1.2"는 "이 표본평균의 추정 오차 범위"를 나타낸다. SE가 작을수록 x̄가 μ에 가깝다고 볼 수 있다. 신뢰구간(Ch.9)은 바로 이 SE를 기반으로 계산된다.

## 6. 논문 스니펫 읽기 실습

다음은 가상의 논문 Methods 및 Results 절이다. 읽고 질문에 답하라.

---

*"A community sample of N = 120 adults completed the State-Trait Anxiety Inventory (STAI-T; Spielberger et al., 1983). For this population, the STAI-T normative mean is μ = 40.0 (SD = 10.0). In the present sample, the mean STAI-T score was M = 43.2 (SE = 0.91). The distribution of individual scores was positively skewed (skewness = 1.24); however, by the central limit theorem, the sampling distribution of the mean was assumed to be approximately normal."*

---

**연습 질문:**

1. SE = 0.91이 맞는지 확인하라. (σ = 10, n = 120 사용)
2. "positively skewed임에도 CLT를 적용했다"는 것은 어떤 조건이 충족되었기 때문인가?
3. M = 43.2는 규준 μ = 40.0보다 높다. 이 차이(3.2점)가 "우연히 나온 것"일 확률을 계산하라: P(x̄ ≥ 43.2 | μ=40, σ=10, n=120)
4. 논문에서 "SE = 0.91"이 Table 1에 보고된다. 이것은 SD = 10.0과 무엇이 다른가?
5. 만약 n = 30이었다면 SE와 P(x̄ ≥ 43.2)는 어떻게 달라지는가?

---

**모범 답안:**

**1. SE 확인**
```
SE = σ/√n = 10/√120 = 10/10.95 ≈ 0.913 ≈ 0.91  ✓
```

**2. CLT 적용 조건**
```
n = 120 ≥ 30 → 실용적 CLT 기준 충족

개별 점수는 왜도가 있지만(skewness = 1.24),
CLT에 의해 x̄의 표집분포는 n이 충분히 크면 정규에 가까워진다.
"데이터 자체가 아니라 평균의 분포가 정규"임에 주목.
n = 120이면 대부분의 왜도 수준에서 CLT 근사가 충분하다.
```

**3. P(x̄ ≥ 43.2 | μ=40) 계산**
```
SE = 10/√120 ≈ 0.913

z = (43.2 − 40) / 0.913 = 3.2 / 0.913 ≈ 3.51

P(Z ≥ 3.51) ≈ .0002

해석: μ = 40라는 가정 하에서 x̄ ≥ 43.2가 나올 확률 ≈ 0.02%
     → 극히 드문 결과. 이 표본의 μ는 40보다 높을 가능성이 매우 높다.
     → 이것이 Ch.8에서 배울 가설검정의 논리: p-값 < .001
```

**4. SE vs SD의 차이**
```
SD = 10.0: 개별 응답자들의 STAI-T 점수가 평균에서 얼마나 퍼져 있는가
           "이 집단의 다양성"

SE = 0.91: 표본평균(M)이 모평균(μ)에서 얼마나 벗어날 수 있는가
           "이 추정(M = 43.2)의 정밀도"

비유:
  SD: 반 학생들의 키가 평균에서 ±10cm 범위
  SE: 반 평균 키의 추정치가 실제 평균에서 ±0.91cm 이내일 것

n이 커지면: SD ≈ 일정, SE는 줄어듦 (SE = SD/√n)
```

**5. n = 30일 때 비교**
```
SE_30 = 10/√30 = 10/5.477 ≈ 1.826  (n=120일 때의 2배!)

z = (43.2 − 40) / 1.826 = 3.2 / 1.826 ≈ 1.75

P(Z ≥ 1.75) = 1 − .9599 = .040

해석: n=30이면 P ≈ .040 (약 4%)로, n=120(0.02%)보다 훨씬 높다.
     같은 x̄ = 43.2라도 n이 작으면 "덜 놀라운" 결과로 평가된다.
     → n이 클수록 같은 차이가 더 통계적으로 유의해지는 이유
```

## 7. 오개념 경고

> **⚠️ 오개념 1**: "표본이 크면 표준편차(SD)가 작아진다"
> → **틀렸다.** 표본이 커져도 SD(개별 데이터의 퍼짐)는 크게 변하지 않는다. 줄어드는 것은 **표준오차(SE = σ/√n)** — 표본평균의 불확실성이다.
>
> SD = 10인 모집단에서:
> n=25: SD ≈ 10, SE = 2.0
> n=100: SD ≈ 10, SE = 1.0
>
> SD는 집단의 다양성, SE는 추정의 정밀도다. 전혀 다른 것을 측정한다.

> **⚠️ 오개념 2**: "CLT는 데이터 자체가 정규분포를 따른다는 뜻이다"
> → **아니다.** CLT는 **표본평균 x̄의 분포**가 정규에 수렴한다는 것이다. 개별 데이터(x₁, x₂, ..., xₙ)는 여전히 왜도가 있을 수 있다.
>
> 반응시간 1000개를 수집해도 각 반응시간은 양의 왜도를 가진다. 하지만 그 1000개에서 구한 x̄는 정규분포에 가깝다. "데이터 ≠ 평균"을 혼동하지 않도록 주의.

> **⚠️ 오개념 3**: "n=30이면 무조건 CLT가 적용된다"
> → **n=30은 경험적 기준이지 절대 기준이 아니다.** 모집단 분포가 극단적으로 왜도가 심하거나 이상값이 많으면 n=100 이상이 필요할 수 있다. 반대로 모집단이 이미 정규분포에 가깝다면 n=10도 충분하다.
>
> 실무에서는: 히스토그램·Q-Q plot 확인 + 왜도 수치 + 정규성 검정 결과를 종합적으로 판단한다.

> **⚠️ 오개념 4**: "표준오차가 작으면 무조건 좋은 연구다"
> → **SE = σ/√n이므로 n을 충분히 크게 하면 SE를 0에 가깝게 만들 수 있다.** 그러면 아주 작은(임상적으로 무의미한) 차이도 통계적으로 유의해진다.
>
> 예: BDI-II 0.1점 차이가 n=1,000,000이면 통계적으로 p < .001이 나올 수 있다. SE가 작다고 "중요한 발견"이 되는 것은 아니다. **통계적 유의성 ≠ 임상적 의의.** (Ch.8에서 자세히 다룸)

> **⚠️ 오개념 5**: "표집분포는 실제로 관찰할 수 있는 분포다"
> → **표집분포는 이론적 분포다.** "무한히 많이 반복 표집한다면"이라는 가상의 상황을 전제한다. 실제 연구에서는 표본을 한 번만 뽑는다. 표집분포는 그 한 번의 x̄가 "전체 가능한 x̄들 중 어디쯤 위치하는가?"를 판단하기 위한 이론적 기준이다.

### 논문 용어 확인

- *"Means are reported with standard errors (SE). For the treatment group, STAI-T M = 43.2, SE = 1.8."*
  → SE = 1.8은 표준편차(SD)가 아님. n을 알면 SD를 역산 가능: SD = SE × √n.

- *"Given the large sample size (N = 250), the central limit theorem was invoked to justify the use of parametric analyses despite the non-normal distribution of raw scores."*
  → n = 250 → CLT → 정규성 가정 가능 → t검정/ANOVA 사용 정당화.

- *"The standard error of the difference between means was estimated as SE_diff = 2.4."*
  → 두 집단 평균 차이의 표준오차 (Ch.10에서 자세히 배움). SE 개념의 확장.

## 부록: 보완 주제 — 표준오차 vs 표준편차 완전 정복

> **이 주제가 중요한 이유**: 논문 Table 1에서 M(SD)와 M(SE)를 혼동하는 경우가 매우 흔하다. 오차 막대 그래프에서 SD로 그릴 때와 SE로 그릴 때 시각적 차이가 크다. 이 혼동을 이제 완전히 해소해야 한다.

---

### SD vs SE — 핵심 비교

```
[표준편차 SD]
  무엇을 측정: 개별 데이터 포인트들이 평균에서 얼마나 퍼져 있는가
  식:         s = √[Σ(xᵢ−x̄)²/(n−1)]
  특성:       n이 커져도 크게 변하지 않음 (모집단의 실제 변동성 반영)
  의미:       "집단 내 다양성(variability within a group)"
  논문 사용:  Table 1 기술통계 "M = 24.3, SD = 7.8"

[표준오차 SE]
  무엇을 측정: 표본평균이 모평균에서 얼마나 벗어날 수 있는가
  식:         SE = s/√n  (σ를 모를 때 s 사용)
  특성:       n이 커지면 작아짐 (SE → 0 as n → ∞)
  의미:       "추정의 정밀도(precision of the estimate)"
  논문 사용:  오차 막대, 신뢰구간 계산 "M = 24.3, SE = 0.71"
```

---

### 수치 예시 — 같은 데이터로 SD와 SE

```
데이터: n=121명, BDI-II 점수, s = 7.8

SD = 7.8 (집단의 다양성 — n에 무관)
SE = s/√n = 7.8/√121 = 7.8/11 = 0.709 ≈ 0.71

논문에서:
  "M = 24.3, SD = 7.8"  → 121명이 평균 24.3점에서 ±7.8점 퍼짐
  "M = 24.3, SE = 0.71" → 이 표본평균의 추정 오차가 ±0.71점
```

---

### 오차 막대 (Error Bar) 해석

```
[같은 데이터, 다른 오차 막대]

SD로 그린 경우 (±7.8):         SE로 그린 경우 (±0.71):
  M=24.3                           M=24.3
    │                                │
 ┌──┴──┐  ← ±7.8                ┌─┴─┐  ← ±0.71
```

SE 오차 막대가 훨씬 작아 보인다 → 연구 결과가 "더 정밀해 보이는" 착시

> **논문 읽기 포인트**: 그래프의 오차 막대 설명(figure caption)에 "Error bars represent SD" 또는 "Error bars represent SE" 반드시 확인. SE 막대는 표본이 클수록 작아지므로, 큰 표본 연구에서 SE 막대를 쓰면 매우 좁아 보인다. "정밀해 보인다"고 "효과가 크다"는 것이 아니다.

---

### SD와 SE의 관계 공식

```
SE = SD / √n

역방향: SD = SE × √n

예시: 논문에서 "M = 43.2, SE = 1.8, n = 44"이면
     SD = 1.8 × √44 = 1.8 × 6.63 ≈ 11.9

→ 이 집단의 STAI-T 점수는 평균에서 약 ±12점 퍼져 있다
```
