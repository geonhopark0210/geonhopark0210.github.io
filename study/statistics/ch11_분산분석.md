### 3.1 왜 분산분석인가: 1종 오류 팽창

#### 직관부터 시작

> **질문**: "세 집단(CBT, 약물치료, 통합치료)의 우울 점수가 다른지 알고 싶다. t-검정을 세 번 하면 되지 않을까?"

얼핏 합리적으로 들린다. 그런데 실제로 계산해 보자.

**쌍별 비교 횟수:**

```
세 집단 A, B, C에서 가능한 쌍별 비교:
  A vs B  /  A vs C  /  B vs C  → 총 3번

k개 집단이면: C(k, 2) = k(k-1)/2 번
  k = 4 → 6번
  k = 5 → 10번
```

**1종 오류가 팽창하는 이유:**

각 검정을 α = .05로 설정하면:

```
검정 1번에서 1종 오류가 없을 확률 = 0.95
검정 3번 모두 1종 오류가 없을 확률 = 0.95 × 0.95 × 0.95 ≈ 0.857

→ 적어도 1번은 1종 오류가 날 확률 = 1 − 0.857 ≈ .143
```

즉, α = .05로 검정 3번을 반복하면 실제 오류 확률은 무려 **14.3%** 로 커진다. 검정 횟수가 늘수록 이 팽창은 더 심각해진다.

이것이 **1종 오류 팽창 (familywise error rate inflation)** 문제다.

> **핵심 납득 포인트**
>
> t-검정을 여러 번 반복하는 것은 "시험을 20번 보면 한 번쯤은 운 좋게 합격할 것"이라는 논리와 같다. 우연에 의한 유의 결과 확률이 누적해서 커지기 때문에, **한 번의 통합 검정 (ANOVA)** 이 필요하다.

### 3.2 F-통계량과 F-분포

#### F-통계량의 핵심 아이디어

**직관:** 집단 간에 정말 차이가 있다면, 집단 평균들끼리의 흩어짐(집단 간 변동)이 집단 내 개인들의 흩어짐(집단 내 변동)보다 커야 한다.

```
         집단 간 변동 (집단 평균들이 서로 얼마나 다른가?)
F = ─────────────────────────────────────────────────────
         집단 내 변동 (각 집단 안에서 개인들이 얼마나 다른가?)
```

- **F ≈ 1이면:** 집단 간 차이가 집단 내 개인차와 비슷한 수준 → 우연에 의한 차이일 가능성 → H₀ 지지
- **F >> 1이면:** 집단 간 차이가 집단 내 개인차보다 훨씬 크다 → 처치 효과가 있다 → Hₐ 지지

**비유로 이해하기:**

```
[집단 간 변동이 작은 경우: F ≈ 1]
  집단 A: 20, 22, 24, 18  (평균 21)
  집단 B: 21, 23, 19, 25  (평균 22)
  집단 C: 20, 24, 21, 23  (평균 22)
  → 세 집단 평균이 거의 같다 (21~22)
  → 집단 내 개인차가 집단 간 차이보다 크다 → F가 작다

[집단 간 변동이 큰 경우: F >> 1]
  집단 A: 10, 12, 11, 13  (평균 11.5)
  집단 B: 20, 22, 18, 24  (평균 21)
  집단 C: 30, 28, 32, 29  (평균 29.75)
  → 세 집단 평균이 크게 다르다 (11~30)
  → 집단 간 차이가 집단 내 개인차보다 훨씬 크다 → F가 크다
```

**t-검정과의 연결:**

```
두 집단(k = 2)에서 F-검정을 하면:
  F = t²

즉, F-검정은 t-검정을 세 집단 이상으로 확장한 것이다.
Ch.10의 F-분포(§3.5)와 이 챕터의 F가 같은 것임을 기억하자.
```

**F-분포의 특성:**

```
① 항상 0 이상 (분산은 음수가 될 수 없으므로)
② 오른쪽으로 치우친 비대칭 분포 (right-skewed)
③ 두 자유도(df_between, df_within)에 의해 모양이 결정됨
④ H₀가 참이면 F의 기댓값 ≈ 1
```

> **핵심 납득 포인트**
>
> F-통계량에 "분산분석"이라는 이름이 붙은 이유는 **분산(변동)을 '도구'로 사용해서 평균 차이를 검정**하기 때문이다. 실제로 분석하는 것은 **평균의 차이**다. "분산 = 목적"이 아니라 "분산 = 수단"임을 기억하자 (이는 §7 오개념 경고에서 다시 다룬다).

### 3.3 일원배치 분산분석 (One-way ANOVA)

**"일원배치"란?** 독립변수(집단 구분 변수)가 **1개**인 ANOVA다.
- 예: 치료 유형(CBT / 약물치료 / 통합치료) 1개 독립변수, 결과 변수 1개

#### 변동의 분해 (Partitioning of Variance)

ANOVA의 핵심 아이디어는 **전체 변동을 두 가지 원인으로 쪼개는 것**이다.

```
전체 변동 (SS_total)
    = 집단 간 변동 (SS_between) + 집단 내 변동 (SS_within)

SS_total   = SS_between + SS_within
```

각 변동의 의미:

| 변동 | 기호 | 의미 | 수식 |
|------|------|------|------|
| **전체 변동** | SS_total | 모든 관측값이 **전체 평균(x̄)** 에서 벗어난 정도 | Σᵢⱼ(xᵢⱼ − x̄)² |
| **집단 간 변동** | SS_between | 각 **집단 평균(x̄ᵢ)** 이 **전체 평균(x̄)** 에서 벗어난 정도 | Σᵢ nᵢ(x̄ᵢ − x̄)² |
| **집단 내 변동** | SS_within | 각 개인(xᵢⱼ)이 **자기 집단 평균(x̄ᵢ)** 에서 벗어난 정도 | Σᵢⱼ(xᵢⱼ − x̄ᵢ)² |

**기호 약속:**
```
k       : 집단 수
N       : 전체 표본 크기
nᵢ      : i번째 집단의 표본 크기
x̄       : 전체(grand) 평균  = ΣΣxᵢⱼ / N
x̄ᵢ     : i번째 집단의 표본평균
xᵢⱼ    : i번째 집단의 j번째 관측값
```

#### 자유도 (Degrees of Freedom)

```
df_between = k − 1           (집단 수 − 1)
df_within  = N − k           (전체 n − 집단 수)
df_total   = N − 1           (전체 n − 1)

확인: df_between + df_within = (k−1) + (N−k) = N−1 = df_total  ✓
```

#### 평균제곱 (MS, Mean Square)

분산과 마찬가지로, SS를 자유도로 나눠 "평균적인 변동"을 구한다:

```
MS_between = SS_between / df_between
MS_within  = SS_within  / df_within
```

#### F-통계량 계산

```
F = MS_between / MS_within
```

#### 분산분석표 (ANOVA Table)

논문의 Results에 자주 등장하는 표 형식:

| 변동원 | SS | df | MS | F |
|--------|----|----|----|----|
| 집단 간 (Between) | SS_B | k−1 | SS_B/(k−1) | MS_B/MS_W |
| 집단 내 (Within) | SS_W | N−k | SS_W/(N−k) | |
| 합계 (Total) | SS_T | N−1 | | |

> **핵심 납득 포인트**
>
> ANOVA table은 처음 보면 복잡하게 느껴진다. 그런데 사실은 딱 두 칸만 보면 된다:
> **F 값**과 그 옆의 **p 값**. F가 크고 p < .05이면 "적어도 한 쌍의 집단이 다르다"는 결론이다.
> 나머지 SS, df, MS는 F를 계산하는 중간 과정이다.

### 3.4 다중비교 — 사후검정 (Post-hoc Tests)

**ANOVA가 알려주는 것:** "적어도 한 쌍의 집단 평균이 다르다" (전체 검정)

**ANOVA가 알려주지 않는 것:** "A와 B가 다른가? A와 C가 다른가? B와 C가 다른가?"

ANOVA에서 유의한 결과가 나오면, **어떤 집단들이 서로 다른지 알아내기 위해 사후검정이 필요**하다.

#### LSD (Least Significant Difference, 최소유의차) 방법

Fisher가 제안한 가장 기본적인 사후검정법이다. 각 쌍 비교에서 "유의하다고 인정받기 위한 최소 평균 차이(LSD)"를 구한다.

```
LSD = t*(α/2, df_W) × √[MS_W × (1/nᵢ + 1/nⱼ)]

여기서:
  t*(α/2, df_W) : df_within을 자유도로 하는 t-분포의 임계값
  MS_W          : 집단 내 평균제곱 (분산분석표에서 가져옴)
  nᵢ, nⱼ        : 비교하는 두 집단의 표본 크기
```

**판단:** |x̄ᵢ − x̄ⱼ| > LSD 이면 두 집단이 유의하게 다르다

**특징:** 1종 오류를 교정하지 않아 비교적 관대(liberal)하다. 비교 횟수가 많을수록 1종 오류가 팽창한다.

#### Bonferroni(본페로니) 방법

비교 횟수 m에 맞게 유의수준을 조정하는 방법이다.

```
α' = α / m

예: α = .05, 3집단 쌍별 비교 m = 3
  α' = .05 / 3 ≈ .017

→ 각 쌍 비교에서 p < .017이어야 유의하다고 판정
```

**왜 이렇게 하는가?**

```
3번 비교에서 각 α' = .017이면:
  모든 3번에서 1종 오류가 없을 확률 = (1 − .017)³ ≈ 0.950

→ familywise error rate ≈ 1 − 0.950 = .050  ✓
```

즉, Bonferroni 교정을 하면 전체(family) 1종 오류율을 α = .05로 유지할 수 있다.

**특징:** 보수적(conservative). 1종 오류를 잘 통제하지만, 그만큼 검정력(2종 오류를 피하는 능력)이 낮아진다. 집단 수가 많을수록 α'이 매우 작아져 실제로 다른 집단도 유의하지 않다고 판정하는 오류가 증가한다.

> **핵심 납득 포인트**
>
> LSD는 관대하고 Bonferroni는 엄격하다. 어느 쪽이 더 낫다는 정답은 없다. 탐색적 연구라면 LSD를, 임상 결론에 신중을 기해야 할 때는 Bonferroni를 선택하는 것이 일반적이다. 논문에서는 "어떤 방법을 썼는지"를 명시하므로, 그 이름만 알아두면 된다.

## §4 수식 정리

```
■ 기호 약속
k        : 집단 수 (number of groups)
N        : 전체 표본 크기
nᵢ       : i번째 집단의 표본 크기
x̄        : 전체(grand) 평균
x̄ᵢ      : i번째 집단의 표본평균
xᵢⱼ     : i번째 집단의 j번째 관측값
SS_B     : 집단 간 제곱합 (Sum of Squares Between)
SS_W     : 집단 내 제곱합 (Sum of Squares Within)
SS_T     : 전체 제곱합 (Sum of Squares Total)
MS_B     : 집단 간 평균제곱 (Mean Square Between)
MS_W     : 집단 내 평균제곱 (Mean Square Within)
η²       : 에타제곱 (eta squared, 효과크기)
α'       : Bonferroni 교정 유의수준
m        : 사후검정 비교 횟수
```

---

### [수식 1] 제곱합 (Sum of Squares)

```
SS_total   = Σᵢ Σⱼ (xᵢⱼ − x̄)²

SS_between = Σᵢ nᵢ (x̄ᵢ − x̄)²

SS_within  = Σᵢ Σⱼ (xᵢⱼ − x̄ᵢ)²

SS_total = SS_between + SS_within  (변동의 분해)
```

### [수식 2] 자유도, 평균제곱, F

```
df_between = k − 1
df_within  = N − k
df_total   = N − 1

MS_between = SS_between / df_between
MS_within  = SS_within  / df_within

F = MS_between / MS_within
```

### [수식 3] 효과크기 η²

```
η² = SS_between / SS_total

해석 기준 (Cohen, 1988):
  .01 : 작은 효과 (small)
  .06 : 중간 효과 (medium)
  .14 : 큰 효과 (large)
```

### [수식 4] Bonferroni 교정

```
α' = α / m

m = k(k−1) / 2   (k개 집단의 쌍별 비교 횟수)
```

### [손계산 예시] ANOVA Table 완성

**설정:** 세 가지 치료 조건에 따른 BDI-II 점수 비교 (k = 3, 각 nᵢ = 4, N = 12)

| 참여자 | CBT (집단 1) | 약물치료 (집단 2) | 통합치료 (집단 3) |
|--------|------------|---------------|---------------|
| 1      | 12         | 18            | 10            |
| 2      | 15         | 21            | 11            |
| 3      | 11         | 17            | 9             |
| 4      | 14         | 20            | 10            |
| **집단 합계** | **52** | **76**    | **40**        |
| **집단 평균 (x̄ᵢ)** | **13** | **19** | **10**    |

```
■ 1단계: 전체 평균 계산
x̄ = (52 + 76 + 40) / 12 = 168 / 12 = 14

■ 2단계: SS_between 계산 (집단 평균이 전체 평균에서 벗어난 정도)
SS_between = Σ nᵢ (x̄ᵢ − x̄)²
           = 4×(13 − 14)² + 4×(19 − 14)² + 4×(10 − 14)²
           = 4×(−1)²      + 4×(5)²        + 4×(−4)²
           = 4×1          + 4×25          + 4×16
           = 4            + 100           + 64
           = 168

■ 3단계: SS_within 계산 (각 개인이 자기 집단 평균에서 벗어난 정도)
집단 1 (CBT, x̄₁ = 13):
  (12−13)² + (15−13)² + (11−13)² + (14−13)²
  = 1 + 4 + 4 + 1 = 10

집단 2 (약물치료, x̄₂ = 19):
  (18−19)² + (21−19)² + (17−19)² + (20−19)²
  = 1 + 4 + 4 + 1 = 10

집단 3 (통합치료, x̄₃ = 10):
  (10−10)² + (11−10)² + (9−10)² + (10−10)²
  = 0 + 1 + 1 + 0 = 2

SS_within = 10 + 10 + 2 = 22

■ 4단계: 검산
SS_total = SS_between + SS_within = 168 + 22 = 190
(직접 계산: Σ(xᵢⱼ − 14)² = 190  ✓)

■ 5단계: 자유도
df_between = k − 1   = 3 − 1 = 2
df_within  = N − k   = 12 − 3 = 9
df_total   = N − 1   = 12 − 1 = 11

■ 6단계: 평균제곱
MS_between = 168 / 2 = 84
MS_within  = 22 / 9  ≈ 2.44

■ 7단계: F 통계량
F = MS_between / MS_within = 84 / 2.44 ≈ 34.43

F(2, 9) = 34.43  → p < .001  (F 분포표에서 F_(.05, 2, 9) ≈ 4.26을 크게 초과)

■ 8단계: ANOVA Table 완성
┌──────────────┬──────┬────┬────────┬────────┐
│ 변동원       │  SS  │ df │   MS   │   F    │
├──────────────┼──────┼────┼────────┼────────┤
│ 집단 간(B)   │  168 │  2 │  84.00 │ 34.43* │
│ 집단 내(W)   │   22 │  9 │   2.44 │        │
│ 합계 (T)     │  190 │ 11 │        │        │
└──────────────┴──────┴────┴────────┴────────┘
* p < .001

■ 9단계: 효과크기
η² = SS_between / SS_total = 168 / 190 ≈ .884

→ 매우 큰 효과 (이 예시는 세 집단 평균 차이가 매우 커서 η²도 크게 나왔다.
  실제 논문에서는 η² = .11 수준도 "중간 효과"로 의미 있음 — §6 참조)

■ 10단계: Bonferroni 교정 적용 (α = .05, m = 3)
α' = .05 / 3 ≈ .017

APA 보고 형식:
"A one-way ANOVA revealed a significant effect of treatment,
 F(2, 9) = 34.43, p < .001, η² = .88."
```

## §6 논문 스니펫 읽기 실습

### 가상 논문 발췌 (APA 7판 형식)

> **Study excerpt:**
>
> Participants with major depressive disorder (N = 90) were randomly assigned to one of three treatment conditions: cognitive-behavioral therapy (CBT; n = 30), pharmacotherapy (n = 30), or combined treatment (n = 30). Following 12 weeks of treatment, post-treatment depression severity was assessed using the Beck Depression Inventory-II (BDI-II). A one-way analysis of variance (ANOVA) was conducted to compare BDI-II scores across the three conditions. Results revealed a statistically significant effect of treatment condition, F(2, 87) = 5.43, p = .006, η² = .11. Post hoc analyses using Bonferroni correction indicated that the combined treatment group (M = 11.4, SD = 6.2) showed significantly lower BDI-II scores than the pharmacotherapy group (M = 17.8, SD = 7.1, p = .004), while CBT (M = 14.2, SD = 6.8) did not differ significantly from either condition (all ps > .05).

---

### 연습 질문

**Q1.** `F(2, 87) = 5.43` 에서 각 숫자가 무엇을 의미하는지 설명하라.

**모범 답안:**

- `F` : F-통계량. 집단 간 평균제곱(MS_between)을 집단 내 평균제곱(MS_within)으로 나눈 값.
- `2` : df_between = k − 1 = 3 − 1 = 2. 집단 수가 3개이므로 집단 간 자유도는 2.
- `87` : df_within = N − k = 90 − 3 = 87. 전체 90명, 3집단이므로 집단 내 자유도는 87.
- `5.43` : 집단 간 변동이 집단 내 변동의 5.43배라는 뜻. H₀(세 집단 평균이 모두 같다)이 참이면 F ≈ 1에 가까워야 하므로, 5.43은 우연보다 크다는 증거.

---

**Q2.** `η² = .11`은 Cohen의 기준으로 어느 수준의 효과크기인가?

**모범 답안:**

η² = .11을 Cohen(1988)의 기준과 비교하면:
- 작은 효과: η² ≥ .01
- 중간 효과: η² ≥ .06
- **큰 효과: η² ≥ .14**

η² = .11은 "중간"과 "큰" 사이에 위치한다. 정확히는 **중간-큰 효과**로 해석하거나, 많은 연구에서 "중간 이상의 효과"라고 표현한다.

η²의 정의에서 직접 해석하면: SS_between / SS_total = .11, 즉 BDI-II 점수의 전체 변동 중 **11%가 치료 조건의 차이로 설명**된다. 나머지 89%는 집단 내 개인차(측정 오차, 개인 특성 등)에 의한 변동이다.

---

**Q3.** `p = .006`의 의미는 무엇인가?

**모범 답안:**

H₀(세 치료 조건의 BDI-II 평균이 모두 동일하다)이 참일 때, 표본에서 F(2, 87) = 5.43 이상의 통계량이 관찰될 확률이 p = .006이다. 즉, 이 정도의 집단 간 차이가 우연에 의해 나타날 확률은 0.6%밖에 안 된다. p < .05(= α)이므로 H₀를 기각하고, "적어도 한 쌍의 치료 조건 간 BDI-II 평균이 유의하게 다르다"고 결론 내릴 수 있다.

---

**Q4.** 사후검정(Bonferroni) 결과를 요약하면 어떻게 되는가?

**모범 답안:**

Bonferroni 교정 결과(α' = .05/3 ≈ .017):

```
① 통합치료 vs. 약물치료: p = .004 < .017 → 유의하게 다름
   통합치료(M = 11.4)가 약물치료(M = 17.8)보다 BDI-II 점수가 유의하게 낮음

② CBT vs. 약물치료: p > .05 → 유의하지 않음

③ CBT vs. 통합치료: p > .05 → 유의하지 않음
```

따라서 세 집단이 "모두" 다른 것이 아니라, **통합치료와 약물치료 사이에만 유의한 차이**가 있었다.

---

**Q5.** "통합치료 vs. 약물치료"는 유의하지만 "CBT vs. 기타"는 유의하지 않다. ANOVA 전체 결과(p = .006)와 모순인가?

**모범 답안:**

모순이 아니다. ANOVA 전체 검정(omnibus test)은 "적어도 한 쌍이 다르다"만을 알려준다. 이 경우 통합치료–약물치료 쌍이 크게 달라서 전체 F가 유의해진 것이고, 다른 쌍들은 차이가 작아서 Bonferroni 교정 기준을 통과하지 못한 것이다.

비유: "시험에서 한 문제는 틀렸다" → 몇 번 문제인지는 모른다. ANOVA가 "한 문제는 틀렸다"고 말해주면, 사후검정이 "어떤 문제"인지를 찾아주는 역할이다. 어떤 문제만 틀렸어도 전체적으로는 "오답이 있다"는 사실에는 변함이 없다.

## §7 오개념 경고

> **⚠️ 오개념 1: "ANOVA p < .05이면 모든 집단이 서로 다르다."**
>
> **바로잡기:** ANOVA의 귀무가설은 "모든 집단 평균이 동일하다(μ₁ = μ₂ = μ₃)"이고, 이를 기각하면 알 수 있는 것은 **"적어도 한 쌍"** 이 다르다는 것뿐이다. 어떤 집단들이 다른지는 ANOVA만으로 알 수 없으며, 반드시 **사후검정(post-hoc test)** 이 필요하다. 논문에서 ANOVA 결과만 보고하고 사후검정이 없다면, "어디서 차이가 났는지"는 알 수 없다.

---

> **⚠️ 오개념 2: "F-통계량이 크면 효과도 크다."**
>
> **바로잡기:** F 값은 표본 크기(n)에도 크게 영향을 받는다. n이 크면 같은 η²(효과크기)라도 F가 매우 커진다. 실질적인 효과 크기는 **η²** 로 따로 판단해야 한다.
>
> ```
> 예: F(2, 297) = 5.43  →  n이 크고 η² = .04 (작은 효과)
>     F(2, 9)   = 5.43  →  n이 작고 η² = .55 (매우 큰 효과)
> ```
>
> F 값이 같아도 효과크기가 다를 수 있다. APA 7판 지침에 따라 효과크기(η²)를 F와 함께 반드시 보고해야 한다.

---

> **⚠️ 오개념 3: "ANOVA 후에 사후검정 대신 t-검정으로 쌍별 비교하면 된다."**
>
> **바로잡기:** 이렇게 하면 §3.1에서 설명한 **1종 오류 팽창 문제로 되돌아간다.** ANOVA를 먼저 실시한 의미가 없어진다. 사후검정(LSD, Bonferroni, Tukey 등)은 다중 비교 상황에서 familywise error rate을 통제하도록 설계된 방법이다. 단순 t-검정 반복은 이 통제를 포기하는 것이다.

---

> **⚠️ 오개념 4: "Bonferroni 방법이 항상 최선이다."**
>
> **바로잡기:** Bonferroni는 **보수적(conservative)** 방법이다. 집단 수가 많아질수록 α'이 매우 작아지고 검정력이 급감한다. 예를 들어 k = 6이면 m = 15, α' = .05/15 ≈ .003이 되어 실제로 다른 집단도 유의하다고 찾지 못하는 2종 오류가 늘어난다. 비교 횟수가 많거나 탐색적 연구에서는 Tukey HSD, Scheffé 등 다른 방법이 더 적절할 수 있다. **"어떤 사후검정 방법이 왜 선택되었는지"가 논문의 Methods에 명시되어야 한다.**

---

> **⚠️ 오개념 5: "분산분석이란 분산을 분석하는 것이다 — 즉, 분산이 다른지 검정한다."**
>
> **바로잡기:** ANOVA는 **분산을 '도구'로 사용하여 집단 간 평균의 차이를 검정**하는 방법이다. 검정하는 목적은 **평균 차이**이지 분산 차이가 아니다. 분산을 비교하는 검정은 따로 있다(Levene 검정, Bartlett 검정 등). ANOVA의 이름에 "분산"이 들어간 이유는 분석 도구(MS_between, MS_within)로 분산을 사용하기 때문이지, 분산 자체가 목적이 아니다.

## §10 다음 챕터 연결

이 챕터는 **범주형 독립변수**(예: 치료 조건 A / B / C)에 따른 집단 간 평균 차이를 검정했다. 이제 자연스럽게 다음 질문이 생긴다:

> **"독립변수가 범주형이 아니라 연속형(수치)이라면 어떻게 분석하는가?"**
> "불안 점수가 1점 높아질 때 우울 점수는 몇 점 오르는가?"

ANOVA는 "치료A vs. 치료B vs. 치료C 중 어느 게 더 좋은가?"에 답하지만, 변수들 사이의 **방향성과 크기가 있는 관계(relationship)**를 분석하지는 못한다.

```
[Ch.11 분산분석(ANOVA)]
    "독립변수: 범주형 (집단)"
    "종속변수: 연속형 (점수)"
    "질문: 집단 간 평균이 다른가?"
            ↓
[Ch.12 회귀분석(Regression)]
    "독립변수: 연속형 (수치)"
    "종속변수: 연속형 (점수)"
    "질문: X가 1 증가하면 Y는 얼마나 변하는가?"
```

회귀분석에서 만날 핵심 개념:
- 회귀계수(β): X가 1 증가할 때 Y의 평균 변화량
- 절편(intercept): X = 0일 때 Y의 예측값
- 결정계수(R²): X가 Y 변동의 얼마나(%)를 설명하는가? → ANOVA의 η²에 대응

## 부록: 효과크기 — η²(에타제곱)과 ω²(오메가제곱)

*(CLAUDE.md §5 보완 주제: "효과크기 (Cohen's d, η², r) — Ch.9~11")*

### A. η²(에타제곱)이란?

ANOVA에서 효과크기를 나타내는 지표다. 전체 변동 중 집단 간 차이로 설명되는 비율이다.

```
η² = SS_between / SS_total

범위: 0 ≤ η² ≤ 1
  0: 집단 간 차이가 전혀 없음
  1: 집단이 전체 변동을 완전히 설명
```

**Cohen(1988) 해석 기준:**

| η² 값 | 효과크기 | 의미 |
|-------|---------|------|
| .01   | 작은 효과 (small)  | 집단 차이가 전체 변동의 1% 설명 |
| .06   | 중간 효과 (medium) | 집단 차이가 전체 변동의 6% 설명 |
| .14   | 큰 효과 (large)    | 집단 차이가 전체 변동의 14% 설명 |

---

### B. η²의 한계: 편향 추정(Biased Estimate)

η²은 모집단의 효과크기를 **과대 추정**하는 경향이 있다 (표본에서 계산된 SS_between이 우연 요인도 포함하기 때문).

특히 표본 크기가 작을수록 편향이 커진다.

---

### C. ω²(오메가제곱) — 불편(Unbiased) 추정량

η²의 편향을 교정한 효과크기 지표다:

```
ω² = (SS_between − df_between × MS_within) / (SS_total + MS_within)

= (SS_B − (k−1) × MS_W) / (SS_T + MS_W)
```

**특징:**
- η²보다 항상 작게 나온다 (편향 교정)
- 표본이 클수록 η²과 ω²의 차이는 작아진다
- 보고 권장 — APA Publication Manual에서 ω²를 선호한다는 견해도 있음

**실제 논문에서:**
- SPSS 기본 출력: `partial η²` 보고
- 교정된 값 원할 때: `ω²` 또는 `partial ω²` 따로 계산·보고

---

### D. η² vs. Cohen's d — 효과크기 지표 비교

| 지표 | 사용 상황 | 수식 | Cohen 기준 |
|------|-----------|------|------------|
| Cohen's d | t-검정 (두 집단) | d = Δx̄ / sp | .20 / .50 / .80 |
| η² | ANOVA (세 집단 이상) | SS_B / SS_T | .01 / .06 / .14 |
| r (점이연 상관) | t 결과 → 상관 변환 | r = t / √(t² + df) | .10 / .30 / .50 |
| R² | 회귀분석 | 설명된 분산 비율 | Ch.12에서 다룸 |

**두 집단 특수 경우:**

k = 2(집단이 2개)이면 F = t²이고, 이때:

```
η² ≈ d² / (d² + 4)

→ d = 0.50(중간 효과)이면 η² ≈ 0.059 ≈ .06 (중간 효과)
   d = 0.80(큰 효과)이면   η² ≈ 0.138 ≈ .14 (큰 효과)

두 지표의 Cohen 기준이 대응함을 확인할 수 있다.
```

---

### E. APA 7판 효과크기 보고 기준

APA Publication Manual (7판)은 통계 검정 결과와 함께 효과크기를 반드시 보고하도록 명시한다:

> *"For each inferential test reported, include measures of effect size."*
> *(APA Manual, 2020, §6.24)*

**ANOVA 올바른 보고 형식:**
```
F(2, 87) = 5.43, p = .006, η² = .11
```

p값만 보고하는 것은 APA 7판 기준에 부적합하다. 효과크기는 "통계적으로 유의한가?" 외에 "실질적으로 의미 있는 크기인가?"를 판단하는 필수 정보다.

## 부록 2: 공분산분석 (ANCOVA, Analysis of Covariance)

*(CLAUDE.md §5 보완 주제에 해당하지는 않으나, ANOVA 설계의 자연스러운 확장으로 이 챕터 부록에 수록한다.)*

---

### A. ANCOVA란 무엇인가?

#### 직관부터 시작

> **질문**: "CBT vs. 약물치료 집단을 비교하고 싶은데, 치료 시작 전 우울 점수(사전 검사)가 집단마다 다르다면 어떻게 해야 하는가?"

ANOVA로 치료 후(사후) 점수만 비교하면, 사전 점수의 차이가 결과에 섞여 들어온다. 이를 해결하는 방법이 **공분산분석 (ANCOVA, Analysis of Covariance)** 이다.

ANCOVA = ANOVA + 공변량 통제

```
ANOVA:   집단 간 Y의 차이 검정
ANCOVA:  공변량(X)의 영향을 제거한 후 집단 간 Y의 차이 검정

                 공변량(X) 통제
                      ↓
집단 (A/B/C)  →  수정된 Y 점수  →  F 검정
```

**임상 예시**:
- 독립변수: 치료 조건 (CBT / 약물치료 / 통합치료)
- 종속변수: 사후 BDI-II 점수
- 공변량 (covariate): 사전 BDI-II 점수

> **핵심 납득 포인트**
>
> ANCOVA는 "이미 우울했던 사람이 치료 후에도 점수가 높은 것"과 "치료 효과 때문에 점수가 달라진 것"을 구분해 준다. 사전 검사 점수를 통계적으로 제거하면, 치료의 순수한 효과만 볼 수 있다.

---

### B. ANCOVA의 SS 분해: ANOVA와 무엇이 다른가?

#### 기본 구조

ANCOVA의 핵심 아이디어: **공변량(X)이 Y를 예측하는 부분을 먼저 회귀로 제거하고, 그 잔차에 ANOVA를 적용한다.**

```
■ 단계 1: 공변량 X로 Y를 회귀
  Y = β₀ + β₁X + ε
  → 잔차(residual) = Y − (β₀ + β₁X) = "X의 효과가 제거된 Y"

■ 단계 2: 잔차에 일원배치 ANOVA 적용
  → 집단 간 잔차 차이 검정
```

**SS 분해 비교:**

```
ANOVA:   SS_total = SS_between + SS_within
ANCOVA:  SS_total = SS_between(조정됨) + SS_covariate + SS_error(조정됨)
```

| 변동원 | ANOVA | ANCOVA |
|--------|-------|--------|
| 집단 간 | SS_between | SS_between(adj) — 공변량 제거 후 |
| 공변량 | 없음 | SS_covariate = β₁² × Sxx |
| 오차 | SS_within | SS_error(adj) — 더 작아짐 |
| 합계 | SS_total | SS_total |

**왜 ANCOVA가 더 정확한가:**
```
ANOVA의 SS_within = 개인차 + 공변량 효과 (혼합됨)
ANCOVA의 SS_error = 개인차만 (공변량 효과 제거됨)

→ SS_error < SS_within  →  MS_error 감소  →  F값 증가  →  검정력 향상
```

---

### C. 수정 평균 (Adjusted Means)

ANCOVA가 ANOVA와 다른 또 하나의 특징: **수정 평균(adjusted mean)** 을 보고한다.

**수정 평균이란**: 모든 집단의 공변량 값이 동일하다고 가정했을 때의 예측 Y 평균.

```
수정 평균(i집단) = 관측 평균(x̄ᵢ) − β̂₁ × (x̄_covariate_i − x̄_covariate_grand)

여기서:
  β̂₁           : 공변량의 회귀계수 (집단 공통)
  x̄_covariate_i : i집단의 공변량 평균
  x̄_covariate_grand : 전체 공변량 평균
```

**예시:**

| 집단 | 관측 Y 평균 | 사전 점수(X) 평균 | 수정 Y 평균 |
|------|------------|-----------------|------------|
| CBT | 14.2 | 20.1 | **15.6** ← 사전이 높았음을 조정 |
| 약물치료 | 17.8 | 22.3 | **16.8** ← 사전이 더 높았음을 조정 |
| 통합치료 | 11.4 | 18.4 | **12.2** ← 사전이 낮았음을 조정 |

전체 공변량 평균 x̄_grand = 20.3, β̂₁ = 0.7 (가정)

```
CBT 수정 평균 = 14.2 − 0.7 × (20.1 − 20.3) = 14.2 + 0.14 = 14.34
```

> **핵심 납득 포인트**
>
> 관측 평균은 "치료 전부터 우울이 심했던 사람"의 영향을 받는다. 수정 평균은 "모든 집단이 치료 시작 전에 동일한 우울 수준이었다면 어떤 결과가 나왔을까?"를 보여준다. 이것이 ANCOVA가 RCT가 아닌 준실험 연구에서 특히 유용한 이유다.

---

### D. 기울기 동질성 가정 (Homogeneity of Regression Slopes)

ANCOVA에는 ANOVA에는 없는 중요한 가정이 하나 더 있다.

**가정**: 각 집단에서 공변량(X)과 종속변수(Y)의 관계(기울기 β₁)가 모든 집단에서 동일해야 한다.

```
수학적 표현:
  β₁(CBT) = β₁(약물치료) = β₁(통합치료) = β₁(공통)

시각적으로:
  각 집단의 회귀선들이 기울기가 같아야 한다 (평행해야 함)

위반:
  집단 A: Y와 X의 관계가 강함 (가파른 기울기)
  집단 B: Y와 X의 관계가 약함 (완만한 기울기)
  → 이 경우 ANCOVA의 F 검정이 부적절
```

**검정 방법:**

공변량 × 집단 상호작용 항(X × 집단)을 모형에 추가했을 때 유의한지 확인.

```
H₀: X × 집단 상호작용이 없다 (기울기 동질)
Hₐ: X × 집단 상호작용이 있다 (기울기 비동질)

→ p > .05이면 기울기 동질성 가정 충족 (ANCOVA 진행 가능)
→ p < .05이면 가정 위반 → 별도 분석 필요
```

**논문 보고 예시:**
> "Prior to the main ANCOVA, the homogeneity of regression slopes assumption was tested by examining the interaction between the covariate (baseline BDI-II) and treatment condition. This interaction was not significant, F(2, 84) = 1.23, p = .296, confirming that the assumption was met."

---

### E. 자유도와 F 통계량

ANCOVA의 자유도는 ANOVA와 약간 다르다:

```
df_between(adj) = k − 1                  (집단 수 − 1, ANOVA와 같음)
df_error(adj)   = N − k − c              (c = 공변량 수)
df_total        = N − 1

공변량이 1개(c=1)일 때:
df_error = N − k − 1   (ANOVA의 N−k보다 1 작음)

F = MS_between(adj) / MS_error(adj)      (F-분포는 그대로)
```

**분산분석표 (ANCOVA Table):**

| 변동원 | SS | df | MS | F | p |
|--------|----|----|----|----|---|
| 공변량 (사전 BDI-II) | SS_cov | 1 | MS_cov | F_cov | |
| 집단 (치료 조건) | SS_between(adj) | k−1 | MS_B(adj) | F_main | |
| 오차 | SS_error(adj) | N−k−1 | MS_error | | |
| 합계 | SS_total | N−1 | | | |

---

### F. 완전한 수치 예시

**설계**: 세 치료 조건(CBT/약물/통합), 각 n=5, N=15
공변량: 사전 BDI-II (X), 종속변수: 사후 BDI-II (Y)

| 집단 | 참가자 | X(사전) | Y(사후) |
|------|--------|--------|--------|
| CBT(1) | 1 | 22 | 14 |
| CBT(1) | 2 | 18 | 11 |
| CBT(1) | 3 | 25 | 16 |
| CBT(1) | 4 | 20 | 13 |
| CBT(1) | 5 | 21 | 14 |
| 약물(2) | 6 | 24 | 19 |
| 약물(2) | 7 | 27 | 22 |
| 약물(2) | 8 | 23 | 18 |
| 약물(2) | 9 | 26 | 20 |
| 약물(2) | 10 | 22 | 17 |
| 통합(3) | 11 | 19 | 10 |
| 통합(3) | 12 | 20 | 11 |
| 통합(3) | 13 | 22 | 12 |
| 통합(3) | 14 | 18 | 9 |
| 통합(3) | 15 | 21 | 11 |

```
■ 단계 1: 집단별 X, Y 평균 계산
  CBT:  x̄₁ = 21.2,  ȳ₁ = 13.6
  약물: x̄₂ = 24.4,  ȳ₂ = 19.2
  통합: x̄₃ = 20.0,  ȳ₃ = 10.6

  전체:  x̄ = 21.87,  ȳ = 14.47

■ 단계 2: 공변량의 회귀계수 추정 (단순화)
  공변량 X와 Y의 전체 회귀:
  Sxy = Σ(xᵢ−x̄)(yᵢ−ȳ) (집단 내 계산)
  β̂₁ ≈ 0.75  (사전 점수 1점 증가 → 사후 점수 0.75점 증가)

■ 단계 3: 수정 평균 계산
  CBT:  13.6 − 0.75 × (21.2 − 21.87) = 13.6 + 0.50 = 14.1
  약물: 19.2 − 0.75 × (24.4 − 21.87) = 19.2 − 1.90 = 17.3
  통합: 10.6 − 0.75 × (20.0 − 21.87) = 10.6 + 1.40 = 12.0

■ 단계 4: ANCOVA F 검정 결과 (계산 생략)
  공변량: F(1, 11) = 18.43, p < .001  (사전 점수가 유의한 예측변수)
  치료 조건(수정됨): F(2, 11) = 9.87, p = .003  ✓

■ 비교: ANOVA vs. ANCOVA
  ANOVA  (사전 미통제): F(2, 12) = 6.23, p = .014
  ANCOVA (사전 통제):   F(2, 11) = 9.87, p = .003  ← 더 강한 검정력

→ 공변량을 통제하면 오차(MS_error)가 줄어 F가 커지고 p가 작아진다.
```

### G. 논문에서 ANCOVA 읽기

**전형적인 논문 보고 형식 (APA 7판):**

> "An analysis of covariance (ANCOVA) was conducted to examine differences in post-treatment BDI-II scores across treatment conditions, with baseline BDI-II as a covariate. Prior to analysis, the homogeneity of regression slopes assumption was verified (p = .296). The ANCOVA revealed a significant main effect of treatment after controlling for baseline depression, F(2, 86) = 8.43, p < .001, partial η² = .16. Estimated marginal means (adjusted for baseline BDI-II = 22.1) were: CBT = 14.2 (SE = 0.8), pharmacotherapy = 17.3 (SE = 0.8), combined treatment = 11.8 (SE = 0.9)."

**독해 포인트:**

| 표현 | 의미 |
|------|------|
| "with baseline BDI-II as a covariate" | 사전 점수를 공변량으로 통제함 |
| "homogeneity of regression slopes" | 기울기 동질성 가정 확인 |
| "controlling for baseline depression" | 사전 점수의 영향 제거 후 |
| "Estimated marginal means" | 수정 평균 (adjusted means) |
| "adjusted for baseline BDI-II = 22.1" | 공변량을 전체 평균(22.1)에서 조정 |

### H. ANCOVA 사용 시 주의사항

**① 공변량은 처치 이전에 측정되어야 한다**

만약 공변량이 처치 이후에 측정된 변수라면, 처치 효과가 공변량에도 반영되어 분석이 왜곡된다.
- ✓ 올바른 예: 사전 BDI-II를 공변량으로, 사후 BDI-II를 종속변수로
- ✗ 잘못된 예: 치료 중간(4주차)에 측정한 변수를 공변량으로 사용

**② 공변량과 독립변수가 독립적이어야 한다**

집단 배정(처치)이 공변량 값에 영향을 미쳐서는 안 된다. RCT에서는 무선 배정으로 이를 보장하지만, 준실험에서는 집단 간 공변량 차이 자체가 의미 있을 수 있다.

**③ ANCOVA ≠ 완전한 통제**

ANCOVA는 측정된 공변량의 영향만 제거한다. 측정되지 않은 혼재변수는 여전히 남아 있다. ANCOVA가 인과 추론을 보장하지는 않는다.
