### 3.1 자료의 종류와 구조

#### 직관부터 시작

> **질문**: "BDI-II 점수 21점과 성별(여성)은 둘 다 숫자나 범주로 표현된다. 같은 방식으로 다뤄도 되는가?"

답: 아니다. **숫자처럼 보여도 성격이 다른 데이터가 있다.** 리커트 척도의 "불안 없음(1) ~ 극심한 불안(5)"은 1과 3의 차이가 3과 5의 차이와 같다고 보장할 수 없다. 반면 체중(kg) 60과 80의 차이는 정확히 20kg이다.

이 차이가 "어떤 통계를 쓸 수 있는가"를 결정한다.

#### 측정 척도 4종

| 척도                      | 특징                           | 가능한 연산         | 심리학 예시                                        |
| ------------------------- | ------------------------------ | ------------------- | -------------------------------------------------- |
| **명목 (Nominal)**  | 이름만 다름. 순서 없음         | 빈도, 백분율만 가능 | MBTI 유형 (INFP, ENTJ 등), 진단명 (MDD, GAD, PTSD) |
| **서열 (Ordinal)**  | 순서 있음. 간격은 불균등       | 중앙값, 백분위수    | 우울 심각도 (없음/경미/중등/심각), 리커트 척도     |
| **등간 (Interval)** | 순서 + 균등 간격. 절대 0 없음  | 평균, 표준편차 가능 | BDI-II 점수, IQ 점수, 섭씨 온도                    |
| **비율 (Ratio)**    | 순서 + 균등 간격 + 절대 0 있음 | 모든 연산 가능      | 반응시간(ms), 체중(kg), 코티솔 농도                |

> **핵심 납득 포인트**: 척도의 종류가 높아질수록(명목 → 비율) 더 많은 통계를 적용할 수 있다. 역방향은 안 된다 — 비율 척도 자료를 명목형으로 다룰 수 있지만, 명목형 자료에 평균을 내는 것은 무의미하다. (MBTI에서 "INFP = 1, ENTJ = 2"로 코딩하고 평균이 1.6이라고 해도 아무 의미가 없다.)

---

#### 범주형 vs. 연속형 — 두 개의 큰 덩어리

4종 척도는 분석 방법을 결정하는 두 상위 범주로 묶인다:

```
범주형 (Categorical):  명목 + 서열
연속형 (Continuous):   등간 + 비율
```

**범주형 데이터 (Categorical Data)**

- 숫자가 아닌 **이름·범주**로 표현되는 데이터. 숫자로 코딩해도 그 숫자에 크기 의미가 없다.
- 명목 척도: 범주 간 순서도 없음 (진단명, 성별)
- 서열 척도: 범주 간 순서는 있으나, 간격이 불균등 (우울 심각도 등급)
- **할 수 있는 것**: 빈도(몇 명인지), 비율(전체의 몇 %)
- **할 수 없는 것**: 평균·표준편차 계산 (순서나 간격이 보장되지 않으므로)
- **적합한 시각화**: 막대그래프, 파이차트

**연속형 데이터 (Continuous Data)**

- 수치 간 간격이 동일하고, 의미 있는 덧셈·뺄셈이 가능한 데이터.
- 등간 척도: 절대 0 없음 (BDI-II 점수, IQ — "0점 = 우울 없음"이 성립하지 않음)
- 비율 척도: 절대 0 있음, 비율 해석 가능 (반응시간(ms), 체중(kg))
- **할 수 있는 것**: 평균·표준편차·상관 등 모든 기술통계
- **적합한 시각화**: 히스토그램, 상자그림, 산점도

> **핵심 납득 포인트**: "어떤 통계를 써야 하는가?"는 **변수가 범주형인지 연속형인지**가 가장 먼저 결정한다. 논문에서 "성별 차이"를 분석할 때 χ²검정(Ch.13)을 쓰고, "BDI-II 점수 차이"를 분석할 때 t검정(Ch.10)을 쓰는 이유가 여기에 있다. 분석 방법을 선택하기 전, 항상 "이 변수는 범주형인가, 연속형인가?"를 먼저 묻는 습관을 들여라.

### 3.2 표를 이용한 자료 정리

#### 3.2.1 도수분포표 (Frequency Distribution Table)

**직관**: 10명의 BDI-II 점수가 있다. 이 숫자들을 그냥 나열하면 한눈에 파악하기 어렵다. **구간을 나눠서 각 구간에 몇 명이 속하는지** 세면 전체 분포가 보인다.

**예시 데이터**: BDI-II 점수 10개: 8, 14, 21, 11, 6, 18, 25, 13, 9, 17

**도수분포표 작성**:

| 계급 (Class)   | 도수 (f)     | 상대도수 (rel. f) | 누적도수 (cum. f) |
| -------------- | ------------ | ----------------- | ----------------- |
| 0 ~ 9점        | 3            | 3/10 = .30        | 3                 |
| 10 ~ 19점      | 5            | 5/10 = .50        | 8                 |
| 20 ~ 29점      | 2            | 2/10 = .20        | 10                |
| **합계** | **10** | **1.00**    | —                |

- **계급 (class)**: 자료를 나누는 구간 (BDI-II 임상 절단점 0 ~ 9 최소, 10 ~ 18 경미, 19 ~ 29 중등, 30+ 심각과 비슷하게 설정)
- **도수 (frequency, f)**: 각 계급에 속하는 자료의 개수
- **상대도수 (relative frequency)**: 도수 ÷ 전체 n. 백분율로 해석 가능
- **누적도수 (cumulative frequency)**: 해당 계급까지의 도수 합계

> **핵심 납득 포인트**: 도수분포표에서 "상대도수"가 더 유용한 경우가 많다. n이 다른 두 집단을 비교할 때, 도수(명수)는 직접 비교할 수 없지만 상대도수(비율)는 비교 가능하다.

---

#### 3.2.2 분할표 (Contingency Table / Cross-tabulation)

**직관**: 한 변수가 아니라 두 범주형 변수의 **조합**이 궁금할 때 쓴다.

**예시**: 성별(남/여) × 우울증 유무(있음/없음)

|                   | 우울증 있음  | 우울증 없음  | **행 합계** |
| ----------------- | ------------ | ------------ | ----------------- |
| **남성**    | 15           | 35           | **50**      |
| **여성**    | 28           | 22           | **50**      |
| **열 합계** | **43** | **57** | **100**     |

- 이 표를 보면 여성(28/50 = 56%)이 남성(15/50 = 30%)보다 우울증 비율이 높음을 즉시 알 수 있다
- 분할표는 Ch.13(범주형 자료분석, χ² 검정)에서 통계적 검정의 대상이 된다

> **핵심 납득 포인트**: 분할표는 두 변수 사이의 관련성을 "눈으로" 확인하는 첫 단계다. 통계 검정을 하기 전, 분할표를 먼저 그려서 방향을 파악하는 것이 좋은 분석 습관이다.

### 3.3 그래프를 이용한 자료 정리

#### 3.3.1 파이차트 (Pie Chart)

- **용도**: 명목형 변수의 **구성비** 표시
- **적합한 경우**: 범주가 3~5개이고, 전체 대비 비율이 중요할 때
- **부적합한 경우**: 범주가 많거나, 범주 간 크기 차이가 미묘할 때 (인간의 눈은 각도보다 길이를 더 정확히 인식함)

```
[파이차트 예시: 진단명 비율]
        MDD 43%
       ╔═══════╗
  GAD  ║       ║ PTSD
  22%  ║  ●    ║ 20%
       ╚═══════╝
          기타 15%
```

#### 3.3.2 막대그래프 (Bar Graph)

- **용도**: 명목형·서열형 변수의 빈도 또는 평균 비교
- **히스토그램과의 차이**: 막대 사이에 **간격이 있다** (범주형 데이터이므로 연속성이 없음)

```
[막대그래프: 진단별 빈도]
  50|  ████
  40|  ████ ████
  30|  ████ ████ ████
  20|  ████ ████ ████ ████
   0+--MDD--GAD--PTSD--기타
```

#### 3.3.3 히스토그램 (Histogram)

- **용도**: **연속형 변수**의 분포 시각화
- **막대그래프와의 차이**: 막대 사이에 **간격이 없다** (연속 데이터이므로)
- **계급 너비 선택의 중요성**: 같은 데이터도 계급 너비에 따라 모양이 완전히 달라 보인다

```
[계급 너비 = 10인 히스토그램: BDI-II 점수]
   5|       ██
   4|    ██ ██
   3| ██ ██ ██
   2| ██ ██ ██ ██
   1| ██ ██ ██ ██ ██
   0+--0--10--20--30--40
```

> **핵심 납득 포인트**: 히스토그램의 세로축은 "해당 구간에 몇 명이 속하는가"를 나타낸다. 분포의 형태(대칭/왜도/이봉형 등)를 한눈에 파악할 수 있어서, 통계 분석 전 **가장 먼저 그려야 할 그래프**다.

#### 3.3.4 줄기-잎 그림 (Stem-and-Leaf Plot)

- **특징**: 원데이터를 그대로 보존하는 히스토그램. 소규모 데이터(n ≤ 50)에 적합
- **예시**: BDI-II 점수 10개 (6, 8, 9, 11, 13, 14, 17, 18, 21, 25)

```
줄기 | 잎
  0  | 6 8 9
  1  | 1 3 4 7 8
  2  | 1 5

(줄기 = 십의 자리, 잎 = 일의 자리)
```

#### 3.3.5 산점도 (Scatter Plot)

- **용도**: **두 연속형 변수**의 관계 시각화
- **Ch.12 연결**: 회귀분석에서 산점도는 분석의 시작점이다

```
[산점도 예시: BDI-II vs GAD-7]
GAD-7
 20|           ·  ·
 15|        ·    ·  ·
 10|     ·   ·  ·
  5|  ·  ·
  0+--5--10--15--20--25-- BDI-II
```

양의 방향(BDI-II 높을수록 GAD-7도 높음): 우울·불안 공존 경향

#### 3.3.6 상자그림 (Box Plot / Box-and-Whisker Plot)

**용도**: 분포의 **5가지 요약 수치**와 이상값을 동시에 시각화

```
[상자그림 구성]

    ┃                          ← 최댓값 (또는 울타리 내 최댓값)
    ┃
 ┌──┴──┐
 │     │  ← Q3 (3사분위수, 75번째 백분위)
 │─────│  ← 중앙값 (Median, 50번째 백분위)
 │     │  ← Q1 (1사분위수, 25번째 백분위)
 └──┬──┘
    ┃
    ┃                          ← 최솟값 (또는 울타리 내 최솟값)

  ○ ○                         ← 이상값 (outlier): Q3+1.5×IQR 초과 또는 Q1-1.5×IQR 미만
```

- **IQR (사분위간 범위)** = Q3 − Q1: 중앙 50% 데이터의 범위
- **이상값 판별**: Q3 + 1.5 × IQR 초과하거나 Q1 − 1.5 × IQR 미만인 값

> **핵심 납득 포인트**: 상자그림 하나로 중심위치, 퍼짐, 분포의 대칭성, 이상값 유무를 동시에 볼 수 있다. 두 집단을 나란히 비교할 때(예: 치료군 vs 통제군) 매우 강력한 시각화 도구다.

### 3.4 수치를 이용한 자료 정리

---

#### 3.4.1 중심위치 (Measures of Central Tendency)

**직관**: 데이터 전체를 한 숫자로 요약한다면? "이 집단의 우울 수준을 대표하는 숫자 하나를 골라라."

---

**평균 (Mean)**

수식:

$$
\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n} = \frac{x_1 + x_2 + \cdots + x_n}{n}
$$

- x̄ = 표본평균
- xᵢ = i번째 데이터 값
- n = 표본 크기
- Σ = 모두 더하기

**손계산 예시** (BDI-II 점수 5개: 8, 13, 17, 22, 10):

```
x̄ = (8 + 13 + 17 + 22 + 10) / 5
   = 70 / 5
   = 14.0
```

---

**중앙값 (Median)**

- 데이터를 작은 순서로 정렬했을 때 **정 가운데** 위치한 값
- n이 홀수: (n+1)/2 번째 값
- n이 짝수: n/2번째와 (n/2)+1번째 값의 평균

**손계산 예시** (5개: 8, 10, 13, 17, 22):

```
정렬: 8, 10, [13], 17, 22
n = 5 (홀수) → (5+1)/2 = 3번째 값
중앙값 = 13
```

**짝수 예시** (6개: 8, 10, 13, 17, 22, 30):

```
정렬: 8, 10, [13, 17], 22, 30
n = 6 (짝수) → 3번째(13)와 4번째(17)의 평균
중앙값 = (13 + 17) / 2 = 15
```

---

**최빈값 (Mode)**

- 가장 자주 등장하는 값
- 명목형 데이터에도 사용 가능한 유일한 중심위치 측도
- 예: (8, 10, 10, 13, 17) → 최빈값 = 10

---

**절사평균 (Trimmed Mean)**

- 극단값(최솟값·최댓값 쪽의 일정 비율)을 제거하고 나머지로 계산한 평균
- 5% 절사평균: 위아래 각 5%씩 제거 후 평균
- 이상값의 영향을 줄이면서도 원본 데이터의 대부분을 활용

---

> **핵심 납득 포인트**: 우울 점수(BDI-II)처럼 **양의 왜도(오른쪽 꼬리)**가 있는 자료에서는 소수의 매우 높은 점수가 평균을 끌어올린다. 이런 경우 **중앙값이 더 대표적인 대표값**이다. 논문에서 "왜도가 있는 분포이므로 중앙값과 IQR을 보고한다"는 문장을 자주 볼 수 있다.

---

#### 3.4.2 퍼짐의 측도 (Measures of Spread / Dispersion)

**직관**: 두 집단의 평균이 같아도, 데이터가 평균 주위에 얼마나 퍼져 있는지는 다를 수 있다. "집단 A의 BDI-II 평균 = 집단 B의 BDI-II 평균 = 15"여도, A는 모두 12 ~ 18점에 몰려 있고 B는 0 ~ 30점까지 흩어져 있을 수 있다.

---

**범위 (Range)**

```
범위 = 최댓값 − 최솟값
```

- 예: (8, 10, 13, 17, 22) → 범위 = 22 − 8 = 14
- **단점**: 이상값 하나에 극히 민감하다. (8, 10, 13, 17, 100) → 범위 = 92

---

**분산 (Variance)**

```
표본분산: s² = Σ(xᵢ − x̄)² / (n−1)
```

**왜 (n−1)인가?** — 자유도 직관

**1단계: 구체적 예시로 이해하기**

n = 3인 데이터가 있고, 평균이 x̄ = 10으로 고정되어 있다고 하자.

- 첫 번째 값 = 7로 정했다.
- 두 번째 값 = 12로 정했다.
- 세 번째 값은? → 7 + 12 + ? = 30 (평균 10 × 3 = 30이어야 하므로)
- → 세 번째 값은 반드시 **11**이어야 한다. 선택의 여지가 없다.

즉, n = 3개 중 **2개(= n−1)만** 자유롭게 선택할 수 있다. 마지막 값은 나머지가 결정되면 자동으로 정해진다. 이렇게 "자유롭게 변할 수 있는 값의 개수"를 **자유도(degrees of freedom, df)**라 한다.

```
자유도 공식: df = n − 1

n = 3이면 df = 2  (3개 중 마지막 1개는 자동으로 결정됨)
n = 5이면 df = 4  (5개 중 마지막 1개는 자동으로 결정됨)
```

**2단계: 왜 n으로 나누면 과소추정인가**

분산을 계산할 때 우리는 실제 모평균 μ 대신 표본에서 계산한 x̄를 사용한다. 문제는 x̄가 "이 표본에 맞춰진 값"이라는 점이다. 숫자로 직접 확인해보자.

**설정**: 모집단의 진짜 평균이 μ = 10이라고 가정한다. 여기서 표본 3개를 뽑았더니 8, 11, 14가 나왔다.

```
표본평균: x̄ = (8 + 11 + 14) / 3 = 11

→ μ = 10이지만, 이 표본의 x̄ = 11로 다르다.
```

**μ = 10으로 편차를 계산하면 (우리가 원하는 상황)**:

```
 8 − 10 = −2   → 제곱: 4
11 − 10 = +1   → 제곱: 1
14 − 10 = +4   → 제곱: 16

편차 제곱의 합 = 4 + 1 + 16 = 21
```

**x̄ = 11로 편차를 계산하면 (실제로 하는 계산)**:

```
 8 − 11 = −3   → 제곱: 9
11 − 11 =  0   → 제곱: 0
14 − 11 = +3   → 제곱: 9

편차 제곱의 합 = 9 + 0 + 9 = 18
```

| 기준값                | 편차 제곱의 합 |
| --------------------- | -------------- |
| μ = 10 (진짜 모평균) | **21**   |
| x̄ = 11 (표본평균)   | **18**   |

x̄를 쓰면 편차 제곱의 합이 21 → 18로 작아진다. 왜 항상 이렇게 되는가?

> x̄는 단순한 "평균값"이 아니다. x̄는 수학적으로 **"이 데이터들로부터 편차 제곱의 합을 가장 작게 만드는 값"** 으로 정의된다. 즉 x̄는 표본 데이터에 딱 달라붙어 있고, μ는 표본과 관계없이 고정된 외부 값이라 약간 빗나가 있다. 빗나간 μ를 쓸 때 편차가 더 크고, 달라붙은 x̄를 쓸 때 편차가 항상 더 작다.

이 작아진 분자를 n으로 그냥 나누면 분산이 체계적으로 과소추정된다. 분모를 n−1로 줄이면 분산 값이 커져서 이 과소추정을 보정한다.

```
n = 3으로 나누면:     18 / 3 = 6.0   ← 과소추정
n−1 = 2로 나누면:    18 / 2 = 9.0   ← μ 기준(21/3=7.0)에 더 가까운 추정
```

n−1로 나누면 s²이 σ²을 체계적으로 과소추정하지 않는다. 이런 추정량을 **불편추정량 (unbiased estimator)**이라 한다.

> **핵심 납득 포인트**: 자유도(n−1)는 단순한 "보정 트릭"이 아니다. "x̄를 사용함으로써 잃어버린 정보 1개"를 반영한 것이다. 이 개념은 t검정(Ch.9~10), ANOVA(Ch.11), 회귀분석(Ch.12) 등 이후 모든 추론통계에서 반복 등장한다.

**손계산 예시** (5개: 8, 13, 17, 22, 10, 평균 x̄ = 14.0):

```
각 값의 편차 (xᵢ − x̄):
  8 − 14 = −6
 13 − 14 = −1
 17 − 14 =  +3
 22 − 14 =  +8
 10 − 14 = −4

편차의 제곱 (xᵢ − x̄)²:
  (−6)² = 36
  (−1)² =  1
  (+3)² =  9
  (+8)² = 64
  (−4)² = 16

합계: 36 + 1 + 9 + 64 + 16 = 126

표본분산: s² = 126 / (5−1) = 126 / 4 = 31.5
```

---

**표준편차 (Standard Deviation, SD)**

```
표본표준편차: s = √s²
```

```
예시: s = √31.5 ≈ 5.61
```

- **단위가 원래 데이터와 같다**: 분산은 "점²"이지만 표준편차는 "점"
- 논문에서 `M = 14.0, SD = 5.61`처럼 보고한다

---

**사분위간 범위 (Interquartile Range, IQR)**

```
IQR = Q3 − Q1
```

- **Q1 (1사분위수)**: 하위 25% 지점
- **Q3 (3사분위수)**: 하위 75% 지점
- **중앙 50% 데이터의 범위**: 이상값에 강건(robust)한 퍼짐 측도

```
예시: Q1 = 10, Q3 = 19 이면 IQR = 9
```

> **핵심 납득 포인트**: 왜도 있는 분포나 이상값이 있을 때는 **평균+SD 대신 중앙값+IQR**을 보고하는 것이 더 정직하다. 논문에서 두 가지 모두 보고하는 경우도 많다.

---

#### 3.4.3 분포의 형태

**왜도 (Skewness)**

**[1] 대칭 분포 (Symmetric)**

```
       ██
      ████
     ██████
    ████████
───────────────
       |▲
    중앙값
    =평균
```

**[2] 양의 왜도 (Positive Skew, right-skewed — 오른쪽 꼬리)**

```
     ██
    ████
   ██████
  ████████ . . . . .
──────────────────────
     |       ▲
  중앙값     평균
```

→ **꼬리가 있는 쪽(오른쪽)으로 평균이 끌린다.** 소수의 높은 값이 평균을 밀어올린다.
→ 평균 > 중앙값

**[3] 음의 왜도 (Negative Skew, left-skewed — 왼쪽 꼬리)**

```
              ██
             ████
       	   ███████
. . . .  ██████████
──────────────────────
    	▲     |
       평균   중앙값
```

→ **꼬리가 있는 쪽(왼쪽)으로 평균이 끌린다.** 소수의 낮은 값이 평균을 끌어내린다.
→ 평균 < 중앙값

- **양의 왜도 (positive skewness, right-skewed)**: 오른쪽에 긴 꼬리. 극단적 높은 값 몇 개가 평균을 오른쪽으로 끌어당김
  - 예: PHQ-9 지역사회 표본 (대부분 낮은 점수, 일부 높은 점수)
- **음의 왜도 (negative skewness, left-skewed)**: 왼쪽에 긴 꼬리
  - 예: 임상집단에서 치료 후 증상 개선 점수 (대부분 크게 개선, 일부만 미미)

**첨도 (Kurtosis)**

- **정규분포 대비** 꼬리의 두께를 나타냄
- **양의 첨도 (leptokurtic)**: 꼬리가 두꺼움, 극단값이 많음
- **음의 첨도 (platykurtic)**: 꼬리가 얇음, 극단값이 드묾
- 논문에서는 주로 정규성 검정(Shapiro-Wilk, Kolmogorov-Smirnov)으로 보고

**[1] 정규분포 기준 (mesokurtic)**

```
       ████
      ██████
     ████████
    ██████████
───────────────────
```

**[2] 양의 첨도 — 뾰족하고 꼬리가 두꺼움 (leptokurtic)**

```
        ██
        ██
       ████
      ██████
. . ██████████ . .
───────────────────
```

→ **가운데는 날카롭게 뾰족하고, 꼬리는 두껍다. 극단값이 자주 나온다.**
→ 예: PTSD 증상 점수 분포 — 대부분 낮은 점수에 몰리지만, 일부는 매우 극단적으로 높은 점수를 보임.

**[3] 음의 첨도 — 납작하고 꼬리가 얇음 (platykurtic)**

```
    ████████████
   ██████████████
  ████████████████
───────────────────
```

→ **가운데가 납작하고 꼬리가 거의 없다. 극단값이 드물다.**
→ 예: 훈련이 균일하게 이루어진 동질 집단의 점수 — 모두 비슷한 수준으로 분포.

> **핵심 납득 포인트**: "왜 심리학 연구에서 정규분포를 가정하는가?" — t검정, ANOVA 등 모수적 통계 기법은 데이터(또는 잔차)의 정규성을 전제한다. 만약 심각한 왜도나 첨도가 있다면, 비모수 방법(Ch.13 이후 부록)을 고려해야 한다.

#### 3.4.4 상관 정도

**직관**: "불안이 높을수록 우울도 높은가?" — 두 변수가 **함께 변하는 경향**을 수치로 요약한다.

---

**공분산 (Covariance)**

**직관: "편차의 곱"을 사분면으로 이해하기**

두 변수가 함께 움직이는지 보려면, 각 데이터 점이 두 변수의 평균(x̄, ȳ)에서 같은 방향으로 벗어나는지 확인하면 된다. 산점도에 두 평균선을 그으면 4개의 사분면이 생긴다:

```
     yᵢ (GAD-7)
      ↑
      │  ② x낮, y높       │ ① x높, y높
      │  (xᵢ−x̄)<0,       │ (xᵢ−x̄)>0,
      │  (yᵢ−ȳ)>0        │ (yᵢ−ȳ)>0
      │  → 곱 = 음수       │ → 곱 = 양수
  ȳ ─┼────────────────────┼──────── → xᵢ (BDI-II)
      │  ③ x낮, y낮       │ ④ x높, y낮         x̄
      │  → 곱 = 양수       │ → 곱 = 음수
      │                   │
```

- **양의 공분산**: 대부분의 점이 사분면 ①, ③에 → x가 크면 y도 크다 (같은 방향)
- **음의 공분산**: 대부분의 점이 사분면 ②, ④에 → x가 크면 y는 작다 (반대 방향)
- **공분산 ≈ 0**: 4개 사분면에 점이 고르게 흩어져 양수·음수가 서로 상쇄됨

**단위 문제 구체 예시**:

BDI-II(점)와 체중(kg)의 공분산을 계산하면 단위가 "점·kg"이 된다. 이 숫자는 크기 자체로 해석이 불가능하다. BDI-II와 GAD-7 공분산은 "점·점" 단위로, 두 연구의 공분산 값을 직접 비교할 수도 없다. 이것이 공분산의 치명적 단점이다.

```
Sxy = Σ[(xᵢ − x̄)(yᵢ − ȳ)] / (n−1)
```

- **단점**: 단위의 영향을 받아 크기 해석이 어렵다. 이 문제를 해결하는 것이 피어슨 r이다.

---

**피어슨 상관계수 (Pearson Correlation Coefficient, r)**

**직관: 단위를 없애서 비교 가능한 순수 수로 만든다**

공분산을 두 변수의 표준편차 곱(sₓ · sᵧ)으로 나누는 것은 "단위를 제거(표준화)"하는 작업이다. BDI-II의 단위(점)가 sₓ로, GAD-7의 단위(점)가 sᵧ로 각각 약분되어 사라진다. 그 결과 r은 항상 −1과 +1 사이의 단위 없는 순수한 숫자가 된다.

**왜 r이 반드시 −1 ~ +1 사이인가**: 공분산을 표준화했기 때문이다. 두 변수를 각각의 표준편차로 나누면 "표준 단위"로 바뀌는데, 이 표준화된 값들의 곱은 절대로 1을 초과할 수 없다. 직관적으로는 "최대로 일치할 수 있는 정도가 ±1이다"로 이해하면 충분하다.

```
r = Sxy / (sₓ · sᵧ) = Σ[(xᵢ−x̄)(yᵢ−ȳ)] / [(n−1) · sₓ · sᵧ]
```

**r의 세 가지 극단 상황 (산점도로 보기)**:

**r = +1: 완전한 양의 선형 관계 (모든 점이 우상향 직선 위)**

```
y │               ·
  │           ·
  │       ·
  │   ·
  │·
  └──────────────── x
```

**r = 0: 선형 관계 없음 (점이 무작위로 흩어짐)**

```
y │  ·     ·   ·
  │    ·  ·
  │  ·   ·   ·
  │    ·    ·
  │  ·   ·   ·
  └──────────────── x
```

**r = −1: 완전한 음의 선형 관계 (모든 점이 우하향 직선 위)**

```
y │·
  │   ·
  │       ·
  │           ·
  │               ·
  └──────────────── x
```

- r의 범위: **−1 ≤ r ≤ +1**
- r = +1: 완전한 양의 선형 관계
- r = 0: 선형 관계 없음
- r = −1: 완전한 음의 선형 관계

**Cohen(1988)의 해석 기준 (심리학 관행)**:

| r 절댓값  | 해석           |
| --------- | -------------- |
| .10 미만  | 매우 약한 관계 |
| .10 ~ .29 | 약한 관계      |
| .30 ~ .49 | 중간 관계      |
| .50 이상  | 강한 관계      |

**손계산 예시** (n = 5):

| i            | xᵢ (BDI-II) | yᵢ (GAD-7) | xᵢ−x̄ | yᵢ−ȳ | (xᵢ−x̄)(yᵢ−ȳ) |
| ------------ | ------------ | ----------- | -------- | ------- | ------------------- |
| 1            | 8            | 5           | −6      | −5     | 30                  |
| 2            | 13           | 9           | −1      | −1     | 1                   |
| 3            | 17           | 12          | +3       | +2      | 6                   |
| 4            | 22           | 15          | +8       | +5      | 40                  |
| 5            | 10           | 9           | −4      | −1     | 4                   |
| **합** | x̄=14       | ȳ=10       |          |         | **Σ = 81**   |

```
sₓ = √31.5 ≈ 5.61  (앞서 계산)
sᵧ: y 분산 = [(−5)²+(−1)²+(+2)²+(+5)²+(−1)²] / 4
           = [25+1+4+25+1] / 4 = 56/4 = 14.0
    sᵧ = √14.0 ≈ 3.74

r = 81 / [(5−1) × 5.61 × 3.74]
  = 81 / [4 × 20.98]
  = 81 / 83.92
  ≈ .965
```

→ BDI-II와 GAD-7 사이에 매우 강한 양의 상관관계 (r ≈ .97)

> **핵심 납득 포인트**: 상관계수는 **선형 관계만** 포착한다. 비선형 관계(예: 역U자형)는 r = 0으로 나와도 실제로 강한 관계가 있을 수 있다. 또한 **상관 ≠ 인과**다 — BDI-II와 GAD-7의 상관이 높다고 해서 우울이 불안을 "유발"한다고 말할 수 없다.

## 4. 수식 정리

```
=== 기호 약속 ===
n       = 표본 크기
xᵢ      = i번째 관측값
x̄       = 표본평균 (모평균은 μ, 절대 혼동 금지)
s       = 표본표준편차 (모표준편차는 σ)
s²      = 표본분산 (모분산은 σ²)
Q1, Q3  = 1사분위수, 3사분위수
IQR     = 사분위간 범위 = Q3 − Q1
r       = 피어슨 상관계수
Sxy     = 공분산

=== 수식 목록 ===

① 표본평균
   x̄ = (x₁ + x₂ + ... + xₙ) / n = Σxᵢ / n

② 표본분산 (왜 n-1: 자유도 보정, 모분산의 불편추정량)
   s² = Σ(xᵢ − x̄)² / (n−1)

③ 표본표준편차 (단위를 원래 데이터 단위로 복원)
   s = √s² = √[Σ(xᵢ − x̄)² / (n−1)]

④ 사분위간 범위
   IQR = Q3 − Q1

⑤ 공분산
   Sxy = Σ[(xᵢ − x̄)(yᵢ − ȳ)] / (n−1)

⑥ 피어슨 상관계수
   r = Sxy / (sₓ · sᵧ)
     = Σ[(xᵢ−x̄)(yᵢ−ȳ)] / [(n−1) · sₓ · sᵧ]
     범위: −1 ≤ r ≤ +1

=== 손계산 예시 요약 (n=5 데이터: 8, 13, 17, 22, 10) ===
x̄    = 70 / 5 = 14.0
s²   = 126 / 4 = 31.5
s    = √31.5 ≈ 5.61
중앙값 = 13 (정렬 후 3번째)
IQR  = (예) Q1=10, Q3=17이면 IQR=7
```

2. GAD-7 점수의 기술통계로 왜 중앙값과 IQR을 사용했는가?
3. "skewness = 1.43"은 어떤 방향의 왜도를 의미하는가? 분포의 꼬리가 어느 쪽인가?
4. `r(100) = .61, p < .001`에서 괄호 안의 숫자 100은 무엇을 의미하는가?

3. 양의 왜도(positive skewness). 오른쪽(높은 점수 방향)에 긴 꼬리가 있음을 의미한다. 즉 대부분 참가자는 낮은 GAD-7 점수를 가지며, 소수가 매우 높은 점수를 가진다.

## 7. 오개념 경고

> **⚠️ 오개념 1**: "평균이 항상 가장 좋은 대표값이다"
> → 틀렸다. **분포가 왜도를 보이거나 이상값이 있을 때**, 평균은 소수의 극단값에 의해 왜곡된다. 서울의 평균 아파트 가격처럼, 극소수 초고가 아파트가 전체 평균을 끌어올려 "전형적인" 가격을 과대표현한다. 왜도 있는 자료에서는 중앙값이 더 대표적이다.

> **⚠️ 오개념 2**: "SD가 크면 데이터가 잘못 수집된 것이다"
> → 틀렸다. SD는 **데이터의 다양성(variability)**을 반영한다. 지역사회 표본에서 PHQ-9 점수가 0~27점까지 다양하게 분포하는 것은 자연스러운 현상이다. SD가 크다는 것은 오류가 아니라 집단이 이질적임을 의미한다.

> **⚠️ 오개념 3**: "히스토그램과 막대그래프는 같다"
> → 다르다. **막대그래프**: 범주형 데이터, 막대 사이에 간격 있음. **히스토그램**: 연속형 데이터, 막대 사이에 간격 없음(연속성 표현). 또한 히스토그램의 x축 순서는 수치적 의미가 있지만, 막대그래프의 x축 순서는 임의로 바꿀 수 있다.

> **⚠️ 오개념 4**: "상관계수 r = .30은 약하니까 무시해도 된다"
> → 심리학에서 r = .30은 **중간 효과크기**다(Cohen, 1988). 교육·심리학 분야에서 두 복잡한 심리 변수 사이에 r = .30 이상이 나온다면 충분히 의미 있는 관계다. r = .30이라는 숫자만 보고 "약하다"고 판단하지 말고, 해당 분야의 맥락과 연구 문헌을 함께 고려해야 한다.

> **⚠️ 오개념 5**: "분산은 표준편차의 제곱이니까 표준편차만 있으면 분산은 필요 없다"
> → 틀렸다. 분산(s²)은 많은 통계 공식 내부에서 **직접 사용**된다. ANOVA(분산분석)에서 집단 간 분산과 집단 내 분산을 비교하고, 회귀분석에서도 분산이 기본 단위로 쓰인다. 해석의 편의를 위해 표준편차를 보고하지만, 이론적·수식적 기반은 분산이다.

## 부록: 보완 주제 및 추가 읽기 자료

### ★ 보완 주제 1: 표준오차 vs 표준편차

> **이 주제가 중요한 이유**: 논문의 Table 1에서 SD와 SE(또는 SEM)를 혼동하는 경우가 매우 흔하다. 둘은 완전히 다른 것을 측정한다.

**표준편차 (Standard Deviation, SD)**:

- **데이터 포인트들**이 평균에서 얼마나 퍼져 있는지
- 집단의 **다양성(variability)**을 나타냄
- n이 커져도 SD는 크게 줄지 않음

**표준오차 (Standard Error, SE 또는 SEM)**:

- **표본평균들**이 모평균에서 얼마나 퍼져 있는지
- **추정의 정밀도(precision)**를 나타냄
- n이 커질수록 SE는 줄어듦

```
공식:  SE = s / √n

예시: s = 10, n = 100이면 SE = 10/√100 = 10/10 = 1.0
      s = 10, n = 25이면  SE = 10/√25  = 10/5  = 2.0
```

**직관**: 같은 모집단에서 여러 번 표본을 뽑아 평균을 계산한다면, 그 평균들이 얼마나 흩어지겠는가? 표본이 클수록 평균은 모평균 근처에 더 일관되게 모인다. 이것이 SE다.

|                       | SD                 | SE                    |
| --------------------- | ------------------ | --------------------- |
| **측정 대상**   | 개별 데이터의 퍼짐 | 표본평균의 퍼짐       |
| **해석**        | 집단 다양성        | 추정 정밀도           |
| **n 증가 효과** | 거의 변화 없음     | 줄어듦 (√n에 반비례) |
| **Ch.7 연결**   | 기술통계           | 표집분포의 핵심 개념  |
| **논문에서**    | Table 1의 M(SD)    | 신뢰구간, 오차 막대   |

> **논문 읽기 포인트**: 그래프의 오차 막대(error bar)가 SD인지 SE인지 반드시 확인하라. 같은 데이터도 SE로 그리면 오차 막대가 훨씬 작아 보여 결과가 "더 정밀해 보이는" 착시 효과가 생긴다. 논문에서는 그래프 설명(figure caption)에 "Error bars represent SD" 또는 "Error bars represent SE" 라고 명시해야 한다.

SE의 개념은 **Ch.7(표집분포)**에서 정식으로 다루게 된다. 지금은 "SD ≠ SE, 혼동하지 말 것"만 기억하면 된다.

import numpy as np
import pandas as pd
from scipy import stats

bdi = [8, 13, 17, 22, 10]

print(f"평균: {np.mean(bdi):.2f}")
print(f"중앙값: {np.median(bdi):.2f}")
print(f"표준편차: {np.std(bdi, ddof=1):.2f}")  # ddof=1: 표본표준편차
print(f"분산: {np.var(bdi, ddof=1):.2f}")
print(f"왜도: {stats.skew(bdi):.3f}")
print(f"첨도: {stats.kurtosis(bdi):.3f}")
print(f"IQR: {np.percentile(bdi, 75) - np.percentile(bdi, 25):.2f}")
```

```

Note. BDI-II = Beck Depression Inventory-II; GAD-7 = Generalized

  CBT: Mdn = 8.5, IQR = 6.0; Control: Mdn = 8.0, IQR = 5.5.

APA 7판 핵심 서식 규칙:

- 소수점 앞 0 생략: `M = .83` (O), `M = 0.83` (X)

- 각주: ᵃ, ᵇ 형식으로 표 아래에
- 열 구분선: 표 위아래만 이중선, 중간은 단선 하나
