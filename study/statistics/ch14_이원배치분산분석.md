### 3.1 왜 이원배치인가: 독립변수가 2개인 연구설계

#### 직관부터 시작

> **질문**: "치료 유형(CBT vs. 약물치료)에 따라 BDI-II 점수가 다르다는 것을 알았다. 그런데 이 효과가 남성과 여성에서 동일하게 나타나는지, 아니면 다르게 나타나는지를 알고 싶다면?"

일원배치 ANOVA로는 이 질문에 답할 수 없다. 치료 유형만 독립변수로 넣으면, 성별에 따른 차이나 "치료 × 성별 조합"에 의한 차이를 볼 방법이 없기 때문이다.

**연구 예시:**

```
연구 질문:
"치료 유형(CBT vs. 약물치료) × 성별(남/여)에 따라
 주요우울장애 환자의 BDI-II 점수가 달라지는가?"

독립변수 A: 치료 유형 (2수준: CBT / 약물치료)
독립변수 B: 성별     (2수준: 남성 / 여성)
종속변수:   BDI-II 점수 (연속형)

설계: 2 × 2 요인 설계 (factorial design)
총 셀(cell) 수: 2 × 2 = 4
```

이원배치 설계를 표로 나타내면:

| | 남성 | 여성 |
|---|---|---|
| **CBT** | CBT + 남성 (셀 11) | CBT + 여성 (셀 12) |
| **약물치료** | 약물치료 + 남성 (셀 21) | 약물치료 + 여성 (셀 22) |

각 칸(cell)에는 여러 명의 참여자가 배정된다. 이 설계에서 검정할 수 있는 것은 세 가지다:

```
① 치료 유형의 주효과 (main effect of A):
   성별을 무시하고, CBT와 약물치료 간 BDI-II 차이가 있는가?

② 성별의 주효과 (main effect of B):
   치료 유형을 무시하고, 남성과 여성 간 BDI-II 차이가 있는가?

③ 치료 × 성별 상호작용 효과 (interaction effect A×B):  ← 이것이 핵심 신규 개념!
   치료 유형의 효과가 성별에 따라 달라지는가?
   즉, CBT가 여성에서는 효과적이지만 남성에서는 그렇지 않은가?
```

**일원배치로는 상호작용을 볼 수 없는 이유:**

```
일원배치 방법 1: 치료 유형만 독립변수
  → 성별 정보를 완전히 무시 → 상호작용 효과 분석 불가능

일원배치 방법 2: 남성과 여성을 따로 분석
  → 두 분석의 결과를 "공식적으로" 비교할 방법이 없음
  → 1종 오류 통제가 되지 않음
  → 두 그룹 간 효과 차이의 통계적 유의성을 검정할 수 없음
```

> **핵심 납득 포인트**
>
> 이원배치 ANOVA의 가장 큰 장점은 **상호작용 효과를 검정할 수 있다는 것**이다. "CBT가 좋다"는 결론 뒤에 "그런데 이 효과는 여성에게만 강하게 나타나고 남성에게는 약하다"는 사실이 숨어 있을 수 있다. 이를 파악하지 못하면 임상 현장에서 잘못된 처치를 할 위험이 있다. 이원배치는 "집단 간 비교"와 "효과의 조절 여부 확인"을 동시에 해결하는 효율적인 설계다.

### 3.2 이원배치 ANOVA의 SS 분해

#### 직관부터 시작

일원배치에서는 전체 변동을 2개로 분해했다:

```
일원배치: SS_total = SS_between + SS_within
```

이원배치에서는 "집단 간 변동(SS_between)"을 더 세밀하게 3가지로 분해한다:

```
이원배치: SS_total = SS_A + SS_B + SS_A×B + SS_within
```

**각 성분의 의미:**

| 성분 | 기호 | 의미 | 해당 검정 |
|------|------|------|-----------|
| 요인 A의 주효과 | SS_A | B를 무시하고, A의 수준 간 평균 차이 | 치료 유형 효과 |
| 요인 B의 주효과 | SS_B | A를 무시하고, B의 수준 간 평균 차이 | 성별 효과 |
| 상호작용 효과 | SS_A×B | A의 효과가 B에 따라 달라지는 정도 | 치료 × 성별 효과 |
| 오차 (집단 내 변동) | SS_within | 같은 셀 안에서의 개인차 | 오차 |

**변동 분해를 그림으로:**

```
SS_total
  ├── SS_A       (요인 A 주효과: CBT vs. 약물치료)
  ├── SS_B       (요인 B 주효과: 남성 vs. 여성)
  ├── SS_A×B     (상호작용: 치료 효과가 성별에 따라 다른 정도)
  └── SS_within  (오차: 셀 내 개인차)
```

**자유도:**

```
a  = 요인 A의 수준 수 (예: 치료 유형 2가지 → a = 2)
b  = 요인 B의 수준 수 (예: 성별 2가지 → b = 2)
n  = 각 셀(cell)의 관측 수
N  = 전체 표본 크기 = a × b × n

df_A      = a − 1                    → 2 − 1 = 1
df_B      = b − 1                    → 2 − 1 = 1
df_A×B    = (a − 1)(b − 1)           → (2−1)(2−1) = 1
df_within = N − ab                   → 20 − 4 = 16  (N = 20, ab = 4인 경우)
df_total  = N − 1                    → 20 − 1 = 19

확인: df_A + df_B + df_A×B + df_within = 1 + 1 + 1 + 16 = 19 = df_total ✓
```

> **핵심 납득 포인트**
>
> 일원배치에서 "집단 간 변동(SS_between)"이 하나였다면, 이원배치에서는 그것이 SS_A + SS_B + SS_A×B의 세 조각으로 나뉜다. SS_within(오차)은 구조적으로 동일하다. 이원배치의 핵심 신규 개념은 SS_A×B, 즉 **"A의 효과가 B에 따라 달라지는 부분"** 을 따로 떼어 검정할 수 있다는 것이다.

### 3.3 주효과 (Main Effects) 해석

#### 직관부터 시작

주효과는 "다른 요인을 무시하고 한 요인만의 효과"를 말한다.

**요인 A의 주효과 (main effect of A):**

```
B를 무시하고, A의 각 수준에 따라 종속변수의 평균이 다른가?

구체 예시:
  성별(B)을 무시하고,
  CBT 집단 전체(남성 + 여성)의 BDI-II 평균 vs.
  약물치료 집단 전체(남성 + 여성)의 BDI-II 평균이 다른가?
```

**요인 B의 주효과 (main effect of B):**

```
A를 무시하고, B의 각 수준에 따라 종속변수의 평균이 다른가?

구체 예시:
  치료 유형(A)을 무시하고,
  남성 전체(CBT + 약물치료)의 BDI-II 평균 vs.
  여성 전체(CBT + 약물치료)의 BDI-II 평균이 다른가?
```

**주효과를 표로 이해하기:**

다음 가상 셀 평균 표를 보자:

| | 남성 (x̄.₁.) | 여성 (x̄.₂.) | 행 평균 (x̄ᵢ..) |
|---|---|---|---|
| **CBT** | 14 | 10 | **12** |
| **약물치료** | 18 | 16 | **17** |
| **열 평균 (x̄.ⱼ.)** | **16** | **13** | **전체 평균 = 14.5** |

- **A의 주효과**: 행 평균(12 vs. 17)을 비교 → CBT 집단이 약물치료 집단보다 BDI-II 평균이 낮음
- **B의 주효과**: 열 평균(16 vs. 13)을 비교 → 여성이 남성보다 BDI-II 평균이 낮음

**F 통계량 계산:**

```
F_A = MS_A / MS_within      (요인 A 주효과 F)
F_B = MS_B / MS_within      (요인 B 주효과 F)
```

MS는 SS를 자유도로 나눈 값이다:

```
MS_A      = SS_A / df_A
MS_B      = SS_B / df_B
MS_within = SS_within / df_within
```

> **핵심 납득 포인트**
>
> 주효과를 해석할 때 가장 중요한 조건이 있다: **"상호작용이 유의하지 않을 때만 주효과를 독립적으로 해석할 수 있다."** 상호작용이 유의하면 "요인 A의 효과는 요인 B의 수준에 따라 다르다"는 뜻이므로, 요인 A만의 "평균적인 효과"를 말하는 것은 오해를 줄 수 있다. 이 점은 3.4절에서 더 자세히 다룬다.

### 3.4 상호작용 효과 (Interaction Effect) — 핵심

#### 직관부터 시작

상호작용이란:

> **"A의 효과가 B의 수준에 따라 달라진다."**

즉, "CBT가 약물치료보다 효과적이다"는 결론이 **여성에게는 맞지만 남성에게는 맞지 않을 수 있다.**

**상호작용이 있는 경우 vs. 없는 경우 — 수치로 비교:**

**[상호작용 없는 경우]:**

| | 남성 | 여성 | 차이 (CBT − 약물) |
|---|---|---|---|
| CBT | 14 | 10 | — |
| 약물치료 | 18 | 14 | — |
| **처치 효과 (차이)** | **−4** | **−4** | 동일 |

CBT가 약물치료보다 BDI-II를 4점 낮추는 효과가 남성과 여성 모두에서 동일하다. → 상호작용 없음

**[상호작용 있는 경우]:**

| | 남성 | 여성 | 차이 (CBT − 약물) |
|---|---|---|---|
| CBT | 16 | 10 | — |
| 약물치료 | 18 | 16 | — |
| **처치 효과 (차이)** | **−2** | **−6** | 다름 |

CBT의 효과가 여성에게서는 6점, 남성에게서는 2점으로 다르다. → 상호작용 있음

#### 상호작용 도표 (Interaction Plot)로 시각화

상호작용을 가장 직관적으로 파악하는 방법은 **상호작용 도표(interaction plot)** 이다. 가로축에 요인 A, 세로축에 종속변수 평균, 요인 B의 각 수준을 별도 선으로 표시한다.

**[상호작용 없을 때: 두 선이 평행]**

```
BDI-II
  18 |   약물치료 ●────────────● 약물치료
     |            (남성=18)  (여성=14)
  14 |   CBT      ●────────────● CBT
     |            (남성=14)  (여성=10)
  10 |
     +─────────────────────────
         남성         여성

→ 두 선이 평행 → A의 효과가 B 수준에 관계없이 동일
  (약물치료가 CBT보다 4점 높음: 남성에서도, 여성에서도)
```

**[상호작용 있을 때: 두 선이 교차 또는 비평행]**

```
BDI-II
  18 |   약물치료 ●
     |              ╲
  16 |                ╲ 약물치료
     |   CBT ●         ● (여성=16)
     |        ╲
  10 |          ● CBT (여성=10)
     +─────────────────────────
         남성         여성

→ 두 선이 교차 → 상호작용 강함
  (남성: 약물치료-CBT = 2점, 여성: 약물치료-CBT = 6점)
```

**두 선이 교차하면 강한 상호작용, 선이 평행하면 상호작용 없음이라는 규칙:**

```
완전 평행      → 상호작용 없음  (SS_A×B ≈ 0)
비평행 (교차 없음) → 약한 상호작용
교차            → 강한 상호작용 (이탈적 상호작용, disordinal interaction)
```

#### 상호작용 F 통계량

```
F_A×B = MS_A×B / MS_within

MS_A×B = SS_A×B / df_A×B
```

#### 상호작용이 유의하면 주효과 해석은 왜 주의해야 하는가?

예를 들어 상호작용이 유의하고 셀 평균이 아래와 같다면:

| | 남성 | 여성 | 행 평균 |
|---|---|---|---|
| CBT | 16 | 10 | **13** |
| 약물치료 | 12 | 18 | **15** |
| 열 평균 | **14** | **14** | **14** |

- A(치료)의 주효과: 행 평균 13 vs. 15 → "CBT가 약물치료보다 더 좋다"
- B(성별)의 주효과: 열 평균 14 vs. 14 → "성별 차이 없음"

그런데 실제 셀 평균을 보면:
- 남성: CBT(16) > 약물치료(12) → 남성에서는 약물치료가 더 좋음
- 여성: CBT(10) < 약물치료(18) → 여성에서는 CBT가 더 좋음

"CBT가 전반적으로 더 좋다"는 주효과 해석은 **완전히 오해**를 줄 수 있다. 치료 효과는 성별에 따라 반전되기 때문이다.

```
결론:
상호작용이 유의할 때
→ 주효과 해석은 "평균적으로는 ○○이지만 성별에 따라 다름"이라고 해야 함
→ 이어서 단순 주효과 분석(simple effects analysis)이 필요
```

> **핵심 납득 포인트**
>
> 상호작용은 이원배치 ANOVA의 핵심 개념이자 가장 중요한 결과다. **"F 검정 세 개 중 상호작용 F를 가장 먼저 확인하라"** 는 것이 실무적 원칙이다. 상호작용이 유의하면, 주효과는 "그 자체로는 오해를 줄 수 있는 평균적 결과"이고 진짜 이야기는 단순 주효과 분석에 있다. 임상 현장에서 "어떤 치료가 좋은가?"는 대상자 특성(성별, 진단, 애착 유형 등)에 따라 달라질 수 있다는 것이 이원배치가 가르쳐주는 교훈이다.

### 3.5 2×2 설계 손계산 예시

#### 설계 및 데이터

**설계:** 2(치료 유형: CBT / 약물치료) × 2(성별: 남성 / 여성), 각 셀 n = 5, 전체 N = 20

**BDI-II 데이터 (가상):**

| | CBT + 남성 (셀 11) | CBT + 여성 (셀 12) | 약물치료 + 남성 (셀 21) | 약물치료 + 여성 (셀 22) |
|---|---|---|---|---|
| 참여자 1 | 15 | 10 | 18 | 14 |
| 참여자 2 | 17 | 9  | 20 | 16 |
| 참여자 3 | 14 | 11 | 17 | 15 |
| 참여자 4 | 16 | 10 | 19 | 13 |
| 참여자 5 | 18 | 10 | 21 | 17 |
| **셀 합계** | **80** | **50** | **95** | **75** |
| **셀 평균 (x̄ᵢⱼ)** | **16** | **10** | **19** | **15** |

```
■ 0단계: 주변 평균 계산 (marginal means)

행 평균(A 주효과용):
  CBT:      x̄₁.. = (80 + 50) / 10 = 130 / 10 = 13.0
  약물치료:  x̄₂.. = (95 + 75) / 10 = 170 / 10 = 17.0

열 평균(B 주효과용):
  남성: x̄.₁. = (80 + 95) / 10 = 175 / 10 = 17.5
  여성: x̄.₂. = (50 + 75) / 10 = 125 / 10 = 12.5

전체(grand) 평균:
  x̄... = (80 + 50 + 95 + 75) / 20 = 300 / 20 = 15.0

■ 1단계: SS_A (요인 A = 치료 유형의 주효과) 계산
  공식: SS_A = b·n × Σᵢ (x̄ᵢ.. − x̄...)²
        여기서 b = 2(성별 수준), n = 5(셀당 관측 수)
        b·n = 2 × 5 = 10

  SS_A = 10 × [(13 − 15)² + (17 − 15)²]
       = 10 × [(-2)² + (2)²]
       = 10 × [4 + 4]
       = 10 × 8
       = 80

■ 2단계: SS_B (요인 B = 성별의 주효과) 계산
  공식: SS_B = a·n × Σⱼ (x̄.ⱼ. − x̄...)²
        여기서 a = 2(치료 수준), n = 5
        a·n = 2 × 5 = 10

  SS_B = 10 × [(17.5 − 15)² + (12.5 − 15)²]
       = 10 × [(2.5)² + (−2.5)²]
       = 10 × [6.25 + 6.25]
       = 10 × 12.5
       = 125

■ 3단계: SS_A×B (상호작용 효과) 계산
  공식: SS_A×B = n × ΣᵢΣⱼ (x̄ᵢⱼ − x̄ᵢ.. − x̄.ⱼ. + x̄...)²
        n = 5

  각 셀에 대해 (x̄ᵢⱼ − x̄ᵢ.. − x̄.ⱼ. + x̄...) 계산:

  셀 11 (CBT+남성):    x̄₁₁ = 16, x̄₁.. = 13, x̄.₁. = 17.5, x̄... = 15
    → 16 − 13 − 17.5 + 15 = 0.5

  셀 12 (CBT+여성):    x̄₁₂ = 10, x̄₁.. = 13, x̄.₂. = 12.5, x̄... = 15
    → 10 − 13 − 12.5 + 15 = −0.5

  셀 21 (약물치료+남성): x̄₂₁ = 19, x̄₂.. = 17, x̄.₁. = 17.5, x̄... = 15
    → 19 − 17 − 17.5 + 15 = −0.5

  셀 22 (약물치료+여성): x̄₂₂ = 15, x̄₂.. = 17, x̄.₂. = 12.5, x̄... = 15
    → 15 − 17 − 12.5 + 15 = 0.5

  SS_A×B = 5 × [(0.5)² + (−0.5)² + (−0.5)² + (0.5)²]
          = 5 × [0.25 + 0.25 + 0.25 + 0.25]
          = 5 × 1.0
          = 5

■ 4단계: SS_within (오차) 계산
  공식: SS_within = ΣᵢΣⱼΣₖ (xᵢⱼₖ − x̄ᵢⱼ)²
  각 셀 내에서 각 관측값이 셀 평균에서 벗어난 정도의 제곱합

  셀 11 (x̄₁₁ = 16): (15−16)²+(17−16)²+(14−16)²+(16−16)²+(18−16)²
                     = 1 + 1 + 4 + 0 + 4 = 10

  셀 12 (x̄₁₂ = 10): (10−10)²+(9−10)²+(11−10)²+(10−10)²+(10−10)²
                     = 0 + 1 + 1 + 0 + 0 = 2

  셀 21 (x̄₂₁ = 19): (18−19)²+(20−19)²+(17−19)²+(19−19)²+(21−19)²
                     = 1 + 1 + 4 + 0 + 4 = 10

  셀 22 (x̄₂₂ = 15): (14−15)²+(16−15)²+(15−15)²+(13−15)²+(17−15)²
                     = 1 + 1 + 0 + 4 + 4 = 10

  SS_within = 10 + 2 + 10 + 10 = 32

■ 5단계: SS_total 검산
  SS_total = SS_A + SS_B + SS_A×B + SS_within
           = 80 + 125 + 5 + 32
           = 242
  (직접 계산: 모든 20개 값에서 전체 평균 15를 뺀 제곱합 = 242 ✓)

■ 6단계: 자유도
  df_A      = a − 1      = 2 − 1 = 1
  df_B      = b − 1      = 2 − 1 = 1
  df_A×B    = (a−1)(b−1) = 1 × 1 = 1
  df_within = N − ab     = 20 − 4 = 16
  df_total  = N − 1      = 20 − 1 = 19
  확인: 1 + 1 + 1 + 16 = 19 ✓

■ 7단계: 평균제곱 (MS)
  MS_A      = SS_A / df_A           = 80 / 1    = 80.00
  MS_B      = SS_B / df_B           = 125 / 1   = 125.00
  MS_A×B    = SS_A×B / df_A×B       = 5 / 1     = 5.00
  MS_within = SS_within / df_within = 32 / 16   = 2.00

■ 8단계: F 통계량
  F_A    = MS_A / MS_within    = 80.00 / 2.00  = 40.00
  F_B    = MS_B / MS_within    = 125.00 / 2.00 = 62.50
  F_A×B  = MS_A×B / MS_within  = 5.00 / 2.00   = 2.50

  임계값: F(.05, 1, 16) ≈ 4.49
    F_A    = 40.00 > 4.49 → p < .001  (치료 유형 주효과 유의)
    F_B    = 62.50 > 4.49 → p < .001  (성별 주효과 유의)
    F_A×B  = 2.50  < 4.49 → p > .05   (상호작용 효과 비유의)

■ 9단계: 분산분석표 (ANOVA Table)
┌─────────────────────┬──────┬────┬────────┬────────┐
│ 변동원              │  SS  │ df │   MS   │   F    │
├─────────────────────┼──────┼────┼────────┼────────┤
│ 치료 유형 (A)       │   80 │  1 │  80.00 │ 40.00* │
│ 성별 (B)            │  125 │  1 │ 125.00 │ 62.50* │
│ 치료 × 성별 (A×B)  │    5 │  1 │   5.00 │   2.50 │
│ 오차 (Within)       │   32 │ 16 │   2.00 │        │
│ 합계 (Total)        │  242 │ 19 │        │        │
└─────────────────────┴──────┴────┴────────┴────────┘
* p < .001

■ 10단계: 효과크기 (partial η²)
  partial η²_A    = SS_A / (SS_A + SS_within)
                  = 80 / (80 + 32) = 80 / 112 ≈ .714

  partial η²_B    = SS_B / (SS_B + SS_within)
                  = 125 / (125 + 32) = 125 / 157 ≈ .796

  partial η²_A×B  = SS_A×B / (SS_A×B + SS_within)
                  = 5 / (5 + 32) = 5 / 37 ≈ .135

APA 보고 형식:
"A 2 × 2 factorial ANOVA revealed a significant main effect of treatment,
 F(1, 16) = 40.00, p < .001, partial η² = .71, and a significant main effect
 of sex, F(1, 16) = 62.50, p < .001, partial η² = .80. The Treatment × Sex
 interaction was not significant, F(1, 16) = 2.50, p = .133, partial η² = .14."
```

> **핵심 납득 포인트**
>
> 이 예시에서 상호작용은 유의하지 않았다. 이는 CBT가 약물치료보다 효과적이라는 A의 주효과가 남성과 여성 모두에서 비슷하게 적용된다는 뜻이다. 반면, 이 예시에서는 여성이 남성보다 치료 후 BDI-II가 낮은 B의 주효과도 유의하다. 상호작용이 없으므로 두 주효과를 독립적으로 해석할 수 있다.

### 3.6 사후검정 (Post-hoc in Two-way ANOVA)

#### 언제 어떤 사후검정이 필요한가?

이원배치 ANOVA에서 사후검정 전략은 **상호작용의 유의 여부**에 따라 달라진다.

**[시나리오 1: 상호작용이 유의하지 않을 때]**

```
상호작용이 없음 → 요인 A와 요인 B의 효과는 독립적으로 해석 가능

→ 각 주효과에 대해 별도 사후검정 실시
  (단, 수준이 2개인 경우는 사후검정 불필요 — 유의하면 두 수준 간 차이가 있다는 뜻)

예: 치료 유형이 3수준(CBT / 약물 / 통합)이라면
    치료 주효과 사후검정: CBT vs. 약물, CBT vs. 통합, 약물 vs. 통합
    → Bonferroni 또는 Tukey HSD 적용
```

**[시나리오 2: 상호작용이 유의할 때]**

```
상호작용이 있음 → "A의 효과가 B 수준에 따라 다르다"
→ 각 B 수준별로 A의 효과를 따로 검정 = 단순 주효과 분석 (simple effects analysis)

예: 치료 × 성별 상호작용이 유의
  → "남성 집단에서" CBT vs. 약물치료 비교
  → "여성 집단에서" CBT vs. 약물치료 비교
  → 두 비교가 서로 다른 결과를 보임 → 상호작용의 실체 확인
```

**단순 주효과 분석 (Simple Effects Analysis):**

| 검정 | 방법 | 해석 |
|------|------|------|
| 남성 집단 내 치료 효과 | CBT vs. 약물치료 (남성만) | 남성에서 치료 효과가 있는가? |
| 여성 집단 내 치료 효과 | CBT vs. 약물치료 (여성만) | 여성에서 치료 효과가 있는가? |

APA 논문에서의 표현 예시:

> "Simple effects analyses indicated that CBT was significantly more effective than pharmacotherapy for female participants (p < .001), but not for male participants (p = .412)."

> **핵심 납득 포인트**
>
> 단순 주효과 분석은 "상호작용이 있다면, 구체적으로 어디서 어떻게 효과가 다른지 찾아주는 사후 탐색"이다. 마치 ANOVA 후 사후검정처럼, 상호작용 F가 유의하면 단순 주효과 분석이 뒤따라야 한다. "상호작용이 유의했다"는 말만 쓰고 단순 주효과 분석을 생략하면, 독자는 "도대체 어디서 어떻게 다른데?"라는 의문이 해결되지 않는다.

## §4 수식 정리

```
■ 기호 약속

a        : 요인 A의 수준 수 (number of levels of factor A)
b        : 요인 B의 수준 수 (number of levels of factor B)
n        : 각 셀(cell)의 관측 수 (균형 설계 기준)
N        : 전체 표본 크기 = a × b × n
i        : 요인 A의 수준 인덱스 (i = 1, 2, ..., a)
j        : 요인 B의 수준 인덱스 (j = 1, 2, ..., b)
k        : 셀 내 관측값 인덱스 (k = 1, 2, ..., n)
xᵢⱼₖ   : i번째 A 수준, j번째 B 수준, k번째 관측값
x̄ᵢⱼ    : (i, j) 셀의 평균 (cell mean)
x̄ᵢ..   : 요인 A의 i번째 수준의 주변 평균 (marginal mean of A)
x̄.ⱼ.   : 요인 B의 j번째 수준의 주변 평균 (marginal mean of B)
x̄...   : 전체(grand) 평균
SS_A    : 요인 A의 주효과 제곱합
SS_B    : 요인 B의 주효과 제곱합
SS_A×B  : 상호작용 효과 제곱합
SS_within: 오차 제곱합 (집단 내 제곱합)
SS_total : 전체 제곱합
MS_A    : 요인 A의 평균제곱 = SS_A / df_A
MS_B    : 요인 B의 평균제곱 = SS_B / df_B
MS_A×B  : 상호작용의 평균제곱 = SS_A×B / df_A×B
MS_within: 오차 평균제곱 = SS_within / df_within
partial η²: 부분 에타제곱 (효과크기)
```

---

### [수식 1] SS 분해 공식

```
SS_total = ΣᵢΣⱼΣₖ (xᵢⱼₖ − x̄...)²
         = SS_A + SS_B + SS_A×B + SS_within

SS_A     = b·n × Σᵢ (x̄ᵢ.. − x̄...)²
  [해석: 요인 A의 각 수준 주변 평균이 전체 평균에서 벗어난 정도 × 반복 수]

SS_B     = a·n × Σⱼ (x̄.ⱼ. − x̄...)²
  [해석: 요인 B의 각 수준 주변 평균이 전체 평균에서 벗어난 정도 × 반복 수]

SS_A×B   = n × ΣᵢΣⱼ (x̄ᵢⱼ − x̄ᵢ.. − x̄.ⱼ. + x̄...)²
  [해석: 셀 평균에서 두 주효과로 설명되는 부분을 빼고 남은 "교호작용" 부분]

SS_within = ΣᵢΣⱼΣₖ (xᵢⱼₖ − x̄ᵢⱼ)²
  [해석: 각 관측값이 자기가 속한 셀 평균에서 벗어난 정도의 제곱합]
```

### [수식 2] 자유도

```
df_A      = a − 1
df_B      = b − 1
df_A×B    = (a − 1)(b − 1)
df_within = N − ab         (= ab(n − 1))
df_total  = N − 1

확인: df_A + df_B + df_A×B + df_within = N − 1 = df_total
     (a−1) + (b−1) + (a−1)(b−1) + ab(n−1) = N − 1  ✓
```

### [수식 3] F 통계량 (세 개)

```
F_A    = MS_A / MS_within      ← 요인 A 주효과 검정
F_B    = MS_B / MS_within      ← 요인 B 주효과 검정
F_A×B  = MS_A×B / MS_within    ← 상호작용 효과 검정
```

### [수식 4] 효과크기 (Partial η²)

```
partial η²_A    = SS_A    / (SS_A    + SS_within)
partial η²_B    = SS_B    / (SS_B    + SS_within)
partial η²_A×B  = SS_A×B  / (SS_A×B  + SS_within)

[해석]: 특정 효과(SS_효과)와 오차(SS_within)만을 고려했을 때,
        해당 효과가 설명하는 분산의 비율

η²(전체 에타제곱)과의 차이:
  η²_A    = SS_A / SS_total           ← 전체 변동 대비
  partial η²_A = SS_A / (SS_A + SS_within) ← 효과 + 오차 대비
  → partial η² ≥ η² (항상 크거나 같음)

Cohen 기준 (η²와 동일하게 적용):
  .01 : 작은 효과 (small)
  .06 : 중간 효과 (medium)
  .14 : 큰 효과 (large)
```

---

### [손계산 요약] 2×2 이원배치 ANOVA 전체 흐름

```
①  셀 평균 x̄ᵢⱼ 계산
②  주변 평균 (행 평균 x̄ᵢ.., 열 평균 x̄.ⱼ.) 계산
③  전체 평균 x̄... 계산
④  SS_A 계산:   b·n × Σ(x̄ᵢ.. − x̄...)²
⑤  SS_B 계산:   a·n × Σ(x̄.ⱼ. − x̄...)²
⑥  SS_A×B 계산: n × ΣΣ(x̄ᵢⱼ − x̄ᵢ.. − x̄.ⱼ. + x̄...)²
⑦  SS_within 계산: 각 셀 내 편차 제곱합 합산
⑧  df_A, df_B, df_A×B, df_within 계산
⑨  MS_A, MS_B, MS_A×B, MS_within 계산 (SS ÷ df)
⑩  F_A, F_B, F_A×B 계산 (각 MS ÷ MS_within)
⑪  ANOVA table 완성
⑫  partial η² 계산 (SS_효과 ÷ (SS_효과 + SS_within))
```

## §5 심리학 연구 맥락 연결

### 시나리오 A: 치료 × 애착 유형에 따른 우울 점수

임상심리사 J는 주요우울장애 환자 120명을 대상으로 치료 유형과 애착 유형의 교호작용이 치료 효과에 영향을 미치는지 검토하고자 했다.

**연구 설계:**

```
독립변수 A: 치료 유형 (2수준: CBT / 약물치료)
독립변수 B: 애착 유형 (3수준: 안정(secure) / 불안(anxious) / 회피(avoidant))
종속변수:   12주 치료 후 BDI-II 점수

설계: 2 × 3 요인 설계 (factorial design)
셀 수: 2 × 3 = 6
각 셀 n = 20, 전체 N = 120
```

**분산분석표 (가상 결과):**

| 변동원 | SS | df | MS | F | p | partial η² |
|--------|----|----|----|----|---|------------|
| 치료 유형 (A) | 486.2 | 1 | 486.2 | 28.14 | < .001 | .20 |
| 애착 유형 (B) | 712.4 | 2 | 356.2 | 20.63 | < .001 | .27 |
| 치료 × 애착 (A×B) | 389.0 | 2 | 194.5 | 11.26 | < .001 | .17 |
| 오차 | 1970.3 | 114 | 17.28 | | | |
| 합계 | 3557.9 | 119 | | | | |

**결과 해석:**

```
상호작용 F(2, 114) = 11.26, p < .001 → 유의
→ CBT vs. 약물치료의 효과가 애착 유형에 따라 다름
→ 단순 주효과 분석 필요

단순 주효과 분석 결과 (가상):
  안정 애착 집단: CBT와 약물치료 간 차이 없음 (p = .312)
  불안 애착 집단: CBT가 약물치료보다 유의하게 효과적 (p < .001)
  회피 애착 집단: 약물치료가 CBT보다 유의하게 효과적 (p = .003)

임상적 함의:
  "어떤 치료가 더 좋은가?"는 환자의 애착 유형에 따라 답이 달라진다.
  치료 계획 수립 시 애착 유형 평가가 필요하다.
```

**논문 방법론 섹션 표현 실습:**

> "A 2(Treatment: CBT vs. pharmacotherapy) × 3(Attachment: secure vs. anxious vs. avoidant) between-subjects factorial ANOVA was conducted to examine the effects of treatment type and attachment style on post-treatment BDI-II scores. A significant Treatment × Attachment interaction was obtained, F(2, 114) = 11.26, p < .001, partial η² = .17, indicating that the efficacy of CBT relative to pharmacotherapy differed as a function of attachment style. Simple effects analyses were subsequently conducted."

### 시나리오 B: 성별 × 진단 여부에 따른 외상 후 스트레스 점수

상담연구자 K는 성별과 우울증 진단 여부가 PTSD 증상에 미치는 영향을 검토하고자 했다.

**연구 설계:**

```
독립변수 A: 성별    (2수준: 남성 / 여성)
독립변수 B: 진단 여부 (2수준: 우울증 있음 / 없음)
종속변수:   PCL-5 (PTSD Checklist for DSM-5) 점수

설계: 2 × 2 요인 설계
셀 수: 4, 각 셀 n = 25, 전체 N = 100
```

**가상 셀 평균 (PCL-5 점수):**

| | 우울증 있음 | 우울증 없음 | 행 평균 |
|---|---|---|---|
| **남성** | 42.3 | 28.6 | **35.5** |
| **여성** | 38.1 | 22.4 | **30.3** |
| **열 평균** | **40.2** | **25.5** | **32.9** |

**분석 결과 (가상):**

```
F_성별(1, 96) = 6.42, p = .013, partial η² = .06   → 유의
F_진단(1, 96) = 87.31, p < .001, partial η² = .48  → 유의 (매우 큰 효과)
F_성별×진단(1, 96) = 0.83, p = .364, partial η² = .01 → 비유의

해석:
- 우울증 진단이 있는 집단이 없는 집단보다 PCL-5 점수가 유의하게 높음
  (주효과 B의 매우 큰 효과: partial η² = .48)
- 남성이 여성보다 PCL-5 점수가 유의하게 높음
  (주효과 A의 중간 효과: partial η² = .06)
- 상호작용 비유의 → 성별 효과는 우울 진단 여부와 무관하게 일관됨
  → 두 주효과를 독립적으로 해석 가능
```

**임상적 함의:**

```
진단 여부와 성별이 모두 PTSD 증상 수준과 관련된다.
그러나 이 두 요인이 "상호작용"하지는 않으므로,
치료 계획 수립 시 두 요인을 독립적으로 고려할 수 있다.
```

## §6 논문 스니펫 읽기 실습

### 가상 논문 발췌 (APA 7판 형식)

> **Study excerpt:**
>
> Participants with major depressive disorder (N = 80) were randomly assigned to a 2(Treatment: CBT vs. pharmacotherapy) × 2(Sex: male vs. female) factorial design. Following 12 weeks of treatment, post-treatment depression severity was assessed using the Beck Depression Inventory-II (BDI-II). A 2 × 2 factorial ANOVA was conducted to examine the main effects of treatment type and sex, as well as their interaction. Results revealed a significant main effect of Treatment, F(1, 76) = 8.43, p = .005, partial η² = .10, and a significant Treatment × Sex interaction, F(1, 76) = 5.21, p = .025, partial η² = .06. The main effect of Sex was not significant, F(1, 76) = 1.23, p = .270. Simple effects analyses indicated that CBT was significantly more effective than pharmacotherapy for female participants (p < .001), but not for male participants (p = .412).

---

### 연습 질문

**Q1.** 이 연구에서 세 가지 F 검정이 각각 무엇을 검정하는지 설명하라.

**모범 답안:**

이 2×2 요인 설계 ANOVA에서 세 가지 F 검정은 다음과 같다:

| F 검정 | 귀무가설 | 의미 |
|--------|---------|------|
| F(1, 76) = 8.43 (치료 주효과) | 성별을 무시했을 때, CBT와 약물치료의 BDI-II 평균이 동일하다 | 치료 유형 간 차이 |
| F(1, 76) = 1.23 (성별 주효과) | 치료를 무시했을 때, 남성과 여성의 BDI-II 평균이 동일하다 | 성별 간 차이 |
| F(1, 76) = 5.21 (상호작용) | 치료 효과가 성별에 따라 동일하다 (선이 평행하다) | 치료 효과의 성별 조절 여부 |

모든 F 통계량의 자유도는 (1, 76)이다:
- 분자 df = 1: 치료(2수준→df=1), 성별(2수준→df=1), 상호작용(1×1=1)
- 분모 df = 76: df_within = N − ab = 80 − 4 = 76

---

**Q2.** 상호작용의 partial η² = .06은 어떻게 해석하는가?

**모범 답안:**

partial η² = .06은 상호작용 효과의 효과크기를 나타낸다. Cohen(1988)의 기준에 따르면 **중간 효과(medium effect)** 에 해당한다 (.01 = 작음, .06 = 중간, .14 = 큼).

구체적 해석:
```
partial η²_A×B = SS_A×B / (SS_A×B + SS_within) = .06

즉, 오차(SS_within)를 고려했을 때 처치-성별 상호작용이
"오차 + 상호작용 변동" 중 6%를 설명한다.
```

중요한 것은, partial η²는 **다른 효과들의 SS를 제외하고** 오차만을 기준으로 계산한다는 점이다. 전체 에타제곱(η²)과 달리, partial η²는 SS_total(모든 요인 + 오차)이 아닌 SS_A×B + SS_within만을 분모로 사용하기 때문에 항상 η²보다 크거나 같다.

임상적 해석: 치료 효과가 성별에 따라 다른 정도(상호작용)가 "중간 크기의 효과"이므로, 이 결과는 임상적으로 의미 있다. 처치 결정 시 성별을 고려해야 할 실질적 이유가 있다.

---

**Q3.** 상호작용이 유의하다는 사실이 왜 중요한가?

**모범 답안:**

상호작용이 유의하다는 것은 **"치료 효과가 성별에 따라 다르다"** 는 것을 의미한다. 이것이 중요한 이유는 다음과 같다:

첫째, **치료 주효과 해석이 달라진다.** 치료의 주효과(F = 8.43, p = .005)만 보면 "CBT가 약물치료보다 더 효과적이다"고 결론 내릴 수 있다. 그러나 상호작용이 유의하므로 이 결론은 오해를 줄 수 있다. 실제로는 CBT의 이점이 여성에게만 유의하고 남성에게는 그렇지 않다.

둘째, **임상 결정이 달라진다.** 상호작용이 없다면 모든 환자에게 CBT를 권할 수 있지만, 상호작용이 있으므로 성별에 따라 다른 치료를 권해야 한다.

셋째, **단순 주효과 분석이 필요해진다.** 상호작용이 유의하면 "상호작용의 실체"를 단순 주효과 분석으로 확인해야 한다. 이 논문에서는 "여성: CBT 유의(p < .001), 남성: 비유의(p = .412)"로 그 실체가 밝혀진다.

---

**Q4.** 이 설계의 셀 수는 몇 개이고 전체 N은 얼마인가? 각 셀의 n은 얼마인가?

**모범 답안:**

```
설계: 2(치료: CBT / 약물치료) × 2(성별: 남성 / 여성)
셀 수: 2 × 2 = 4 (CBT+남성, CBT+여성, 약물+남성, 약물+여성)
전체 N = 80 (논문에서 명시)
각 셀 n = N / (a × b) = 80 / 4 = 20 (균형 설계 가정 시)

df_within 확인:
  df_within = N − ab = 80 − (2 × 2) = 80 − 4 = 76
  → F(1, 76)의 분모 df = 76 ✓
```

균형 설계(balanced design)라면 각 셀에 20명씩 배정된 것이다. 단, 논문에서 균형 여부를 명시하지 않으면 "각 조건에 약 20명"으로 이해한다.

---

**Q5.** 상호작용이 유의할 때 주효과를 해석할 때 왜 주의해야 하는가? 이 논문의 구체적인 예로 설명하라.

**모범 답안:**

상호작용이 유의하다는 것은 "A의 효과가 B 수준에 따라 다르다"는 것을 의미한다. 이때 주효과는 **"B를 무시하고 A만 봤을 때의 평균적인 차이"** 이므로, 이 평균이 어떤 B 수준에서도 동일하게 적용된다고 해석하면 오류가 된다.

이 논문의 구체적 예:
```
치료 주효과: F(1, 76) = 8.43, p = .005 → 유의
→ 표면적으로 "CBT가 약물치료보다 BDI-II를 더 낮춘다"

그러나 단순 주효과 분석 결과:
  여성: CBT가 유의하게 더 효과적 (p < .001)
  남성: CBT와 약물치료 간 차이 없음 (p = .412)

즉, "CBT가 더 좋다"는 주효과는 사실 여성에서의 강한 CBT 효과가
전체 평균을 끌어올린 결과이지,
모든 집단에 동일하게 적용되는 결론이 아니다.
```

따라서 상호작용이 유의할 때의 올바른 해석 순서:
1. 상호작용 효과를 먼저 보고
2. 단순 주효과 분석으로 실체 파악
3. 주효과는 "전반적 경향"으로만 언급하고 제한적으로 해석

## §7 오개념 경고

> **⚠️ 오개념 1: "주효과가 유의하면 상호작용에 관계없이 주효과를 그대로 해석해도 된다."**
>
> **바로잡기:** 상호작용이 유의하면 주효과는 **"오해를 줄 수 있는 평균적 결과"** 일 수 있다. 예를 들어 CBT의 주효과가 유의하더라도 실제로는 여성에게만 효과적이고 남성에게는 차이가 없을 수 있다. 이 경우 "CBT가 효과적"이라는 주효과 해석은 남성 환자에게는 잘못된 임상 결정을 유도할 수 있다. **상호작용이 유의하면 → 주효과 해석 전에 반드시 단순 주효과 분석(simple effects analysis)을 실시**해야 한다.

---

> **⚠️ 오개념 2: "상호작용이 없으면 이원배치 ANOVA를 쓸 필요가 없다."**
>
> **바로잡기:** 상호작용이 없어도 이원배치 ANOVA는 매우 유용하다. 두 가지 이유가 있다: (1) **두 요인의 주효과를 동시에 하나의 분석으로 효율적으로 검정**할 수 있다. 각각 일원배치 ANOVA를 두 번 하면 1종 오류 팽창 문제가 생기고, SS_within이 더 커져 검정력이 낮아진다. (2) **오차(SS_within)를 줄일 수 있다.** 이원배치에서는 요인 B가 설명하는 변동(SS_B)이 오차에서 분리되어, 더 정확한 F 검정이 가능하다. 상호작용 유의 여부와 무관하게, 이원배치 설계를 선택한 것 자체가 정당화된다.

---

> **⚠️ 오개념 3: "partial η²와 η²는 같은 것이다."**
>
> **바로잡기:** 이 둘은 분모가 다르다.
> ```
> η²           = SS_A / SS_total               (분모: 모든 변동의 합)
> partial η²_A = SS_A / (SS_A + SS_within)     (분모: 해당 효과 + 오차만)
>
> 예: SS_A = 80, SS_B = 125, SS_A×B = 5, SS_within = 32
>     SS_total = 242
>
>     η²_A         = 80 / 242 ≈ .33
>     partial η²_A = 80 / (80 + 32) = 80 / 112 ≈ .71
> ```
> partial η²는 항상 η² 이상이다 (같거나 크다). SPSS가 기본 출력하는 것은 partial η²이므로, 논문에서 "partial η² = .71"로 보고한 것을 η² = .33인 것처럼 오해하면 안 된다. 특히 이원배치에서는 둘의 차이가 크게 날 수 있다.

---

> **⚠️ 오개념 4: "이원배치 ANOVA에서 F 값이 3개 나오므로 Bonferroni 교정이 필요하다."**
>
> **바로잡기:** 이원배치 ANOVA의 세 F 검정(주효과 A, 주효과 B, 상호작용)은 **설계에서 사전에 계획된(planned) 검정**이다. 이는 사후에 탐색적으로 여러 비교를 추가하는 다중비교와 다르다. 따라서 이 세 F 검정 자체에 Bonferroni 교정을 적용할 필요가 없다. Bonferroni 교정이 필요한 시점은 **사후검정(post-hoc comparisons)** 을 실시할 때, 즉 유의한 주효과나 상호작용에 대해 수준 간 쌍별 비교를 할 때다.

---

> **⚠️ 오개념 5: "이원배치 ANOVA는 항상 피험자 간(between-subjects) 설계여야 한다."**
>
> **바로잡기:** 이원배치 ANOVA는 설계에 따라 세 가지 형태가 있다:
> ```
> ① 완전 피험자 간 (Between-Between): 두 요인 모두 독립변수 → Ch.14에서 다룬 형태
> ② 완전 피험자 내 (Within-Within):  두 요인 모두 반복측정 → 반복측정 ANOVA
> ③ 혼합 설계 (Mixed):               한 요인은 피험자 간, 한 요인은 피험자 내
>    예: 치료 유형(피험자 간) × 시간(사전/사후; 피험자 내)
> ```
> 피험자 내 요인이 포함되면 독립성 가정(Independence assumption)이 위반되므로 SS 분해와 오차 항이 달라진다. 피험자 내 설계는 Ch.15 반복측정 ANOVA에서 다룬다. 논문의 Methods를 읽을 때 설계 유형을 정확히 파악하는 것이 중요하다.

## §10 다음 챕터 연결

이 챕터는 **피험자 간(between-subjects) 이원배치 ANOVA**를 다루었다. 두 독립변수가 모두 "서로 다른 사람들"을 비교하는 변수였다.

이제 자연스럽게 다음 질문이 생긴다:

> **"같은 사람을 여러 시점에서 반복 측정한다면(예: 치료 전/중/후)? 또는 여러 조건에서 모두 측정한다면? 이때는 일반 ANOVA의 독립성 가정이 위반되는데..."**

이 챕터가 남긴 한계:

```
[Ch.14 이원배치 ANOVA]
    "가정: 모든 관측값은 서로 독립이다"
    "문제: 같은 사람에서 반복 측정하면 상관이 있다 → 독립성 위반"

예: 치료 전(t₁), 치료 중(t₂), 치료 후(t₃)에 동일 환자를 측정
    → 한 환자의 t₁, t₂, t₃는 독립이 아님 → 일반 ANOVA 사용 불가
```

다음 챕터의 답:

```
[Ch.15 반복측정 분산분석(Repeated-measures ANOVA)]
    "독립성 가정이 위반될 때의 ANOVA"
    "동일 참여자를 여러 조건/시점에서 반복 측정"
    "장점: 개인 간 차이(individual differences)를 오차에서 분리 → 검정력 증가"
    "가정: 구형성(Sphericity) — Mauchly 검정"
    "위반 시 수정: Greenhouse-Geisser, Huynh-Feldt"
```

Ch.15에서 만날 핵심 개념:
- 피험자 내 요인(within-subjects factor): 같은 사람에서 반복 측정
- 구형성(Sphericity): 반복측정 ANOVA의 고유 가정
- 개인차 오차 제거: 왜 반복측정이 더 검정력이 높은가?
- 혼합 설계(Mixed ANOVA): 피험자 간 요인 + 피험자 내 요인 동시 분석

```
이원배치 ANOVA (Between-Between)
        ↓
반복측정 ANOVA (Within) / 혼합 설계 (Between × Within)
        ↓
[비모수 대안] Friedman 검정 (정규성 가정 위반 시)
```

## 부록

### A. partial η² vs. η² vs. ω² — 이원배치 효과크기 비교

이원배치 ANOVA에서 효과크기는 어느 지표를 사용하느냐에 따라 값이 크게 달라질 수 있다. 세 지표를 정확히 구분해야 한다.

#### A-1. η² (에타제곱, Eta squared)

```
η²_A = SS_A / SS_total

특징:
- 전체 변동에서 해당 효과가 차지하는 비율
- 이원배치에서는 SS_B, SS_A×B, SS_within이 모두 분모(SS_total)에 포함됨
- 요인이 많을수록 분모가 커져 η²가 작아짐
- 설계(요인 수, 각 요인 수준 수)에 따라 값이 달라짐 → 비교 어려움

예 (§3.5 손계산):
  η²_A    = 80 / 242 ≈ .331
  η²_B    = 125 / 242 ≈ .517
  η²_A×B  = 5 / 242 ≈ .021
  η²_W    = 32 / 242 ≈ .132    (오차의 η²는 해석하지 않음)
  합계:   .331 + .517 + .021 + .132 = 1.001 ≈ 1.0  ✓
```

#### A-2. partial η² (부분 에타제곱, Partial eta squared)

```
partial η²_A = SS_A / (SS_A + SS_within)

특징:
- 분모에 오차(SS_within)와 해당 효과만 포함
- 다른 요인의 SS를 분모에서 제외 → 설계와 무관하게 효과 크기 비교 가능
- SPSS 기본 출력값 (자동으로 계산)
- η² ≤ partial η² (항상 크거나 같음)
- 여러 효과의 partial η² 합이 1을 초과할 수 있음

예 (§3.5):
  partial η²_A    = 80 / (80 + 32) = .714
  partial η²_B    = 125 / (125 + 32) = .796
  partial η²_A×B  = 5 / (5 + 32) = .135
  합계: .714 + .796 + .135 > 1.0  ← 이원배치에서 흔한 현상
```

#### A-3. ω² (오메가제곱, Omega squared) — 불편 추정량

```
ω²_A = (SS_A − df_A × MS_within) / (SS_total + MS_within)

특징:
- η²의 편향(과대추정)을 교정한 불편 추정량
- 표본이 클수록 η²과 ω²의 차이가 줄어듦
- 항상 η²보다 작음 (때로 음수가 될 수도 있음: 0으로 처리)
- APA Publication Manual이 권장하는 효과크기 중 하나

예 (§3.5):
  ω²_A = (80 − 1 × 2) / (242 + 2) = 78 / 244 ≈ .320
  ω²_B = (125 − 1 × 2) / 244 = 123 / 244 ≈ .504
  ω²_A×B = (5 − 1 × 2) / 244 = 3 / 244 ≈ .012
```

#### A-4. 세 지표 비교 요약

| 지표 | 수식 | 분모 | 특징 | SPSS 출력 |
|------|------|------|------|-----------|
| η² | SS_A / SS_total | 전체 변동 | 해석 직관적, 설계 의존 | 별도 계산 필요 |
| partial η² | SS_A / (SS_A + SS_W) | 효과 + 오차 | 설계 무관 비교 가능 | 자동 출력 |
| ω² | 교정 수식 | SS_total + MS_W | 불편 추정, 더 정확 | 별도 계산 필요 |

**실무 권장:**
- SPSS 기본값: partial η² → 논문에서 "partial η² = .06"으로 보고
- 정확한 효과 크기 보고 원하면: ω² 계산 후 병기
- 비교 연구(두 연구의 효과 크기 비교)에서는 partial η² 사용이 표준

### B. 불균형 설계 (Unequal Cell Sizes) 주의사항

#### B-1. 균형 설계 vs. 불균형 설계

```
균형 설계 (balanced design): 모든 셀의 n이 동일
  예: 각 셀 n = 20, 총 N = 80 (2×2 설계)
  → SS 분해가 직교(orthogonal): SS_A + SS_B + SS_A×B + SS_W = SS_total

불균형 설계 (unbalanced design): 셀의 n이 다름
  예: 셀 (CBT+남성) n=15, 셀 (CBT+여성) n=20, ...
  → SS가 더 이상 더해서 SS_total이 되지 않음 (비직교, non-orthogonal)
  → SS_A + SS_B + SS_A×B + SS_W ≠ SS_total
```

#### B-2. Type I / Type II / Type III 제곱합

불균형 설계에서는 SS를 어떻게 계산하느냐에 따라 결과가 달라진다:

| 유형 | 설명 | 언제 사용 |
|------|------|-----------|
| Type I SS | 순서 의존적: 먼저 입력한 변수의 고유 효과 → 나중 변수의 효과 | 위계적(hierarchical) 분석에서 특수 목적으로 |
| Type II SS | 상호작용이 없을 때 주효과 검정에 적합 | 상호작용 없는 모델에서 |
| Type III SS | 다른 효과가 모두 모델에 포함된 후 각 효과의 고유 분산 | **이원배치 ANOVA의 표준** — SPSS/R 기본값 |

**실무 권장: Type III SS (Partial SS) 사용**

```
SPSS: General Linear Model → Options → Sum of Squares: Type III (기본값)
R: Anova(lm(...), type = "III")
```

#### B-3. 불균형 설계에서의 주의사항

```
① 셀 n이 다를 때 "전체 평균"이 단순 셀 평균들의 평균이 아님
   → 가중 평균(weighted mean)과 비가중 평균(unweighted mean)이 달라짐
   → 연구 질문에 따라 어느 평균을 원하는지 명확히 해야 함

② 결측(missing data) 발생 시 원래 균형 설계가 불균형이 될 수 있음
   → 결측 패턴이 랜덤한지 확인 필요

③ 표본 크기 차이가 너무 크면 → 정규성, 등분산성 가정 위반 위험 증가
   → 사전에 설계 단계에서 균형 설계 권장

④ 논문에서 "An unbalanced design with unequal cell sizes was employed;
   Type III sums of squares were used for all analyses."와 같이 명시해야 함
```

### C. APA 7판 이원배치 ANOVA 보고 예시

```
방법(Methods) 섹션:
"A 2(Treatment: CBT vs. pharmacotherapy) × 2(Sex: male vs. female)
 between-subjects factorial ANOVA was conducted to examine the main effects
 of treatment type and sex, and their interaction, on post-treatment BDI-II scores."

결과(Results) 섹션:
"Results revealed a significant main effect of Treatment,
 F(1, 76) = 8.43, p = .005, partial η² = .10, indicating that CBT
 (M = 12.4, SD = 4.8) produced lower BDI-II scores than pharmacotherapy
 (M = 15.9, SD = 5.2) on average. The main effect of Sex was not significant,
 F(1, 76) = 1.23, p = .270, partial η² = .02. However, a significant
 Treatment × Sex interaction was obtained, F(1, 76) = 5.21, p = .025,
 partial η² = .06 (see Figure 1). Simple effects analyses indicated that
 CBT was significantly more effective than pharmacotherapy for female
 participants (p < .001), but not for male participants (p = .412)."
```
