## §3 핵심 개념 학습

### 3.1 독립표본 vs 대응표본 — 먼저 구조부터

> **핵심 납득 포인트**
>
> 두 집단을 비교하기 전에 반드시 물어야 할 **한 가지 질문**이 있다:
>
> **"두 집단의 관측값들이 서로 연결되어 있는가?"**
>
> - **연결되어 있지 않다** → **독립표본 (independent samples)**
> - **같은 사람의 전·후, 또는 매칭된 쌍** → **대응표본 (paired samples)**
>
> 이 구분을 잘못하면 검정력이 크게 낮아지거나, 아예 틀린 분석을 하게 된다.

**독립표본 예시:**
- CBT 집단(n = 30명)과 대기 통제 집단(n = 30명) ← 완전히 다른 사람들
- 실험집단과 통제집단의 우울 점수 비교

**대응표본 예시:**
- 같은 30명에게 치료 전/후 BDI-II 측정 ← 같은 사람의 두 측정값
- 쌍둥이를 한 쌍으로 배정한 연구 ← 매칭된 쌍

**왜 대응표본이 검정력이 높은가?**

```
[독립표본]
개인차  →  x̄₁ − x̄₂의 변산성이 큼
           개인마다 기준 점수가 다르기 때문

[대응표본]
개인차를  →  차이(d)만 분석: 개인 기준점이 제거됨
제거함       → d의 변산성이 훨씬 작음 → SE 감소 → t값 증가
```

---

### 3.2 독립표본 t-검정 — 등분산 가정 (Pooled t-test)

**직관:** "두 집단의 점수 분산이 비슷하다고 믿을 수 있다면, 두 집단의 데이터를 '하나의 큰 분산 추정치'로 합쳐서 더 안정적인 SE를 구할 수 있다."

**가설:**
```
H₀: μ₁ = μ₂   (또는 μ₁ − μ₂ = 0)
Hₐ: μ₁ ≠ μ₂   (양측)  또는  μ₁ > μ₂ / μ₁ < μ₂  (단측)
```

**풀드 분산 (pooled variance, sp²):**
```
sp² = [(n₁ − 1)s₁² + (n₂ − 1)s₂²] / (n₁ + n₂ − 2)
```
- 각 집단의 분산을 표본 크기(−1)로 가중 평균한 것
- df = n₁ + n₂ − 2

**검정통계량:**
```
t = (x̄₁ − x̄₂) / [sp × √(1/n₁ + 1/n₂)]
```

**신뢰구간:**
```
(x̄₁ − x̄₂) ± t* × sp × √(1/n₁ + 1/n₂)
```

**등분산 확인 — Levene 검정 (Levene's test):**
```
H₀: σ₁² = σ₂²

p ≥ .05  →  등분산 가정 유지  →  Pooled t 사용
p < .05  →  등분산 가정 위반  →  Welch t 사용 (§3.3)
```

> **핵심 납득 포인트**
>
> SPSS 출력표에서 "Levene's Test for Equality of Variances" 결과를 **먼저** 확인하고, 그 결과에 따라 "Equal variances assumed" 또는 "Equal variances not assumed" 행을 선택한다. 이 절차를 모르면 잘못된 t값을 보고하게 된다.

---

### 3.3 독립표본 t-검정 — 이분산 가정 (Welch t-test)

**직관:** "두 집단의 분산이 다르다면, 두 집단의 SE를 따로 계산해서 합산해야 한다."

**검정통계량:**
```
t = (x̄₁ − x̄₂) / √(s₁²/n₁ + s₂²/n₂)
```

**자유도 (Welch-Satterthwaite 근사법):**
```
        (s₁²/n₁ + s₂²/n₂)²
df = ─────────────────────────────────
     (s₁²/n₁)²/(n₁−1) + (s₂²/n₂)²/(n₂−1)
```
- 이 공식은 복잡하므로, 소프트웨어가 자동 계산
- 결과: df가 정수가 아닌 소수로 나옴 (예: t(22.7) = ...)
- 항상 pooled t보다 df가 작거나 같음 → 보수적

> **핵심 납득 포인트**
>
> 실무에서 많은 연구자들이 Levene 검정 결과에 관계없이 **항상 Welch t를 사용**하는 경향이 있다. 두 분산이 같을 때도 Welch t는 pooled t와 거의 같은 결과를 주기 때문이다. 보수적이고 안전한 선택이다.

---

### 3.4 대응표본 t-검정 (Paired t-test)

**직관:** "치료 전·후 점수를 직접 빼서 '차이 점수(difference score)'를 구한다. 그 다음은 단일표본 t-검정과 완전히 같다."

**핵심 변환:**
```
d_i = x₁ᵢ − x₂ᵢ    (i번째 사람의 차이 점수)
d̄   = (1/n) Σd_i    (차이 점수의 평균)
sd  = 차이 점수의 표준편차
SE  = sd / √n
```

**검정통계량:**
```
t = d̄ / (sd / √n),   df = n − 1
```

**신뢰구간:**
```
d̄ ± t* × (sd / √n)
```

**가설:**
```
H₀: μ_d = 0    (치료 전후 차이가 없다)
Hₐ: μ_d ≠ 0   (양측)  또는  μ_d > 0 / μ_d < 0  (단측)
```

> **핵심 납득 포인트**
>
> 대응표본 t-검정은 사실 **단일표본 t-검정**이다 — 단지 분석 단위가 '개인 점수' 대신 '차이 점수(d)'로 바뀐 것뿐이다. 이 점을 이해하면 공식을 별도로 외울 필요가 없다.

---

### 3.5 두 모분산 비교 (F-검정)

**직관:** "두 집단의 분산이 다른지 검정하고 싶다면, 두 분산의 비(ratio)를 검정통계량으로 사용한다."

**검정통계량:**
```
F = s₁² / s₂²    (일반적으로 더 큰 분산을 분자에 놓아 F ≥ 1로 만들기도 함)
```

**자유도:**
```
df₁ = n₁ − 1   (분자 집단의 자유도)
df₂ = n₂ − 1   (분모 집단의 자유도)
```

**F-분포의 특성:**
```
- 항상 0 이상 (분산은 음수 불가)
- 오른쪽으로 치우친 비대칭 분포
- 두 분산이 같다면 F ≈ 1
- F가 1보다 훨씬 크면 두 분산이 다르다는 증거
```

**주의:** F-검정은 정규성 위반에 매우 민감하다. 실제 연구에서는 더 강건한 **Levene's test** (편차의 절댓값에 기반)를 선호한다.

---

### 3.6 두 모비율 비교

**직관:** "CBT 집단과 대기 집단에서 치료 완주율(비율)이 다른지 비교하고 싶다."

**풀드 비율 (pooled proportion, p̂_c):**
```
p̂_c = (x₁ + x₂) / (n₁ + n₂)    (H₀하에서 두 집단의 공통 비율 추정)
```

**검정통계량:**
```
z = (p̂₁ − p̂₂) / √[p̂_c(1 − p̂_c) × (1/n₁ + 1/n₂)]
```

**신뢰구간 (검정과 다르게 풀드 비율 미사용):**
```
(p̂₁ − p̂₂) ± z* × √[p̂₁(1−p̂₁)/n₁ + p̂₂(1−p̂₂)/n₂]
```

> **핵심 납득 포인트**
>
> 검정에서는 H₀을 가정하므로 두 비율이 같다고 보고 **풀드 비율**을 SE 계산에 사용한다. 신뢰구간에서는 H₀을 가정하지 않으므로 **각 집단의 비율을 따로** 사용한다. 이 차이를 기억하자.

## §4 수식 정리

```
■ 기호 약속
x̄₁, x̄₂    : 집단 1, 2의 표본평균
s₁², s₂²   : 집단 1, 2의 표본분산
n₁, n₂     : 집단 1, 2의 표본 크기
sp²         : 풀드(합동) 분산
d_i         : i번째 대응쌍의 차이 점수
d̄           : 차이 점수의 평균
sd          : 차이 점수의 표준편차
p̂₁, p̂₂     : 집단 1, 2의 표본비율
p̂_c         : 풀드 표본비율
```

---

### [수식 1] 풀드 분산과 독립표본 t (등분산)

```
sp² = [(n₁−1)s₁² + (n₂−1)s₂²] / (n₁+n₂−2)

t = (x̄₁ − x̄₂) / [sp × √(1/n₁ + 1/n₂)]

df = n₁ + n₂ − 2
```

**손계산 예시** (CBT vs 통제 집단, 치료 후 BDI-II):

| | CBT 집단 (집단 1) | 통제 집단 (집단 2) |
|--|--|--|
| n | 8 | 8 |
| x̄ | 20 | 28 |
| s² | 36 | 64 |

```
① 풀드 분산
sp² = [(8−1)×36 + (8−1)×64] / (8+8−2)
    = [7×36 + 7×64] / 14
    = [252 + 448] / 14
    = 700 / 14
    = 50

sp = √50 ≈ 7.07

② 표준오차
SE = sp × √(1/n₁ + 1/n₂)
   = 7.07 × √(1/8 + 1/8)
   = 7.07 × √(0.25)
   = 7.07 × 0.500
   = 3.54

③ 검정통계량
t = (20 − 28) / 3.54 = −8 / 3.54 ≈ −2.26

df = 8 + 8 − 2 = 14

④ p값 (양측)
t(14) = −2.26  →  p ≈ .040

⑤ 95% 신뢰구간 (t*(14) ≈ 2.145)
(20−28) ± 2.145 × 3.54
= −8 ± 7.59
= [−15.59,  −0.41]

⑥ Cohen's d
d = |x̄₁ − x̄₂| / sp = 8 / 7.07 ≈ 1.13   → 큰 효과크기
```

**해석:** CBT 집단(M = 20)이 통제 집단(M = 28)보다 BDI-II 점수가 유의하게 낮았다, t(14) = −2.26, p = .040, 95% CI [−15.59, −0.41], d = 1.13.

---

### [수식 2] 대응표본 t

```
d_i = x₁ᵢ − x₂ᵢ
d̄ = Σd_i / n
sd = √[Σ(d_i − d̄)² / (n−1)]
t = d̄ / (sd / √n),   df = n − 1
```

**손계산 예시** (치료 전·후 BDI-II, n = 6):

| 참여자 | 치료 전 (x₁) | 치료 후 (x₂) | d_i = x₁ − x₂ |
|--------|-------------|-------------|----------------|
| 1      | 32          | 24          | 8              |
| 2      | 28          | 22          | 6              |
| 3      | 35          | 28          | 7              |
| 4      | 30          | 20          | 10             |
| 5      | 27          | 25          | 2              |
| 6      | 33          | 26          | 7              |
| **합계** |           |             | **40**         |

```
① d̄ = 40 / 6 ≈ 6.67

② 편차 제곱합 계산
d_i − d̄:   1.33,  −0.67,  0.33,  3.33,  −4.67,  0.33
(d_i−d̄)²:  1.77,   0.45,  0.11, 11.09,  21.81,  0.11
합계 = 35.33

③ sd = √(35.33/5) = √7.07 ≈ 2.66

④ SE = 2.66 / √6 = 2.66 / 2.449 ≈ 1.086

⑤ t = 6.67 / 1.086 ≈ 6.14,   df = 5

⑥ p값 (양측)
t(5) = 6.14  →  p < .001
(t*(5) = 4.032 for α = .001 two-tailed  →  6.14 > 4.032)

⑦ 95% CI  (t*(5) ≈ 2.571)
6.67 ± 2.571 × 1.086
= 6.67 ± 2.79
= [3.88,  9.46]
```

**해석:** 치료 후 BDI-II 점수가 치료 전보다 평균 6.67점 유의하게 감소하였다, t(5) = 6.14, p < .001, 95% CI [3.88, 9.46].

---

### [수식 3] 두 모비율 비교

```
p̂_c = (x₁ + x₂) / (n₁ + n₂)

z = (p̂₁ − p̂₂) / √[p̂_c(1−p̂_c)(1/n₁ + 1/n₂)]

95% CI: (p̂₁ − p̂₂) ± 1.96 × √[p̂₁(1−p̂₁)/n₁ + p̂₂(1−p̂₂)/n₂]
```

**손계산 예시** (치료 완주율: CBT 18/30, 통제 9/30):

```
p̂₁ = 18/30 = .60,   p̂₂ = 9/30 = .30

p̂_c = (18+9)/(30+30) = 27/60 = .45

SE = √[.45 × .55 × (1/30 + 1/30)]
   = √[.2475 × 0.0667]
   = √.0165
   ≈ .1285

z = (.60 − .30) / .1285 = .30 / .1285 ≈ 2.33

p ≈ .020 (양측)

95% CI:
(.60−.30) ± 1.96 × √(.60×.40/30 + .30×.70/30)
= .30 ± 1.96 × √(.008 + .007)
= .30 ± 1.96 × .1225
= .30 ± .240
= [.060,  .540]
```

**해석:** CBT 집단(60%)이 통제 집단(30%)보다 완주율이 유의하게 높았다, z = 2.33, p = .020, 95% CI [.060, .540].

## §5 심리학 연구 맥락 연결

### 시나리오 A: 두 집단 간 우울 점수 비교 — 독립표본 설계

임상 연구자 K는 주요우울장애 진단을 받은 환자 60명을 무작위로 CBT 집단(n = 30)과 약물 치료 집단(n = 30)에 배정했다. 12주 치료 후 BDI-II 점수를 측정했다.

- CBT 집단: M = 17.3, SD = 6.8
- 약물 집단: M = 21.0, SD = 7.5

**분석 절차:**
1. Levene 검정으로 등분산 여부 확인
2. p ≥ .05 → Pooled t / p < .05 → Welch t
3. 검정통계량 산출 → p값 → 효과크기 d → 신뢰구간

**SPSS 출력표 읽는 법:**

```
┌─────────────────────────────┬───────────┬──────────────────────────────────────────────┐
│ Levene's Test               │           │ t-test for Equality of Means                 │
├─────────────────────────────┼───────────┼──────┬──────┬────────┬─────────┬────────────┤
│                             │  F   Sig. │  t   │  df  │  Sig.  │  Mean   │  95% CI    │
│                             │           │      │      │(2-tl.) │  Diff.  │Lower Upper │
├─────────────────────────────┼───────────┼──────┼──────┼────────┼─────────┼────────────┤
│ Equal variances assumed     │1.24  .270 │−2.27 │  58  │  .027  │  −3.70  │−6.98 −0.42 │
│ Equal variances not assumed │           │−2.27 │55.3  │  .027  │  −3.70  │−6.99 −0.41 │
└─────────────────────────────┴───────────┴──────┴──────┴────────┴─────────┴────────────┘
```

Levene F = 1.24, p = .270 (**p > .05 → 등분산 가정 유지**) → 첫 번째 행 사용 → t(58) = −2.27, p = .027.

### 시나리오 B: 치료 전후 불안 변화 비교 — 대응표본 설계

상담사 L은 범불안장애 내담자 20명에게 16회기 CBT를 실시하고 GAD-7 점수를 치료 전·후에 측정했다.

- 치료 전: M = 13.4, SD = 3.2
- 치료 후: M = 6.8, SD = 2.9
- 차이 점수: d̄ = 6.6, sd = 2.4

```
SE = 2.4 / √20 = 2.4 / 4.472 ≈ 0.537

t = 6.6 / 0.537 ≈ 12.29,   df = 19

p < .001

95% CI: 6.6 ± 2.093 × 0.537 = 6.6 ± 1.12 = [5.48, 7.72]

Cohen's d = d̄ / sd = 6.6 / 2.4 = 2.75   → 매우 큰 효과크기
```

**연구 보고 형식:**
> "GAD-7 scores decreased significantly from pre-treatment (M = 13.4, SD = 3.2) to post-treatment (M = 6.8, SD = 2.9), t(19) = 12.29, p < .001, 95% CI [5.48, 7.72], d = 2.75."

**해석 포인트:** d = 2.75는 매우 큰 효과크기다. 그러나 대응표본에서는 개인차가 제거되어 d가 독립표본보다 상대적으로 크게 나오는 경향이 있으므로, 독립표본의 d와 직접 비교하지 않도록 주의한다.

## §6 논문 스니펫 읽기 실습

### 가상 논문 발췌 (APA 7판 형식)

> **Study excerpt:**
>
> Participants were adults with major depressive disorder (MDD), randomly assigned to cognitive-behavioral therapy (CBT; n = 34) or a waitlist control condition (WLC; n = 33). Prior to the main analysis, Levene's test indicated no significant difference in BDI-II score variances between groups, F(1, 65) = 1.82, p = .182. An independent samples t-test revealed that CBT participants reported significantly lower BDI-II scores (M = 17.3, SD = 6.8) compared to WLC participants (M = 24.1, SD = 7.2), t(65) = 4.28, p < .001, 95% CI [3.63, 9.97], d = 1.05. Additionally, a significantly higher proportion of CBT participants achieved remission (BDI-II < 14) compared to WLC (CBT: 21/34, 61.8%; WLC: 8/33, 24.2%), z = 3.37, p < .001, 95% CI [.178, .570].

---

### 연습 질문

**Q1.** "Levene's test indicated no significant difference in BDI-II score variances between groups, F(1, 65) = 1.82, p = .182" — 이 결과는 무엇을 의미하는가? 연구자는 이후 어떤 종류의 t-검정을 사용해야 하는가?

**모범 답안:**
Levene 검정은 두 집단의 분산이 동일한지 검정한다. p = .182 > .05이므로 H₀(두 분산 동일)를 기각하지 못한다. 즉, 등분산 가정을 유지한다. 따라서 연구자는 **풀드(등분산) t-검정 (equal variances assumed)**을 사용해야 한다. 실제로 보고된 df = 65 = 34 + 33 − 2이므로, 풀드 t-검정이 사용되었음을 확인할 수 있다.

---

**Q2.** `t(65) = 4.28, p < .001, 95% CI [3.63, 9.97], d = 1.05` 를 APA 형식 그대로 해석하라.

**모범 답안:**
- `t(65) = 4.28`: 자유도 65의 t-분포에서 검정통계량이 4.28. 두 집단 평균 차이(24.1 − 17.3 = 6.8점)를 표준오차로 나눈 비율이다.
- `p < .001`: 귀무가설(두 집단 평균이 동일)이 참일 때 이 정도 이상의 차이가 관찰될 확률이 0.1% 미만. 통계적으로 유의함.
- `95% CI [3.63, 9.97]`: WLC − CBT 평균 차이의 95% 신뢰구간. 모집단에서 두 집단 BDI-II 평균 차이가 3.63점에서 9.97점 사이에 있을 것으로 추정됨. 구간이 0을 포함하지 않으므로 유의하다는 결론과 일치한다.
- `d = 1.05`: Cohen's d. 두 집단 평균 차이가 풀드 표준편차의 1.05배. Cohen(1988) 기준 '큰 효과크기'(d > 0.8). CBT가 WLC보다 실질적으로도 큰 효과가 있음을 나타냄.

---

**Q3.** "a significantly higher proportion of CBT participants achieved remission (61.8%) compared to WLC (24.2%), z = 3.37, p < .001, 95% CI [.178, .570]" — 신뢰구간 [.178, .570]은 어떤 값의 범위를 의미하는가?

**모범 답안:**
95% CI [.178, .570]은 **두 집단의 완화율 차이(CBT 비율 − WLC 비율)**에 대한 신뢰구간이다. 즉, 모집단에서 CBT의 완화율이 WLC보다 .178(약 17.8%p)에서 .570(약 57.0%p) 더 높을 것으로 추정된다. 구간이 0을 포함하지 않으므로 통계적으로 유의하다는 사실과 일치한다.

---

**Q4.** 이 연구에서 n = 34(CBT), n = 33(WLC)이다. 만약 각 집단이 n = 10이었다면 p값과 CI에 어떤 변화가 예상되는가? (계산 없이 논리적으로 설명하라)

**모범 답안:**
표본 크기가 줄어들면:
- SE = sp × √(1/n₁ + 1/n₂)가 커진다 (n이 작을수록 SE 증가)
- t = (x̄₁ − x̄₂)/SE가 작아진다 (같은 평균 차이라도 SE가 크면 t 감소)
- p값이 커지고, 통계적 유의성을 놓칠 수 있다
- 95% CI의 폭이 넓어진다 (불확실성 증가)

즉, 동일한 효과(d = 1.05)가 있더라도 n = 10에서는 p < .001을 얻기 어렵다. 이것이 **검정력(statistical power)**의 문제이며, 충분한 표본 크기가 왜 중요한지를 보여준다.

---

**Q5.** 이 연구에서 독립표본 t-검정을 사용했다. 만약 연구자가 대응표본 설계를 원했다면 연구 설계를 어떻게 바꿔야 하는가?

**모범 답안:**
대응표본 설계를 위해서는 다음 중 하나가 필요하다:
1. **전후 설계**: 같은 67명에게 CBT를 제공하고, 치료 전·후의 BDI-II를 각각 측정한다. 이때 각 사람의 치료 전 점수와 치료 후 점수가 쌍을 이룬다.
2. **매칭 설계**: 나이·성별·기저 BDI-II 점수 등을 기준으로 CBT 참여자와 WLC 참여자를 일대일로 매칭시킨다.

무작위 배정 비교 설계(RCT)처럼 서로 완전히 다른 사람을 두 집단에 배정하는 경우에는 독립표본 t-검정을 사용하는 것이 맞다.

## §7 오개념 경고

> **⚠️ 오개념 1:** "t(65) = 4.28이면 CBT가 WLC보다 4.28점 더 효과적이다."
>
> **바로잡기:** t값은 검정통계량(test statistic)이지 **점수 차이가 아니다**. t = (x̄₁ − x̄₂) / SE이므로, 실제 평균 차이는 분자 x̄₁ − x̄₂ = 6.8점이다. t = 4.28은 그 차이를 표준오차(SE)로 나눈 비율이며, SE가 작을수록 t가 커진다. 논문에서 실제 효과 크기를 알려면 **평균 차이(Mean Difference)**와 **Cohen's d**를 함께 봐야 한다.

---

> **⚠️ 오개념 2:** "대응표본인데 독립표본 t-검정을 써도 결과가 비슷하게 나올 것이다."
>
> **바로잡기:** 대응 구조를 무시하고 독립표본 t를 쓰면 **개인차가 오차(SE) 안에 남아** SE가 커지고 검정통계량이 작아진다. §4의 대응표본 예시에서 t = 6.14가 나왔지만, 같은 데이터를 독립표본 t로 잘못 분석하면 t가 훨씬 작아져서 p값이 크게 올라가거나 유의하지 않은 결과가 나올 수 있다. 연구 설계를 정확히 반영하는 검정을 선택하는 것은 **분석의 기본 전제**다.

---

> **⚠️ 오개념 3:** "Levene 검정 p > .05 → 두 집단의 분산이 같다고 증명된 것이다."
>
> **바로잡기:** Levene 검정에서 p > .05는 귀무가설(σ₁² = σ₂²)을 **기각하지 못한 것**이지, 두 분산이 같다고 **증명한 것이 아니다**. 표본이 작으면 실제로 분산이 달라도 검정력 부족으로 p > .05가 나올 수 있다. "귀무가설 채택 ≠ 귀무가설 참 확인"이라는 원칙(Ch.8 §7)을 여기에서도 적용해야 한다.

---

> **⚠️ 오개념 4:** "p < .001이므로 d도 클 것이다. 통계적 유의성이 높으면 효과도 크다."
>
> **바로잡기:** p값은 **표본 크기**에 크게 영향을 받는다. n이 매우 크면 작은 차이(d = 0.10)도 p < .001을 만들 수 있고, n이 작으면 큰 차이(d = 1.00)도 p > .05가 나올 수 있다.
>
> ```
> 예시 A: n = 5000, d = 0.10  →  p < .001  (유의하지만 효과는 매우 작음)
> 예시 B: n = 15,   d = 1.00  →  p = .07   (유의하지 않지만 효과는 큼)
> ```
>
> **유의성(p)은 "효과가 존재하는가?"를, 효과크기(d)는 "효과가 얼마나 큰가?"를 각각 따로 답한다.** APA 매뉴얼(7판)은 검정 결과와 함께 효과크기를 반드시 보고하도록 명시한다.

## §10 다음 챕터 연결

이 챕터는 두 집단을 비교하는 법을 배웠다. 자연스럽게 다음 질문이 생긴다:

> **"두 집단이 아니라 세 집단 이상을 비교하고 싶다면?"**

**왜 t-검정을 여러 번 반복하면 안 되는가?**

```
3개 집단(A, B, C)에서 t-검정을 반복하면:
  A vs B  /  A vs C  /  B vs C  → 총 3번

각 검정의 α = .05이면:
1종 오류 없을 확률 = 0.95 × 0.95 × 0.95 ≈ 0.857

적어도 하나의 1종 오류 확률 = 1 − 0.857 ≈ .143

→ 비교 횟수가 늘어날수록 우연에 의한 유의 결과 확률 급증
→ 이것이 "1종 오류 팽창(familywise error rate)" 문제
```

**해결책: 분산분석 (ANOVA)**

```
[Ch.10 두 모집단 비교]
    "두 집단 평균이 다른가?"
            ↓
[Ch.11 분산분석(ANOVA)]
    "세 집단 이상의 평균이 다른가?"
    F = (집단 간 분산) / (집단 내 분산)
    사후검정(post-hoc test)으로
    어떤 집단끼리 다른지 확인
```

**ANOVA에서 만날 핵심 개념:**
- F-통계량: 이미 §3.5에서 F-분포를 맛봤다
- 집단 간 분산 (Between-group variance): 집단 평균들의 차이
- 집단 내 분산 (Within-group variance): 각 집단 내 개인차
- 효과크기: η² (에타제곱) — Cohen's d의 ANOVA 버전

---

## 부록: 효과크기 — Cohen's d 완전 정리

*(CLAUDE.md §5 보완 주제: "효과크기 (Cohen's d, η², r) — Ch.9~11")*

### A. Cohen's d란?

**직관:** t-검정에서 p값은 "효과가 있는가?"에 답하지만, **"효과가 얼마나 큰가?"**는 p값으로 알 수 없다. Cohen's d는 두 집단 평균 차이를 표준편차로 나눈 표준화 지수다.

```
독립표본:
  d = (x̄₁ − x̄₂) / sp       (sp = 풀드 표준편차)

대응표본:
  d = d̄ / sd                  (sd = 차이 점수의 표준편차)

단일표본 (Ch.9):
  d = (x̄ − μ₀) / s
```

---

### B. 해석 기준 (Cohen, 1988)

| d 값 | 효과크기 해석 | 직관적 이미지 |
|------|-------------|--------------|
| 0.2  | 작은 효과 (small)  | 두 집단 분포가 79% 겹침 — 차이가 거의 안 보임 |
| 0.5  | 중간 효과 (medium) | 두 집단 분포가 67% 겹침 — 차이가 약간 보임   |
| 0.8  | 큰 효과 (large)    | 두 집단 분포가 53% 겹침 — 차이가 명확히 보임 |

---

### C. p값 vs Cohen's d: 각자의 역할

| | p값 | Cohen's d |
|--|-----|-----------|
| 핵심 질문 | 효과가 **있는가**? | 효과가 **얼마나 큰가**? |
| 영향 요인 | 평균 차이 + n + SE | 평균 차이 + 분산 |
| n의 영향 | n 클수록 p 감소 | n에 의존하지 않음 |

**함정 예시:**
```
연구 A: n = 1000, d = 0.10  →  p < .001  (매우 유의, 하지만 효과는 매우 작음)
연구 B: n = 20,   d = 0.80  →  p = .08   (유의하지 않음, 하지만 효과는 큼)
```

→ **n이 크면 임상적으로 무의미한 차이도 통계적으로 유의해질 수 있다.**
→ **n이 작으면 임상적으로 중요한 차이도 통계적으로 유의하지 않을 수 있다.**

---

### D. 다른 효과크기 지표 미리 보기

| 지표 | 사용 상황 | 공식 |
|------|-----------|------|
| Cohen's d | t-검정 (두 집단 평균 비교) | d = Δx̄ / sp |
| η² (에타제곱) | ANOVA (세 집단 이상) | η² = SS_집단간 / SS_전체 |
| r (점이연 상관) | t-검정 ↔ 상관으로 변환 | r = t / √(t² + df) |
| R² | 회귀분석 | 종속변수 분산 중 설명된 비율 |

### E. APA 7판 효과크기 보고 기준

APA Publication Manual (7판)은 통계적 유의성 검정 결과와 함께 효과크기를 반드시 보고하도록 명시한다:

> *"For each inferential test reported, include measures of effect size."*
> *(APA Manual, 2020, §6.24)*

**올바른 보고 형식:**
```
t(65) = 4.28, p < .001, 95% CI [3.63, 9.97], d = 1.05
```

p값만 보고하는 것은 APA 7판 기준에 부적합하다. 효과크기는 결과의 **실질적 의미(practical significance)**를 알려주는 필수 정보다.
