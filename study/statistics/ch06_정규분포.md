### 3.1 정규분포의 성질

#### 직관부터 시작

> **질문**: "왜 많은 심리 척도 점수가 종 모양 분포를 보이는가?"

정규분포는 **독립적인 많은 요인들이 합쳐져서 하나의 결과를 만들 때** 자연스럽게 나타난다. BDI-II 점수가 종 모양인 이유: 우울을 구성하는 수면 문제, 기력 저하, 인지 왜곡 등 많은 독립적 요인들이 더해지기 때문이다. 이것이 Ch.7에서 배울 중심극한정리(CLT)의 직관이다.

#### 정규분포의 5가지 핵심 성질

```
1. 종 모양 (bell-shaped): 가운데가 높고 양쪽이 낮음
2. 좌우 대칭: 평균(μ)을 중심으로 완벽히 대칭
3. 평균 = 중앙값 = 최빈값 (대칭이므로 세 값이 모두 같음)
4. 두 모수로 완전히 결정: μ(위치)와 σ(퍼짐)만 알면 분포 전체를 안다
5. 점근선: 양 끝이 x축에 점근하지만 닿지 않음 (−∞ ~ +∞)
```

#### 표기법

```
X ~ N(μ, σ²)

읽는 법: "X는 평균 μ, 분산 σ²인 정규분포를 따른다"
주의: 괄호 안이 σ²(분산)인지 σ(표준편차)인지 교재마다 다름. 이 계획서는 σ² 사용.
```

**μ와 σ가 분포 모양에 미치는 영향**:

```
[μ의 효과 — 위치 이동]

σ 동일, μ 다름:
         N(10, σ²)   N(20, σ²)   N(30, σ²)
              ╭─╮       ╭─╮         ╭─╮
              │ │       │ │         │ │
   ───────────╯ ╰───────╯ ╰─────────╯ ╰────
    0    10   20   30   40
         ↑         ↑         ↑
         (분포 모양 동일, 위치만 이동)

[σ의 효과 — 퍼짐 변화]

μ 동일, σ 다름:
              σ=2: 좁고 높음
                  ╭───╮
         σ=4:     │   │
            ╭─────╯   ╰─────╮
   σ=8: ─────╯               ╰─────
   ────────────────────────────────
                   μ
```

#### 68-95-99.7 법칙 (Empirical Rule)

정규분포에서 표준편차 범위와 확률의 관계:

```
P(μ − σ  ≤ X ≤ μ + σ)  ≈ .683  (약 68%)
P(μ − 2σ ≤ X ≤ μ + 2σ) ≈ .954  (약 95%)
P(μ − 3σ ≤ X ≤ μ + 3σ) ≈ .997  (약 99.7%)

시각화:
   ┌────────────────────────────────────────┐
   │                                        │
   │         ├── 68% ──┤                   │
   │       ├──── 95% ────┤                 │
   │     ├────── 99.7% ──────┤             │
   │  ───╯     │     │     │     ╰───      │
   └──────────────────────────────────────┘
        μ-3σ  μ-2σ  μ-σ   μ   μ+σ  μ+2σ  μ+3σ
```

**임상 예시** — BDI-II: X ~ N(μ=24, σ=8) (임상 표본 가정)

```
P(16 ≤ BDI-II ≤ 32) ≈ .683
→ 이 임상 집단의 약 68%가 16~32점 범위

P(8 ≤ BDI-II ≤ 40) ≈ .954
→ 약 95%가 8~40점 범위

P(BDI-II > 40) ≈ (1 − .997)/2 = .0015
→ 약 0.15% (매우 극단적 고점수)
```

> **핵심 납득 포인트**: 68-95-99.7 법칙은 어떤 정규분포에도 적용된다. 평균과 표준편차만 알면, "상위 2.5%는 어디서부터인가?" (μ + 2σ)와 같은 질문에 즉시 답할 수 있다. 이것이 Ch.9 신뢰구간에서 "z = 1.96"이 등장하는 이유다.

### 3.2 표준정규분포 (Standard Normal Distribution)

#### 직관부터 시작

> **문제**: 연구 A의 BDI-II 점수(μ=24, σ=8)와 연구 B의 STAI 점수(μ=50, σ=10)에서, 어느 쪽이 더 "극단적인" 점수인가?
> - 연구 A에서 BDI-II = 32점
> - 연구 B에서 STAI = 62점

두 점수를 **공통의 단위(표준편차)로 변환**하면 비교가 가능하다 — 이것이 **표준화**다.

#### 표준화 공식 (z-점수 변환)

```
z = (X − μ) / σ

기호 해설:
  X = 원래 관측값
  μ = 분포의 평균
  σ = 분포의 표준편차
  z = "평균에서 표준편차 단위로 얼마나 떨어졌는가"
```

**선형 변환으로 이해하기** (Ch.4 부록 연결):

```
Z = (1/σ)X − (μ/σ)  →  a = 1/σ, b = −μ/σ인 선형 변환

E(Z) = (1/σ)μ − μ/σ = 0
Var(Z) = (1/σ)² × σ² = 1

따라서: Z ~ N(0, 1)  ← 표준정규분포
```

#### 표준정규분포

```
Z ~ N(0, 1): 평균 = 0, 분산 = 1

       f(z)
        │      ╭────╮
        │    ╭─╯    ╰─╮
        │  ╭─╯          ╰─╮
        │╭─╯                ╰──
        └──────────────────────
     -3  -2  -1   0   1   2   3    z

P(Z < 0) = .500  (정확히 대칭)
P(Z < 1) = .841
P(Z < -1) = .159
P(−1.96 < Z < 1.96) ≈ .950  ← 95%에 해당하는 임계값
```

**위 예시 비교**:

```
연구 A: BDI-II = 32, μ=24, σ=8
  z = (32 − 24) / 8 = 8/8 = 1.00
  → 평균보다 1 표준편차 높음

연구 B: STAI = 62, μ=50, σ=10
  z = (62 − 50) / 10 = 12/10 = 1.20
  → 평균보다 1.2 표준편차 높음

결론: STAI 62점이 BDI-II 32점보다 상대적으로 더 높은 점수
     (각 분포 안에서의 위치 비교가 가능해짐)
```

#### 임상심리에서 T점수 (T-score)

심리검사(MMPI, K-WAIS 등)에서 z점수를 T점수로 변환한다:

```
T = 10z + 50  (평균 50, 표준편차 10)

이유: z점수는 음수와 소수가 있어 직관적 해석이 어려움.
     T점수는 50이 평균, 40~60이 "정상 범위"로 해석하기 쉬움.

예시: z = 2.0 → T = 10×2.0 + 50 = 70점
     T ≥ 65점을 임상적으로 유의한 상승으로 해석하는 경우 많음
```

> **핵심 납득 포인트**: z점수와 T점수는 같은 정보를 다른 단위로 표현한 것이다. "z = 1.5"와 "T = 65"는 동일한 상대적 위치를 의미한다. 어떤 분포든 표준화하면 N(0,1)으로 변환되므로, z-표 하나로 모든 정규분포의 확률을 계산할 수 있다.

### 3.3 정규분포의 계산

#### z-표 읽는 법

z-표는 **P(Z ≤ z)** — z 이하의 누적 확률을 제공한다.

```
[z-표 일부 발췌]

  z  │  .00   .01   .02   .03   .04   .05   .06   .07   .08   .09
─────┼────────────────────────────────────────────────────────────
 0.0 │ .5000  .5040  .5080  .5120  .5160  .5199  .5239  .5279  .5319  .5359
 0.6 │ .7257  .7291  .7324  .7357  .7389  .7422  .7454  .7486  .7517  .7549
 1.0 │ .8413  .8438  .8461  .8485  .8508  .8531  .8554  .8577  .8599  .8621
 1.2 │ .8849  .8869  .8888  .8907  .8925  .8944  .8962  .8980  .8997  .9015
 1.6 │ .9452  .9463  .9474  .9484  .9495  .9505  .9515  .9525  .9535  .9545
 1.9 │ .9713  .9719  .9726  .9732  .9738  .9744  .9750  .9756  .9761  .9767
 2.0 │ .9772  .9778  .9783  .9788  .9793  .9798  .9803  .9808  .9812  .9817

읽는 법: z = 1.24라면 → 행: 1.2, 열: .04 → P(Z ≤ 1.24) = .8925
```

#### 세 가지 계산 유형

**유형 1: P(X < a)**

```
공식: z = (a − μ) / σ  → z-표에서 P(Z < z) 조회

예시: X ~ N(24, 8²), P(X < 32) = ?
  z = (32 − 24) / 8 = 1.00
  P(Z < 1.00) = .8413

해석: 이 임상 집단의 약 84%가 BDI-II < 32점
```

**유형 2: P(X > a)**

```
공식: P(X > a) = 1 − P(X < a)

예시: P(BDI-II > 32) = ?
  P(X > 32) = 1 − .8413 = .1587

해석: 약 16%가 BDI-II > 32점 (중등도 심각 이상)
```

**유형 3: P(a < X < b)**

```
공식: P(a < X < b) = P(X < b) − P(X < a)

예시: P(16 < BDI-II < 32) = ?
  z₁ = (16 − 24) / 8 = −1.00 → P(Z < −1.00) = 1 − .8413 = .1587
  z₂ = (32 − 24) / 8 =  1.00 → P(Z < 1.00)  = .8413

  P(16 < X < 32) = .8413 − .1587 = .6826

해석: 약 68%가 μ±σ 범위 내 (68-95-99.7 법칙 확인!)
```

#### 역방향 계산 — "상위 k%의 절단점은?"

```
문제: X ~ N(24, 8²)에서 상위 5%의 절단점(BDI-II 점수) = ?

1단계: P(X < x) = .95 → z 찾기
       z-표에서 .9500에 해당하는 z ≈ 1.645

2단계: x 계산
       x = μ + z × σ = 24 + 1.645 × 8 = 24 + 13.2 = 37.2

해석: BDI-II 37점 이상이 상위 5% → 심각한 수준의 임상적 절단점
```

**중요한 임계 z값 암기**:

```
신뢰구간/가설검정에서 자주 쓰이는 z값:
  P(Z < 1.645) = .9500  → 상위 5% (단측)
  P(Z < 1.960) = .9750  → 상위 2.5% (양측 95%에 해당)
  P(Z < 2.326) = .9900  → 상위 1% (단측)
  P(Z < 2.576) = .9950  → 상위 0.5% (양측 99%에 해당)

  → Ch.9에서 "95% 신뢰구간에서 z = 1.96을 쓰는 이유"가 여기 있다
```

> **핵심 납득 포인트**: 정규분포 계산은 결국 **모두 표준화 → z-표 조회 → 역변환**의 세 단계다. 어떤 정규분포(어떤 μ, σ이든)도 z-표 하나로 해결된다. 이것이 표준화가 강력한 이유다.

## 4. 수식 정리

```
=== 기호 약속 ===
X        = 정규분포를 따르는 확률변수
μ        = 모평균 (정규분포의 위치 모수)
σ        = 모표준편차 (정규분포의 퍼짐 모수)
σ²       = 모분산
Z        = 표준정규분포 확률변수 Z ~ N(0, 1)
z        = 표준화된 값 (소문자)
Φ(z)     = P(Z ≤ z) — z-표에서 읽는 누적확률

=== 수식 목록 ===

① 정규분포 표기
   X ~ N(μ, σ²)

② 표준화 (z-점수 변환)
   z = (X − μ) / σ
   직관: "평균에서 σ 단위로 얼마나 떨어졌는가"

③ 역변환 (z → X)
   X = μ + z × σ
   사용: 백분위 절단점 계산 시

④ 68-95-99.7 법칙
   P(μ − σ  ≤ X ≤ μ + σ)  ≈ .683
   P(μ − 2σ ≤ X ≤ μ + 2σ) ≈ .954
   P(μ − 3σ ≤ X ≤ μ + 3σ) ≈ .997

⑤ 세 가지 확률 계산 유형
   P(X < a)     = Φ((a−μ)/σ)
   P(X > a)     = 1 − Φ((a−μ)/σ)
   P(a < X < b) = Φ((b−μ)/σ) − Φ((a−μ)/σ)

⑥ T점수 변환
   T = 10z + 50  (평균 50, 표준편차 10)

=== 중요 임계값 ===
  z = ±1.645  → 양쪽 합산 90% / 단측 95%
  z = ±1.960  → 양쪽 합산 95% / 단측 97.5%  ← 가장 중요!
  z = ±2.576  → 양쪽 합산 99% / 단측 99.5%

=== 손계산 예시 (X ~ N(24, 8²)) ===
P(X < 32):  z = (32−24)/8 = 1.00  → Φ(1.00) = .8413
P(X > 32):  1 − .8413 = .1587
P(16 < X < 32): Φ(1.00) − Φ(−1.00) = .8413 − .1587 = .6826
상위 5% 절단점: x = 24 + 1.645×8 = 37.2
```

## 5. 심리학 연구 맥락 연결

### 시나리오 A: 임상 절단점의 확률적 의미

BDI-II의 임상 절단점(cutoff score)을 정규분포 맥락에서 해석한다.

**지역사회 성인 표본에서**: X ~ N(μ=8, σ=6) (BDI-II, 지역사회 규준)

```
BDI-II 절단점 14점(경미 우울 이상)의 의미:
  z = (14 − 8) / 6 = 1.00
  P(BDI-II ≥ 14) = 1 − .8413 = .1587

해석: 지역사회 성인의 약 16%가 BDI-II 14점 이상
     → 절단점을 14로 설정하면 선별 검사에서 상위 16%가 "양성"

BDI-II 절단점 21점(중등도 이상) 의미:
  z = (21 − 8) / 6 = 13/6 ≈ 2.17
  P(BDI-II ≥ 21) = 1 − Φ(2.17) ≈ 1 − .985 = .015

해석: 약 1.5%만이 중등도 이상 → 임상 집단에서의 기준으로는 적절하지만
     일반 집단에서 이 절단점을 쓰면 민감도가 매우 낮아짐
```

> **시나리오 A 연결**: Ch.3 §5에서 "유병률이 낮을 때 PPV가 낮다"는 베이즈 정리와 직접 연결된다. 지역사회 집단(μ=8)에서 BDI-II 절단점을 적용하면 유병률 자체가 낮아 PPV가 낮아진다.

---

### 시나리오 B: MMPI-2 T점수 해석

MMPI-2(Minnesota Multiphasic Personality Inventory-2)에서 임상 척도는 T점수(μ=50, σ=10)로 보고된다.

```
[T점수의 정규분포적 해석]

T = 65점:  z = (65−50)/10 = 1.5
           P(T ≥ 65) = 1 − Φ(1.5) = 1 − .9332 = .0668 ≈ 7%
           → 상위 7%에 해당하는 점수
           → "임상적으로 의미 있는 상승" 기준 (많은 교재에서 T≥65 사용)

T = 70점:  z = (70−50)/10 = 2.0
           P(T ≥ 70) = 1 − .9772 = .0228 ≈ 2%
           → 상위 2%에 해당
           → "심각한 상승" 기준

T = 80점:  z = (80−50)/10 = 3.0
           P(T ≥ 80) = 1 − .9987 = .0013
           → 상위 0.13% — 극단적 상승
```

> **중요한 시사점**: MMPI-2에서 "T = 65"를 임상 절단점으로 쓰는 것은 "정규분포 기준 상위 약 7%"를 임상적으로 의미 있는 수준으로 설정한 것이다. 이 결정에는 통계적 근거(분포)와 임상적 판단이 함께 작용한다.

## 6. 논문 스니펫 읽기 실습

다음은 가상의 논문 Methods/Results 절 일부다. 읽고 질문에 답하라.

---

*"Depressive symptom severity was assessed using the Beck Depression Inventory-II (BDI-II; Beck et al., 1996). In the present clinical sample (N = 120), BDI-II scores were approximately normally distributed with M = 24.3 and SD = 7.8 (Shapiro-Wilk W = .982, p = .23). Participants scoring above BDI-II ≥ 29 were classified as moderately severe to severe. Based on the observed distribution, the estimated probability of scoring in this range was approximately .27."*

---

**연습 질문:**

1. "normally distributed"를 확인한 근거는 무엇인가? "Shapiro-Wilk p = .23"은 어떻게 해석하는가?
2. BDI-II = 29의 z-점수를 계산하라.
3. P(BDI-II ≥ 29) ≈ .27을 z-표를 이용해 검증하라.
4. 이 집단에서 BDI-II 하위 10%의 절단점(x값)은 얼마인가?
5. P(14 ≤ BDI-II ≤ 34) = ? — 임상적으로 어떤 범위에 해당하는 사람들인가?

---

**모범 답안:**

**1. 정규성 확인**
```
Shapiro-Wilk 검정: "데이터가 정규분포를 따르는가?"를 검정
  귀무가설 H₀: 데이터는 정규분포를 따른다
  p = .23 > .05 → H₀ 기각 실패 → 정규성 가정 위반 없음

해석: "p = .23은 귀무가설(정규분포)에 불리한 증거가 충분하지 않다는 뜻."
     → 정규분포 가정 유지. (p < .05이면 정규성 위반 의심)
     → 자세한 내용은 Ch.8(가설검정) 후 이해 완성
```

**2. z-점수 계산**
```
z = (X − μ) / σ = (29 − 24.3) / 7.8 = 4.7 / 7.8 ≈ 0.60

해석: BDI-II 29점은 이 표본 평균보다 0.60 표준편차 높음
```

**3. P(BDI-II ≥ 29) 검증**
```
P(X ≥ 29) = P(Z ≥ 0.60)
           = 1 − P(Z < 0.60)
           = 1 − .7257
           = .2743 ≈ .27  ✓ (논문 보고값과 일치)

해석: 이 임상 집단의 약 27%가 BDI-II 29점 이상(중등도 심각~심각 범위)
```

**4. 하위 10% 절단점**
```
P(X < x) = .10 → z-표에서 누적확률 .10에 해당하는 z 찾기

z-표에서: Φ(−1.28) ≈ .100
          → z ≈ −1.28

x = μ + z × σ = 24.3 + (−1.28) × 7.8
  = 24.3 − 9.984
  ≈ 14.3

해석: BDI-II ≈ 14점 이하가 하위 10%
     → 이 임상 집단에서 BDI-II 14점은 경미 수준에 해당
        (일반 지역사회 기준이 아닌 이 임상 집단 내 상대적 위치)
```

**5. P(14 ≤ BDI-II ≤ 34)**
```
z₁ = (14 − 24.3) / 7.8 = −10.3 / 7.8 ≈ −1.32
z₂ = (34 − 24.3) / 7.8 =  9.7  / 7.8 ≈  1.24

P(Z < −1.32) ≈ .0934
P(Z < 1.24)  ≈ .8925

P(14 ≤ X ≤ 34) = .8925 − .0934 = .7991 ≈ .80

임상적 의미: BDI-II 14~34점은 "경미~중등도 심각" 범위.
            이 집단의 약 80%가 이 범위 안에 있음.
            68-95-99.7 법칙의 "μ±1.3σ ≈ 80%" 직관과 일치
```

## 7. 오개념 경고

> **⚠️ 오개념 1**: "모든 데이터는 정규분포를 따른다고 가정해도 된다"
> → **반드시 확인해야 한다.** 반응시간(양의 왜도), 소득 데이터(극단적 왜도), 임상 선별 집단의 점수(천장 효과·바닥 효과)는 정규분포를 따르지 않는 경우가 흔하다.
>
> 정규성 확인 방법:
> - 히스토그램·Q-Q plot 시각 확인
> - Shapiro-Wilk 검정 (n < 50), Kolmogorov-Smirnov (n ≥ 50)
> - 왜도(skewness)와 첨도(kurtosis) 수치 확인
>
> 논문에서 정규성 확인 없이 t검정을 사용했다면 비판적으로 읽어야 한다.

> **⚠️ 오개념 2**: "정규분포에서 P(X = 15)가 0이므로, BDI-II = 15점인 사람이 없다는 뜻이다"
> → **아니다.** 연속확률변수에서 특정 점의 이론적 확률이 0이라는 것이지, 관측이 불가능하다는 뜻이 아니다. 확률밀도함수(PDF)에서는 구간의 면적만이 확률이다. 실제 표본에서 BDI-II = 15인 사람은 당연히 있을 수 있다.

> **⚠️ 오개념 3**: "표준정규분포만 정규분포다"
> → **아니다.** Z ~ N(0, 1)은 무한히 많은 정규분포들 중 특별히 μ=0, σ=1인 하나일 뿐이다. X ~ N(24, 8²)도 완전히 정당한 정규분포다. 표준화(z 변환)는 편의를 위한 도구이지 "더 올바른 형태"가 아니다.

> **⚠️ 오개념 4**: "z = 2이면 정확히 상위 2%다"
> → **틀렸다.** P(Z ≥ 2.00) = 1 − .9772 = .0228 ≈ 2.28%이지, 정확히 2%가 아니다.
>
> "상위 2.5%"에 해당하는 z값은 1.96이고, "상위 2%"는 z ≈ 2.05다. "z = 2이면 상위 약 2.3%"로 기억하되, 정확한 값은 z-표를 확인해야 한다.

> **⚠️ 오개념 5**: "표본이 크면 데이터 자체가 정규분포를 따른다"
> → **중심극한정리(CLT)와 혼동한 것이다.** CLT는 "표본의 평균들이 정규분포에 가까워진다"는 것이지, "개별 데이터 포인트들이 정규분포를 따른다"는 것이 아니다.
>
> 반응시간 1000개를 수집해도 데이터 자체는 여전히 양의 왜도를 가진다. 하지만 그 1000개에서 구한 평균 x̄은 정규분포에 가깝다 — 이것이 Ch.7에서 배울 내용이다.

## 8. 자기점검

### 개념 질문 (페인만 기법: 아무것도 보지 않고 말로 설명해보기)

1. **68-95-99.7 법칙의 활용**: "BDI-II가 N(24, 8²)를 따른다고 할 때, μ±2σ 범위를 계산하고 '이 범위의 임상적 의미'를 설명하라. 이 범위 밖에 있다는 것이 무엇을 뜻하는가?"

2. **표준화의 목적**: "연구 A(BDI-II)와 연구 B(STAI)의 점수를 비교하고 싶다. 두 척도의 단위와 범위가 다른데 어떻게 비교할 수 있는가? z-점수가 이 문제를 어떻게 해결하는가?"

3. **정규성 가정의 중요성**: "Shapiro-Wilk p = .02가 나왔다. 이것이 무슨 의미인가? 이 데이터에 t검정을 사용해도 되는가? 대안은?"

### 논문 용어 확인

- *"BDI-II scores were normally distributed (skewness = 0.23, kurtosis = −0.14; Shapiro-Wilk W = .991, p = .67)."*
  → 왜도·첨도가 0에 가깝고 Shapiro-Wilk p > .05 → 정규성 가정 충족.

- *"A z-score transformation was applied to standardize all predictor variables prior to regression analysis."*
  → z = (X−μ)/σ 변환 적용. 각 예측변수를 N(0,1)로 표준화. 회귀계수가 "표준화 회귀계수(β)"로 해석 가능해짐.

- *"Participants scoring more than 2 SDs above the sample mean were excluded as outliers."*
  → |z| > 2, 즉 상위/하위 약 2.3% 이상 극단값 제거.

## 부록: 보완 주제 — 정규성 검정과 정규성 위반 시 대안

> **이 주제가 중요한 이유**: t검정, ANOVA, 회귀분석은 모두 정규성(또는 잔차의 정규성)을 가정한다. 논문의 Results나 Methods에서 정규성 검정 결과가 자주 보고되며, 정규성 위반 시 어떤 대안을 쓸 것인지가 방법론적으로 중요하다.

---

### 정규성 확인 방법들

**방법 1: Q-Q plot (시각적 방법)**

```
[정규 Q-Q plot 해석]

완벽한 정규분포:       정규성 위반 (오른쪽 왜도):
  │       ╱           │
  │     ╱             │       ╱
  │   ╱               │     ╱
  │ ╱                 │  ╱
  │╱                  │╱
  └──────────         └──────────
  점들이 직선 위에     점들이 직선에서 벗어남
  (정규성 OK)
```

**방법 2: Shapiro-Wilk 검정** (소규모 표본, n < 50 권장)

```
H₀: 데이터가 정규분포를 따른다
Hₐ: 정규분포가 아니다

해석:
  p > .05: H₀ 기각 실패 → "정규성 위반이 검출되지 않았다"
  p < .05: H₀ 기각 → "정규성 위반" → 데이터 변환 또는 비모수 검정 고려

주의: 표본이 매우 크면(n > 200) 사소한 위반도 p < .05가 나올 수 있음.
      반대로 n이 작으면 심각한 위반도 검출 못 할 수 있음.
```

**방법 3: 왜도와 첨도 수치 확인**

```
일반적 기준 (여러 교재에서 제안):
  |왜도(skewness)| < 2.0   → 허용 가능
  |첨도(kurtosis)| < 7.0   → 허용 가능
  (단, 이 기준은 절대적이지 않음)
```

---

### 정규성 위반 시 대안

| 상황 | 권장 대안 |
|------|-----------|
| 양의 왜도가 심한 연속 자료 | 로그 변환 (log transformation) |
| 두 집단 평균 비교, 왜도 있음 | Mann-Whitney U 검정 (Ch.13 이후) |
| 단일 집단 중앙값 검정 | Wilcoxon signed-rank 검정 |
| n이 크고 왜도가 약함 | CLT에 의해 정규분포 근사 허용 (Ch.7) |

> **논문 읽기 포인트**: "Assumption of normality was met" 또는 "Due to violation of normality, non-parametric tests were used"라는 문장이 Methods에 나오면, 연구자가 정규성 가정을 적절히 확인했다는 신호다. 이 문장이 없다면 독자로서 "정규성을 왜 검토하지 않았는가?"를 질문해볼 필요가 있다.
