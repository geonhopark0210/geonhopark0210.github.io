# Chapter 5: 정보처리이론 — 부호화와 저장 (Information Processing: Encoding & Storage)

---

## 1. 교육학적 핵심 개념 정리

### 정보처리이론의 기본 모델

컴퓨터 은유: 인간의 마음을 정보를 입력·처리·저장하는 시스템으로 봄

```
[외부 자극]
    ↓
[감각 기억 (Sensory Memory)]
  - 시각: 도상 기억(Iconic memory, ~0.5초)
  - 청각: 반향 기억(Echoic memory, ~2-4초)
  - 용량: 거의 무한, 지속시간: 매우 짧음
    ↓ 주의(Attention) → 선택
[작업 기억 (Working Memory)]
  - 용량: 7±2 청크 (Miller)
  - 지속: ~20-30초 (시연 없을 경우)
  - 처리: 정보를 능동적으로 조작·처리하는 공간
    ↓ 부호화(Encoding) → 의미있게 처리
[장기 기억 (Long-term Memory)]
  - 용량: 사실상 무한
  - 지속: 영구적
```

---

### 핵심 개념 1: 감각 기억 (Sensory Memory)

- **주의(Attention)**: 감각 기억에서 작업 기억으로 정보를 선택하는 관문
- **선택적 주의**: 모든 자극이 아닌 일부만 주목 → 교실에서 교사의 과제는 학생 주의 확보
- **자동적 주의 vs. 통제적 주의**:
  - 자동적: 노력 없이 이루어짐 (갑작스러운 소리, 자신의 이름)
  - 통제적: 의도적 노력 필요 (복잡한 수학 문제)

---

### 핵심 개념 2: 작업 기억 (Working Memory) — Baddeley & Hitch

**구성요소:**
| 구성요소 | 기능 | 예시 |
|----------|------|------|
| 중앙 집행부(Central Executive) | 주의 통제, 전략 선택 | 계획 세우기, 전략 전환 |
| 음운 루프(Phonological Loop) | 언어·소리 정보 유지 | 전화번호 외우기 |
| 시공간 메모장(Visuospatial Sketchpad) | 시각·공간 정보 유지 | 지도 읽기, 퍼즐 |
| 삽화 완충기(Episodic Buffer) | 다양한 정보 통합 | 이야기 이해 |

**인지 부하 이론 (Cognitive Load Theory — Sweller):**
- 작업 기억의 용량은 제한적 → 교육 설계의 핵심 고려 사항
- **내재적 부하(Intrinsic Load)**: 내용 자체의 복잡성
- **외재적 부하(Extraneous Load)**: 불필요한 자극에서 오는 부하 (나쁜 교재 설계)
- **본질적 부하(Germane Load)**: 학습 스키마 형성에 필요한 부하 (좋은 부하)
- **교육 시사점**: 외재적 부하를 줄이고 → 본질적 부하를 높이는 교수 설계

**청킹(Chunking)**: 7±2 제한을 극복하는 방법 — 개별 항목을 의미 있는 단위로 묶기

---

### 핵심 개념 3: 부호화 (Encoding) — 장기 기억으로의 전환

부호화 = 작업 기억에서 처리된 정보를 장기 기억에 저장하는 과정

**부호화 수준 이론 (Levels of Processing — Craik & Lockhart):**
- 구조적 처리 (얕은): "이 단어는 대문자인가?" → 빠른 망각
- 음운적 처리 (중간): "이 단어는 사과와 운이 맞는가?"
- 의미적 처리 (깊은): "이 단어를 문장에 넣을 수 있는가?" → 장기 파지

**정교화 부호화 (Elaborative Encoding):**
- 새 정보를 기존 지식과 연결하여 의미 있는 방식으로 저장
- "이 개념이 내가 아는 X와 어떻게 연결되는가?"
- 예: 심장 구조 공부 → "마치 펌프처럼 작동하는 구나" (비유 사용)

**생성 효과 (Generation Effect):**
- 스스로 생성한 정보가 수동적으로 읽은 것보다 더 잘 기억됨
- 교육 시사점: 강의 청취 < 스스로 요약·설명

---

### 핵심 개념 4: 장기 기억 (Long-term Memory) 의 구조

**선언적 기억 vs. 비선언적 기억:**
```
장기 기억
├── 선언적 기억 (명시적, Explicit)
│   ├── 의미 기억(Semantic Memory): 일반적 사실·개념 ("수도는 서울")
│   └── 일화 기억(Episodic Memory): 개인적 경험 ("작년 생일")
└── 비선언적 기억 (암묵적, Implicit)
    ├── 절차 기억(Procedural Memory): 기술·습관 (자전거 타기)
    ├── 점화(Priming): 선행 자극이 처리를 돕는 효과
    └── 조건 형성: 고전적·조작적 조건형성
```

**스키마(Schema):**
- 조직화된 지식 구조 — 새 정보 이해와 저장의 틀
- 기존 스키마에 맞는 정보는 쉽게 부호화, 맞지 않으면 왜곡되거나 망각
- 교육 시사점: 선행 조직자(advance organizer) 활용 → 새 스키마 형성 준비

### 이론의 한계 및 비판
- 컴퓨터 은유의 한계: 정서, 동기, 사회적 맥락 경시
- 작업 기억 용량의 개인차 설명 부족
- 정보처리를 지나치게 선형적으로 봄

## 2. 임상/상담심리 연결 포인트

### 직접적 연결

#### 작업 기억 → 인지 부하와 상담 장면
- 심리적 위기 상태에서 작업 기억 용량 감소 (불안, 우울 등이 인지 자원 점유)
- 위기 내담자에게 복잡한 인지 작업 요청은 과부하 유발 → 단계적·간결한 개입 필요
- PTSD에서 플래시백: 외상 기억이 작업 기억을 침범 → 현재 기능 방해

#### 부호화 수준 → 인지 치료의 깊이
- **표면적 개입**: 증상(행동, 자동적 사고)만 다룸 → 단기 효과
- **깊은 부호화적 개입**: 핵심신념(스키마) 수준에서 의미를 재처리 → 장기적 변화
- **EMDR**: 외상 기억의 재처리(re-encoding) — 외상 기억을 안전한 상태에서 다시 처리하여 의미기억과 통합

#### 선언적/비선언적 기억 → 다양한 치료 접근
| 기억 유형 | 임상 관련 | 치료 접근 |
|----------|----------|----------|
| 의미 기억 | 역기능적 신념, 스키마 | 인지치료 |
| 일화 기억 | 외상 기억, 자전적 기억 | EMDR, 노출치료, 내러티브 치료 |
| 절차 기억 | 자동화된 반응, 습관 | 행동치료, 습관 역전 훈련 |
| 암묵적 기억 | 무의식적 반응, 전이 | 정신역동적 접근 |

#### 스키마 이론 → 인지치료와 스키마 치료
- Beck의 핵심신념 = 인지심리학의 스키마
- Young의 초기 부적응 스키마(Early Maladaptive Schema): 어린 시절 형성된 역기능적 스키마 → 성인기 심리 문제
- 스키마 치료(Schema Therapy): 핵심 스키마 변화를 목표로 인지·행동·정서·관계적 개입 통합

#### 생성 효과 → 상담에서 내담자 참여
- 치료자가 답을 주기보다 내담자가 스스로 통찰에 이르도록 → 더 강력한 변화
- 소크라테스식 질문: 내담자가 스스로 대안을 생성 → 생성 효과로 더 잘 기억하고 내면화

### 간접적 연결
- **주의 편향(Attention Bias)**: 불안장애에서 위협 자극에 선택적 주의 → 주의 재훈련(Attention Bias Modification)
- **인지 부하와 치료**: 너무 복잡한 숙제는 내담자 부담 → 인지 부하를 고려한 과제 설계

### "자립-종결" 관점에서 해석
- 상담 초기: 새로운 인지 도식을 외부(치료자)의 도움으로 부호화
- 중기: 치료 안에서 반복 처리 → 장기 기억에 통합
- 종결: 새로운 스키마가 자동화(암묵적 기억화) → 치료자 없이 자동으로 작동
- **진정한 변화 = 새로운 건강한 스키마의 자동화** (더 이상 의식적 노력 불필요)

**Q1. "PTSD 내담자를 정보처리 관점에서 어떻게 이해하나요?"**
> "외상 기억은 극도의 각성 상태에서 부호화되어, 일반 자전적 기억과 달리 맥락·시간·의미 정보 없이 파편화된 감각 기억으로 저장됩니다. 이 기억이 촉발 자극을 만나면 작업 기억을 침범하여(플래시백) 현재 기능을 방해합니다. EMDR이나 노출치료는 이 외상 기억을 안전한 상태에서 다시 처리하여 의미 기억에 통합시키는 재부호화 과정으로 이해할 수 있습니다."

**Q2. "인지 부하 이론이 상담 장면에 어떤 시사점을 주나요?"**
> "심리적 고통 상태에서 내담자의 작업 기억 용량은 줄어듭니다. 특히 위기 상황이나 심한 우울/불안 상태에서는 복잡한 인지적 작업이 어렵습니다. 저는 초기에는 내담자의 인지 부하를 고려하여 간결하고 구조화된 개입을 사용하고, 상태가 안정되면 점차 복잡한 인지 재구조화 작업으로 나아가겠습니다."

## 4. 확인 퀴즈

### 교육학 개념 확인

**Q1.** 인지 부하 이론의 세 가지 부하 유형을 설명하고, 교사가 외재적 부하를 줄이기 위해 교재 설계 시 적용할 수 있는 원칙을 두 가지 제시하라.

<details>
<summary>정답 보기</summary>

**세 가지 부하:**
- 내재적 부하: 내용 자체의 복잡성 (화학 반응식 > 덧셈) — 조절 어려움
- 외재적 부하: 잘못된 설계에서 오는 불필요한 인지 자원 소비 — 줄여야 함
- 본질적 부하: 스키마 형성에 필요한 처리 부하 — 높여야 함

**외재적 부하 감소 원칙:**
1. **분리 효과 제거**: 그림과 텍스트를 멀리 떨어뜨리면 시선 이동 부하 발생 → 통합 배치
2. **이중 채널 활용**: 시각(그림) + 청각(설명)을 동시에 제공 → 각 채널의 부하 분산
3. **불필요한 정보 제거**: 흥미롭지만 학습 목표와 무관한 정보 삭제
</details>

**Q2.** 부호화 수준 이론(Levels of Processing)에 따르면 왜 단순 반복 읽기(시연)보다 정교화 부호화가 효과적인가? 학생이 역사 공부를 할 때 정교화 부호화를 적용하는 구체적 방법을 제시하라.

<details>
<summary>정답 보기</summary>

**이유**: 단순 반복(음운적 처리)은 얕은 수준의 처리 → 표면 특성만 부호화 → 빠른 망각. 정교화(의미적 처리)는 기존 지식과 연결되어 더 많은 신경 연결망 형성 → 더 많은 인출 단서 → 장기 파지.

**역사 공부 정교화 방법:**
- "왜 그 사건이 일어났을까?" 원인·결과 연결
- "만약 내가 그 시대에 살았다면?" 개인화
- 다른 역사 사건과 비교·대조
- 현재 사회 문제와 연결 ("이와 유사한 일이 지금도 일어나는가?")
</details>

### 임상/상담 연결 확인

**Q3.** Young의 초기 부적응 스키마(Early Maladaptive Schema) 개념이 인지심리학의 스키마(Schema) 이론과 어떻게 연결되는지 설명하고, 이를 치료하는 과정을 "자립-종결" 관점(부호화 → 자동화 → 독립)으로 논하라.

<details>
<summary>정답 보기</summary>

**스키마 이론과의 연결:**
인지심리학에서 스키마는 경험을 통해 형성된 조직화된 지식 구조. Young의 초기 부적응 스키마는 어린 시절 부정적 경험이 반복적으로 부호화되어 형성된 역기능적 자기·세계·관계에 대한 핵심 믿음 구조. "나는 무가치하다", "타인은 믿을 수 없다" 같은 스키마는 새로운 경험을 왜곡하여 해석하게 만듦(스키마 확인 편향).

**치료 과정 — 자립-종결 관점:**

1. **부호화 단계**: 치료자가 안전한 관계 속에서 새로운 관계 경험 제공 → "나는 가치 있다"는 새 스키마 형성 시작 (치료자의 적극적 개입 = 비계)

2. **처리·통합 단계**: 인지적 재구성 + 행동 실험 + 정서 처리를 통해 새 스키마 반복 활성화 → 장기 기억에 통합 (중기)

3. **자동화 단계**: 새 스키마가 점점 자동적으로 활성화 → 역기능적 스키마의 영향력 감소 (비계 fading)

4. **종결(자립)**: 새로운 건강한 스키마가 암묵적 기억처럼 자동화 → 치료자 없이도 새 스키마가 자동으로 작동 = 자립
</details>
