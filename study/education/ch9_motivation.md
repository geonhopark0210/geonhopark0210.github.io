# Chapter 9: 동기이론 (Motivation)

---

## 1. 교육학적 핵심 개념 정리

### 동기의 정의와 기본 구분
- **동기(Motivation)**: 행동을 시작하고, 방향을 결정하며, 지속시키는 내적 상태
- **내재적 동기(Intrinsic Motivation)**: 활동 자체의 흥미, 즐거움, 도전감에서 비롯됨
- **외재적 동기(Extrinsic Motivation)**: 보상, 칭찬, 성적 등 외부 요인에서 비롯됨

---

### 주요 동기이론

#### 1) 자기결정이론 (Self-Determination Theory, SDT) — Deci & Ryan
교육학에서 가장 영향력 있는 동기이론 중 하나.

**세 가지 기본 심리적 욕구:**
| 욕구 | 내용 | 교육 장면 |
|------|------|----------|
| 자율성(Autonomy) | 스스로 선택하고 행동하는 느낌 | 학습 선택권 제공 |
| 유능감(Competence) | 효과적으로 수행한다는 느낌 | 적절한 도전 수준 |
| 관계성(Relatedness) | 타인과 연결된다는 느낌 | 교사-학생 신뢰 관계 |

**동기의 연속선(Motivation Continuum):**
```
무동기 → 외적 조절 → 부과된 조절 → 확인된 조절 → 통합된 조절 → 내재적 동기
                    ←  외재적 동기 (점점 자율적) →
```
- 핵심: 외재적 동기도 내면화(internalization)를 통해 자율적이 될 수 있음
- 교육 목표: 외부 통제 → 내적 자기조절로의 이행 촉진

#### 2) 성취목표이론 (Achievement Goal Theory)
- **숙달목표(Mastery Goal)**: 이해, 향상 자체에 초점 → 깊은 학습, 지속적 노력
- **수행목표(Performance Goal)**: 타인보다 잘 하거나 못 하는 것을 피하는 데 초점
  - 수행-접근목표: 타인보다 잘 보이려 함
  - 수행-회피목표: 무능해 보이는 것을 피하려 함
- **교육 시사점**: 숙달목표 지향 교실 분위기(mastery climate) 조성

#### 3) 기대-가치이론 (Expectancy-Value Theory) — Eccles
- **동기 = 성공 기대 × 과제 가치**
- 과제 가치의 구성요소:
  - 흥미 가치: 과제 자체가 즐거운가
  - 유용 가치: 미래 목표에 유용한가
  - 중요 가치: 자기 정체성에 중요한가
  - 비용: 참여에 따른 포기, 노력, 불안

#### 4) 귀인이론 (Attribution Theory) — Weiner
- 성공/실패의 원인을 어떻게 귀인하느냐가 미래 동기에 영향
- **귀인 차원:**

| 차원 | 내적 | 외적 |
|------|------|------|
| 안정적 | 능력 | 과제 난이도 |
| 불안정적 | 노력 | 운 |
| 통제 가능 | 노력, 전략 | — |

- **교육 시사점**: 노력 귀인 강화 → 통제 가능한 귀인 → 자기효능감↑

#### 5) Maslow의 욕구위계이론
- 생리적 → 안전 → 소속/사랑 → 존중 → 자아실현
- 교육 적용: 하위 욕구(안전, 소속감)가 충족되어야 학습 동기 발생
- **비판**: 위계의 경직성, 문화적 보편성 문제

### 자기효능감과 동기 (Bandura)
- 특정 과제에 대한 성공 능력 믿음 → 목표 설정 수준, 지속성, 노력에 직접 영향
- 자기효능감 원천: 성취 경험 > 대리 경험 > 사회적 설득 > 생리적 상태

### 이론의 한계 및 비판
- SDT: 자율성의 문화적 차이 — 집단주의 문화에서는 관계성이 더 핵심
- 성취목표이론: 수행목표의 부정적 영향이 맥락에 따라 다름
- Maslow: 욕구 단계의 순서가 항상 고정되지 않음

## 2. 임상/상담심리 연결 포인트

### 직접적 연결

#### 자기결정이론 (SDT) = 상담의 철학적 목표와 일치
```
[SDT 관점]              [상담 관점]
자율성 지원         →   내담자 자율성 존중 (Rogers의 인본주의)
유능감 증진         →   내담자 강점 발견, 자기효능감 증진
관계성 충족         →   치료적 동맹 (therapeutic alliance)
외재 → 내재 동기    →   외부 의존 → 내적 자기조절 (상담의 종결 목표)
```

> **핵심 통찰**: SDT의 동기 연속선(외적 조절 → 내재적 동기)은 상담에서 내담자가 치료자에게 의존하다가 점차 스스로 자신을 조절하게 되는 과정과 동일한 방향성을 가진다.

#### 동기강화상담 (Motivational Interviewing, MI)
- **직접 연결**: MI는 SDT를 기반으로 Miller & Rollnick이 개발
- 핵심 원리: 내담자의 변화 동기를 외부에서 심어주는 것이 아니라, 내부에서 이끌어냄
- 자율성 강조, 저항과의 씨름 금지, 불일치 만들기 (현재 행동 vs. 가치/목표)
- 적용: 중독, 건강행동변화, 치료 동기 강화

#### 귀인이론 → 인지치료
- 우울증의 인지 삼제(cognitive triad, Beck): 자기, 세계, 미래에 대한 부정적 귀인
- 학습된 무력감(Seligman): 통제 불가능한 결과 반복 경험 → 내적·안정적·전반적 귀인 → 우울
- 상담 개입: 귀인 패턴 재구성 — "능력 부족" 귀인 → "노력/전략 부족" 귀인으로 수정

#### Maslow의 욕구위계 → 상담 목표 설정
- 위기 내담자: 하위 욕구(안전, 안정) 먼저 다룸
- 성장 지향 상담: 자아실현을 향한 여정 (인본주의 상담의 목표)
- **실제 적용**: 외상 내담자에게 인지재구성 전에 안전감 확보가 우선

### 간접적 연결
- **성취목표이론**: 내담자가 상담 목표를 숙달목표(성장)로 설정할 때 vs. 수행목표(증상 제거만)로 설정할 때 상담 과정이 달라짐
- **자기결정이론 무동기 상태**: 치료 저항/비자발적 내담자 이해에 활용

### "자립-종결" 관점에서 해석
- SDT의 최종 상태 = 완전한 내재적 동기 = 자율적 자기조절
- 상담의 종결 = 내담자가 외적 지지(상담자) 없이 자신의 심리적 건강을 스스로 유지·조절
- **두 분야 모두 목표는 "외부 조절의 내면화"이며, 이 과정이 완성될 때 관계는 종결됨**

## 3. 면접 활용 포인트

### 예상 질문 & 답변

**Q1. "비자발적 내담자(mandated client)를 어떻게 다룰 것인가?"**
> "Deci와 Ryan의 자기결정이론 관점에서, 비자발적 내담자는 외적 조절 상태에 있습니다. 저는 먼저 자율성을 최대한 보장하고(선택지 제공), 유능감을 경험할 수 있는 작은 성공을 만들며, 치료적 관계를 통한 관계성을 충족시켜 외적 동기를 점진적으로 내면화하도록 돕겠습니다. 동기강화상담의 원리도 함께 활용할 것입니다."

**Q2. "우울증 내담자의 동기 문제를 어떻게 이해하나요?"**
> "Seligman의 학습된 무력감 연구에서 보듯, 우울증의 핵심에는 '아무리 해도 안 된다'는 통제 불가능한 귀인 패턴이 있습니다. 귀인이론과 인지치료를 연결하여, 내담자가 결과를 통제 가능한 요인(노력, 전략)으로 귀인하도록 재구성하는 작업이 중요합니다."

**Q3. "상담에서 내재적 동기를 어떻게 활용할 수 있나요?"**
> "내담자 자신이 변화를 원하는 이유(내재적 동기)를 발견하고 강화하는 것이 핵심입니다. 동기강화상담에서처럼 내담자의 가치와 현재 행동 사이의 불일치를 탐색하면, 외부 압력이 아닌 내면의 변화 동기가 활성화됩니다."

## 4. 확인 퀴즈

### 교육학 개념 확인

**Q1.** 자기결정이론(SDT)에서 '동기의 연속선'을 설명하고, 교사가 학생의 외재적 동기를 내재적 동기에 가깝게 만들기 위해 할 수 있는 구체적인 교수 전략 두 가지를 제시하라.

<details>
<summary>정답 보기</summary>

**동기 연속선**: 무동기 → 외적 조절(보상/처벌) → 부과된 조절(죄책감/수치) → 확인된 조절(가치 인정) → 통합된 조절(정체성 일치) → 내재적 동기(활동 자체 즐거움)

**전략 예시:**
1. **자율성 지원**: 학습 주제나 방법에 선택권 제공 → 확인된/통합된 조절로 이행
2. **유능감 지원**: 적절한 도전 수준의 과제 + 긍정적 피드백 → 내재적 동기 활성화
3. **의미 연결**: 과제의 실생활 유용성 설명 → 확인된 조절(가치 인정) 촉진
</details>

**Q2.** Weiner의 귀인이론에서, 시험에 실패한 학생이 "나는 머리가 나빠서"라고 귀인할 때와 "이번에 공부를 덜 해서"라고 귀인할 때 미래 동기에 미치는 차이를 귀인의 세 차원(소재, 안정성, 통제가능성)을 사용하여 비교하라.

<details>
<summary>정답 보기</summary>

| 차원 | "머리가 나빠서" | "공부를 덜 해서" |
|------|---------------|----------------|
| 소재 | 내적 | 내적 |
| 안정성 | 안정적 (변하지 않음) | 불안정적 (변할 수 있음) |
| 통제가능성 | 통제 불가 | 통제 가능 |

**결과**: "머리" 귀인 → 미래도 실패할 것이라는 기대 → 동기 저하, 무력감. "노력" 귀인 → 다음엔 더 노력하면 된다 → 동기 유지, 지속적 시도.
</details>

### 임상/상담 연결 확인

**Q3.** 동기강화상담(MI)이 자기결정이론(SDT)을 어떻게 적용하는지 설명하고, 이것이 Ch.8에서 다룬 "자립-종결" 관점(비계설정 → fading)과 어떻게 연결되는지 논하라.

<details>
<summary>정답 보기</summary>

**MI와 SDT 연결:**
- MI는 세 가지 기본 욕구(자율성, 유능감, 관계성)를 상담 관계에서 충족시킴
- 자율성 존중: "당신이 어떻게 할지 결정합니다" → 내담자 주도성 강조
- 저항과 씨름 금지 → 자율성 위협 없음
- 불일치 만들기 → 내담자 내면의 변화 동기 활성화 (외재적 → 내재적 전환 촉진)

**자립-종결 연결:**
초기 상담에서 MI는 내담자 변화 동기를 탐색하고 강화하는 데 적극적 역할을 함(비계). 내담자가 자신의 변화 이유와 방법을 스스로 언어화하고 계획하게 되면 상담자 역할이 줄어들고(fading) 종결로 이어짐. SDT의 내재화 과정(외적 → 내적)이 완성되면 외부 지지가 필요 없는 상태(자립)가 됨.
</details>
